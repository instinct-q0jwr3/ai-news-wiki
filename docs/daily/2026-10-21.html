Agents meet the physical world

A benchmark for wet-lab robot recovery and a backdoor that turns trigger words into dangerous robots.

Gamow Labs, which builds frontier AI systems to interpret the human genome, presents LabRobotBench v0.1, a benchmark for evaluating whether agents can run wet-lab experiments and recover from equipment failures. Their in-silico simulation mirrors the command interfaces of their physical robots, so agents can be developed and evaluated before touching hardware. The motivation is downtime: when a robot errors mid-experiment, work stalls until a person steps in, and an agent that can diagnose and safely resume could keep experiments running overnight. Tasks include cell assay recovery, where a robot stopped halfway through four trays at different steps and the agent must infer what is done, finish washing, add the measurement chemical, run the instrument, and set aside the spoiled tray, plus dose-response recovery and cold-stock handling; repeating a treatment can ruin a sample, and a tray can look correctly shelved while the experiment is unfinished. (read more).

Binghamton University researchers demonstrate that hidden trigger words embedded in an LLM can hijack the robot it plans for: their MuTRAP backdoor activates when an innocuous word appears in the robot's instructions, sending it off-script into dangerous actions. Tested on a Segway-based mobile robot mimicking a cutting task, the work, from Adnan Siraj Rakin, Shiqi Zhang, and PhD students, was presented as two papers at the 2026 IEEE/RSJ International Conference on Intelligent Robots and Systems, alongside a defense. The team stresses the attacks are published to build defenses, arguing that LLM-generated task plans cannot be blindly trusted when they reach the physical world, from factory arms to Mars rovers. Security as reachability, and its limits

Anthropic's Chris Rohlf summarizes initial research into automated attack surface analysis and reduction with Claude: instead of hunting individual vulnerabilities, which scales poorly because each fix says nothing about what remains, use the model to map which code is reachable in a given deployment and remove or gate everything it does not need to expose. Reducing reachability lowers the severity of unknown vulnerabilities, including ones under active exploitation, without ever finding them. Running Claude over 25 open-source projects in a variety of languages produced 493 issues, and Anthropic says the data shows the approach can meaningfully and economically improve software security, with guidance for developers to apply the same techniques to their own code. AI finds the bug of the decade in PHP

Agent plumbing matures

Persistent memory that pays for itself, durable harnesses, agent filesystems, and mods that flip the harness toward the human.

Databricks introduces MemCurrent, a persistent memory architecture for production agents that now powers Agent Bricks Memory and Genie. The design problem: memory can raise quality and efficiency at once by carrying user preferences, prior corrections, and successful workflows across tasks, but dumping every past interaction is costly and imports stale or conflicting context, so the core challenge is deciding what to retain, how to maintain it, and how to measure usefulness. Agents read and write memory as they work, while an offline 'dreaming' pipeline consolidates memory to keep it consistent and fresh. On an internal benchmark of realistic enterprise tasks, MemCurrent triples the no-memory pass rate while using 31% fewer tokens and running 26% faster, landing on the Pareto frontier ahead of Mem0, PropMem, and OpenClaw memory. (read more).

PyTorch becomes portable

Google and Meta detail TorchTPU, a principled native backend with eager execution first.

Google and Meta's PyTorch team detail TorchTPU, an open-source native PyTorch backend for Google TPUs, started at Google in mid-2025. Unlike PyTorch/XLA (2020, Lazy Tensors) and TorchAX, which shoehorned PyTorch into JAX's model and suffered intrusive code changes, slow compiles, no eager mode, and lagging distributed primitives, TorchTPU was built as a principled backend: eager execution is a top priority, existing workloads run out of the box, and performance comes from eager optimizations, torch.compile integration, and native hardware acceleration on the XLA stack. The pitch is seamless TPU migration with industry-competitive inference and training performance, giving PyTorch's huge user base a second serious hardware target. (read more).

Build your own stack

Access control for multi-user agents, an opinionated Rust web stack, SPARQL in SQLite, and Doctorow on adversarial interop.

Simon Willison runs an experiment in Claude Code for web's 'Ultracode' mode, where dynamic workflows generate JavaScript coordinating networks of subagents. A single phone-typed prompt with an accidental typo, 'hit the delete rows directly' instead of 'hit the rows directly', asked for a SQLite extension in Rust implanting SPARQL, and Claude Code churned for over 12 hours producing a full SPARQL 1.1 implementation in Rust inside SQLite. A follow-up prompt added READMEs per crate, a tutorial teaching SPARQL with the extension, and a script populating realistic example data. His verdict: next-level vibe coding, the code is not remotely feasible to review, and he is unsure what a full SPARQL-in-SQLite implementation is worth if nobody can vouch for it. (read more).

Cory Doctorow's Pluralistic for 21 October argues adversarial interoperability is a team sport. Digital technology should be hard to enshittify because every computer is a Turing-complete universal machine: when a boss removes a valued feature (Sonos bricking speaker functionality) or adds a hated one (Chamberlain forcing seven ads before your garage door opens), a programmer can write an interoperable program that restores the good or blocks the bad, distribute it costlessly, and get paid for disenshittification. In a state of nature, that threat alone disciplines companies. His point in this edition: vibe-coded individual jailbreaks are fun but do not solve the structural problem; the counterpower has to be organized. (read more).

Rust off Rails pitches an opinionated web stack for the AI era whose founding rule is that all code is written by AI: every line of Rust, SQL, HTML, CSS, TypeScript, and every Dockerfile comes from an agent, while humans write intent, specs in a product/ directory, answers in interviews, feedback in conversation, never code. The fetched page returned only its opening sections, so this summary is limited to them. (read more ⚠).

Alter (YC S25) launches access control for agents acting on behalf of multiple users. The problem it names: credentials pasted into prompts, configs, and .env files, every agent borrowing the same over-scoped credential, and nobody able to say which agent did what on whose behalf. With Alter, credentials are stored once and injected per request so proxied calls keep them out of code, each agent gets its own identity and scopes with an optional human gate for sensitive calls, and every action lands in a tamper-evident audit trail attributable to a real person. One SDK call handles storage, refresh, policy, and audit across 140 providers, with first-class LangChain, MCP, and AWS integrations and SIEM streaming; its trust center publishes monitored controls and a recent independent penetration test. Something called Claude Duet.

Anthropic previews Claude Duet, a proactive agent built for judgment: it understands what needs your attention, takes on tasks of all sizes, keeps working while you're away, and waits for your ok when it matters. Powered by Opus 5.5 and available in Pro and Max plans in the US, it briefs you each morning, drafts next steps, then goes quiet until something needs you; a message can set up a meeting or build a dashboard, and your memory, skills, and apps from the Claude app carry over into one thread. The demo persona runs a cafe business: a hiring offer expiring at 6 p.m., a redlined $410K renewal summarized, a health permit filled and its $640 fee paid with the county asked for inspection dates, and a Series A prep that rebuilt the deck with Q3 numbers, flagged the two slides needing review, pulled 25 of 26 data-room docs, and drafted answers on cafe payback and subscription churn from the owner's numbers.
