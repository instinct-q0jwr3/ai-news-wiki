Agents that reason beyond text

A new architecture mixes latent-space thinking with text-based tool use, claiming better performance at a fraction of the tokens.

An arXiv paper proposing HybridAgents, an agent architecture that lets an LLM reason internally in latent (continuous) space while still acting through ordinary text. Pure text-based agents are transparent and tool-friendly but expensive; latent reasoning is efficient but opaque and cannot call tools. HybridAgents bridge the two with a lightweight 'HybridLink' module that switches between text and latent modes inside one generation process, plus a continuous working memory that keeps the hybrid context lossless across turns. Training comes in two stages: HybridSFT teaches the backbone model to coordinate with HybridLink, then HybridRL learns when to think latently and when to act in text. Across 11 benchmarks (math, science, medicine, search, agentic reasoning) at three model scales, the authors report a consistent 10.4% performance gain over frontier text-based and latent baselines, with 35-55% fewer tokens, 1.8-2.6x faster inference and 2.7-3.7x lower cost. Code and data are released. (read more).

Agents reach personal messaging

A self-hosted MCP server gives AI agents read-only access to your WhatsApp chats, with the phone staying the source of truth.

A Show HN project that lets an AI agent read your WhatsApp messages through the Model Context Protocol, running entirely inside your own Cloudflare account. You deploy a small Workers server, link your phone once the way you would link WhatsApp Web, and any MCP client (Claude Code, Claude Desktop, others) can then search and read your chats. The design is deliberately privacy-conscious: the server is a linked device that only connects intermittently (on demand and once a day), pulls whatever WhatsApp queued for it, stores it in a SQLite database inside a Cloudflare Durable Object in your account, and disconnects. Your phone stays the source of truth and keeps working normally; the agent can read and search but cannot send. Setup requires a Cloudflare Workers Paid plan, Node 20+, a KV namespace for sign-in tokens and an owner password for the linking page. (read more).

Cory Doctorow argues that the internet's original sin is not advertising but surveillance. Working from Langdon Winner's 'Do Artifacts Have Politics?', he distinguishes politics designed into artifacts (Robert Moses's bus-blocking bridges), politics that are accidental but unavoidable (the tomato harvester), and politics that are simply political choices - and puts ad-tech spying in the last category. Advertising itself, he says, is fine and even necessary: without channels for reaching unfamiliar audiences, political causes, books, music and community events would all suffer. The fusion of advertising with surveillance was a decision, not a technological inevitability - specifically the decision by US politicians to stop passing and enforcing privacy laws, leaving the Video Privacy Protection Act of VHS fame as the last consumer privacy statute. The downstream costs he catalogs include surveillance pricing, surveillance wages, dossiers feeding ICE deportation operations, and oligarchic power that finds targeted repression cheaper than broad prosperity. His conclusion: an internet compatible with privacy is possible because the surveillance was chosen and can be unchosen. (read more).

Trusting the code agents write

A Meta engineer's black-box discomfort, a practitioner's pyramid for trusting agents, and a fine-tune that scrubs AI writing tics.

A practitioner's framework, posted by Lauren (@poteto) on X and formatted to be handed directly to your own agent, for trusting coding agents more. It is an inverse pyramid of leverage. At the top, codebase improvements: better architecture, stronger types and invariants, and clear boundaries, because agents copy what exists and take the shortest path - so make the easy thing the right thing and categorically eliminate problem classes. Next, static analysis: lint rules, tests, CI and formal verification like TLA+, which catch issues early and are very token-efficient. Then prose - comments, rules files, AGENTS.md, skills - for whatever can't be enforced and needs judgment; use it minimally. At the bottom, human review: the hardest to scale, since nobody can thoroughly review every PR at the rate agents land code, so spend that scarce effort designing an environment where agents do the right thing by default. The harness is the body

A free book builds agents from first principles around the loop that owns the context.

Harness Engineering 101 is a free 16-chapter online book that builds AI agents from first principles, growing a roughly 300-line toy agent in plain Python. Its organizing claim: an LLM API is stateless - every turn you resend the whole conversation as a JSON array and get text back - so the 'harness', the program that builds, maintains and protects that array, is where agency actually lives. Everything the field calls agents is a set of patches to that one loop, and each patch exists because something concrete broke. Every chapter follows the same shape: the failure, the minimal patch, what the patch costs. The patterns are developed in full in One Code, an open-source coding agent, and the book is meant to be read in order or as standalone chapters when needed. (read more).

Silicon for the agent era

Nvidia's Vera team says agents reverse CPU design priorities, Qualcomm hears labs want 100B models on phones by 2028, and Tenstorrent banks $1.5B.

A Wccftech Q&A with Nvidia's Vera CPU team argues that agentic AI is reversing a decade of CPU design priorities. The chiplet era - filling packages with as many cores as possible - sacrificed single-threaded performance and IPC, because chiplets leave no space to design for per-core performance and force cores to cross IO boundaries. Agent workloads invert the requirements: an agent runs sequential control logic on the CPU between reasoning steps, and the goal is to finish that sequential work fast and get back to the GPU, keeping the expensive accelerators highly utilized. Nvidia's answer in Vera is a single monolithic compute die where all cores talk to each other without crossing IO boundaries or incurring that latency - a deliberate move back to per-core performance over core counts. (read more).
