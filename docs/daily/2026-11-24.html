Runtime shields and static scanners protect different boundaries

A temporary Linux mitigation and a configuration scanner describe scoped defenses, not universal protection.

OpenAI and Cisco introduce Shirudo, an open-source runtime using eBPF to apply temporary protections to running Linux systems while permanent patches are prepared. Their controlled Java4Shell example describes a Codex-generated input check attached to Elasticsearch without a restart. The announcement describes operator approval, signed shields and TPM-backed evidence of loading or removal. The demonstration is a vendor-controlled example, not proof that shields work for arbitrary vulnerabilities without disrupting real workloads. The eBPF verifier checks its own program-safety rules, not complete application correctness. Temporary mitigation does not remove the need to patch, test workloads and validate deployment. No software, kernel program, keys or system settings were installed or changed here. (read more).

He says suggestions use sampling while displayed charts aggregate across the full result set through SQL, avoiding the previous limitation of charting only the visible page.
