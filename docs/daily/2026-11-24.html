A temporary Linux mitigation and a configuration scanner describe scoped defenses, not universal protection.

OpenAI and Cisco introduce Shirudo, an open-source runtime using eBPF to apply temporary protections to running Linux systems while permanent patches are prepared. Their controlled Java4Shell example describes a Codex-generated input check attached to Elasticsearch without a restart.
