How agents get built now

Concepts: AI coding agents and the software pipeline · Agentic systems

An open-source IDE for thoughtful design, Claude measuring then optimizing, a million agents as a distributed-systems problem, and cloud agents as 'inevitable AI prisons'.

Anthropic's engineering team describes handing website and desktop performance work to an @Claude channel briefed to monitor deploys for regressions, assess telemetry, maintain observability dashboards, implement fixes for low-hanging fruit and propose performance projects - with an explicit goal of becoming as autonomous as possible. The team says it ended up funding nearly every project on Claude's original list, and pushed it to prove that hill-climbing against each candidate produced measurable wall-clock wins before keeping the benchmarks. (read more).

Whiteboard (YC W26) is an open-source desktop IDE where humans and agents architect software together in a common workspace. It plugs into the tools developers already use, such as Claude Code and Codex, and gives the agent an SDK to draw on an in-app canvas to describe its work - for example proposing API examples and motivations for a stack of commits, or explaining the telemetry changes in a PostHog PR and how to build dashboards from them. (read more).

A Norman Ponte essay argues that cloud agents are 'inevitable AI prisons' - that agents running inside a provider's cloud are structurally confined by the platform's incentives and controls. The cached page is thin (only the title and byline were retrievable), so the argument's mechanism and proposed alternatives are unavailable; this summary is based on the headline and cached stub. (read more ⚠).

An Instacloud blog post argues that a million agents is a distributed system problem: one agent is a worker, a thousand agents is an organization, and an organization of machines is a distributed system. It cites recent research warnings: unrestricted access to LLM or tool resources can lead to inefficient or harmful allocation; the 'more agents' approach hits a ceiling and can degrade performance; and agents spontaneously form coordination topologies yet systematically fail to synthesize distributed state into correct answers.
