Sonnet 5.5 lands

Concepts: Frontier Model Launches

Anthropic's faster, cheaper tier arrived and immediately became the day's reference point - with prompt notes for Opus 5.5 close behind.

Anthropic introduces Claude Sonnet 5.5, the second model in the 5.5 family: a clear upgrade over Sonnet 5, more than 30% faster, and up to 30% cheaper per task in Anthropic's testing despite unchanged list prices. Positioned as the fast, lower-cost complement to Opus 5.5, it targets well-scoped everyday work like bug fixing and polished documents, slides, and spreadsheets. Notably it scores 70.6% on Terminal-Bench 4.0 versus Sonnet 5's 10.3%, sits two points below Opus 5.5 on GDPval-AA, and is the first Sonnet to beat Pokémon Red from screenshots alone. Because its cyber capabilities match Opus 5's, it is the first Sonnet shipping with cyber safeguards. Epic's early testing praised its performance on system design audits and multi-hour tasks. Haiku 5.5 follows in coming weeks. (read more).

Anthropic's prompting guide for Claude Opus 5.5 opens with migration economics: the model generates output over 30% faster than Opus 5 and finishes the same task with fewer tokens, and existing Opus 5 prompts should work unchanged. The central control is effort - thinking is always on in 5.5 - and the defaults shifted: Opus 5.5 defaults to medium where Opus 5 defaulted to high. In Anthropic's testing, 5.5 at medium matches or exceeds Opus 5 at high on coding and knowledge-work evals, and low comes close on several coding evals at much lower cost. But effort names aren't portable: at the same level, 5.5 thinks more per turn than Opus 5, especially at xhigh and max, so carried-over settings mean longer turns. (read more).

The craft of working with models

Concepts: AI coding agents and the software pipeline · Agentic systems

Architecture knowledge over code volume, 'do not guess' cutting made-up claims from 71% to 20%, metacognition, a BEAM port of DSPy, and George Hotz on AI coding.

Simon Späti argues the real danger of AI-generated codebases is not code quality but organizational amnesia: teams that no longer understand their own system architecture or the intent behind past decisions. He anchors the essay in a striking anonymous account from an engineer at a large company where specs, tests, PRDs, tickets, and reports are all produced by Claude Code, engineers work 12-13 hour days 'just to press enter', and management treats code output as a solved bottleneck while wondering why delivery is still slow. Späti's counterpoint is that AI can lift a below-average codebase to average, but only people who understand the system can tell whether what ships is right. (read more).

This 2021 paper argues that state-of-the-art AI, for all its progress, remains narrow - and that Kahneman's 'thinking fast and slow' distinction is a useful blueprint for what to build next. The authors propose a multi-agent architecture in which incoming problems route to either System 1 ('fast') agents that react from past experience, or System 2 ('slow') agents that are deliberately activated when a problem needs reasoning and search beyond the fast agent's reach. (read more).

Imp brings DSPy's model of declarative, self-improving language-model programs to Elixir and the BEAM. You declare what each LLM step takes and returns as a typed signature ('issue -> kind: enum[bug,feature,question], summary'), choose how it thinks (predict, chain_of_thought, react with tools), and never write a prompt or parser - Imp builds the prompt from the signature, validates the reply, and hands back typed fields or an error. On the BEAM, an agent is a supervised process: Imp.start_run/3 runs a program under OTP with an authorize callback that can approve or deny each tool call (the example allows only raw.githubusercontent.com URLs). (read more).

Earn an Honest Dollar is a free marketplace where agents sell services and other agents buy them - and this piece is its first benchmark, aimed at a buyer's core problem: before paying, an agent needs to know whether a service admits when it doesn't know. The test measures one service type, web extraction, using trap page pairs that differ by a single row: one page shows the answer, the other doesn't, and both show the same decoy. An honest extractor answers on the first and returns null on the second. 42 pairs across 7 page types were scored on the missing-field pages. (read more).

George Hotz announces that tinygrad is hiring - and along the way gives his verdict on AI coding. The company's bounty program, once a good hiring signal, is dead: people who barely understand a bounty now paste it into Claude Code and submit the PR, so the signal is gone. AI companies promise anyone who pays can be a software developer, and for a 'slop app for your slop brand' that's true - but that isn't software development, it 'looks a lot more like a slightly more flexible WordPress.' tinygrad encourages AI as tooling, but 'there's nobody now that we would hire because AI exists who we wouldn't have hired before and vice versa.' PaperMono turns the M5Stack PaperMono - an ESP32-S3 with a 3.97-inch 480x800 e-paper touchscreen - into a household shopping list that lives on the fridge and syncs with a phone web app. The firmware is deliberately small enough to read (about 2,400 lines of C++) and works as a starting point for other PaperMono projects. The list is grouped by aisle in the order you walk the shop; you set the aisle order once from the phone. Everything - the list, suggestions, ticking, adding - works offline, including in a shop with no signal. (read more).

Cloudflare introduces cf, a new CLI built to give AI agents access to the entire Cloudflare API rather than the roughly 280 operations Wrangler exposes. The motivation is usage data: agents went from single-digit percentages of Wrangler use a year ago to 48% last week, run nearly twice as many distinct commands per day as humans, and are four times as likely to chain six or more. Wrangler was assembled product-by-product with inconsistent command patterns that were impossible to standardize, so cf is designed from scratch for agent-driven development. It is available as an open beta via npm. (read more).
