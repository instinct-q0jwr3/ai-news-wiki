The agent-mcts repository describes a Monte Carlo tree-search harness that explores coding attempts in separate Git worktrees and uses tests, optionally supplemented by a model judge, to rank branches. Claude Code is its verified integration; the supplied Codex adapter has only fake-binary tests, and other adapters remain planned. Its own harder-task evaluation is unusually cautionary. Across ten runs per setting, tests-only search produced no better final answers than the first attempt and one worse answer; judge-assisted search improved four, tied four and worsened two, with a slightly negative mean change.
