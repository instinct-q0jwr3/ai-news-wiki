Show HN: AegisKernel – Zero-trust POSIX runtime for AI agents in <0.016ms

type: news-summary · created: 2026-11-06 · updated: 2026-11-14 · confidence: high

Summary

A Show HN demo of AegisKernel, a zero-trust runtime for AI agents that claims deterministic capability boundaries block tool hijacking in under 0.016 ms. The page simulates attacks such as .env theft via path traversal, SQL drop injection and rm -rf, and offers a two-line integration for LangChain, CrewAI and AutoGen. Its argument is that probabilistic LLM guardrails fail where deterministic checks hold. Claims come from the project's own demo.

Highlights

  • Deterministic capability boundaries instead of LLM guardrails
  • Claims <0.016 ms interception (self-reported)
  • Demo of .env theft, SQL drop and rm -rf attacks
  • Two-line integration with LangChain, CrewAI, AutoGen
