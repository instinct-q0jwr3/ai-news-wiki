Mave, which is developing an AI-driven tool to automate security investigations, raised a $28M Series A led by Red Dot, bringing its total funding to $34M

type: news-summary · created: 2026-10-24 · updated: 2026-10-24 · confidence: high

Summary

Mave, a cyber startup building an AI-driven tool to automate security investigations, raised a $28 million Series A led by Red Dot, bringing its total funding to $34 million, CTech reports. The raise lands in a market where, as CTech's own coverage puts it, AI has made vulnerability detection table stakes and the competitive frontier has moved to remediation and investigation - with Anthropic's Project Glasswing cited as proof the attackers' economics have shifted.
