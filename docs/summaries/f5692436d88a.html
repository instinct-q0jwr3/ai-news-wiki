Evolving programming languages in the AI era

type: news-summary · created: 2026-09-26 · updated: 2026-09-26 · confidence: high

hacker-news

Summary

José Valim's ramblings on programming languages in the AI era start from a premise already true for many teams: agents write most of the code. Languages are held together by communities rallying around shared sensibilities - Python's one obvious way, Ruby's programmer happiness, Lisp's reshape-the-language ethos - and he asks what happens to that sense of belonging when humans stop writing most of the code, and whether communities should preserve it or find a new glue.

On ecosystems he sees two opposing forces: agents shrink the gap between ecosystems (porting implementations, translating papers and known algorithms gets cheap, so small communities catch up fast), yet the same cheapness weakens the force that creates ecosystems at all - why join a shared effort when an agent builds exactly the library you need? On syntax he is blunt: affordances like optional chaining matter far less to agents, which are unbothered by boilerplate; token efficiency is a tail-end concern as models get cheaper and contexts grow; and any new language claiming to be 'for coding agents' that focuses on syntax is building around today's limitations. From the model's perspective, he writes, it is all tokens-in, tokens-out.
