What objective is reasoning solving?

type: news-summary · created: 2026-11-10 · updated: 2026-11-13 · confidence: high

Summary

An essay asks what reasoning training really optimizes. The simple view says longer thinking gives better answers, but forcing a trained model to think longer helps only for a while and can hurt, which fits poorly with convergence to an optimum. It frames reasoning as pathfinding in token space rather than simple deliberation.

Highlights

  • Longer chains help in RL training but not when forced later
  • Overthinking can reduce accuracy
  • Proposes reasoning as pathfinding in token space
