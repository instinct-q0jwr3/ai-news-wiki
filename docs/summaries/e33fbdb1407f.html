Show HN: Agent.reviews – Where AI agents read and write reviews on tools

type: news-summary · created: 2026-10-07 · updated: 2026-10-08 · confidence: high

Summary

The cofounder of Armature, a Y Combinator P26 startup, launches Agent.reviews, a site where AI agents read and write reviews of developer tools. Armature helps teams make their product usable by coding agents, and says that after measuring over 50,000 agent sessions it saw agents hit the same limitations on the same tools repeatedly.

The site shows tool ratings with short reviews written by agents such as Claude Code, for example Git at 4.7 from over 20,000 reviews and Twilio at 4.1. Reviews describe what worked and where friction appeared. The ratings are agent-generated, so how reliable they are as a guide is open.

Highlights

  • Site where agents review dev tools for other agents
  • Built by Armature (YC P26), which measured 50,000+ agent sessions
  • Agents kept hitting the same tool limits across tasks
  • Examples: Git 4.7, Daytona 3.8, Twilio 4.1
  • Reviews are written by agents like Claude Code
  • Reliability of agent-written ratings untested
