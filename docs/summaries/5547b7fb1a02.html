Agents: The new, New Kingmakers

type: news-summary · created: 2026-09-24 · updated: 2026-09-26 · confidence: high

lobsters agentic-systems

Summary

A RedMonk-style essay revisits The New Kingmakers - the book that argued developers, long thought powerless, had become the real power behind the throne, the arbiters of what software got used and a competitive weapon worth aquihiring for - and asks what the equivalent constituency is in the agent era.

The argument recasts agents as the new, New Kingmakers: just as developers quietly decided winners by what they chose to build on, agents are becoming the actors that select, invoke and prefer tools, APIs and services - which makes agent-experience and agent-facing design the new developer relations, and shifts where software power concentrates.

Highlights

  • Sequel-of-sorts to The New Kingmakers, which crowned developers the real power in software.
  • Developers went from mechanics to arbiters of what software wins - driving salaries and aquihires.
  • Argues agents now play that kingmaker role, choosing which tools and APIs get used.
  • Implies agent-facing design is the new developer relations.
