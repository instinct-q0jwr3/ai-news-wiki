Show HN: I wrote an email app that accepts only one sender per inbox

type: news-summary · created: 2026-10-14 · updated: 2026-10-30 · confidence: high

Summary

A Show HN email app, with infinite inboxes where the first sender to write claims the address and everyone else is rejected, so leaked or resold lists are worthless. Temporary addresses can be set to expire after an hour or a month.

Highlights

  • One-sender inboxes reject everyone but the first sender.
  • Temporary addresses with set lifetimes.
  • Aims at zero spam.
