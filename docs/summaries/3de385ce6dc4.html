Pluralistic: Lindsay Owens's "Gouged" (29 Sep 2026)

type: news-summary · created: 2026-09-29 · updated: 2026-10-01 · confidence: high

Summary

Cory Doctorow plugs Lindsay Owens's new book Gouged, a guide to surveillance pricing and algorithmic wage discrimination - using computers and commercial surveillance data to pick pockets and shrink paychecks. Owens runs Groundwork Collaborative, whose fellow Katie Wells co-authored the report showing how nursing shiftwork apps collude with data brokers to learn nurses' credit-card debt so the most desperate can be offered lower wages. Doctorow presents the book as the accessible, comprehensive reference on a modern scourge that makes 'the worst people on earth far richer.'
