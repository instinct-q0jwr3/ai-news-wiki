Python 3.15.0 added to actions/python-versions

type: news-summary · created: 2026-10-11 · updated: 2026-10-11 · confidence: high

Summary

Simon Willison notes that Python 3.15.0 has been added to actions/python-versions, which means you can now add '3.15' to a GitHub Actions testing matrix and run tests against the new release.

He admits the link is niche and that he had been waiting days for it, to the point of telling ChatGPT to clone the repo and git pull once an hour until the stable 3.15 landed, a small, honest example of delegating a tedious watch task to an agent.
