ClawDOS – An AI coding agent for DOS

type: news-summary · created: 2026-11-21 · updated: 2026-11-27 · confidence: high

Summary

ClawDOS is a hobby coding-agent harness designed for an IBM PC XT running DOS. The project describes local file tools, compiler handoff, persistent conversations and screenshot capture, while using a separate modern machine for TLS and a remote model API for inference.

Running the harness on an 8088 does not mean the language model runs there. The page distinguishes emulator screenshots from a filmed real-machine demo and reports default confirmation prompts for changes, but neither those controls nor the claimed tests were independently audited. No setup commands, key handling or software installation were performed.

Highlights

  • DOS machine runs the harness rather than model weights
  • Separate bridge handles encrypted transport
  • Compiler can run while harness leaves memory
  • Emulated captures differ from filmed hardware demonstration
  • Safe mode is a project-described control
  • API usage still depends on a remote service
  • No code or configuration was executed
