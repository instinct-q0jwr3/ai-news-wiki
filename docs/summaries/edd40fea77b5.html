Show HN: Pinrail – A desktop inbox where coding agents wait for your review

type: news-summary · created: 2026-10-07 · updated: 2026-10-09 · confidence: high

Summary

Pinrail is a desktop app, in early development, where coding agents ask for a person's decision before acting. It works with any agent that can run a command, including Claude Code, Codex, Cursor and OpenCode, on macOS and Linux.

The agent submits a review request and Pinrail shows a view fitted to the content: a diff with the agent's findings for code review, or generated images where you draw a box on what to change. The decision comes back as structured Markdown or JSON listing what was accepted, rejected and any notes. The app serves its API on loopback only and keeps reviews and decisions on the user's machine. The repository is new, with a single stated contributor.

Highlights

  • Desktop inbox where agents wait for human review
  • Works with Claude Code, Codex, Cursor, OpenCode
  • Views tailored to content, such as diffs or images
  • Returns structured accept or reject decisions with notes
  • Local only: loopback API, data on your machine
  • Early development, expect rough edges
