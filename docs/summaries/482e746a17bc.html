  • In the previous chapter we configured a neural network and made it learn to distinguish between the digits 3 and 7.
  • Every neural network system (PyTorch, TensorFlow, Flashlight ) implements an autogradient system that performs automatic differentiation.
  • First, let’s look at what such a system can do: Tensor x ( 2.0f ); Tensor z ( 0.0f ); Tensor y = Tensor( 3.0f ) * x * x * x + Tensor( 4.0f ) * x + Tensor( 1.0f ) + x * z; This configures y to be \( 3x^3 + 4x + 1 +xz\).
  • As an example: Tensor x ( 2.0f ); Tensor z ( 0.0f ); Tensor y = Tensor( 3.0f ) * x * x * x + Tensor( 4.0f ) * x + Tensor( 1.0f ) + x * z; The values 3.0, 4.0 and 1.0 are all temporaries.
