Show HN: DBDelve – Open-Source DB Client Made with Rust and GPUI

type: news-summary · created: 2026-11-09 · updated: 2026-11-14 · confidence: high

Summary

DBDelve’s creator presents a Rust and GPUI database client focused on responsiveness, keyboard control and a simpler interface. The launch post compares launch time, memory and query rendering with DBeaver on a specified Mac and Postgres dataset.

The author’s benchmark favors DBDelve but includes an unusually large whole-table load and manually adjusted DBeaver memory limits. Those conditions matter: the figures are a reproducible-looking self-report, not an independent result for every database or everyday workflow.

Highlights

  • Client uses Rust and GPUI
  • Keyboard control and project grouping are described
  • Author reports lower resource use in one comparison
  • Large-table test is not a normal workload
  • Independent replication is not provided
