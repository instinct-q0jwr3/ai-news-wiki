llm-typesafe 0.1a0

type: news-summary · created: 2026-09-25 · updated: 2026-09-26 · confidence: high

simon-willison typesafe ai-policy-regulation

Summary

Simon Willison released llm-typesafe, a plugin for his LLM command-line tool adding support for TypeSafe AI's new Jev model. After 'llm install llm-typesafe' and setting an API key (the waitlist 'seems to move pretty fast'), Jev answers structured questions: yes/no 'noul' questions returning a probability ({'type':'noul','noul':0.99}), choice questions with caller-defined criteria (route this message to billing/technical/other), and scoring questions against a caller-supplied rubric (how reproducible is this bug report).

The examples show Jev being used as a classification and judgment primitive inside shell pipelines rather than as a chat model.

Highlights

  • llm-typesafe connects Willison's LLM CLI to TypeSafe AI's Jev model
  • Jev returns structured answers: 'noul' probabilities, criteria-based choices, rubric scores
  • Example use: detect whether a message explicitly requests a refund, with a 0.99 confidence output
  • Choice mode routes messages to teams using caller-defined category criteria
  • Scoring mode grades text against a custom rubric, e.g. bug-report reproducibility
