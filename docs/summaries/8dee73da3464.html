Show HN: Agentic CUDA Kernel Optimizer

type: news-summary · created: 2026-09-25 · updated: 2026-09-26 · confidence: high

hacker-news agentic-systems external-evaluation

Summary

A Show HN presents an agentic CUDA kernel optimizer that turns workload descriptions into GPU implementations through an automated cycle of code generation, correctness checks, benchmarking and refinement. Powered by LangGraph, the agent explores kernel implementations and launch configurations, queries GPU properties, researches NVIDIA documentation for optimization guidance, and inspects Nsight Compute counters to inform its next experiment.

Each experiment is recorded and the fastest validated implementation is retained; the model can change both kernel code and per-case launch configurations. A standalone C++ harness compiles kernels with NVRTC and launches them through the CUDA Driver API, Python handles comparison and candidate selection, and every case must pass validation.
