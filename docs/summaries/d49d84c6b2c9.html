Claude Sonnet 5.5

type: news-summary · created: 2026-09-29 · updated: 2026-10-01 · confidence: high

simon-willison openai anthropic external-evaluation

Summary

Simon Willison's link-blog take on Claude Sonnet 5.5: priced identically to Sonnet 5 while beating it on every benchmark and running cheaper and 30%+ faster. His pelican-riding-a-bicycle benchmark reproduced the same bug he hit with Opus 5.5 - at 'max' thinking effort the model thought for 128,000 tokens ($1.28) and ran out of tokens before producing an SVG - while 'xhigh' effort delivered a solid WebGL pelican for 5.74 cents in 41 seconds. Sonnet 5.5 is nearly Opus 5.5-level on some coding tasks, including viral 3D animation tricks. The strategically interesting detail: Sonnet 5.5 is now the free-tier model on claude.ai, against ChatGPT's free tier on Luna 5.6, giving Anthropic the more capable free offering. Haiku 5.5 is promised in coming weeks; Willison hopes it competes with GPT-6 Luna on price.

  • Sonnet 5.5: same price as Sonnet 5, beats it on every benchmark, 30%+ faster and cheaper per task
  • Willison's pelican benchmark hit the same bug as Opus 5.5: 128k thinking tokens at max effort, then failure
