There are now 5 inference providers for abliterated DeepSeek

type: news-summary · created: 2026-10-27 · updated: 2026-10-28 · confidence: high

Summary

Basis: the page is a live routing dashboard that yields little static text, so this note rests on its visible description. There are now five inference providers serving the abliterated - refusal-trained-out - variant of DeepSeek, a fast reasoning model. The tracking page, AllModels, routes text requests across a fallback pool of providers and sends image requests only to providers that can actually handle them. The spread of abliterated hosting across five independent providers marks how quickly uncensored fine-tunes of frontier open models achieve mainstream inference distribution.
