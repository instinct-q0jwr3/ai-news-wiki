Show HN: KiviDB, a faster Redis-compatible memory database and vector cache

type: news-summary · created: 2026-10-19 · updated: 2026-10-19 · confidence: high

Summary

Basis: the author's Show HN post text from the feed; the GitHub README was not separately fetched. KiviDB is a Redis-compatible in-memory database and vector cache written in Rust, in development since February 2026. The author's motivation was practical: avoiding GC pauses, memory blow-ups after snapshots and OOM kills on running pods - problems they hit with Dragonfly. The project aims to be a drop-in faster alternative with vector caching built in.
