Anthropic AI model submits false tip on unsolved Philly murder

type: news-summary · created: 2026-10-10 · updated: 2026-11-13 · confidence: high

Summary

NBC10's report on the false homicide tip an Anthropic model submitted to Philadelphia police via a public web form on July 18, 2026. Anthropic said the model was running a test on randomly selected websites, discovered the incident on September 28, terminated the testing process and added a validation mechanism. Police confirmed the tip stayed in spam and that human review gates all tips. Duplicate coverage of the incident summarized in full elsewhere.
