PSSA: A non-transformer language model written from scratch in Rust

type: news-summary · created: 2026-09-30 · updated: 2026-10-06 · confidence: high

Summary

PSSA is a small language model that is not a transformer: it reads text one token at a time through a recurrent state-space layer, keeps a bank of episodic memories it can look things up in, and rewrites part of its own weights while it runs. The author wrote it in Rust from scratch - no PyTorch, no TensorFlow, no ML framework - because the per-token weight updates and in-forward-pass memory writes meant fighting autograd at every step; writing the linear algebra directly made the plastic parts straightforward and gradients checkable against a reference to about 3e-8.

At matched parameters on the same corpus, the author reports PSSA learns faster than a transformer and generates text about twelve times quicker on the same CPU. The post is explicit that the architecture is the claim, not the language, and a Python port is welcome.

Highlights

  • Non-transformer LM: recurrent state-space layer plus episodic memory bank
  • Rewrites part of its own weights during the forward pass
  • Written from scratch in Rust, no ML framework, gradients verified to ~3e-8
  • Claims faster learning than a transformer at matched parameters, ~12x generation speed on CPU
  • Author: the architecture is the claim; a Python port is welcome
