"Proof of use" as a requirement for open source contributions?

type: news-summary · created: 2026-11-17 · updated: 2026-11-27 · confidence: high

Summary

A Lobsters contributor proposes requiring evidence that a submitter actually uses a project before reviewing their pull request. The aim is to prioritize downstream users and reduce speculative, AI-generated or contribution-count-driven changes that consume maintainer attention.

The discussion offers anecdotes and reactions, not measured evidence that such a gate improves maintenance. It could filter low-value patches but also exclude useful newcomers or contributors unable to disclose private work. This is one maintainer’s proposed experiment, not a platform-wide rule.

Highlights

  • Proposal prioritizes demonstrated downstream need
  • Private production use can be described
  • Discussion evidence is anecdotal
  • Newcomer exclusion is a possible tradeoff
  • No platform-wide policy is announced
