Show HN: Lossless-memory – a personal AI memory that never summarizes

type: news-summary · created: 2026-09-21 · updated: 2026-09-22 · confidence: high

hacker-news

Summary

Lossless-memory is a personal AI memory system built on a refusal to summarize: most long-term memory systems either compress conversations into notes or embed and retrieve similar chunks, and both lose what actually matters to someone who talks to the same AI every day, what was actually said, and when. This project appends every conversation turn as a fixed seven-field record (timestamp, actor, role, type, verbatim text, model, session) to a per-day JSONL file; the raw logs are the source of truth and every index can be deleted and rebuilt from them.

Time is the primary axis, not metadata: the AI can answer 'what did we decide last Tuesday night?' with the actual lines from last Tuesday night, in order. A tiny index of timestamped topic markers (LLL), injected into the model's context every turn, lets a long-running assistant come back from compaction. The lineage runs from a December 2025 memory-inheritance tool through a predecessor in daily use since January 2026; this implementation has run every day since July 2026 for one user, with raw logs back to June 2026, and docs/lessons.md documents the failures.

Highlights

  • Lossless-memory: personal AI memory that never summarizes; keeps every line with a timestamp.
  • Critique: summarization and embedding retrieval both lose what was actually said and when.
  • Seven-field record per turn: ts, actor, role, type, verbatim text, model, session; per-day JSONL files.
  • Raw logs are the source of truth; all indexes are rebuildable and disposable.
  • Time as primary axis: answer 'what did we decide last Tuesday night?' with the actual lines.
  • LLL: tiny timestamped topic-marker index injected into context every turn to survive compaction.
  • In daily use since July 2026 for one user; lineage back to December 2025; failures documented in docs/lessons.md.
