Ladybird's first alpha release

type: news-summary · created: 2026-11-23 · updated: 2026-11-23 · confidence: high

Summary

Simon Willison reports trying Ladybird's first alpha, a browser with its own implementation of much of the web stack. His examples include working WebAssembly-based tools and a failing Datasette Lite service-worker path. He relays the project's October conformance gains and attribution of many small fixes to coding agents, while saying the exact model versions behind that work are not established in his account.

An alpha release and more passing tests do not establish daily-driver security or compatibility with every site. The project explicitly makes no security promises at this stage, and Willison says he will not use it for sensitive logins. His performance impressions and the project's benchmark gains are attributed observations, not tests reproduced here. No browser was installed and no accounts were signed into through it.
