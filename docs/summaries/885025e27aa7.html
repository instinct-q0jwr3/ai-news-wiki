Show HN: Scry, programmable internet search w/ congestion pricing

type: news-summary · created: 2026-09-19 · updated: 2026-09-26 · confidence: high

hacker-news google agentic-systems small-specialist-models compute-buildout ai-price-war

Summary

Scry is an open-alpha MCP connector that lets an agent run arbitrary read-only programs - SQL and some Datalog - over a claimed 166.9 billion rows of internet documents, adding 62.4 billion rows in the last week alone. The pitch: where web search hands an agent ten links, Scry answers questions like 'every page that mentions this compound but not that patent, grouped by domain, since March' as a single query. Setup is a two-minute, no-code MCP install for ChatGPT or Claude.

The index spans social (27.2B Reddit comments, 3.75B Reddit posts, 2.43B Bluesky, 45.7M Hacker News items), web (45.5B Common Crawl index entries, 26.1B pages, 1.67B mailing-list posts), scholarship (3.33B book passages, 512M OpenAlex works, 6.93M arXiv papers), markets (632M Kalshi trades, 310M Polymarket trades), records (1.05B Google Trends points, 234M SEC filings) and code (25.2B deps.dev graph entries, 11.2B GitHub Archive events), plus 262B rows from 20 undisclosed sources. The associated Show HN describes a 500 TB NVMe index in ClickHouse with congestion-based micro-auction pricing for contention, free for non-commercial use when capacity allows.

Highlights

  • MCP server at mcp.scry.io; two-minute no-code setup for ChatGPT (Developer mode) or Claude.
  • Claims 166,912,566,110 queryable rows, +62.4B in one week; open alpha.
  • Show HN: 500 TB NVMe internet index in ClickHouse; arbitrary read-only SQL plus some Datalog.
  • Resource contention handled by congestion-based micro-auction pricing; free for non-commercial use when there's capacity.
  • Social data: 27.2B Reddit comments, 3.75B Reddit posts, 2.43B Bluesky, 45.7M Hacker News.
  • Scholarship: 3.33B book passages, 512M OpenAlex works, 6.93M arXiv, 91.2M full-text academic papers.
  • Code: 25.2B deps.dev graph entries, 11.2B GitHub Archive events, 5.94B Software Heritage revisions.
  • Markets/records: 632M Kalshi trades, 310M Polymarket trades, 234M SEC filings, 434M FEC transactions.
  • Example query shape: 'every page that mentions this compound but not that patent, grouped by domain, since March.'
