Quick Study

type: news-summary · created: 2026-10-24 · updated: 2026-10-29 · confidence: high

Summary

Simon Willison's Quick Study: a Claude Opus 5.5 High artifact that opens a photo and repaints it in seconds on a canvas element with simulated brushstrokes - built from a single prompt. The technique uses Sobel edge detection with no external libraries beyond Google Fonts, following his earlier experiment getting Claude Fable to simulate a watercolor illustration in P5.js.

The beat is a small, legible example of artifact-style prompting: a self-contained creative tool where the model chooses both the algorithm (edge detection guiding stroke placement) and the implementation, producing a painterly rendering pipeline in one shot.
