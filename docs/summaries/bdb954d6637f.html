OpenAI launches Images 2.6 with GIFs and image reference

type: news-summary · created: 2026-11-05 · updated: 2026-11-08 · confidence: high

Summary

TestingCatalog covers OpenAI's Images 2.6 launch: global rollout in ChatGPT and Codex on all tiers, with GIF creation and reusable reference images, so you can save yourself or a pet once and reuse them.
