Bringing Devin Cloud to your terminal

type: news-summary · created: 2026-09-22 · updated: 2026-09-24 · confidence: high

tldr-ai

Summary

Devin added Devin Cloud to its CLI: devin --cloud or /cloud creates, steers, resumes and watches cloud sessions from the terminal, and /handoff transfers any local task to Devin's cloud VM while keeping terminal-based steering - the laptop can be closed while Devin continues in the background.

Cloud sessions outlive the terminal that started them. /open web and /open desktop move the current session to the web app or Devin Desktop for watching or reviewing recordings, and devin --cloud --resume reattaches any cloud session in the terminal.

Highlights

  • Create, steer, resume and watch Devin Cloud sessions from the terminal
  • /handoff transfers a local task to Devin's cloud VM
  • Steering stays in the terminal; laptop can be closed mid-task
  • Sessions outlive the terminal; /open web|desktop for watching and recordings
  • devin --cloud --resume reattaches any cloud session
