AI-Built Torrent Site Looks Inside Downloads to Catch Fakes and Malware

type: news-summary · created: 2026-10-12 · updated: 2026-10-30 · confidence: high

Summary

TorrentClaw, a torrent search engine launched in February, has grown to an index of over six million torrents built from its own DHT crawler plus dozens of external sites. Its developers - all using the name Deivid Soto - say the platform is largely built and run with AI: 'basically, the core framework is Claude Code combined with local LLMs for specific execution and ingestion tasks', including matching torrents to film and TV titles for clean organization.

The AI also built novel features like TrueSpec, which inspects what a torrent actually contains rather than trusting its release name - catching fake uploads and malware that moderator-driven sites handle manually. The homepage wears its AI-design tells openly; AI is central to both the site's development and its marketing.

Highlights
