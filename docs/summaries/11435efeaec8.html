Show HN: Ramasite, a Self-Contained Laravel/Filament/SQLite CMS

type: news-summary · created: 2026-11-12 · updated: 2026-11-13 · confidence: high

Summary

RamaSite packages a small content-management system around Laravel, Filament and SQLite. Its design aims to keep a site self-contained, with a release archive that includes dependencies and first-visit setup that creates the database and settings. This reduces the separate services an operator must configure.

The repository describes preserving pages, media, settings and accounts when release files are replaced, and running tests and a package-security check before publishing release archives. The project is MIT-licensed. Its developer's dissatisfaction with WordPress motivates the design, but does not establish that this alternative is immune to security or maintenance problems.

Highlights

  • Laravel and Filament with SQLite
  • Release archive includes dependencies
  • First visit initializes settings and database
  • User content is kept separate from release files
  • Release process includes tests and dependency checks
  • MIT license does not imply a security guarantee
