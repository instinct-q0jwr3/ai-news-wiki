Why Agents Love Supabase

type: news-summary · created: 2026-10-28 · updated: 2026-10-30 · confidence: high

Summary

Latent Space interviews Supabase founders Paul Copplestone and Ant Wilson on why agents pick Supabase: in the host's frontier AEO tracker, it was the near-unanimous first choice for app backends across every frontier model from Astra to Fable to Muse. Familiarity to the model is distribution, but the founders argue the real work is removing friction between a generated app and a running one.

Standout announcements from Select, grouped as Build, Operate and Scale: a local backend runtime without Docker, database schema kept in Git, and compute running beside the database - small frictions for humans that become significant when agents repeatedly create and test environments.

Highlights

  • Supabase swept frontier-model backend recommendations in AEO tracking
  • New alpha: local Supabase runtime without Docker
  • Schema in Git and compute beside the database
  • Agent workflows make small setup frictions expensive
