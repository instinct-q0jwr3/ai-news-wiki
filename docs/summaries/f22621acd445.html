Vibecoding an inference chip

type: news-summary · created: 2026-11-20 · updated: 2026-11-27 · confidence: high

Summary

Ankit describes using coding agents to run a language model on an FPGA and accelerate a bit-exact baseline through many small software and hardware changes. The examined account emphasizes memory movement, pipeline changes and the importance of a fixed correctness rule.

This is an author-run project with a large token budget, not an independent comparison against commercial accelerators. The examined process retrospective also describes a tradeoff: shorter simulation cycles got hardware results sooner but may have allowed hangs to reach the board. No code, hardware reservation or quoted prompt was executed here.

Highlights

  • Project uses reprogrammable hardware not a fabricated new chip
  • Speedup is relative to the project baseline
  • Bit-exact output rules exclude numerical shortcuts
  • Iteration includes both host software and hardware
  • Reported token budget is substantial
  • Faster iteration can weaken fault detection
  • Full later project results were not independently reproduced
