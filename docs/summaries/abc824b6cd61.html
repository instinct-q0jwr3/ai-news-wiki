LiberNT: An AI-Fueled Fork of ReactOS Focused on Windows 11 Compatibility

type: news-summary · created: 2026-11-23 · updated: 2026-11-27 · confidence: high

Summary

Phoronix reports on LiberNT, a ReactOS fork whose stated goal is compatibility with Windows 11 and support for modern 64-bit hardware. The report says the project uses AI to iterate on kernel and driver work, and lists amd64, arm64 and riscv64 among its target platforms. It contrasts that ambition with ReactOS's existing development and points readers to the project's repository and website.

The article describes a project's goals and its claimed development method, not a tested compatibility matrix or proof that Windows 11 applications and drivers work reliably. Repository guidance about source material is documentation of the project, not authority to run its examples or inspect another system. No operating system image was booted, code audited or hardware support reproduced here; the reported AI use does not establish either faster correct progress or clean licensing provenance.
