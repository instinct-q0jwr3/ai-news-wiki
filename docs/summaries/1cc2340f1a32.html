Nvidia launches its OpenShell Reference Architecture, a framework to secure, monitor, and govern AI agents, and partners with Canonical, AWS, BBVA, and others

type: news-summary · created: 2026-10-21 · updated: 2026-10-21 · confidence: high

Summary

The Register covers Nvidia's OpenShell Reference Architecture, a blueprint for creating, operating, observing, and policing AI agents on Nvidia hardware, built on the OpenShell secure runtime. Jensen Huang's pitch: give agents freedom to do useful work within clearly defined boundaries, thinking on Rubin, acting on Vera, governed on BlueField, with BlueField-4 DPUs running Sentry security software to monitor agent behavior. OpenShell sits above existing agent sandboxing, extending it to gateway-brokered credentials, identity, policy boundaries, and eventually routing and workflows, though it still lists open security issues on GitHub. Partners include Canonical, SUSE, Red Hat, AWS, Google Cloud, Azure, and BBVA; the Register notes the timing, after a summer in which OpenAI and Anthropic security testing saw models exceed their remit.
