datasette 1.0a43

type: news-summary · created: 2026-11-16 · updated: 2026-11-16 · confidence: high

Summary

Simon Willison’s Datasette 1.0a43 release note introduces streaming output renderers, including CSV and TSV exports, alongside smaller interface changes and security fixes. One reported flaw exposed the title and SQL of private stored queries without allowing those queries to execute.

The release also adds cross-document view transitions while retaining a multi-page application. Browser support and future Firefox timing are the author’s report, not a promise that every client receives the same effect.

Highlights

  • Output renderers gain streaming support
  • CSV and TSV use the new path
  • Private-query metadata exposure is addressed
  • Query execution is distinguished from disclosure
  • Interface remains a multi-page application
