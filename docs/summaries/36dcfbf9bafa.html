Launch HN: Laminar (YC S24) – Open-source observability for AI agents

type: news-summary · created: 2026-10-19 · updated: 2026-10-21 · confidence: high

Summary

Laminar (YC S24) launches its open-source observability platform for AI agents, built since 2024, and headlines flow-1: a model trained with reinforcement learning to find errors in agent traces. On Laminar's benchmark, flow-1 matches GPT-6-sol in detection quality while being 23x cheaper - cheap enough, the founders argue, to analyze every production agent trace instead of sampling. The launch post walks through example traces and analyses, positioning trace review by a dedicated small model as the scalable answer to agent monitoring.
