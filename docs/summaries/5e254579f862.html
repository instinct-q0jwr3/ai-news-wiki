Understanding is the new bottleneck

type: news-summary · created: 2026-09-25 · updated: 2026-09-26 · confidence: high

geoffrey-litt agentic-systems

Summary

Geoffrey Litt's AI Engineer conference talk argues it is still important to understand the code our agents write - but for a better reason than the usual one. Understanding-as-verification (thumbs up or down on the agent's work) matters less as agents get better at verifying themselves. Understanding-as-participation matters more: a project is many loops with the agent, and your grasp of the system is what lets you come up with the next idea. Without that fluency you are a limited participant - the 'cognitive debt' idea popularized by Margaret Storey and Simon Willison.

His how-to borrows from education. First technique: explanations. His /explain-diff skill produces thoughtfully structured code explainers - background first ('teach me about the game engine'), intuition before details (state the goal, explain isometric projection before the code), and interactive figures to build intuition. The point is to catch the human up as an equal participant rather than handing over a raw diff.

Highlights

  • Litt: understanding agent-written code still matters - but for participation, not just verification
  • Agents increasingly verify their own work, shrinking the value of human thumbs-up/down
  • A project is many loops; understanding fuels the next creative idea
  • Cognitive debt (Storey, Willison): skipping understanding works short-term, bites later
  • Steal techniques from education to build human understanding at AI speed
  • /explain-diff: structured explainers as HTML, markdown or Notion docs
  • Principles: teach background first, intuition before details, interactive figures
