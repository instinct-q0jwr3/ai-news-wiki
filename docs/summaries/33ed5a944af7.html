How Devin's Memory and Dreaming Work

type: news-summary · created: 2026-10-06 · updated: 2026-10-28 · confidence: high

Summary

Cognition introduced Memory and Dreaming for Devin. Memory carries lessons across sessions - your preferences, corrections, and project gotchas - as short notes with links back to the sessions where they were learned, stored in a personal Memory Drive: a persistent Git repository of markdown files organized by repository, project or topic, with a MEMORY.md index loaded at session start. Devin searches that drive with the same tools it uses to navigate code.

Dreaming is a daily asynchronous process that improves the memory index: deduplicating memories, linking them to sessions and artifacts, and surfacing new knowledge. Memory is personal per user within each organization rather than shared team instructions. Cognition also open-sourced the standard behind the system at cognition.ai/agent-memory-repo, inviting other agent builders to integrate it.

Highlights

  • Memories live in a personal Git-backed Memory Drive indexed by MEMORY.md.
  • Dreaming: a daily async process that deduplicates, links and improves the memory index.
  • Memory is personal per user, not shared org instructions.
  • Cognition open-sourced the underlying agent-memory standard.
