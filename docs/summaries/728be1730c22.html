Show HN: Ambits – agentic grep/rg tool will history tracking

type: news-summary · created: 2026-09-21 · updated: 2026-09-21 · confidence: high

hacker-news agentic-systems

Summary

Ambits is a code-reading tool for AI agents plus a memory of what they have read. The problem it targets: coding agents read whole files to find one function, re-read code they already know, and lose all of it when the context window compacts. Ambits answers both halves: a grep whose every hit knows which symbol it landed in, and a session history that can be handed back automatically after every compaction, with plain-text and JSON surfaces that carry no vendor coupling, so the record can move between agents or providers.

The tool ships two front ends over one engine, the same matcher, symbol attribution and output contract, because grep(1) and ripgrep assign opposite meanings to the same short flags. ambits rg is the one to reach for since Claude Code's own Grep tool is ripgrep-backed; ambits grep keeps grep's defaults, and the three flags it cannot honor say so rather than pretending. Ingestion is currently built and tested against Claude Code, with a live TUI for watching what the agent is looking at. Install: cargo install ambits.

Highlights

  • Ambits: code-reading tool for AI agents with a persistent memory of what they read.
  • Problem: agents read whole files for one function and lose everything on context compaction.
  • Grep whose every hit names the enclosing symbol and how deeply the session has read it.
  • restore-context command hands read history back after every compaction; hook install automates it.
  • Plain text and JSON surfaces, no vendor coupling; history portable across agents and providers.
  • Two front ends, one engine: ambits rg (ripgrep dialect, matches Claude Code's Grep tool) and ambits grep (grep defaults).
  • Built and tested against Claude Code ingestion; live TUI included; cargo install ambits.
