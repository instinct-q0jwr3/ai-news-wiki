SIMD-accelerated computer vision on a $2 microcontroller

type: news-summary · created: 2026-10-25 · updated: 2026-10-30 · confidence: high

Summary

A hobbyist has coaxed serious computer-vision performance out of the ESP32-S3, a dual-core 240MHz microcontroller that costs about two dollars, by exploiting a set of 128-bit SIMD instructions buried in its technical reference manual. The project is a SIMD-accelerated implementation of the FAST corner detector, the first stage of many feature-matching pipelines, and it runs roughly twice as fast as the reference implementation, processing a QVGA frame in about six milliseconds.

The write-up doubles as a tutorial on the chip's eccentricities. Finding almost no example code online, the author worked from three scattered sources, learned the ESP32-S3's assembly conventions, and hit its unusual constraints - including alignment rules and a quirky instruction set - head on. Along the way the project spawned basm, a small custom register allocator written to make the hand-written vector code manageable. The result is both a practical detector for cheap vision hardware and a readable map of an instruction set almost nobody documents.

Highlights

  • SIMD-accelerated FAST corner detector for the ESP32-S3 runs about twice as fast as the reference implementation
  • Processes a 320x240 (QVGA) frame in roughly 6 milliseconds on a ~$2 dual-core 240MHz microcontroller
  • The ESP32-S3's 128-bit SIMD instructions are documented in the chip's reference manual but were supported by almost no example code online
  • The SIMD pre-test samples one pixel per cardinal direction and checks for at least three pixels whose brightness differs from the center beyond a threshold
  • Working around the chip's alignment rules and instruction quirks led the author to write basm, a small custom register allocator
  • Source code for the detector is published and linked from the article
