ICANN receives 1,615 TLD applications from 481 applicants; Meta, OpenAI, and eight others applied for .agent, seven companies applied for .agi, and six for .asi

type: news-summary · created: 2026-10-08 · updated: 2026-10-09 · confidence: high

Summary

The Verge reports ICANN received 1,615 top-level domain applications from 481 applicants, many about AI. Meta, OpenAI and eight others applied for .agent, seven companies for .agi, and six for .asi.

Only the excerpt was reviewed. The applications are not approvals.
