OpenAI prepares new $500/month Pro Max plan for ChatGPT

type: news-summary · created: 2026-09-25 · updated: 2026-09-26 · confidence: high

tldr-ai openai

Summary

OpenAI appears to be preparing a new higher-tier ChatGPT plan: Pro Max, priced at $500 per month, according to leaks collected by TestingCatalog and leaker Tibor Blaho.

The same roundup notes OpenAI's Ultrafast mode for GPT-5.6 Sol in preview - speeding up model performance by up to 14 times, built with Cerebras - currently available to a limited set of customers with a waitlist for expansion.

  • Separately: Ultrafast mode for GPT-5.6 Sol in preview.
  • Ultrafast promises up to 14x speed, built with Cerebras.
  • Limited availability now; waitlist for expansion.
