The New York Times tells photographers not to use the latest Photoshop

type: news-summary · created: 2026-11-25 · updated: 2026-11-26 · confidence: high

Summary

DPReview reports the New York Times telling freelance photographers not to use the latest Photoshop because some functions may apply generative AI without users realizing it and leave AI-related metadata. The concern is both editorial alteration and misleading downstream labeling of documentary photographs.

This is DPReview's account of an email reportedly confirmed by The Verge, not a directly inspected universal Times policy manual. The restriction is described as applying at this time to freelance contributors and the latest version, not a ban on all Adobe tools or proof that every image from that version was generated. Existing generative features predate this release, and software settings were not tested here.

Highlights

  • Report concerns freelance contributors
  • Latest-version restriction is described as temporary
  • Metadata labels can blur edits and full generation
  • Generative features already existed in older tools
  • Original policy manual was not independently inspected
  • No Photoshop installation or image metadata was tested
