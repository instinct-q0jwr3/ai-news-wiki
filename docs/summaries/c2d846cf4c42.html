I Deleted 168,000 Lines of Comments. My AI Agent Didn't Notice

type: news-summary · created: 2026-10-14 · updated: 2026-10-31 · confidence: high

Summary

An engineer deleted all comments, about 168,000 lines and nearly a third of the code, from a codebase and gave an AI agent the same two tasks on both versions, three runs each. Every run passed lint, type checks and tests, and the code was judged as good with or without comments, suggesting comments don't help or hinder agents much.

Highlights

  • Removed 168,000 lines of comments.
  • Same agent, same tasks, three runs on each version.
  • All runs passed all checks; quality was equal.
