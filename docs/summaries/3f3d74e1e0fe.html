Locating the source of a mysterious beep with Claude

type: news-summary · created: 2026-11-10 · updated: 2026-11-10 · confidence: high

Summary

Simon Willison used Claude to build a tool that finds a mysterious beeping device in a room. Several laptops, phones and iPads join a Python web app through the browser and listen at once with WebAudio, then triangulate the sound. He started from the BeepBeep acoustic ranging paper, so the devices can also locate one another by playing sounds, and the app gained a rough-placement map, clap detection, timestamps, replays and a mark for 'this is the mystery beep'.

The post is a worked example of prompting with a problem file and iterating step by step.

Highlights

  • Browser devices listen together to locate a beep
  • Based on the BeepBeep acoustic ranging paper
  • Claude built the Python and WebAudio app in steps
  • Features: rough map, clap tests, replay, labeling the beep
