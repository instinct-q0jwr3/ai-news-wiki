Octomind – open-source AI harness that saves your tokens, static rust

type: news-summary · created: 2026-11-03 · updated: 2026-11-11 · confidence: high

Summary

Octomind is an open-source coding-agent harness written in Rust that gives an LLM access to a repo - reading and writing files, running shells, searching code, delegating to sub-agents - through MCP tools. The same engine runs interactively, through stdin for CI and scripts, as a background daemon, over WebSocket, or as an ACP agent inside an editor or another agent stack.

Its pitch is 'most coding agents assume a human is watching the screen; Octomind is built for work that keeps going after you leave.' A supervising model plans and checks the work, and policy lives in TOML guardrails instead of approval prompts. Roles such as developer:general come from a tap registry, in the style of Homebrew taps. The title's claim is that it saves tokens; benchmarks are linked from the project site rather than reproduced in the README.
