Summary

antirez announces redis.antirez.com, a documentation site aimed at LLMs and coding agents working with Redis: exhaustive command and data-type docs, commonly used patterns, configuration hints, and algorithms that can be assembled from Redis commands. He adds that humans reportedly find it useful too - and that he's posting the link mainly so search engines index it.
