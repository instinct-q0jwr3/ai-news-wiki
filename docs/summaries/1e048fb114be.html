Show HN: Waymark – A workflow engine that compiles jobs instead of replaying

type: news-summary · created: 2026-11-06 · updated: 2026-11-09 · confidence: high

Summary

Waymark is an open-source durable execution library like Temporal or DBOS, built on Postgres with no other infrastructure, Python first. Jobs survive server restarts and crashes. The Show HN's pitch is that it compiles workflows instead of replaying them. Actions are plain async functions sent to workers, with fan-out and dependency injection; the package ships client and server binaries together.

Highlights

  • Durable background tasks on Postgres only
  • Compiles workflows instead of replaying them
  • Python first, more languages planned
  • Similar to Temporal and DBOS
