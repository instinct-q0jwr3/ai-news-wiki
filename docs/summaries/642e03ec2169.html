Apple has new Mac app coming to make running local AI models easy

type: news-summary · created: 2026-11-11 · updated: 2026-11-14 · confidence: high

Summary

Leaker Aaron Perris found evidence of an Apple Mac app called Harbor, which would turn a Mac into a private AI inference server for open-weight models on Apple silicon, with data staying on-device. Multiple Macs could be linked over Thunderbolt 5 to pool unified memory for larger models and more concurrency. Unannounced; reported from leaked evidence.

Highlights

  • Harbor: a local inference server app for Mac
  • Thunderbolt 5 pooling of unified memory across Macs
  • Unannounced; from a leaker's findings
