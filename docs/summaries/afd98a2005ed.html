NVIDIA, Microsoft Kick Off a New Beginning for Windows PCs with RTX Spark and AI Agents

type: news-summary · created: 2026-10-08 · updated: 2026-10-09 · confidence: high

Summary

NVIDIA and Microsoft held a Windows and Surface event on agents for PCs. Jensen Huang and Satya Nadella spoke in a fireside chat, and Huang said that in the agent era the PC becomes a personal assistant.

Microsoft announced general availability of Microsoft Execution Containers, OS-level infrastructure meant to make Windows a secure platform for agents, alongside the RTX Spark hardware push. The page is NVIDIA's own event write-up; details beyond the excerpt were not reviewed.
