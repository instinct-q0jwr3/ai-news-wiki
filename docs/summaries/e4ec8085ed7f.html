Quoting Prompting Claude Fable 5.2

type: news-summary · created: 2026-11-10 · updated: 2026-11-11 · confidence: high

Summary

Anthropic's prompting guide for Fable 5.2 says the model follows what a prompt says about who owns the code. With no ownership statement, or code framed as someone else's, it tends to add to existing structure even when that duplicates code. To get it to improve structure, tell it the codebase is its own, for example: 'This codebase is yours.'

Highlights

  • Ownership framing changes how much it restructures
  • Default: add to existing structure
  • Tip: say the codebase is the model's own
