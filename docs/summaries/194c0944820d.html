Much shorter version of GRH Lean verification from Anthropic

type: news-summary · created: 2026-11-25 · updated: 2026-11-25 · confidence: high

Summary

A new lsernau/grh-lean repository presents shorter Lean editions of Alpöge's proof of RH and GRH for Dirichlet L-functions, attributed to collaboration with Anthropic colleagues and Claude. The README describes approximately 300,000-line and 76,000-line editions with the same five theorems and only the three standard axioms.

The repository expressly calls itself a research artifact and says no mathematician has read the proof through and no paper accompanies it. Advertised machine checks and build-resource estimates were not reproduced here. This abbreviated artifact is separate from the original export checked in Sutherland's verification record; success of one artifact should not be silently transferred to another or widened beyond Dirichlet L-functions.

Highlights

  • Two editions have different reported line counts
  • README states the same five theorems
  • GRH scope is Dirichlet L-functions
  • Only standard axioms are advertised
  • Artifact is not maintained for contributions
  • No human mathematical read-through is claimed
  • No build was run for this wiki
  • Original-export certification is a separate record
