Sub-1-Bit LLM Compression via Latent Factorization

type: news-summary · created: 2026-10-08 · updated: 2026-10-10 · confidence: high

Summary

LittleBit is a Samsung Labs codebase for compressing large language models below one bit per weight. It factorizes each dense weight matrix into low-rank latent factors, binarizes those factors and restores magnitude with small learned scales, supporting settings down to 0.1 bits per weight while keeping the model architecture unchanged at inference.

LittleBit-2 improves initialization by aligning the latent factors with the binary hypercube using rotation and Joint-ITQ before quantization-aware training, with an opt-in flag and no inference cost. It supports models such as Llama, Phi-4, Qwen and Gemma. The papers appeared at NeurIPS 2025 and ICML 2026; the README gives no quality numbers in the part reviewed.
