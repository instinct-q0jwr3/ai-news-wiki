Tencent Releases Hy4 With Multimodal Input and Million-Token Context

type: news-summary · created: 2026-11-23 · updated: 2026-11-25 · confidence: high

Summary

Tencent's Hy4 model card describes multimodal text, image and video understanding with a 770B-parameter language backbone and 49B active parameters per token. It specifies a 1,048,576-token context, sparse attention with index reuse, and a separate speculative drafter. The card provides architecture tables and benchmark results rather than only a release headline.

These specifications and evaluations are model-publisher claims. Total backbone parameters exclude the vision encoder, adapter and drafter, so they should not be confused with the full deployed system or active compute. A million-token window is not proof of robust retrieval or reasoning at that length. No weights were downloaded, license assessment completed or serving performance reproduced.

Highlights

  • Card describes text, image and video input
  • Language backbone is stated as 770B total and 49B active
  • Context specification is 1,048,576 tokens
  • Vision components and drafter are separate from backbone count
  • Benchmark and architecture claims are publisher-reported
  • No deployment or long-context validation was performed
