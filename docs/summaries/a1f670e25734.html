Building a gemini server in python

type: news-summary · created: 2026-11-02 · updated: 2026-11-03 · confidence: high

Summary

Seven years late to the party, a developer discovers the Gemini protocol and falls for it: imagine the web with no cookies, no headers beyond GET, no scripting, no styling, no images - no trusted certificate authorities either. The minimalism sounds useless until you see what it buys: a geminispace of capsules run by writers and tinkerers with no commercial aim, no influencers, no bots, no e-commerce, no subscriptions. The Lagrange client makes browsing it a pleasure, and the search engine he bookmarks runs on one guy's Mac mini.

The post then does the thing: building a Gemini server in Python from the spec. It is the small-web counterpart to the same week's AI story - while the main web negotiates robots.txt training controls with trillion-dollar crawlers, here is a protocol where the whole stack fits in one person's head and a weekend of code. Sometimes the escape hatch from a web drowning in generated content is a protocol where generating a page costs somebody real effort.
