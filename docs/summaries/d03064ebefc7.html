Show HN: Klad, a paint app your coding agent can drive (source-available)

type: news-summary · created: 2026-11-11 · updated: 2026-11-12 · confidence: high

Summary

Klad gives coding agents a drawing interface built from editable strokes, fills, layers and animation keys. People draw in a shared editor while an agent uses a command-line interface on the same document. Unlike image generation, the system preserves the parts of a drawing so a later change can target one shape or brush mark without regenerating the whole scene.

The project demonstrates agent-made illustrations and animation assembled from those parts. It is a source-available art tool rather than a new image model; the value depends on how well an agent can plan, inspect and revise an explicit drawing. The examples are project demonstrations, not a general quality benchmark.

Highlights

  • Shared editor and command-line interface
  • Persistent editable strokes and fills
  • Layers and timeline support animation
  • No image-generation model inside the app
  • Local edits avoid whole-image rerolls
  • Project demonstrations do not establish general performance
