Generate fonts where every LLM token is the same width

type: news-summary · created: 2026-09-26 · updated: 2026-09-26 · confidence: high

hacker-news

Summary

A delightfully odd tool: token-space fonts, where a font and a tokenizer are compiled together so that every LLM token renders at exactly the same width - 3 em per token. You pick a model's tokenizer (the preset pairs DeepSeek V4.1 Flash's byte-level BPE with Inter), and the site compiles a single TTF with the tokenizer built into its shaping rules, so no script is needed to display it.

The practical payloads are chat themes: a Vesktop theme that applies the token font to a specific Discord user's messages (so you can spot the em using an LLM by the tell-tale even spacing), and a Slack userscript that restyles messages from named agents or member IDs, threads included, making no network requests and leaving text untouched. Caveats are honest: browser shaping, line breaks and normalization can shift token boundaries, contextual shaping is not universally preserved, and it is a token font, not an exact token counter. Everything compiles locally with Pyodide and fontTools, and the author invites someone with more font expertise to 'implement this project properly.'
