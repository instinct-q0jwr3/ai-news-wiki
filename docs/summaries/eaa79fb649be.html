Artificial Analysis Intelligence Index v5

type: news-summary · created: 2026-10-28 · updated: 2026-10-30 · confidence: high

Summary

Artificial Analysis launched Intelligence Index v5, its biggest composite-benchmark upgrade since v4 in January, with 60% of the index now built on private test sets or held-out answers to resist overfitting. New components include FrontierCode 2.0, Cognition's private benchmark of real-world coding tasks graded on whether a maintainer would merge the agent's change, and Terminal-Bench-Science with 70 agentic research tasks.

Upgrades replace Humanity's Last Exam with the refined 1,000-question HLE-Diamond, refresh AA-Omniscience and add a hard private CritPt v2 subset, while GDPval-AA, SciCode and AA-LCR are removed. The index splits evenly across knowledge work, coding, science and general categories (25% each). A companion Progress Index v1 now tracks model capability over time on one continuous scale.

Highlights

  • 60% of Intelligence Index v5 uses private test sets
  • FrontierCode 2.0 grades agent PRs by merge-worthiness
  • HLE replaced by refined HLE-Diamond; GDPval-AA, SciCode, AA-LCR dropped
  • New Progress Index v1 tracks capability on one continuous scale
