Unofficial Command-Line Tool Removes Apple Intelligence From MacOS 27

type: news-summary · created: 2026-10-06 · updated: 2026-10-08 · confidence: high

Summary

A command-line tool called RemoveMacAI, by developer Om Lahore, switches off Apple Intelligence on macOS 27, which has no toggle for it. It uses a configuration profile you approve plus Apple's own asset service, so System Integrity Protection stays on, and a revert command brings the models back. The developer says the models take about 12GB, though The Verge reports over 30GB. It turns off Siri, Writing Tools, Genmoji, Image Playground, the ChatGPT extension and summaries, while dictation still works. Basis: the article text was read.
