Show HN: Critic – Review code with the agent that wrote it

Summary

We help companies build custom models from their data.

Today we're releasing Critic, a change review platform that lets you engage directly with the AI that wrote the code.

Critic works through a plugin for Codex or Claude Code.

Highlights

  • While that has made us more productive, understanding a change and its consequences has become incredibly difficult.
  • As our company adopted more agentic tools, we found it harder to loop people in on the impact of a PR and the state of a project.
  • Critic lets AI agents present their code, annotate key blocks, and include relevant evidence (like screenshots and instructions to run locally).
  • Anyone viewing that change can talk directly to the agent that wrote it.
  • When your agent writes code, the plugin asks it to also write a narrative describing the story behind the change, and highlight any assumptions, decisions, or complex code.
  • You can then view the change at critic.run or have your agent pull it via the bundled MCP.
  • Every feature in Critic is available over MCP, so your agent gets all the same context without leaving its harness.
  • When Critic receives a question, it forks the authoring session and forwards your question there.
