Show HN: KittyBrowser, I built a web browser in your terminal

type: news-summary · created: 2026-11-13 · updated: 2026-11-13 · confidence: high

Summary

KittyBrowser puts rendered Chrome pages inside a terminal using the kitty graphics protocol, preserving layout and images instead of reducing a page to text. Its Rust interface supports ordinary interaction and a control surface intended for use beside coding agents.

The project is an early release. The developer reports daily macOS use but describes several other terminal and platform combinations as untested. Sharing a visible browser surface can help inspection, but the repository is not an independent audit of compatibility or security.

Highlights

  • Chrome renders actual page pixels
  • Terminal graphics retain visual layout
  • Controls support both people and automation
  • Project is at an early version
  • Platform claims distinguish tested and untested setups
