Fuzzers vs. AI: Comparing Fuzzilli and BigSleep on JavaScript Engines

type: news-summary · created: 2026-10-27 · updated: 2026-10-30 · confidence: high

Summary

Google Project Zero compared its two production bug-finding systems on Chrome's V8 JavaScript engine: Fuzzilli, a generative fuzzer, and BigSleep, an LLM-based agentic system. Over the past six months BigSleep found more vulnerabilities than Fuzzilli - 45 versus 37 - with a measured 25% overlap in specific bugs.

Because the methodology underestimates overlap, dedicated experiments on vulnerabilities reported since 2023 estimated true overlap at roughly 60%. Either way, a substantial share of bugs were findable only by one approach, so Project Zero's recommendation is to run both: fuzzing and LLM analysis remain complementary, and vendors should use each to catch vulnerabilities before users are affected.

Highlights

  • BigSleep (LLM) found 45 V8 bugs in six months vs Fuzzilli's 37
  • Measured overlap 25%; dedicated experiments estimate ~60%
  • Each approach finds bugs the other misses
  • Project Zero recommends running both fuzzing and agentic analysis
