The math that OpenAI keeps for itself

type: news-summary · created: 2026-10-18 · updated: 2026-10-22 · confidence: high

Summary

Daniel Paleka analyzes the 700+ mathematics results OpenAI recently released from its latest model, asking not what they cover but what they conspicuously don't. Internet commentators noticed immediately that nothing touched modern cryptography - some suspected that was no accident, and Matthew Green went as far as 'I think we might lose public key cryptography.'

Paleka checks the pattern with data, using a coding agent and the Semantic Scholar API to classify the results by field. Cryptography is indeed underrepresented, and he finds other clear gaps beyond it - suggesting the published set says as much about OpenAI's choices as about the model's ability.
