Show HN: gavel: guided code review with your coding agent

type: news-summary · created: 2026-11-16 · updated: 2026-11-23 · confidence: high

Summary

Gavel presents local Git changes as a guided review: an agent writes a brief and links explanations beside the diff, while a human can ask threaded questions, request changes and issue separate verdicts for focused parts. The whole diff remains available rather than being replaced by the agent’s narrative.

The author describes the tool as MIT-licensed and built from difit. Remote review links carry access tokens, and feedback depends on the originating agent session’s integration. The proposed workflow helps organize review; it does not prove generated explanations are correct or replace reading and testing the code.

Highlights

  • Narrative gives a reading order through changes
  • Threads stay attached to relevant lines
  • Focused reviews retain separate verdicts
  • Remote links contain access credentials
  • Human judgment remains necessary
