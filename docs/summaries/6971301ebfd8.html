Show HN: Carry – Save every AI conversations as Markdown, in a folder you Own

type: news-summary · created: 2026-11-25 · updated: 2026-11-25 · confidence: high

Summary

Carry advertises automatic local Markdown backups of chats, projects and available files from ChatGPT, Claude, Gemini and Grok, plus cross-provider search and continuation. Its examples show one file per conversation and explicit missing-file markers, aiming to reduce dependence on each provider's export interface.

These are product-page claims, not a tested capture or security audit. Carry says chat content stays on the device but discloses compatibility request metadata sent to carry.md, optional usage counts and licensing metadata sent to Polar. Continuing a chat attaches its transcript to another provider rather than universally importing native history; missing source files remain a coverage limit. No extension was installed, account connected or folder access granted.

Highlights

  • Vendor promises recurring Markdown saves to a chosen folder
  • Projects and retrievable attachments are included in examples
  • Missing downloads are marked rather than guaranteed recovered
  • Provider sessions are used for access
  • Compatibility metadata and optional usage telemetry leave the device
  • Continuation can disclose a transcript to the selected destination AI
  • Local storage claim is not an independent privacy audit
  • No installation or account access was performed
