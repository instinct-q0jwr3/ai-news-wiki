llm 0.37.2

type: news-summary · created: 2026-11-11 · updated: 2026-11-12 · confidence: high

Summary

LLM 0.37.2 fixes two paths that could send a configured OpenAI key to another OpenAI-compatible provider. Simon Willison says the problem could occur when a named provider key was absent, or when a Responses-configured model was invoked with a chat-completions override. The release addresses credential selection across endpoints rather than a model-quality issue.

Highlights

  • Security fix in LLM 0.37.2
  • A missing named key could select the wrong credential
  • A request-mode override exposed a second path
  • Endpoint configuration is the relevant boundary
