Highlights

  • Browser tool that remixes fonts by substituting every Nth glyph from another font
  • Output is a normal OpenType file using a liga contextual substitution enabled by default
  • Runs fully locally with Pyodide and fontTools; can load all Google Fonts
  • Use Y-offset and scale effects to align mixed glyphs
  • Prime-number strides minimize collisions when mixing 3+ fonts (5th and 7th collide on the 35th)
  • Mixing fonts creates a derivative work - check source licenses for commercial use
  • Inspired by Times New Bastard and Easy Pete
