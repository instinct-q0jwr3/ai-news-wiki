Voxtral 3

type: news-summary · created: 2026-10-20 · updated: 2026-10-28 · confidence: high

Summary

Mistral launches Voxtral 3, a family of state-of-the-art speech-to-text and text-to-speech models plus a voice agent SDK that combines listening, reasoning, tool calling, and speaking in a single real-time streaming pipeline across 50+ languages. Mistral's pitch is that a reliable voice agent must do four things simultaneously: listen accurately across accents and interruptions, reason about context, speak naturally with emotion, and act over multiple steps through connected systems. A demo dialogue shows an agent reading a French medical referral, extracting the reference number via tool call, and booking a dermatology appointment. Available through Mistral's EU-hosted API or self-deployment for data sovereignty, targeting contact centers, virtual assistants, and hands-free copilots.

Highlights

  • Voxtral 3: new speech-to-text and text-to-speech models plus a voice agent SDK
