Mo' turns, mo' problems

type: news-summary · created: 2026-10-16 · updated: 2026-10-31 · confidence: high

Summary

A post on reinforcement learning for agents argues the basic loop is simple: give each problem a VM with a harness and fresh context, let the model call tools, score the whole run, update. The difficulty, it says, is that production harnesses are closed and change fast, so recreating their control flow inside an RL framework is impractical.

Highlights

  • RL for agents is simple in theory, hard with closed harnesses.
  • Reimplementing a harness's control flow is impractical.
