Co-Designing Sparse Attention for Efficient Long-Context Inference

type: news-summary · created: 2026-11-18 · updated: 2026-11-21 · confidence: high

Summary

Nvidia explains how sparse-attention architecture and GPU kernels need to be designed together for long contexts. Selecting a small attention subset reduces core attention work but moves substantial cost into an indexer and Top-k selection, with different bottlenecks in prefill and decode.

The examined measurements use specified kernel settings, precision and shapes. They illustrate hardware tradeoffs rather than guarantee an end-to-end speedup on another model. This summary covers the examined design and indexer passages, not an independent reproduction of the complete optimization study.

Highlights

  • Sparse attention shifts rather than removes all cost
  • Indexer still scores the full key context
  • Prefill and decode have different bottlenecks
  • Head count and speculation share hardware capacity
  • Precision and kernel shapes affect results
  • Kernel measurements are not universal application gains
