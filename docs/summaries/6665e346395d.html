How Anthropic’s Dynamic Workflows Coordinate Claude Agents

type: news-summary · created: 2026-10-12 · updated: 2026-10-21 · confidence: high

Summary

At AI Engineer New York, two Anthropic engineers presented dynamic workflows ('flows') for Claude Managed Agents, a feature announced the previous Friday. Instead of developers configuring a coordinator and a fixed roster of subagents, the lead agent plans the job and writes an orchestration program that launches agents, collects their results and routes information between them. The pitch draws on Unix and Linux history: agents working on big projects need the same layers of organization that human maintainers provide, so people don't become the bottleneck approving every pull request.

The demo was a stock watchlist scanner: a scan phase hands each ticker to an agent with an isolated context, then a review phase checks the findings before a report is produced. In Q&A the presenters said the model does not know its own budget while running, so developers set a session budget; the number of agents is controlled through evals and conservative defaults; subagents share a filesystem but can't message each other directly; and every hand-off between lead and subagents can be inspected as a graph in Claude Console. Flows cost much more than a single agent but find more of the details, and Anthropic frames them as a way to throw test-time compute at hard problems. The piece carries a marked Union.ai sponsorship block.

Highlights

  • Claude decides the multi-agent topology itself and writes an orchestration program, rather than a developer-defined roster.
  • Pre-configured subagents can still be passed in through the agent config.
  • The model is unaware of its budget; developers cap spend with a session budget.
  • Subagents share a filesystem but cannot message each other through the API.
  • Claude Console graphs show exactly what the lead agent passed to each subagent.
  • Flows cost much more than one agent but were 'much more effective' at finding details in the demo.
  • Sponsored section by Union.ai is marked as such.
