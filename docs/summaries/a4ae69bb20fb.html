Anthropic's Disproof of the ETH

type: news-summary · created: 2026-10-27 · updated: 2026-10-29 · confidence: high

Summary

A paper claiming to refute the Exponential Time Hypothesis presents a deterministic algorithm for 3-SAT on n variables running in 2^{o(n)} time, and solves the harder counting problem #3-SAT. The result has been formalized in Lean 4.

The provenance statement says the core algorithm was found on October 16 by an internal Claude research model using 14M output tokens with no human input, with Anthropic researchers improving the presentation. It adds that an internal OpenAI model independently and concurrently claims a similar result.

Highlights

  • Claims a deterministic 2^{o(n)} algorithm for 3-SAT, refuting ETH
  • Also solves the harder #3-SAT counting problem; formalized in Lean 4
  • Core algorithm attributed to an internal Claude research model, no human input
  • OpenAI internal model claims a similar result concurrently
