Show HN: Airgap-check – find what your AI app silently downloads offline

type: news-summary · created: 2026-11-10 · updated: 2026-11-10 · confidence: high

Summary

Airgap-check is a Go tool that finds what an AI app downloads or tries to reach when the network is gone. Pointing an LLM URL at local vLLM or Ollama does not make an app offline-ready, because libraries fetch tokenizer data, ONNX weights, corpora, price maps or telemetry on first use, then fail or hang on retry backoff. The tool scans a repo statically, suggests a Dockerfile fix, and with --run executes the app in a container with no network.

Highlights

  • Local LLM does not mean offline-ready
  • Libraries fetch tokenizers, weights and telemetry on first use
  • Static scan, fix snippet, and no-network run
  • Useful for air-gapped, hospital or defense networks
