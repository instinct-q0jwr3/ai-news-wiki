Game developer House House confirms using AI during Big Walk's final development, sparking an intense debate among Independent Games Festival judges and jurors

type: news-summary · created: 2026-11-11 · updated: 2026-11-13 · confidence: high

Summary

House House confirmed it used LLMs sparingly in Big Walk's final stretch to work through technical bugs, estimating well under 0.1% of the game's code touched AI output, with no generative AI used elsewhere. Example: Unity URP culled shadow casters only in front of the camera, rendering the rest at infinite distance and halving frame rate at sunrise and sunset. The disclosure sparked intense debate among fans.

Highlights

  • Under 0.1% of code touched AI output
  • Used for research on third-party code issues
  • URP shadow-caster bug example
  • Disclosure fueled a fan debate
