How Stanford Teaches AI-Native Engineering — Mihail Eric, Monaco

type: news-summary · created: 2026-11-09 · updated: 2026-11-11 · confidence: high

Summary

The same Latent Space special, in a second post: the AI Engineer YouTube channel passed one million subscribers, and the host asks Mihail Eric what a software engineer should learn now. Eric teaches The Modern Software Developer at Stanford and leads AI at Monaco, where colleagues use coding agents to ship software and investigate outages. The post is also a preview of AIE Code in San Francisco.

The first CS146S had nine assignments and a capstone, including running an AI code reviewer on a repo. By the next run students could one-shot many of them, and every sophomore and junior he surveyed already used an agent. So part of the homework is now a contribution to an open-source project, reviewed by its maintainer. The host's point: an agent can build a feature in an afternoon, but you still must learn whether the maintainer wants it and what it might break.
