Show HN: WhatsApp MCP running free on Cloudflare

type: news-summary · created: 2026-10-19 · updated: 2026-10-19 · confidence: high

Summary

A Show HN project that lets an AI agent read your WhatsApp messages through the Model Context Protocol, running entirely inside your own Cloudflare account. You deploy a small Workers server, link your phone once the way you would link WhatsApp Web, and any MCP client (Claude Code, Claude Desktop, others) can then search and read your chats. The design is deliberately privacy-conscious: the server is a linked device that only connects intermittently (on demand and once a day), pulls whatever WhatsApp queued for it, stores it in a SQLite database inside a Cloudflare Durable Object in your account, and disconnects. Your phone stays the source of truth and keeps working normally; the agent can read and search but cannot send. Setup requires a Cloudflare Workers Paid plan, Node 20+, a KV namespace for sign-in tokens and an owner password for the linking page.

Highlights

  • Open-source MCP server giving AI agents read-only access to your WhatsApp chats
  • Runs in your own Cloudflare account; messages live in a Durable Object SQLite database
  • Phone links as a device, exactly like WhatsApp Web, via QR or phone-number code
  • Read/search only - the agent cannot send messages
  • Connects on demand and once daily, then hangs up; the phone stays source of truth
  • First link imports chat history with visible progress
  • Requires Cloudflare Workers Paid plan and Node 20 or later
