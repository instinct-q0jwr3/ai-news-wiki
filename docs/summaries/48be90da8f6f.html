Introducing the Microsoft Copilot harness: Unlocking the potential of truly multi-model agentic work

type: news-summary · created: 2026-10-29 · updated: 2026-10-30 · confidence: high

Summary

Microsoft is productizing the multi-model harness its GitHub engineering team built for its own Copilot fleet. The Microsoft Copilot harness - the orchestration layer that gives an agent its instructions, context, execution environment and controls - already powers Copilot Code, Copilot Studio, the GitHub Copilot app, the CLI and VS Code. It is now available through Microsoft Foundry as a fully managed way to build agents that reason, use tools and run long tasks, with support for open standards like MCP, agent skills and plugins.

The pitch is that the model layer commoditizes faster than anyone can rebuild routing: a frontier model today may fall behind tomorrow, and maintaining your own harness or model router is slow and painful. Customers get the right model for each job without switching harnesses or stacks, while Microsoft's science and engineering investment in the harness compounds across its own products and its customers'.

Highlights

  • Orchestration layer: instructions, context, execution environment and controls for agents
