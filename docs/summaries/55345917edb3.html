Property Testing with Agent Swarms

type: news-summary · created: 2026-10-08 · updated: 2026-10-08 · confidence: high

Summary

An essay by the author of recursion.wtf describes a playbook that lets coding agents find real bugs through property testing. It gives the agent methods for choosing targets, building reference models and generators, and turning failures into reviewable fixes, aimed at code with complex behavior but simple correctness checks, like data structures and query planners.

Run against Codex, it found thirteen correctness bugs, with thirteen upstream reports and twelve proposed fixes. The same recipe on uv, Prometheus and others led to merged fixes, four in uv and two in Prometheus, and a reader found two bugs in KittyCAD code. The results are self-reported but backed by merged upstream changes.

Highlights

  • Playbook for agents to find bugs through property testing
  • Best for complex code with simple correctness checks
  • 13 bugs found in Codex, with reports and proposed fixes
