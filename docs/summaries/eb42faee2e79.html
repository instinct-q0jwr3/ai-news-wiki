Chainalysis: agentic commerce on Coinbase's Base grew from ~1,500 transactions in Q2 2025 to 138M+ in Q3 2026; 87%+ of the payments were for less than 10 cents

type: news-summary · created: 2026-10-15 · updated: 2026-10-18 · confidence: high

Summary

A Chainalysis report says agentic commerce is growing fast, with crypto as the payment layer. On Coinbase's Base chain, cumulative x402 protocol transactions went from about 1,500 in mid-2025 to over 138 million by Q3 2026.

The pattern is developers funding an agent's wallet with stablecoins, mostly USDC, so it can buy compute, web data and code tools on its own.

Highlights

  • x402 transactions on Base passed 138 million.
  • Agents get stablecoin allowances to pay for services.
