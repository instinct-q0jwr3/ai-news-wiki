RL infrastructure at Microsoft AI

type: news-summary · created: 2026-11-24 · updated: 2026-11-25 · confidence: high

Summary

Microsoft AI describes Rocket, its internal reinforcement-learning framework for long post-training runs, including work on the three-trillion-parameter MAI Base 2. The architecture coordinates asynchronous rollouts, a learner and an adapted SGLang inference system, with policy-staleness controls, numerical-consistency work, recovery and runtime reconfiguration.

The engineering report explains design choices for Microsoft's training recipe rather than establishing that one framework is best for all RL workloads. Reported efficiency gains and progress on an aggregate of public and private reasoning evaluations are company measurements, not an independently reproducible public leaderboard. A forecast of passing another model in coming weeks remains a forecast, and this work is explicitly separate from MAI Code 2.

Highlights

  • Rocket targets long RL runs from base capabilities
  • Stale rollouts and numeric mismatch are central problems
  • Microsoft maintains an adapted SGLang inference stack
  • Recovery uses reserved spare capacity
  • Runtime elasticity trades controls against operational overhead
  • Aggregate benchmark includes private evaluations
  • Projected model comparisons are not achieved public results
