Cerebras Disaggregated Inference

type: news-summary · created: 2026-11-18 · updated: 2026-11-18 · confidence: high

Summary

Cerebras describes a production inference design that moves prompt processing to AMD GPUs while Cerebras CS-3 systems generate the response. It reports five times the token throughput per megawatt against a CS-3-only baseline on a specified GPT-OSS-120B endpoint, without reducing generation speed in that deployment.

This is a company-reported configuration comparison, not a universal efficiency ratio against GPU systems or across models. Partner integration options include an end-to-end stack and a decode-only SDK; wider deployment plans for 2027 are future capacity, not current availability.

Highlights

  • Prefill and decode run on different accelerators
  • Reported baseline is a CS-3-only configuration
  • Fivefold result concerns throughput per megawatt
  • Model and configuration limit transferability
  • Partner stack and decode SDK offer different control
  • Broader deployment remains planned
