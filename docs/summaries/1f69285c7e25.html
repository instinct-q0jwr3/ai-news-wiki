Show HN: Get your coding agent off ~2019 JavaScript, onto modern web primitives

type: news-summary · created: 2026-11-10 · updated: 2026-11-12 · confidence: high

Summary

Modern Web Guidance is a Google Chrome-stewarded set of skills that gives coding agents web platform expertise, best practices and browser compatibility data, steering them away from about-2019 legacy JavaScript patterns toward modern web primitives. Mozilla, Microsoft Edge and MDN teams also steward it. Install with an npx wizard, then search and pull guides by topic.

Highlights

  • Skills embed web platform knowledge into coding agents
  • Stewarded by Chrome, Edge, Firefox and MDN teams
