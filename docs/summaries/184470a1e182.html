Google rolls out a Googlebook update that frees up 3GB to 6GB of RAM via on-device AI optimizations, reduces Chrome crashes, patches ~60 Android flaws, and more

type: news-summary · created: 2026-11-09 · updated: 2026-11-13 · confidence: high

Summary

Google's November update for Googlebook frees 3 to 6 GB of RAM by updating the NPU driver and tightening how AICore, the on-device AI service, manages memory, according to Google's Mishaal Rahman on Reddit as reported by Android Central. On a 16 GB laptop that is a real gain.

The update also improves how memory is reclaimed when background AI services compete with Chrome, which should cut unexpected tab reloads and crashes. Other fixes: convertibles losing keyboard and touchpad input when switching modes, and Zoom crashes with virtual backgrounds, blur and 3D avatars. The reviewer says some fixes should have shipped at launch.

Highlights

  • 3-6 GB RAM freed via NPU driver and AICore memory changes
  • Better reclaim when AI services clash with Chrome
  • Fixes lost input in convertible modes
  • Fixes Zoom crashes with backgrounds and avatars
  • On-device AI has a real memory cost
