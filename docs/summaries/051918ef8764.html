Highlights

  • Derives REINFORCE from scratch for an LLM answering 'What is 17 x 24?'
  • Frames the model as a policy: each token is sampled from a distribution over the next token
  • A completion's probability is the product of per-token probabilities along one path in a tree
  • Uses RLVR: a verifier reward returns 1 for correct answers, 0 otherwise
  • The objective J is expected reward; RL borrowed the letter from optimal control
  • Positions PPO and GRPO as elaborations of this single policy-gradient idea
