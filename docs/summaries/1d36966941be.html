Cognition Introduces SWE-2 Flash

type: news-summary · created: 2026-11-05 · updated: 2026-11-13 · confidence: high

Summary

Cognition introduces SWE-2 Flash, a coding model it calls fully American and aimed at low cost and high speed. A new mid-training stage before reinforcement learning lifted the base model, Thinking Machines' Inkling-Small, from 0.9% to 20.0% on Terminal-Bench 4.0 and from 3.2% to 24.0% on FrontierCode 2.0. Cognition says it beats all American open-weight models, including ones 3x larger. Weights will be shared through a program with industry partners and researchers because of cyber risk. Smaller models can handle much agent work such as code review and docs. Available in Devin Desktop and more (cut off).

Highlights

  • Mid-training before RL: Terminal-Bench 4.0 0.9% to 20.0%
  • FrontierCode 2.0 3.2% to 24.0%
  • Built on Thinking Machines' Inkling-Small
  • Weights shared only via a partner program, citing cyber risk
  • Vendor-reported benchmarks
