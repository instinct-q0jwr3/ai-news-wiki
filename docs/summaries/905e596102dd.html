FLUX 3 Image

type: news-summary · created: 2026-10-02 · updated: 2026-10-29 · confidence: high

Summary

Black Forest Labs' FLUX 3 Image adds layout control to text-to-image generation: users place bounding boxes with per-region descriptions, and the model renders the scene following that composition exactly. An example shows a festival poster assembled from a JSON list of boxes - typography, a concrete dome, swimmers, a beach crowd - each rendered where and as specified.

Beyond layout, the release emphasizes strong prompt following, box-by-box local editing (recolor a wetsuit and board while everything else stays unchanged), and the use of up to 10 reference images to steer design, all rendered at full resolution.

Highlights

  • FLUX 3 Image supports bounding-box layout control with per-region text descriptions.
  • Compositions are specified as JSON-like box lists and rendered exactly as laid out.
  • Box-by-box editing changes selected regions while leaving the rest of the image untouched.
  • Accepts up to 10 reference images to guide the generated design.
  • Marketed on strong prompt following and native composition understanding.
  • Renders at full resolution.
