OpenAI launches Images 2.6 in ChatGPT, Codex, and the API, saying it generates images 50% faster, and adds animated GIF creation from prompts or photos

type: news-summary · created: 2026-11-05 · updated: 2026-11-08 · confidence: high

Summary

OpenAI launched Images 2.6 across ChatGPT, Codex and the API. ChatGPT can now make GIFs from a prompt or uploaded photo in a single step, with adjustable speed and frame-by-frame editing. OpenAI says image generation is 50% faster, and users now generate over 4 billion images per week across ChatGPT and its API, up from 3 billion reported in September. The model rolls out to all ChatGPT and Codex users, and the API gets GPT-Image-2.6 Flare and Sunburst for faster and higher-quality generation.

Highlights

  • Images 2.6 in ChatGPT, Codex and the API; image generation reportedly 50% faster
  • ChatGPT can create and edit GIFs (speed, frame by frame)
  • 4B+ images per week, up from 3B in September (OpenAI)
  • API adds GPT-Image-2.6 Flare and Sunburst
