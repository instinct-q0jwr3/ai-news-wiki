Search & Fetch

type: news-summary · created: 2026-10-19 · updated: 2026-10-30 · confidence: high

Summary

DeepSeek's API documentation introduces Search and Fetch APIs that give agents and RAG applications access to live web content. Both are raw JSON APIs on the same base URL and bearer authentication as the DeepSeek chat API. The Search API takes a query, a result count and an optional need_content flag, and returns titles, URLs and summaries; the Fetch API retrieves page content. The design target is explicit: tool-using agents that need current web data without standing up their own crawling and search infrastructure.
