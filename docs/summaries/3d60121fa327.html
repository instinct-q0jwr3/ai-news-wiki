Show HN: Graphicle, a Rust port of Graphify with memory for coding agents

type: news-summary · created: 2026-10-14 · updated: 2026-10-25 · confidence: high

Summary

Graphicle is a Rust port of Graphify that maps a repository into a code graph and remembers docs, decisions and past agent sessions, giving coding agents cited excerpts from both. It runs locally with no API key, account or telemetry and works with Claude Code, Cursor, Codex and MCP clients.

Highlights

  • Code graph plus project memory for coding agents.
  • Runs fully locally; no telemetry.
  • Works through MCP clients.
