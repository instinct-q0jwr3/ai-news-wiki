Enterprise Brain – Memory that learns from work

type: news-summary · created: 2026-11-07 · updated: 2026-11-11 · confidence: high

Summary

AmpUp pitches 'Enterprise Brain', a shared memory layer for coding agents (Claude Code, Codex, Gemini CLI, Cursor, Copilot) that builds on a company's existing context graph and catalogs. Memory is versioned, and agent trajectory records are stored with the memory version they ran against, so teams can evaluate performance and train custom models from the same records.

The headline numbers are the company's own: root-cause accuracy on ORCA-bench rose from 6.3% to 35.2% after three days of graded practice, and CRM question accuracy on CRMArena-Pro from 57.6% to 76.7%. AmpUp says broader leaderboard standing has not been independently verified, so treat these as vendor claims.

Highlights

  • Shared, versioned memory for coding agents across several tools.
  • Trajectory records are pinned to the memory version used.
  • ORCA-bench root-cause accuracy: 6.3% to 35.2% (vendor figure).
  • CRMArena-Pro accuracy: 57.6% to 76.7% (vendor figure).
  • AmpUp says leaderboard standing is not independently verified.
