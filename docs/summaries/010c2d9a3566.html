Strata — memory is explicit I/O

type: news-summary · created: 2026-11-15 · updated: 2026-11-24 · confidence: high

Summary

Strata explores a processor design in which memory movement is explicit rather than hidden behind predictive caches. The accessible project excerpt describes per-core 64 KiB data and instruction Local Stores, with software responsible for deciding what resides there.

The Lobsters submission says a directed LLM process helped produce a much larger prototype spanning emulation, RTL, a microkernel and language tools. Those implementation and speed-of-development claims come from the submission; the short extracted project page is not enough to assess completeness, correctness or performance.

Highlights

  • Local Stores make movement software-visible
  • Data and instruction stores are distinct
  • Submission credits a directed LLM process
  • Broad prototype claims remain author-reported
  • No performance advantage is established
