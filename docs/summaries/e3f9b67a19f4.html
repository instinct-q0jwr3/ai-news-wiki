Cve.now: A Free Feed of Security Vulnerabilities for Agents

type: news-summary · created: 2026-10-26 · updated: 2026-10-27 · confidence: high

Summary

cve.now is a free vulnerability feed built for agents and the teams running them. It merges siloed sources - the CVE List, CISA's known-exploited catalog, EPSS exploit-probability scores and OSV - into one searchable, filterable stream, adds a plain-English explanation of each vulnerability, and ships as RSS, JSON, an API and an MCP server so a coding agent can check exposure directly. No login, signup or API key.

The launch post makes the timing concrete by replaying October 21st, a rough day for anyone running production software: PHP2Shell, two core PHP bugs allowing command execution with a single POST request, with an exploit attempt seen four days before disclosure; a LiteLLM supply-chain attack that pushed a credential-stealing 1.107.0 to PyPI and Docker; a Node.js security update across three release lines fixing ten vulnerabilities including a Brotli decoder RCE; and Railway's disclosure of unauthorized access to internal systems. The argument: agents that write and deploy code need this feed as much as humans do, and it should cost nothing.

Highlights

  • cve.now merges the CVE List, CISA KEV, EPSS and OSV into one agent-consumable vulnerability feed
  • Each entry gets a plain-English explanation; consumption via RSS, JSON, API and an MCP server
  • Completely free: no login, signup or API key
  • Launch pegged to October 21st: PHP2Shell RCEs, the LiteLLM 1.107.0 supply-chain attack, a Node.js multi-line security update, and the Railway breach
  • LiteLLM's malicious release stole cloud and AI credentials from anyone who ran it
  • Attackers had a four-day head start on PHP2Shell, with an exploit attempt before public disclosure
