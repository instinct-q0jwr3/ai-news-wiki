Eliminating Nondeterminism in LLM Inference with Integer-Only Arithmetic

type: news-summary · created: 2026-11-13 · updated: 2026-11-13 · confidence: high

Summary

DetLLM explores integer-only inference as a way to make model outputs bit-identical across hardware and batch configurations. The author explains how floating-point rounding can change with reduction order, allowing a different winning token even under greedy decoding.

The project replaces arithmetic throughout the inference path rather than merely fixing one GPU's kernel order. Its demonstrations support reproducibility in the tested configurations, not a claim that numerical agreement guarantees correct answers or that every model can be converted without tradeoffs.

Highlights

  • Floating-point order can change token selection
  • Batch invariance differs from repeatability on one setup
  • Integer arithmetic targets cross-platform agreement
  • Conversion covers more than matrix multiplication
  • Determinism does not imply factual correctness
