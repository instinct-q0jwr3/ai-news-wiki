Show HN: Skillset: Easily curate and install agent skills collection

type: news-summary · created: 2026-11-16 · updated: 2026-11-18 · confidence: high

Summary

Skillset wraps Vercel’s Skills CLI to install reusable collections of agent skills from a JSON manifest. Repository sources can be pinned to commits, and collections can be shared within a project or kept separately for reuse across projects.

The project describes explicit updates, installation choices and lockfile recording. Local paths and direct downloads cannot be pinned, and the underlying CLI has its own telemetry behavior. Reproducible selection is distinct from evaluating whether a skill’s instructions or source code are trustworthy.

Highlights

  • Collections use a JSON manifest
  • Repository revisions can be pinned
  • Updates are explicit rather than automatic
  • Local sources have pinning limits
  • Dependency telemetry and content trust remain separate concerns
