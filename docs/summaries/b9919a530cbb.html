Building a RAG pipeline for semantic code search

type: news-summary · created: 2026-10-04 · updated: 2026-10-05 · confidence: high

Summary

JetBrains starts a series on building Air Context, a RAG pipeline for semantic code search that gives LLM agents precise, citable evidence from real repositories instead of whatever grep happens to find. Part one covers parsing, chunking and vectorization, framed as lessons from getting it into production.

The argument is that as development becomes agent-driven, the question is less whether an agent can finish a task and more how much time, effort and steering it needs, and on large code bases much of that goes into searching. Only the opening was read.

Highlights

  • Air Context is JetBrains' semantic code search for agents.
  • Goal: citable evidence rather than grep results.
