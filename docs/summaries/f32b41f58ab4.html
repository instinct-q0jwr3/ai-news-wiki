Claude now works with Google Docs, Sheets, and Slides

type: news-summary · created: 2026-10-07 · updated: 2026-10-10 · confidence: high

Summary

Claude for Google Workspace enters public beta on paid Claude plans, placing a sidebar inside Docs, Sheets and Slides. It can work with the open file and selected content: edit document passages, write formulas and charts, or build slides using a deck's layouts. Larger document edits can be presented as suggestion cards.

Separate beta connectors let users start in Claude and create or edit Google files. The default mode asks before edits, while an accept-all mode applies changes without pausing. The announcement also describes inherited account tools and enterprise controls. These are announced capabilities; file fidelity and task quality have not been tested here.

Highlights

  • The add-on is a public beta for paid Claude plans.
  • Sidebar use and Claude-side connectors are separate routes.
  • The current selection provides editing context.
  • Ask-before-edits is the stated default.
  • Accept-all-edits changes the approval behavior.
  • The article describes enterprise controls applying to the add-on.
