OpenAI prices GPT-6.1 Sol at $2/1M input and $10/1M output tokens, the same as GPT-6 Sol and Claude Sonnet 5.5, and says it performs well on safety tests

type: news-summary · created: 2026-09-29 · updated: 2026-10-10 · confidence: high

Summary

OpenAI prices GPT-6.1 Sol at $2 per million input and $10 per million output tokens - identical to GPT-6 Sol and Claude Sonnet 5.5 - positioning it as near-Astra intelligence at a fifth of the cost while the flagship Astra stays shelved over safety problems. OpenAI claims Sol comes close to Astra in agentic coding, computer use, and office work. Cached input is $0.10, 95% below uncached (Sonnet 5.5 charges $0.20), which specifically helps agents that reuse context across many requests. Sol is available today in ChatGPT Work and Codex for paid tiers (not regular chat yet) and in the API as gpt-6.1-sol, with an Ultrafast version noted.
