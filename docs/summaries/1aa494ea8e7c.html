Do Agent Teams Pay Off? A Case Study on Vibe Code Bench

type: news-summary · created: 2026-10-12 · updated: 2026-10-27 · confidence: high

Summary

Do agent teams pay off? Both OpenAI and Anthropic now ship native multi-agent support - a lead agent spawning subagents, handing each a part, and assembling the returns - and this case study measures what that buys, costs, and helps on Vibe Code Bench, a benchmark for building complete web apps from a product spec, deployed with Docker Compose and graded by browser agents clicking through real workflows.

Setup: GPT 6 Sol and Claude Opus 5.5 each ran 50 apps as a single agent and as a team (lead plus up to five subagents, which cannot spawn their own), at medium and max reasoning effort. Both leads got the same instruction: split the work into independent parts, delegate, integrate and verify. Because the apps split naturally into database, API, interface and deployment, seam bugs show up directly in the score - a clean test of whether coordination overhead beats parallel throughput.

Highlights

  • Case study: single agent vs agent team on 50 full web-app builds (Vibe Code Bench).
  • Models: GPT 6 Sol and Claude Opus 5.5, medium and max reasoning effort.
  • Teams: one lead, up to five subagents, no recursive spawning.
  • Apps graded by browser agents clicking through deployed workflows.
  • Natural split (DB, API, UI, deploy) exposes seam bugs in the score.
