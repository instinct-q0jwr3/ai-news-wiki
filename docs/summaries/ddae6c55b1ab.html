web-edit 0.1a0

type: news-summary · created: 2026-10-13 · updated: 2026-10-14 · confidence: high

Summary

Simon Willison releases web-edit 0.1a0, a Python web app with a UI for viewing and editing files in a folder. He built it, with Codex and GPT-6 Astra Extra High, after wanting to edit a credentials file from his phone via Codex Remote without passing the credentials through the model.
