Show HN: Durable Actors – OSS Durable Objects with configurable compute

type: news-summary · created: 2026-10-07 · updated: 2026-10-08 · confidence: high

Summary

Two founders from Terse introduce Durable Actors, an open-source alternative to Cloudflare's Durable Objects. A durable actor is a small server that handles one request at a time and owns its own SQLite database, with exactly one instance per identifier.

The pitch in the Hacker News post is the same programming model without being tied to Cloudflare, plus configurable compute. Basis: the founders' post text and the repository link; the code and docs were not read in detail.

Highlights

  • Open-source alternative to Cloudflare Durable Objects
  • Each actor handles one request at a time with its own SQLite database
  • Exactly one instance per actor identifier
  • Configurable compute is the stated difference
  • Based on the launch post, repository not reviewed
