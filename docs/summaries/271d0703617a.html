Microsoft agentically ports Copilot runtime to Rust for $120K

type: news-summary · created: 2026-09-20 · updated: 2026-09-26 · confidence: high

hacker-news microsoft agentic-systems

Summary

Microsoft has rewritten the runtime behind GitHub Copilot from TypeScript to Rust, and most of the porting was done by AI agents. The migration cost about $120,000 in AI tokens plus roughly three weeks of developer time, and converted 430,000 lines of TypeScript into 800,000 lines of production Rust across 135 releases over 14.5 weeks. The runtime is not a niche component: it backs the Copilot CLI, the Copilot app, the SDK and the cloud agent, and surfaces in VS Code, Visual Studio, Excel, Outlook and PowerPoint.

The results make the case for Rust at scale: one benchmark went from 7.55 to 120 completed session lifecycles per second (a 15.9x speedup), and a 10-client agent batch dropped from 1,383 MB to 126 MB of memory. The project is also a data point on agent-led engineering: Microsoft Distinguished Engineer Stephen Toub reports agents spent more time investigating than writing code, spawned and coordinated child sessions on their own, and still shipped a few dozen regressions, a reminder that a compiling Rust program is not necessarily a correct one.

Highlights

  • Cost: about $120,000 in AI tokens plus ~3 weeks of a developer's time; a manual port was estimated at years and millions of dollars.
  • Scope: 430,000 lines of TypeScript became 800,000 lines of Rust over 135 releases in 14.5 weeks, about 1.3 port PRs per day.
  • Performance: 7.55 to 120 one-turn session lifecycles per second on a 100-concurrent-pipeline benchmark, a 15.9x speedup.
  • Memory: a 10-client agent batch fell from 1,383 MB (TypeScript) to 126 MB (Rust).
  • Agents did most of the work using several models, including GPT-5.6 Sol and Claude Opus 4.8, chosen per task.
  • Hardest file: session.ts (30,000+ lines) took a 25-hour session that spawned 15 child sessions which coordinated with each other.
  • Caveat: dozens of regressions slipped through; Rust's compiler guarantees memory safety, not program correctness (Lisa Crossman's RustConf warning quoted).
  • Related: Bun's 535,000-line Zig-to-Rust port, also agent-driven, cost $165,000 in tokens and passed 99.8% of tests.
