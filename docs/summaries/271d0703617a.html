Microsoft agentically ports Copilot runtime to Rust for $120K

type: news-summary · created: 2026-09-20 · updated: 2026-09-20 · confidence: high

hacker-news microsoft agentic-systems

Summary

devops The Rust compiler remains unperturbed by the antics of the LLM The software engine underpinning GitHub Copilot and a growing number of Microsoft products is now written entirely in Rust, with AI agents doing most of the porting work. However, managers also had to grapple with a few dozen regressions in the resulting code, pointing to AI’s ongoing challenges in understanding Rust.

Overall, agents converted 430,000 lines of TypeScript into 800,000 lines of production Rust.

Highlights

  • The migration cost about $120,000 in AI token usage plus about three weeks of a developer's time.
  • The effort updated the runtime module-by-module until the job was completed, spanning over 135 releases across a 14.5-week time period.
  • Roughly 1.3 port pull requests were opened per day.
  • To keep the port as simple as possible, the port only replaced TypeScript modules on a case-by-case basis.
  • It didn’t look to optimize the structure of the runtime itself.
  • And Rust, known for its lean performance, did not disappoint.
  • The original TypeScript implementation completed 7.55 of those lifecycles per second, while Rust running in-process managed 120 per second - representing a 15.9x speedup on that particular workload.
  • Within Rust, the work remained in-process instead of spawning external background processes for completion, a requirement for TypeScript.
