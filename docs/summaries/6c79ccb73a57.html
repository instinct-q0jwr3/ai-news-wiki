Anthropic says a malicious actor used access to Cursor's marketplace to publish a "tampered" copy of the Claude Code extension, which it didn't build or publish

type: news-summary · created: 2026-10-31 · updated: 2026-10-31 · confidence: high

Summary

Anthropic has given its own account of the Claude Code extension incident, via engineer Felix Rieseberg: 'We're working with Cursor on this incident, but it wasn't a compromise of Anthropic's systems or employee laptops. A malicious actor used access to Cursor's marketplace to publish a tampered copy of the Claude Code extension, which we didn't build or publish.' The versions on Anthropic's official channels, the statement continues, were not the tampered ones.

This is the company's first public word on the incident and it aligns with Cursor's notice, which put the exposure at at most 5,000 users and said the malicious version was not developed by Anthropic. Between the two statements the marketplace vector is settled; reports from some researchers that the same version also appeared on Open VSX remain those researchers' claims, not addressed by either company.
