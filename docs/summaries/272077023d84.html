Show HN: Proton Drive for Linux

type: news-summary · created: 2026-10-10 · updated: 2026-10-10 · confidence: high

Summary

A developer has built an unofficial FUSE virtual filesystem that mounts Proton Drive as a local folder on Linux, something Proton does not itself offer. Files and folders are listed from Proton's metadata, but contents download lazily, only when read, saving bandwidth and disk space.

Remote changes reach the mount through Proton's event feed, which invalidates affected directory listings and cached content, and writes are buffered locally and uploaded in full when the file closes. The author warns the project is early and unofficial, tested only on common operations on one share, and asks for bug reports.

Highlights

  • Unofficial FUSE mount for Proton Drive on Linux
  • Lazy downloads: file content fetched only on read
  • Proton's event feed keeps the mount in sync
  • Writes buffered locally, uploaded on close
  • Early and unofficial; expect bugs
