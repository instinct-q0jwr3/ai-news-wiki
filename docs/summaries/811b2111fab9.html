Summary

Simon Willison released llm-anthropic 0.31, adding Claude Fable 5.2 and Mythos 5.2. He ran pelican-on-a-bicycle SVG tests at five reasoning levels; the best came from xhigh. The max level failed to return an image after using 128,000 tokens thinking, the same bug he saw with Opus 5.5 but new to the Fable series.
