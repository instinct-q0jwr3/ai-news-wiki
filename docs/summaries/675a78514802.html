Show HN: Automatic deduction of FlashAttention kernel from ~25 lines of SQL

type: news-summary · created: 2026-10-30 · updated: 2026-10-30 · confidence: high

Summary

A Show HN demo automatically derives a FlashAttention kernel from about 25 lines of SQL expressing vanilla attention. The deduction rests on three portable SQL extensions the team is building: xarray-sql, a library representing petabyte-scale array datasets in the cloud as relational tables; ddx, which adds JAX-style automatic differentiation to standard SQL on that array model; and einfold, a modular query planner for fast tensor contractions in vanilla SQL. The cached page is the GitHub file view (code chrome), so the mechanism is summarized from the project's own description.
