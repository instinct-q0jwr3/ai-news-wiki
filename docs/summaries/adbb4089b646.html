What thousands of conversations look like inside a language model

type: news-summary · created: 2026-11-15 · updated: 2026-11-18 · confidence: high

Summary

An exploratory Qwen3-1.7B visualization maps internal token representations across constructed conversations in several languages. The author records normalized final-token states and places datasets in one shared PCA frame so adding another language does not silently rotate the comparison axes.

The initial English paths appear nearly planar in the three-dimensional projection, but that observation is explicitly about the projection, not the full 2,048-dimensional state space. The deliberately small sample and visualization choices limit any claim about universal model geometry or a model’s understanding.

A later full-space check sharpens that warning: the displayed three directions preserve 17.6% of final-token variation, and even the best full-space plane captures 28.7%, with 28.4% on held-out topics. Refitting PCA on conversation averages rather than a vocabulary-heavy point set also changes the visible relationships. The geometry is sensitive to what the map is optimized to preserve.

Highlights

  • Experiment uses a frozen Qwen model
  • Sample covers selected topics and languages
  • Shared PCA axes support visual comparison
  • Projected flatness is not full-space flatness
  • Constructed sample limits generalization
