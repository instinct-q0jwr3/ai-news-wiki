type: news-summary · created: 2026-10-15 · updated: 2026-10-29 · confidence: high

Summary

This is a second report of the same CNBC interview: Bank of America added 1,000 contractors in the second quarter to patch software vulnerabilities surfaced by advanced AI models, Mythos among them.

The piece adds the caution that the spending combines Mythos remediation with anti-money-laundering work, so it should not be read as the model's standalone price.
