DeepSeek just open-sourced its inference engine

type: news-summary · created: 2026-10-20 · updated: 2026-10-21 · confidence: high

Summary

DeepSeek has open-sourced DeepInfer, the inference framework that runs its large-scale production services. The release provides offline inference with the core features needed for serving at scale, while explicitly leaving out some pieces required for a complete inference service. It targets NVIDIA and Ascend accelerators, expects a clean Python 3.12 environment, and pulls the default DeepSeek-V4.1-Flash-1017 checkpoint from the Hugging Face cache on first run. Published benchmarks were measured on SM100 GPUs, split across 4 prefill and 64 decode devices within one scale-up domain, with a sweep script for reproduction. The framework was originally built on vLLM, with additional inspiration from SGLang and TensorRT-LLM, and ships under Apache 2.0.

Highlights

  • DeepSeek's production inference stack is now open source
  • Release covers offline inference; some full-serving components are excluded
  • Runs on NVIDIA and Ascend hardware via an accelerator environment flag
  • Benchmarks measured on SM100 GPUs: 4 for prefill, 64 for decode
  • Default checkpoint is DeepSeek-V4.1-Flash-1017, cached from Hugging Face
  • Lineage: built primarily on vLLM, inspired by SGLang and TensorRT-LLM
  • Apache License 2.0
