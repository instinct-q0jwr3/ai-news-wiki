The fx adapter now runs the harness on the host

type: news-summary · created: 2026-10-30 · updated: 2026-10-30 · confidence: high

Summary

Vercel's fx adapter for the AI SDK's HarnessAgent now runs the harness on the host: built on libfx, the TypeScript library for fx, the harness and model requests execute in the application's own process while filesystem and shell operations stay isolated in the sandbox. Setup gets simpler - no fx install inside the sandbox, no sandbox bridge, no exposed port - and, importantly, model credentials remain on the host, outside the environment where the agent runs commands.

The rewrite adds tool filtering (choose which built-in tools the agent gets), mid-turn steering (send new instructions while a turn runs), structured output, image tool results via toModelOutput(), and sessions that can be saved and resumed in a new host process.

Highlights

  • fx adapter for the AI SDK HarnessAgent now runs the harness in the host process
  • Filesystem and shell stay sandboxed; model credentials never enter the sandbox
  • No fx install in the sandbox, no bridge, no exposed port
  • Adds tool filtering, mid-turn steering, structured output and image tool results
  • Sessions can be saved and resumed in a new host process
