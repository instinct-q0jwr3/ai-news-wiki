AI-assisted proof of optimal packing for 11 squares

type: news-summary · created: 2026-10-07 · updated: 2026-10-09 · confidence: high

Summary

A GitHub repository publishes a Lean formalization of the optimality proof for packing 11 squares into the smallest square. The README says the complete proof passed verification: a run accepted all 7,920 local Lean modules, with zero admissions in the final audit.

The optimal side length comes from a closed formula with a root of an eighth-degree polynomial, about 3.877. Some costly numerical certificate checks use Lean's native_decide, so the final theorem relies on Lean's kernel plus its native compiler, which the authors say is not a kernel-only verification. Geometry, checker soundness and proof assembly use ordinary Lean proofs. Hacker News framed it as an AI-assisted proof; the README excerpt does not itself describe the AI's role.
