Show HN: Rhun, an open-source code editor written in assembly

type: news-summary · created: 2026-10-02 · updated: 2026-10-09 · confidence: high

Summary

Rhun is a small code editor written in assembly for Windows, Linux and macOS. It has tabs, syntax highlighting, fuzzy search, an optional Vim mode and 39 themes, and runs builds, shell commands and coding agents beside the code.

AI is optional but integrated: it can follow Claude Code and Codex sessions as they work, and draft commit messages with local open-weight models or those tools via existing subscriptions. The pitch is that the agent does the heavy lifting while the editor stays light.

Highlights

  • Open-source editor written in assembly; Windows, Linux, macOS.
  • Tabs, syntax highlighting, fuzzy search, optional Vim mode, 39 themes.
  • Runs builds, shell commands and coding agents next to the code.
  • Follows Claude Code and Codex sessions; AI features are optional.
  • Diff review, staging and commit built in.
