Ask HN: When does your app need its own UI vs. using it via MCP?

type: news-summary · created: 2026-11-19 · updated: 2026-11-28 · confidence: high

Summary

An Ask HN thread asks when an application should offer its own interface rather than expose functions through MCP. The few replies favor alternatives such as documented command-line access and treating agent access as an additional interface.

This is a small discussion, not evidence of a market consensus or measured user preference. Application audience, interaction needs and access costs remain unresolved design choices.

Highlights

  • Thread poses an interface-design question
  • Replies suggest complementary access modes
  • Sample is very small
  • No market consensus is established
  • Design depends on the intended users
