Making My Blog Readable by AI Agents

type: news-summary · created: 2026-10-25 · updated: 2026-10-29 · confidence: high

Summary

The author of the Deallocated Objects blog spent an evening making the site readable for AI agents (Claude, ChatGPT, Perplexity and friends), and the write-up is a practical recipe for any static site. Every post now also exists as plain markdown via an .md suffix, with YAML frontmatter carrying title, canonical URL, author, dates and description. The neater trick is content negotiation: an nginx map rewrites to the .md file when the Accept header asks for text/markdown, with Vary: Accept so caches never mix the two, and Link canonical plus X-Robots-Tag: noindex on the markdown so search engines don't see duplicates.

The site also publishes /llms.txt (a markdown index explaining what the site is, how to get markdown, citation preferences and a one-line summary of every post), /llms-full.txt (all posts in one 225 KB file) and /index.md, with a Link header on every response pointing at llms.txt. robots.txt explicitly allows the major AI crawlers and adds a Content-Signal line (search=yes, ai-input=yes, ai-train=yes) - the author wants to be cited, while noting a product site might choose differently. Feeds got markdown alternates too (Atom summary links and a JSON Feed _markdown_url). The pass also fixed inherited issues: rebuilt descriptions from rendered text, removed maximum-scale=1 so phones can pinch-zoom, and added og:image.

Highlights

  • Every post now has a markdown version at the same URL plus .md, with YAML frontmatter.
  • nginx content negotiation serves markdown when Accept: text/markdown, with Vary: Accept to keep caches honest.
  • Markdown responses send Link canonical and X-Robots-Tag: noindex to avoid duplicate-content penalties.
  • /llms.txt describes the site, citation preferences and every post; /llms-full.txt bundles all posts (~225 KB).
  • robots.txt explicitly allows AI crawlers and adds Content-Signal: search=yes, ai-input=yes, ai-train=yes - the author wants citations.
  • Atom and JSON Feeds now link markdown alternates per item (_markdown_url custom key).
  • Side fixes: descriptions rebuilt from rendered text, maximum-scale=1 removed for pinch-zoom, og:image added.
