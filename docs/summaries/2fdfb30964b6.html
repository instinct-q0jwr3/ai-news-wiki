How We Took Over ChatGPT Accounts

type: news-summary · created: 2026-11-01 · updated: 2026-11-11 · confidence: high

Summary

Simon Willison's annotation of the Parameter Labs ChatGPT exploit is the clearest short version of the chain, and it completes details the original write-up's summary left out. The vulnerable feature is ChatGPT's artifacts pattern - now called HTML previews - where custom HTML apps run in a sandboxed iframe. The graph feature loads the MathLive library, whose virtual keyboard can be triggered in the parent page via postMessage from the sandboxed frame; the receiver writes attacker HTML with innerHTML. That alone does not execute script elements - but it can inject a new iframe without sandbox restrictions.

Then the CSP dance: OpenAI's content security policy blocked inline scripts and allowed script loading only from a handful of domains, one of them YouTube - and YouTube's oEmbed endpoint could be made to reflect JavaScript back in an executable form. With script execution on chatgpt.com achieved, pulling private data from the authenticated APIs and exfiltrating it via an image reference was trivial. Willison closes with the bounty: OpenAI paid $5,000, which he calls a bit cheap for a one-click account takeover this serious.

Highlights

  • Willison's summary fills in the full chain: MathLive postMessage, innerHTML injection, unsandboxed iframe
  • The CSP bypass: script loading allowed from YouTube, whose oEmbed endpoint reflected executable JavaScript
  • The vulnerable feature is the artifacts pattern, now called HTML previews
  • Once script ran on chatgpt.com, exfiltration via an image reference was trivial
  • OpenAI paid a $5,000 bounty - Willison: cheap for a one-click account takeover
