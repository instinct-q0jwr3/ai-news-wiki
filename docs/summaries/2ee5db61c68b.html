Using Parseable with Datasette for OpenTelemetry traces

type: news-summary · created: 2026-10-06 · updated: 2026-10-17 · confidence: high

Summary

Simon Willison connects two pieces: Parseable, a new observability platform with an open-source (AGPL) Rust implementation shipping as a single ~180MB binary, and Datasette 1.0a41, which recently gained OpenTelemetry support thanks to Alex Garcia. He had Codex figure out how to run Parseable and pipe Datasette traces into it, then documented the working patterns in a human-written TIL.

The result is Datasette traces viewable inside Parseable's localhost web UI - a fully self-hosted observability stack for a self-hosted data tool.

Highlights

  • Parseable is a new observability platform: AGPL Rust core, single ~180MB binary, plus enterprise and cloud options.
  • Datasette 1.0a41 added OpenTelemetry tracing support (contributed by Alex Garcia).
  • Willison used Codex to work out the Parseable + Datasette integration.
  • Patterns that worked are documented in a TIL post.
  • Screenshot shows a Datasette trace rendered in Parseable's web app.
