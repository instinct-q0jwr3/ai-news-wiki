An interview with Microsoft CEO Satya Nadella on the Nvidia RTX Spark-powered Surface Laptop Ultra, plans to make Windows a safer OS to run AI agents, and more

type: news-summary · created: 2026-10-18 · updated: 2026-10-29 · confidence: high

Summary

Joanna Stern interviews Microsoft CEO Satya Nadella about the new Surface Laptop Ultra - powered by an Nvidia RTX Spark chip - and Microsoft's plan to make Windows a safer operating system for running AI agents. The framing: with a billion-plus Windows machines, the OS is both a target for rogue agents and the place those agents will do their work.

The conversation also ranges over AI risk more broadly - 'whether AI will kill us' - and, inevitably, Clippy.

Highlights

  • Microsoft plans to make Windows safer for running AI agents
  • Windows' billion-device footprint makes it both target and host for rogue agents
  • Also covers AI risk and Clippy
  • Published in Joanna Stern's The New Things
