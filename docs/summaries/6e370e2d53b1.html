datasette-llm 0.1a11

type: news-summary · created: 2026-11-15 · updated: 2026-11-18 · confidence: high

Summary

Simon Willison announces OpenAI-compatible endpoint support in datasette-llm 0.1a11, the configuration layer used by other Datasette plugins. This lets a Datasette application select a locally or remotely hosted model through the same API-style interface.

The example combines Datasette Agent with a local model server. Compatibility with the protocol is the key addition, not a claim that every model supports the same tools, performs equally well or keeps data local when pointed at a remote endpoint.

Highlights

  • Release adds configurable compatible endpoints
  • Plugin supplies models to other plugins
  • Local servers are one supported use case
  • Protocol compatibility differs from model capability
  • Data location depends on endpoint choice
