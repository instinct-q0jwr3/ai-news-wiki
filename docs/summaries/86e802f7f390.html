dsh-superagent

type: news-summary · created: 2026-11-02 · updated: 2026-11-06 · confidence: high

Summary

DeepSeek has put the Super-Agent code on GitHub - the research prototype behind yesterday's Bloomberg story - with disclaimers that read like a lawyer and an engineer negotiated them: this is a research prototype for reference only, not an official DeepSeek product; much of the engineering was done by coding agents; expect bugs and inconsistent style; and the published code is adapted, not identical to the internal version or to the system described in their writeup 'Exploring Super-agent Design.'

What the prototype actually is: a proactive coding agent for one GitHub repository, packaged as a bundle for DeepSeek Harness. It listens to GitHub and optionally to Feishu; when an allowed user asks for work, it opens a work item, works in its own agent session and directory, and answers back in the original conversation - the group-chat monitoring behavior Bloomberg flagged, in reference form. The honest packaging is the news alongside the code: the industry leader in open weights is handing out its autonomy research as inspectable, explicitly-not-production software.
