How I made it possible to pretrain a 1B LLM on 6GB VRAM

type: news-summary · created: 2026-10-26 · updated: 2026-10-30 · confidence: high

Summary

A hobbyist with a 6GB gaming laptop set out to do what every guide said was impossible: pretrain a language model from scratch - not fine-tune, not rent - on consumer hardware. Every forum said you need an A100, a cluster, or at least 24GB. Instead, the author opened Claude and started asking whether that was actually true, or just unchallenged assumption.

Weeks later, it is not a joke anymore: a working pipeline that pretrains a 1.1 billion parameter model in 6GB of VRAM, with real steps, checkpoints, and kill-and-resume, documented with a 30-minute run video, code on GitLab, and a DOI on Zenodo. The piece is both a how-to and an argument that the hardware floor for serious ML experimentation is much lower than consensus claims.

Highlights

  • A 1.1B parameter LLM pretrained from scratch on a 6GB gaming laptop GPU
  • The author challenged the universal 'you need a real GPU' advice, working through it with Claude over weeks
  • The pipeline does real training steps, checkpointing, and kill-and-resume
  • Fully documented: 30-minute run video, GitLab code, Zenodo DOI
  • An existence proof that the hardware floor for pretraining is far below consensus
