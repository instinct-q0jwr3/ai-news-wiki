Show HN: Lasm – Write formally verified webapps in Lean for Node/serverless/edge

type: news-summary · created: 2026-10-30 · updated: 2026-10-31 · confidence: high

Summary

Lasm compiles ordinary Lean 4 programs ahead of time to WebAssembly, so one Lean codebase can become a Node server, a serverless or edge function, a WASI module or a browser app - and because it is Lean, you can prove properties of the code you deploy. The flagship example is Conduit, the RealWorld Medium clone, written entirely in Lean with 117 proved theorems, all running in CI against each platform's own local runtime or emulator (project policy: CI never deploys to a real cloud account).

Node builds get Lean's full runtime - threads, files, processes, sockets - while edge, Bun/Deno, WASI and browser builds run single-threaded without sockets or processes. Lasm ships on npm with Lean, Lake and build tools included, and the README is explicitly written for AI agents, with an llms.txt index and a docs/AI.md of rules to keep agents from wrong turns - fitting the author's thesis that formal verification is the next evolution of software engineering, enabled by LLMs that understand it.

Highlights

  • Lasm compiles Lean 4 to WebAssembly for Node, serverless, edge, WASI and browser
  • Prove properties of the deployed code itself
  • Flagship: Conduit RealWorld app with 117 proved theorems, all green in CI
  • Full Lean runtime on Node; single-threaded, socket-less on edge/browser
  • npm distribution, batteries included; README and llms.txt written for AI agents
  • Author's bet: LLMs that understand formal verification make it practical
