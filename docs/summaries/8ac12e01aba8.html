The Tmux Menagerie

type: news-summary · created: 2026-09-25 · updated: 2026-10-03 · confidence: high

Summary

Scott Werner makes the case for tmux as the natural habitat of agentic development. Physicists talk about parallel universes, but tmux users actually live in multiple realities at once - and modern agentic coding is exactly that: you are cooking dinner, answering a text, and remembering the cat, except the cat is a Claude Code instance and it is definitely hungry. Computers context-switch thousands of times a second; humans are stuck with tools designed for one terminal window.

His 'Tmux Menagerie' workflow - presented to Latent Space's AI In Action Club - is fifteen years of refinement applied to the new problem of supervising several AI agents in parallel: named sessions and windows per project, quick jumps between them, and a layout where every agent's output stays visible and recoverable.

Highlights

  • tmux as the habitat for parallel agentic coding.
