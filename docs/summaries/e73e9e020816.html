Summary

Marginalia's October 26 project update discusses donations, API-key demand and an exploratory move of index components from Java to C++. The author links query performance to how many candidate results can be ranked, while emphasizing incremental work, measurement and familiarity with the language.

The rewrite is undecided and may be abandoned; the post explicitly doubts a large speedup and supplies no completed benchmark demonstrating one. Comments about AI-assisted coding express the author's preferences, not a controlled productivity comparison. The project lacks analytics establishing where new users come from, so suggested effects from model-generated recommendations remain speculation.
