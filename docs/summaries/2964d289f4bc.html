OpenAI unveils Decisions API, which returns predefined answers with confidence scores, available in limited preview with no pricing details

type: news-summary · created: 2026-09-29 · updated: 2026-09-30 · confidence: high

techmeme openai typesafe ai-price-war

Summary

OpenAI announced a Decisions API at DevDay - its answer to the decision-model category TypeSafe's Jev made hot. The API returns predefined answers with confidence and is based on Luna, the smallest and cheapest model in OpenAI's lineup. The New Stack reads it as a reactive, possibly rushed announcement: for now OpenAI is sharing little beyond the concept, though a spokesperson confirmed the Luna foundation.

Highlights

  • OpenAI's Decisions API returns predefined answers with confidence scores
  • Based on Luna, the smallest and most affordable OpenAI model
  • A response to the decision-model category created by TypeSafe's Jev
  • Announced at DevDay with minimal detail so far
