The OpenAI proofs are us

type: news-summary · created: 2026-10-08 · updated: 2026-10-10 · confidence: high

Summary

Kendall Grant Clark writes that OpenAI's release of 372 mathematical results, nearly all from a single prompt to a single agent at about three hours of compute each, creates an uncanny situation. Many come with Lean formalizations, so a program has checked each step, yet some are certified true while no human yet understands why.

He compares this to earlier unread proofs such as the four-color theorem, but says those used strategies people chose and could inspect in pieces, while these strategies belong to no one and a kernel vouches for validity, not meaning. His first reaction was that it felt alien; using Freud's idea of the uncanny, he reframes it as the familiar returned in a form we cannot recognize. It is an essay, so the argument is interpretation more than reporting.
