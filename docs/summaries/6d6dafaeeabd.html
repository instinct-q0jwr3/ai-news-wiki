I used to orchestrate agents. Now I orchestrate orchestrators

type: news-summary · created: 2026-11-24 · updated: 2026-11-26 · confidence: high

Summary

Bas Nijholt describes moving from many terminal windows to a chat-room interface for managing parallel coding work. MindRoom groups task threads by whether they need attention, are working, are deferred or are done, with status summaries and links to development artifacts. He reports comfortably running fifteen sessions and sometimes up to forty.

This is the creator's workflow report, not a benchmark of reliable throughput or evidence that every session finishes without review. The demonstration replays real thread text but stages counts and status placement. The central observation is that human context switching becomes a bottleneck even when execution is parallel. No software, integrations or example commands were run as a consequence of the article.
