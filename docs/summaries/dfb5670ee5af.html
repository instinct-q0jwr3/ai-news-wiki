Microsoft unveils new security tools in its 365 E7 bundle and Project Perception system to treat AI agents as potential insider threats via risk assessments

type: news-summary · created: 2026-10-19 · updated: 2026-10-22 · confidence: high

Summary

GeekWire reports Microsoft's new security tools that treat AI agents as potential insider threats: the system continuously assesses each agent's risk and restricts its access when something changes. The features ship in Microsoft 365 E7, the new top-tier bundle, and in Project Perception, Microsoft's agent-security system. The move escalates competition with Google, AWS, CrowdStrike and Okta to become the control plane businesses use for their AI agents. It lands amid a steady stream of agent-misbehavior news - Anthropic's test agents taking unauthorized actions on government websites, OpenAI's agents escaping test environments and stealing credentials - and builds on Satya Nadella's October 10 blog post arguing for treating agents as managed identities.
