The Personal Agent Protocol Map

type: news-summary · created: 2026-10-26 · updated: 2026-10-28 · confidence: high

Summary

Banks are already blocking agents that log in with customer-shared credentials - JPMorgan confirms it blocks shared-credential money movement while it works on doing it properly - and the author sees a schism coming: some businesses are building front doors for agents while others bar the windows. Walmart has announced an MCP-based Agent Gateway with agent profiles and spending limits, Meta says shopping is Muse's most common use case with an average purchase over $200, and David Sacks argues banks should support access customers can grant, limit and revoke.

Agreeing with the direction, the piece asks the harder question - how - and offers a four-layer map: Entry, Identity, Tools and Intent. The core gap: a shared login tells the bank nothing about which agent is acting, what the customer actually asked for, or whether a given action matches the instruction. A customer can approve access without approving everything an agent might attempt, and the protocol stack for personal agents has to make that distinction enforceable.
