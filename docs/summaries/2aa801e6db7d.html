QGIS bans AI assisted contributions

type: news-summary · created: 2026-10-12 · updated: 2026-10-19 · confidence: high

Summary

QGIS has banned AI-assisted contributions to its repository - no code written by LLMs or AI agents allowed - and the community is immediately wrestling with where the line sits. Commenters ask whether the policy covers issue text and PR comments, LLM-backed autocomplete, non-LLM ML features like JetBrains' completion ranking, brainstorming designs with ChatGPT, or even Google's AI answers surfacing while searching an error message.

One worried contributor asks to keep the discussion open past the end of the week, fearing the broad words 'assisted' and 'used' throw the baby out with the bathwater - for instance, a developer who asks Claude about a PyQGIS issue, realizes it is a QGIS Core bug, and fixes it manually, or a non-native speaker using Google Translate for an English term.

Highlights

  • QGIS bans LLM/AI-agent-written code contributions to its repo.
  • Community finds the boundary unclear: autocomplete, brainstorming, issue text, PR comments?
  • Non-LLM ML features (IDE completion ranking) sit in the gray zone.
  • Edge case: AI helps diagnose a bug a human then fixes by hand.
  • Contributors ask for a longer comment period before the policy closes.
