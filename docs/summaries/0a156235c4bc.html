llm-openai-decisions 0.1a0

type: news-summary · created: 2026-10-07 · updated: 2026-10-09 · confidence: high

Summary

Simon Willison released llm-openai-decisions 0.1a0, a plugin for OpenAI's new Decisions API, announced at DevDay. He had GPT-6 Astra read the docs and build it, modelled on his llm-typesafe plugin for a similar API. The new gpt-6-luna decision model accepts images as well as text, and costs 10 cents per million input tokens against 4.2 cents for the rival. Both offer yes/no, choice and score questions. His example asks whether an image contains mammals and returns a probability.

Highlights

  • Plugin for OpenAI's Decisions API, built by GPT-6 Astra.
  • gpt-6-luna accepts images; 10 cents per million input tokens.
