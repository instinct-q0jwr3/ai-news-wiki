AI-generated posters don’t have to be horrible

type: news-summary · created: 2026-09-19 · updated: 2026-09-23 · confidence: high

hacker-news

Summary

John Hartnup's experiment answers a familiar complaint, the identikit AI event poster, with a practical finding: the monotony is a prompting failure, not a model limit. The problem with typical AI posters isn't that they're bad; it's that after twenty sightings the same pastel-airbrush style irritates through sheer repetition. He gave ChatGPT invented spring-fayre details, explicitly asked for a clean, bold, non-pastel style, and still got the default look.

The fix was dialogic: he told the model to treat its first attempt as 'what not to do' and pick a completely different aesthetic, which produced a genuinely distinct Bauhaus/modernist geometric design. Asking the model to name and enumerate styles (Swiss Style, risograph, editorial, brutalist, 90s rave flyer, Japanese minimal) turned its latent design vocabulary into a menu a non-designer can choose from. The takeaway for anyone generating event graphics: don't accept the default; force a named style and iterate.

Highlights

  • The complaint: AI event posters aren't bad, they're identical; the same style 20 times is what irritates.
  • Even explicit anti-default art direction ('avoid pastel/airbrush') still produced the default look.
  • Fix: tell the model to treat the first attempt as 'what not to do' and choose a different aesthetic.
  • Result: a Bauhaus/modernist geometric minimalist poster that actually stands out.
  • ChatGPT can name its own styles: Bauhaus, Swiss Style, risograph, editorial, brutalist, 90s rave, Japanese minimal.
  • Practical lesson: the model's range is wide, but you must force a named style; the default is a local minimum.
