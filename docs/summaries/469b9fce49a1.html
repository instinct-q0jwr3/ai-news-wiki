Quicksand

type: news-summary · created: 2026-10-09 · updated: 2026-10-10 · confidence: high

Summary

Microsoft's Quicksand is an async Python library for launching, controlling and snapshotting QEMU virtual machines, aimed at sandboxing AI agents. It ships ready-made Ubuntu and Alpine images for x86_64 and ARM64 on macOS, Linux and Windows.

Sandboxes run without root or Docker. A short context-manager API lets code execute commands, take screenshots and type text in a desktop VM, which is what a computer-using agent needs.

Highlights

  • Async Python API for QEMU VMs
  • Built for sandboxing AI agents
  • Ubuntu and Alpine images, x86_64 and ARM64
  • No root or Docker needed
  • Desktop mode with screenshots and typing
