Show HN: An AI agent runs ten web errands a day, every transcript published

type: news-summary · created: 2026-10-07 · updated: 2026-10-31 · confidence: high

Summary

Agentability is a public experiment on the agentic web: each day an AI producer reads what the world is searching and turns it into ten real errands - kickoff times, quake magnitudes, prices, what actually happened - and a real AI agent attempts them with plain web requests only: no logins, no JavaScript, no human help. Every transcript is published verbatim, wins and failures alike; the October 6 episode hit 10 bot walls while reading 137 pages across 43 sites.

Alongside the daily show, 113 well-known sites are audited weekly against the conventions agents rely on - llms.txt, crawler policy, browserless-readable content, structured data, MCP - each getting a public score and the exact fix for every failed check. The pitch: whether the web works for agents is an empirical question, so test it in public with reproducible checks and open data.
