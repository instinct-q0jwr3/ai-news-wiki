Show HN: An AI agent runs ten web errands a day, every transcript published

type: news-summary · created: 2026-10-07 · updated: 2026-10-09 · confidence: high

Summary

Agentability is an open experiment where an AI producer turns each day's searches into ten real web errands and an AI agent tries them using only plain web requests, with every transcript published. The October 6 episode reports 10 bot walls, 137 pages read and 43 sites visited. A standing panel of 113 well-known sites is scored weekly on how usable they are for agents, checking things like llms.txt and crawler policy. Basis: the opening of the page was read.
