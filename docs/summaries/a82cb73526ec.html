Reproducing Hacker News writing style fingerprinting

type: news-summary · created: 2026-09-26 · updated: 2026-09-26 · confidence: high

antirez meta hugging-face nvidia external-evaluation ai-safety-incidents ai-policy-regulation

Summary

About three years ago I saw a quite curious and interesting post on Hacker News.

A student, Christopher Tarry, was able to use cosine similarity against a vector of top words frequencies in comments, in order to detect similar HN accounts — and, sometimes, even accounts actually controlled by the same user, that is,…

This is the original post: https://news.ycombinator.com/item?id=33755016 I was not aware, back then, of Burrows-Delta method for style detection: it seemed kinda magical that you just needed to normalize a frequency vector of top words…

Highlights

  • I read a few wikipedia pages and took mental note of it.
  • I thought I could reproduce the work with Vector Sets, once I was done with the main work.
  • Now the new data type is in the release candidate, and I found some time to work on the problem.
  • This is a report of what I did, but before to continue, the mandatory demo site: you can play with it at the following link: https://antirez.com/hnstyle?username=pg&threshold=20&action=search NOTE: since the dataset takes 700MB of RAM,…
  • However, later in this post you will find the link and the Github repository with the code to reproduce everything from scratch.
  • NOTE2: I hope the web site will survive, it's a very crude Python script.
  • Fingers crossed. # Raw data download and processing Well, the first problem I had, in order to do something like that, was to find an archive with Hacker News comments.
  • It generates 10k words by default, but for the statistical analysis a lot less are needed (or, actually: if you use too many words you no longer capture the style, but the kind of content a user is talking about!).
