Show HN: InstinctFlash – High-Performance Serving Runtime for Robotics Models

type: news-summary · created: 2026-09-22 · updated: 2026-09-23 · confidence: high

hacker-news nvidia external-evaluation small-specialist-models ai-policy-regulation

Summary

InstinctFlash is an open-source high-performance serving framework for robotics models, claiming up to 33.78x speedup with no observed loss in task performance in real-robot tests. Its benchmarks measure prediction p50 latency on Jetson Thor (September 15, 2026), with the headline figure including a schedule change from 25V/50A to 2V/4A action chunks; FP8 and sampling changes are optional.

The Python 3.10+ core inspects checkpoints and plans without PyTorch or a GPU, while inference runs in a separate pinned environment per model family (va, vla4, vla2, pi05, groot, edge, nano, dreamzero). The repo ships bootstrap scripts with reproduction commands for RTX 4090/5090 and Jetson Thor setups.
