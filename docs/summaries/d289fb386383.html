OpenAI wants agents to tell websites where you are

type: news-summary · created: 2026-11-12 · updated: 2026-11-14 · confidence: high

Summary

This critique examines an individual Internet-Draft proposing that agents forward optional user signals such as country, a masked IP prefix, locale and time zone to websites. It recognizes the operational problem of shared data-center traffic triggering blocks, but argues that disclosing those signals gives back privacy that proxy browsing currently preserves.

The author questions consent, minimization and unsigned claims used for risk scoring, and suggests stronger authentication and purpose limits. These are critiques of a draft, not an adopted IETF standard or evidence that such forwarding is already universally deployed. A masked network identifier can still contribute to identification.

Highlights

  • Draft proposes optional forwarded user signals
  • Agent traffic blocks are the operational motivation
  • Critique focuses on privacy and consent
  • Unsigned signals have authenticity limitations
  • Individual proposal is not an adopted standard
