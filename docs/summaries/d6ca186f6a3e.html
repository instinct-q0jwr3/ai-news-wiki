Runway Praxis-1 Is Now Available: Open-Weight Robotics Model

type: news-summary · created: 2026-11-12 · updated: 2026-11-13 · confidence: high

Summary

Runway releases Praxis-1 weights and adaptation code under Apache 2.0. It describes a 27-billion-parameter mixture-of-experts model that predicts video and robot actions together, with hardware and fine-tuning support intended to let developers adapt one pretrained model to different robot bodies.

Runway reports benchmark results and partner demonstrations, including transfer to a robot absent from training. Those are vendor evaluations on defined tasks, not a guarantee of safe autonomous performance in arbitrary environments. Open access allows inspection and adaptation but does not remove the need for robot-specific validation.

Highlights

  • Open weights and code under Apache 2.0
  • Joint prediction of video and actions
  • 27B mixture-of-experts architecture
  • Supports full adaptation and LoRA
  • Reported results require task-specific validation
