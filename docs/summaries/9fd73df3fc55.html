Ask HN: What's your current AI agentic setup?

type: news-summary · created: 2026-11-05 · updated: 2026-11-13 · confidence: high

Summary

This Hacker News question asks readers to describe their AI subscriptions, API or local models, coding interfaces and multi-agent tools. The goal is a snapshot of changing workflows and the reasons people switch between tools.

Responses are self-selected anecdotes, not a representative adoption survey or a controlled comparison of model quality. The useful distinction is between model access, the interface used to work with it and any orchestration layered above.

Highlights

  • Question gathers workflow snapshots
  • Subscriptions and API use are separate
  • Interfaces and models are different choices
  • Orchestration is another layer
  • Replies are not representative statistics
