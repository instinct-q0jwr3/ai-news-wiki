Claude Whiteboards, Claude Sheets, and Claude Data

type: news-summary · created: 2026-11-10 · updated: 2026-11-13 · confidence: high

Summary

Anthropic launched Claude Whiteboards and Claude Sheets in beta and made Claude Dashboards generally available as Claude Data. Whiteboards is a shared board for brainstorming with Claude, Sheets a spreadsheet Claude builds and edits, and Data adds data stories, certified queries and live sharing. The pitch is that work stays inside Claude instead of being copied into tools it cannot follow. Available on all paid plans.

Highlights

  • Whiteboards and Sheets in beta; Dashboards becomes Claude Data (GA)
  • Work stays live in Claude with team editing
  • Outputs can move into partner tools
  • All paid plans
