AlphaEvolve

type: news-summary · created: 2026-11-05 · updated: 2026-11-13 · confidence: high

Summary

Google DeepMind published a repository for AlphaEvolve. It has a minimal implementation of AlphaEvolve with local evaluation, and an /omega directory with code and data for a new upper bound on the matrix multiplication exponent that AlphaEvolve found. A Colab notebook verifies it with rational arithmetic, and a level_3 folder holds the JAX/Haiku gradient-descent code (32k steps, 32 seeds) that converts the best solution into a verifiable parameter vector. The paper link is still a TODO.
