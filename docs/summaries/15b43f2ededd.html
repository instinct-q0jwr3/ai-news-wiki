Show HN: Flide: Make Jev-like decision models up to 9.5x faster

type: news-summary · created: 2026-11-09 · updated: 2026-11-14 · confidence: high

Summary

Flide is a GitHub project that serves 'Jev-style' decision models through an API and claims up to 9.5 times faster inference than vLLM and SGLang by forking model state exactly, with answers matching those the model gives a question alone. The README shows installing it with pip and serving a small model.

Highlights

  • Claims up to 9.5x faster than vLLM and SGLang
  • Exact state forking, same answers as single queries
  • Serves a /v1/systemone API
