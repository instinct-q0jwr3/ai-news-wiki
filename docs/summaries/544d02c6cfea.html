ttok 0.4

type: news-summary · created: 2026-10-09 · updated: 2026-10-10 · confidence: high

Summary

Simon Willison releases ttok 0.4, his command-line tool for counting tokens using OpenAI's tiktoken. It had not been updated in a couple of years; he fixed a Click warning, updated CI and added a --list-models command that lists the models tiktoken supports.

Highlights

  • ttok 0.4 released
  • Fixes a Click warning, updates CI
  • New --list-models command
  • Counts tokens with OpenAI's tiktoken
