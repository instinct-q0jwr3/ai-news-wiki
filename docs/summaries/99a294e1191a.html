Introducing the llama.cpp benchmark dashboard for AMD Ryzen and Radeon

type: news-summary · created: 2026-11-27 · updated: 2026-11-27 · confidence: high

Summary

The ggml-org post introduces a public dashboard tracking llama.cpp throughput on selected AMD hardware across builds, models and quantizations. It describes PP512 prompt processing and TG128 generation at zero initial context, plus separate context-scaling sweeps and public data files.

These are specific synthetic workloads, not complete application latency or quality comparisons, and the current hardware selection is limited. Means across ten repetitions, Flash Attention settings and weekly workflows make the measurement conditions important. The dashboard plots and raw data were not independently reproduced or visually evaluated here, and no binary or model was installed.

Highlights

  • Post describes public benchmark data and workflows
  • PP512 and TG128 measure different workloads
  • Both standard tests start with no prior context
  • Context scaling has a separate view
  • Results depend on build and quantization
  • No universal hardware ranking follows
  • No installation or benchmark was performed
