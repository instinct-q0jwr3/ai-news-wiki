Claude partial outage

type: news-summary · created: 2026-09-29 · updated: 2026-10-01 · confidence: high

Summary

Claude had a partial outage on September 29: elevated errors hit claude.ai, the desktop and mobile apps, Claude Code, Claude Cowork, and the API from 07:00 to 07:59 PT (14:00-14:59 UTC). Anthropic's status page reports full recovery, warns that some messages sent during the impact window may not have been saved, and marked the incident resolved the same morning while continuing to monitor.

Highlights

  • Partial Claude outage on Sep 29, 07:00-07:59 PT
  • Hit claude.ai, desktop/mobile apps, Claude Code, Cowork, and the API
  • Some messages sent during the window may not have been saved
  • Resolved the same morning; services operating normally
