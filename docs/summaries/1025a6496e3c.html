Show HN: CATT 0.2.1: Test agents/services against a Muse/Instinct-alike, in CI

type: news-summary · created: 2026-10-23 · updated: 2026-10-26 · confidence: high

Summary

CATT (Consumer Agent Testing Tool) is an open-source harness for testing how an AI assistant uses your service: run a scripted or model-driven agent against an MCP server, an MCP app, a website, or an HTTP API, then check what the service did, inspect the evidence, and compare results across builds - designed to fit CI pipelines. Version 0.2.1 adds Instinct as a surrogate emulation target alongside the default Muse, both using a shared connector testing contract covering routing, memory, payments, browser/HTTP tasks, and scheduling.

The project is careful about its limits: CATT is a surrogate that approximates an assistant's host, not its private implementation, so a passing test does not certify compatibility with Muse or any hosted assistant. Each Muse-specific behavior carries a recorded basis - documented, unofficial, assumed, or unknown - and the project disclaims any affiliation with Meta, Instinct, OpenAI, or Anthropic. The model driving a trial is separate from the assistant being emulated. MIT licensed.
