Show HN: Spinf-serve – inference server for bulk scoring and decisions

type: news-summary · created: 2026-10-30 · updated: 2026-10-30 · confidence: high

Summary

spinf-serve is an open-source (Apache 2.0) inference server for bulk scoring and decisions rather than chat: it reads a piece of content once and answers many questions about it in the same forward pass, each answer a probability over provided options instead of generated text. It runs on a single 24GB NVIDIA GPU and exposes an OpenAI-compatible API.

The motivation is workload shape: the team built it for a daily market index read from millions of news articles, each asked dozens of narrow calibrated questions - a job where a chat-oriented server re-reads content per question and generates token by token, making it slow and expensive. spinf-serve lays every question out as a branch of one read and packs many contents into a single pass. Any open instruction model works as a decision model this way; it ships for Linux on Ada, Hopper or Blackwell GPUs with fp8 tensor cores.

Highlights

  • spinf-serve: open-source inference server for bulk classification and decisions
  • One read of the content answers many questions, each a probability over options
  • Runs on a single 24GB NVIDIA GPU; OpenAI-compatible API; Apache 2.0
  • Built for a market-index workload: millions of articles, dozens of questions each
  • Throughput over single-request latency; not a chat server
