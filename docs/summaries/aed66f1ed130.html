Firecrawl, which provides web scraping tools for AI agents, raised a $75M Series B led by Smash Capital

type: news-summary · created: 2026-09-23 · updated: 2026-09-26 · confidence: high

techmeme agentic-systems

Summary

Firecrawl, which builds web-scraping tooling for AI agents, raised a $75 million Series B led by LA-based Smash Ventures (reported as Smash Capital), joined by Y Combinator, Altos Ventures, Nexus Venture Partners, Freestyle and Offline Ventures. Its platform targets the practical problems of collecting web data at agent scale: an agent-optimized search engine that filters pages by creation date and file type, a 'smart wait' that avoids scraping pages before they finish loading, and automatic scrolling, clicking and form submission for interactive content.
