Maria Deutscher / SiliconANGLE : Firecrawl, which provides web scraping tools for AI agents, raised a $75M Series B led by Smash Capital — Firecrawl Inc., a provider of web scraping tools for artificial intelligence agents, today…

SHARE UPDATED 18:46 EDT / SEPTEMBER 22 2026 by Maria Deutscher Firecrawl Inc., a provider of web scraping tools for artificial intelligence agents, today announced that it has raised $75 million in funding.

Los Angeles-based venture capital firm Smash Ventures led the Series B round.

Highlights

  • It was joined by Y Combinator, Altos Ventures, Nexus Venture Partners, Freestyle and Offline Ventures.
  • AI agents rely on information from the web for a wide range of tasks.
  • In theory, they can access that data using a regular browser.
  • In practice, however, collecting large volumes of website data involves multiple technical challenges.
  • Firecrawl has built a platform that eases those challenges for developers.
  • The first prerequisite to collecting the data an AI agent requires for a task is finding the web page that contain it.
  • Firecrawl provides an agent-optimized search engine that can filter web pages based on their creation date, the type of files they host and other parameters.
  • Firecrawl says that its platform can perform those actions automatically.
