How Meta Catches Bugs Before Code Ships

type: news-summary · created: 2026-10-30 · updated: 2026-10-31 · confidence: high

Summary

Meta's Catching JiTTests - just-in-time tests generated by LLMs - have graduated from research prototype to production infrastructure. The approach differs from AI code review: instead of reading a diff and opining, the system generates executable tests designed to fail, each demonstrating a concrete behavioral difference the change introduces. That costs more computation than a review pass, but it catches classes of bugs that LLM- or agent-based reviewers miss, and Meta reports engineers catching more bugs with less load and a smaller false-positive rate.

The engineering post frames five months of deployment at Meta's scale - hundreds of millions of lines of constantly evolving code - as evidence the technique is applicable beyond the company, positioning generated-tests-that-fail as a complement to, rather than a replacement for, both traditional testing and AI review.

Highlights

  • Meta deploys Catching JiTTests at full scale after five months
  • LLM-generated executable tests are designed to fail, proving a concrete behavioral change
  • Catches bug classes that LLM and agentic code review miss

  • Positioned as a complement to traditional testing and AI review, not a replacement
