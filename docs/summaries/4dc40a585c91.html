ATLAS: Evaluating Agents on Search-Intensive Tasks

type: news-summary · created: 2026-10-09 · updated: 2026-10-10 · confidence: high

Summary

Exa previews ATLAS, a benchmark that grades how accurate and complete agent answers are on hard, search-heavy workflows. Queries come from real search demand and are paired with verified golden answers, and an automated pipeline refreshes both as the web and models change.

Exa's argument is that agentic search used to be limited by model intelligence, but frontier models now handle long multi-document tasks reliably and cheaply. The bottleneck has moved to whether the search backend can find the relevant information, which is why it wants a rigorous way to compare search setups.

Highlights

  • ATLAS benchmark for search-intensive agent tasks
  • Real queries with verified golden answers
  • Automated refresh as web and models evolve
  • Bottleneck is now search quality, not model intelligence
