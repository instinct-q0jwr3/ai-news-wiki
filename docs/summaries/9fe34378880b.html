Show HN: Penmentor – Claude marks up your handwritten math like a teacher

type: news-summary · created: 2026-10-20 · updated: 2026-10-27 · confidence: high

Summary

Penmentor turns a pen-tablet math session into a mentored one: while working by hand in xournal++, pressing a key has Claude, Gemini, or GPT mark up the page like a teacher with coloured pens, circling mistakes, ticking what's right, giving hints instead of answers, and rendering a 3Blue1Brown-style manim animation of the idea. It runs on the AI command-line agent the user already has logged in, so it rides an existing subscription rather than a new API bill, with the model picked in Settings. Linux-only (X11, best with i3), needing rofi, slop, xdotool, and PyQt6; MIT licensed.

Highlights

  • Marks handwritten math like a teacher, one keypress away
  • Hints instead of answers; circles errors, ticks correct steps
  • Generates 3Blue1Brown-style manim animations of the concept
  • Runs on the user's existing Claude/Codex/Gemini CLI subscription
  • Built for xournal++ on Linux X11; MIT license
  • Born from the author's calculus study workflow
