Show HN: Pi pod – Run your pi coding agent in sandboxes on your own server

type: news-summary · created: 2026-10-03 · updated: 2026-10-06 · confidence: high

Summary

Pi pod runs the pi coding agent in sandboxes on your own server. The author admires pi's simplicity and customisability and wants a minimal engineering environment around it: agent sandboxing, native clients, RBAC session sharing and browser and native app automation.

A self-hosted edition aims to feel the same as the pi harness you already use. Show HN project.

Highlights

  • Runs the pi agent in isolated sandboxes on your own server.
  • Adds sandboxing, clients, RBAC sharing and automation.
  • Self-hosted; avoids lock-in to AI companies.
  • Early, ongoing effort.
