Claude Code now reads AGENTS.md if there is no Claude.md

type: news-summary · created: 2026-09-19 · updated: 2026-09-21 · confidence: high

hacker-news anthropic agentic-systems

Summary

Claude Code 2.1.277 (September 18, 2026) added AGENTS.md support: in a project with no CLAUDE.md, Claude Code now reads AGENTS.md as its project instructions instead, configurable under 'Project instructions' in /config. The change lands days after Anthropic backed the AGENTS.md convention and contributes to making the file a cross-vendor standard for steering coding agents.

The same changelog entry ships gateway and proxy improvements (CLAUDE_GATEWAY_PROXY_IS_EGRESS_BOUNDARY, static headers for gateway upstreams) and a long list of fixes, from hangs in claude -p and Agent SDK sessions to Edit/Write tool edge cases. The following day's 2.1.278 moved auto mode for API and Enterprise users to a server-side classifier that does not charge for classifier overhead. AGENTS.md support is not yet available on Bedrock, Vertex or Foundry.

Highlights

  • Claude Code 2.1.277: with no CLAUDE.md present, the CLI reads AGENTS.md for project instructions.
  • The file is swappable under 'Project instructions' in /config; not yet on Bedrock, Vertex or Foundry.
  • Context: Anthropic contributed AGENTS.md to the Agentic AI Foundation and recently added support to Claude Code's ecosystem.
  • 2.1.278 (September 19) defaults auto mode to a server-side classifier with no classifier-overhead charge for API/Enterprise users.
  • Also new: an Auto mode server row in /status showing where the session's classifier runs.
  • Gateway additions: egress-boundary proxy mode and static headers for upstream proxies.
  • Fixes include hangs with no result in claude -p, 'text content blocks must be non-empty' failures, and Edit tool regex/escape edge cases.
