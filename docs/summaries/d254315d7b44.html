Rationale for filtering LLM usage links as off-topic

type: news-summary · created: 2026-10-30 · updated: 2026-10-31 · confidence: high

Summary

A Lobsters meta-discussion digs into the site's moderation decision to filter 'LLM usage' links as off-topic. A user who accepts the retirement of the conflated vibecoding tag (and even the appetite for filtering LLM discussion wholesale) asks why stories about using - or not using - LLMs are now considered wholly off-topic, noting months of useful threads about professional programming practice in the presence of LLMs.

The moderating answer articulates the site's topicality litmus: take a story and replace 'LLM' with 'consultant'; if the argument still holds unchanged, it is probably about work practices rather than programming and belongs elsewhere, alongside entrepreneurship, management and careers - popular on larger sites but off-topic here. The tag itself was renamed to building-ai-tooling to keep the subset about constructing the tools.

Highlights

  • Lobsters filters "LLM usage" stories as off-topic; users ask why
  • Useful threads existed on professional programming practice with LLMs
  • Moderation litmus: replace "LLM" with "consultant" - if it still reads the same, it is off-topic
  • vibecoding tag renamed to building-ai-tooling for precision
  • Off-topic bucket includes entrepreneurship, management, careers
