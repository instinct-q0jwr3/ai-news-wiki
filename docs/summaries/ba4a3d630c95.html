OpenAI expands ChatGPT plugins with interactive panels and file viewers, launches a Plugin Creator tool, and adds MCP Events support for plugin automations

type: news-summary · created: 2026-09-29 · updated: 2026-10-06 · confidence: high

Summary

OpenAI is expanding ChatGPT plugins into app-like experiences: developers can now build interactive panels that live in the ChatGPT sidebar, letting users work with their tools while chatting, plus file viewers supporting arbitrary formats. Existing plugins already connect ChatGPT to Slack, SharePoint, Airtable, and Google Drive; the new extensions give apps a dedicated home inside the product. Announced at DevDay alongside Pages, Slides, and Space, it is a clear play to make ChatGPT the container for any application that works better with a model attached.

Highlights

  • Plugin extensions give apps a dedicated home in the ChatGPT sidebar
  • Developers can build interactive panels users operate while chatting
  • File viewers support arbitrary file formats inside ChatGPT
  • Existing plugins connect Slack, SharePoint, Airtable, Google Drive
  • Announced at DevDay with Pages, Slides, and Space - ChatGPT as an app platform
