OpenCode Browse

type: news-summary · created: 2026-11-17 · updated: 2026-11-25 · confidence: high

Summary

OpenCode Browse is presented as a browser extension and MCP server that lets coding agents work in the browser a person already uses, including existing signed-in sessions. The product page describes background tab groups, screenshots, network capture and explicit handoffs for login, verification and payment.

Its allowed-site feature and human handoffs are product claims, not an independent security audit. Reusing a signed-in browser increases what an agent can reach; convenience does not grant permission for every action or establish protection against malicious page content.

Highlights

  • Extension connects agents to an existing browser
  • Background tab groups separate agent activity
  • Human handoffs cover sensitive steps
  • Allowed sites are a stated control
  • Existing session access carries account risk
