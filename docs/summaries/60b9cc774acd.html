Stop running everything through LLMs: How I fixed my research agent

type: news-summary · created: 2026-11-06 · updated: 2026-11-14 · confidence: high

Summary

TinyFish's author describes building TinyResearch, a research agent meant to return reports good enough that neither a person nor a calling agent has to redo them. An agent cannot squint at a weak report and double-check, so the output must be reliable. He measures every change against five criteria: factual correctness, credibility, readability, comprehensiveness and instruction following. The post covers what happens in a run, how deep the loop goes, decisions he reversed (including not running everything through LLMs) and results on three public benchmarks. A question like 'Tesla Model 3 or Camry?' is treated as several sub-questions. Only the opening was read.

Highlights

  • Built so other agents can rely on its reports
  • Five metrics: correctness, credibility, readability, comprehensiveness, instruction following
  • Argues against routing every step through an LLM
  • Benchmarks reported; only the opening was read
