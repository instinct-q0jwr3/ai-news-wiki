Anomaly Innovations, behind coding agent OpenCode, says a breach hit ~1.4% of OpenCode Console users and their API keys, in a "large scale distillation attack"

type: news-summary · created: 2026-10-18 · updated: 2026-10-19 · confidence: high

Summary

Anomaly Innovations, the company behind the open-source coding agent OpenCode, confirmed a breach it describes as 'related to a large scale distillation attack' that hit roughly 1.4% of OpenCode Console users. Exposed: stored OpenAI, Anthropic and Google API keys for a subset of developer workspaces, prompting urgent key rotations across the community.

The company says it emailed every affected account the same morning, that only users who had linked external providers were affected, and that it is working with Anthropic, OpenAI and Google on remediation. The exposure is acute because OpenCode is a terminal agent that runs with the developer's own credentials - those keys are what let it read files, call APIs and execute commands.
