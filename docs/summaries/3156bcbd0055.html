Kcc, a C compiler built solo with an LLM on $100/month boot Linux kernel

type: news-summary · created: 2026-10-02 · updated: 2026-10-04 · confidence: high

Summary

Kcc is a C17 compiler written entirely in ARM64 assembly by one person with an LLM on a $100 a month budget. It is written as a literate program in a metalanguage called weft, where every instruction is explained in prose before the code; the book is about 1,000 pages and the repository commits it as kcc.pdf.

The compiler checks C against the standard, optimises, allocates registers and emits native code. It compiles itself to a byte-identical binary, cross-compiles to x86-64 on Linux and macOS, builds Lua, SQLite and DOOM, and boots a Linux kernel.

Highlights

  • C17 compiler in ARM64 assembly, built solo with an LLM.
  • Self-hosts to a byte-identical binary.
  • Builds Lua, SQLite and DOOM; boots a Linux kernel.
  • Literate source: the ~1000-page book is the compiler.
  • Cross-compiles to x86-64; MIT licensed.
