OpenAI reopens sign-ups for its $200/month Pro tier while halving the API credits provided per dollar to encourage pay-per-use, and removes the five-hour cap

type: news-summary · created: 2026-09-29 · updated: 2026-10-04 · confidence: high

Summary

OpenAI is reopening sign-ups for its $200/month Pro tier while halving the API credits included per dollar. Employee Thibault Sottiaux argues subscribers should still get more done than a month ago because GPT-6 Sol and GPT-6 Luna shipped this week at half their predecessors' API price. The 5-hour usage cap is gone for good, replaced by a weekly allotment subscribers can spread however they want. Strategically, the change moves OpenAI away from subsidized subscriptions toward pay-per-use: Sottiaux expects API prices to fall until there is no significant gap between subscription and API value per dollar, letting labs tie revenue to actual usage. Microsoft already does this with Copilot in places.
