Edge0-145B: Frontier AI Capabilities on Your Own Computer

type: news-summary · created: 2026-11-13 · updated: 2026-11-14 · confidence: high

Summary

Edge0 announces 145B- and 120B-parameter models together with an inference framework and deployment tools for local use. It claims laptop operation for the larger model at more than 80 tokens per second and 28 GB peak memory, positioning it as an alternative to cloud dependence.

These are vendor measurements for a specified setup, not hardware-independent expectations. The announcement separately cites a smaller phone model, whose speed and memory figures should not be confused with the laptop release. Claims of frontier-level ability need task-specific evaluation alongside the practical costs of running the full stack.

Highlights

  • Vendor releases models and deployment stack
  • Local use aims to reduce cloud dependence
  • Laptop speed and memory figures are vendor claims
  • Phone figures refer to a different smaller model
  • Capability comparisons need independent task testing
