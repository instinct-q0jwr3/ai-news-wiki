LabRobotBench v0.1: Benchmarking wet lab robotics

type: news-summary · created: 2026-10-21 · updated: 2026-10-26 · confidence: high

Summary

Gamow Labs, which builds frontier AI systems to interpret the human genome, presents LabRobotBench v0.1, a benchmark for evaluating whether agents can run wet-lab experiments and recover from equipment failures. Their in-silico simulation mirrors the command interfaces of their physical robots, so agents can be developed and evaluated before touching hardware. The motivation is downtime: when a robot errors mid-experiment, work stalls until a person steps in, and an agent that can diagnose and safely resume could keep experiments running overnight. Tasks include cell assay recovery, where a robot stopped halfway through four trays at different steps and the agent must infer what is done, finish washing, add the measurement chemical, run the instrument, and set aside the spoiled tray, plus dose-response recovery and cold-stock handling; repeating a treatment can ruin a sample, and a tray can look correctly shelved while the experiment is unfinished.

Highlights

  • LabRobotBench v0.1: agents troubleshoot and run wet-lab experiments
  • Simulation mirrors the physical robots' command interfaces
  • Goal: agents that recover from equipment failures and keep experiments running overnight
  • Cell assay task: infer completed steps across four trays, finish, measure, quarantine the spoiled one
  • Traps: re-treating a sample ruins it; a shelved tray can hide an unfinished assay
  • From Gamow Labs, which builds genome-interpretation AI and an agent-operated lab
