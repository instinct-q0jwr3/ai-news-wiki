Microsoft launches its Copilot "super app", bundling chat, coding, and agents into a single interface, and rebrands its AI assistant Scout as Autopilot

type: news-summary · created: 2026-09-25 · updated: 2026-09-26 · confidence: high

techmeme microsoft agentic-systems

Summary

Microsoft officially unveiled its redesigned Copilot 'super app', bundling AI chat, coding and agents into a single interface after teasing it last month. As part of the launch, Scout - the AI personal assistant introduced at Build earlier this year - is rebranded as Autopilot.

The new app has three tabs: Home, Code and Autopilot. Home merges Copilot Chat and Cowork as the default landing experience, and Microsoft plans a Today feature inside it: a personalized dashboard for important emails, meeting requests and more.
