Toolfence-scan – static checks for Cursor/Claude/Copilot skills

type: news-summary · created: 2026-11-24 · updated: 2026-11-24 · confidence: high

Summary

ToolFence Scan describes static checks of coding-agent skills, prompt files and MCP configurations before installation. Its repository lists rules for hidden Unicode, secret patterns, remote execution, concealment requests and broad permissions, plus report formats and an optional bridge to another policy product.

A rule match is a signal for review, not a finding that every flagged file is malicious; absence of a match cannot certify safety. The repository exposes suppressions and fixture tests but supplies no independently verified detection rate in the material read. No package was executed, no local credentials were scanned and no policy fragment was applied. Documentation commands are examples, not authorization.

Highlights

  • Static scanner targets agent-related configuration files
  • Rules include concealment, credential and broad-permission patterns
  • Reports and policy fragments are described
  • False positives and missed attacks remain possible
  • Fixture tests do not establish real-world detection rates
  • No installation, private scan or policy change was performed
