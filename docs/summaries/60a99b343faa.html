Claude Code regularly sends each background agent’s transcript to its model

type: news-summary · created: 2026-10-29 · updated: 2026-10-29 · confidence: high

Summary

A gist by Flamerix AI documents an overhead Claude Code users cannot switch off: roughly every 30 seconds, for every background agent, Claude Code ships that agent's entire transcript to the agent's own model (usually Opus) and asks it to describe its most recent action in three to five words. The answer only repaints the status line in the agents panel; it never reaches the conversation. There is no setting to disable it, and it has been on by default since version 2.1.232 in August 2026. The author caught it in Claude Code's OpenTelemetry export, where grouping API requests by query_source showed the agent_summary source costing more than the main conversation itself; a GitHub issue collects four independent measurements of 18 to 26 percent. On a subscription the cost is rate-limit headroom rather than money.

The fix is an 80-line Bun preload, no-agent-summary.js, that wraps setTimeout and setInterval and refuses to arm any timer whose callback source contains the summarizer's anchor log line, returning an inert handle set to 2^31-1 milliseconds - the largest delay Node and Bun will not round down to 1ms. Because the module ships as precompiled bytecode, editing the binary's JS text does nothing, but Function.prototype.toString still leaks a callback's source, which is how the timer is recognized. Installation is an environment variable and a daemon restart; headless runs, cron and CI need it too, and a pass-through mode exists as an A/B control.
