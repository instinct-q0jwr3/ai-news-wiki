Show HN: I built a post-mortem debugger for native Windows x64/x86 crashes

type: news-summary · created: 2026-09-24 · updated: 2026-09-24 · confidence: high

hacker-news agentic-systems ai-safety-incidents

Summary

ForensicDbg is a new post-mortem debugger for Windows, built from the ground up to track down hard-to-catch bugs: it debugs x86 and x64 crash dumps, attaches to live processes, and can register as the just-in-time debugger, with a C++ expression evaluator plus SourceServer and SourceLink support. It is in private beta.

The AI angle is a first-class MCP interface for automated crash analysis: output is tailored for efficient consumption by AI tools, with data interpreted and labeled up front - types deduced from usage and references - so the LLM spends fewer tokens on interpretation and gets higher-quality results. The UI leans on color-coded, clickable navigation of the process space with symbol-labeled memory regions.

Highlights

  • User-mode post-mortem debugger for Windows x86/x64 crash dumps and live processes.
  • Can register as the just-in-time debugger; C++ expression evaluator, SourceServer/SourceLink support.
  • MCP interface designed for automated crash analysis with AI tools.
  • Output pre-interpreted and labeled to cut LLM token costs and improve results.
  • Private beta with invites open.
