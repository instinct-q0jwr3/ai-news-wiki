OpenAI makes Decisions API, its Jev competitor, generally available with new voice and visual modalities, at $0.10/1M input tokens and no output-token charges

type: news-summary · created: 2026-10-23 · updated: 2026-10-26 · confidence: high

Summary

OpenAI made its Decisions API generally available with new voice and visual modes, entering the market for fast, cheap intelligence that made TypeSafe - the startup founded by an ex-OpenAI researcher - a $7.6 billion company. TypeSafe's Jev created the category: decision or System One models that act as super classifiers, taking a set of options and returning a choice with a confidence rating instead of generating prose.

Software developers quickly found these models could replace LLM calls in latency- and cost-sensitive paths, and OpenAI's GA - with Microsoft having shipped its own Decision-1 days earlier - confirms the category is now contested infrastructure rather than one startup's moat. The voice and visual modes extend decision models beyond text classification into multimodal routing, suggesting the labs see System One APIs as a complement to reasoning models across the agent stack.
