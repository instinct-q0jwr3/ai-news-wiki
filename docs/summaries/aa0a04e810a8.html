Maxwell: A new kind of model that sits between code and hardware

type: news-summary · created: 2026-10-19 · updated: 2026-10-19 · confidence: high

Summary

Basis: the Show HN post text from the feed; the product page was not separately fetched. Maxwell is doubleAI's debut 'Code Execution Model', pitched as a new kind of frontier model that sits between code and hardware: it makes programs run faster as they run, without changing a single line, and with no humans in the loop. The model 'sees programs from the inside' - observing execution rather than source text. doubleAI raised $220M and acquired 1,000 Nvidia B300 chips (reported separately by the WSJ).
