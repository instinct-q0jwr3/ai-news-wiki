LLMs are making formal software verification feasible at a much larger scale

type: news-summary · created: 2026-10-23 · updated: 2026-10-25 · confidence: high

Summary

A collaboration with Theorem shows that LLMs have made formal software verification feasible at production scale: using Claude, the team proved security properties at the assembly-code level (RISC-V) across more than 100 real-world open-source libraries - to their knowledge the first large-scale application of AI-driven formal verification to production software. The motivation is blunt: most software is riddled with bugs that AI can now find and exploit, so standard defenses no longer suffice; the only durable answer is proving code free of bug classes.

Formal verification historically demanded years of expert effort per project, confining it to aerospace and crypto kernels. The work shows LLMs collapsing that cost, enabling development workflows where proven security guarantees ride along with ordinary code. The author list spans Anthropic and academic researchers (including Nicholas Carlini and Nickolai Zeldovich), signaling the labs see verified software as part of the answer to the offensive-capability problem they are themselves creating.
