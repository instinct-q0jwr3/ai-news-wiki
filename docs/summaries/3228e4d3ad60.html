Figma announces new features to define how AI agents work on its platform, including Figma Specs, a Markdown editor that lets users define their design language

type: news-summary · created: 2026-10-15 · updated: 2026-10-28 · confidence: high

Summary

At its first Config event in India, Figma announced features to define how AI agents work in its tools. The main one, Figma Specs, is a Markdown editor where teams write down their design language as a reference for people and agents.

Specs can be a standalone file or live inside a design, and Figma also announced a Payload CMS integration.

Highlights

  • Figma Specs lets teams document design rules for agents in Markdown.
  • Adds a Payload headless CMS integration.
