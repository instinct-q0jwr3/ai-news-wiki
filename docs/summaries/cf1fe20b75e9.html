I run multiple Claude Code accounts on one Mac

type: news-summary · created: 2026-11-15 · updated: 2026-11-21 · confidence: high

Summary

A social-post author describes using separate Claude Code configuration directories to keep personal and work accounts signed in on one Mac. The account identity, history and settings can then follow distinct launch commands rather than repeated sign-out and sign-in.

The author emphasizes that separate configurations do not isolate filesystem access and shared links to rules remain shared files. This is one user’s tested setup, with limits noted for other authentication methods and operating systems, not an official guarantee of account or data isolation.

Highlights

  • Post describes a macOS workflow
  • Configuration directories distinguish sessions
  • Account identity still needs checking
  • Filesystem access remains shared
  • Other authentication methods may behave differently
