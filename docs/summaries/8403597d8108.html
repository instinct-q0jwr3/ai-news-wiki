Cairn: Open windows into AI-driven cyber operations

type: news-summary · created: 2026-10-19 · updated: 2026-10-28 · confidence: high

Summary

Cairn is Norforge's transparency project publishing 'open windows' into AI-driven cyber operations - and the excerpted material shows what one looks like from the inside: an agent tasking document aimed at confirmed real e-commerce sites in four countries (US/CA/JP/AU) with 200K-1.5M traffic, pre-verified with Playwright for order placement. The objective listed is unauthenticated RCE via a familiar menu - SQL injection, file-upload webshells, deserialization, SSTI, SSRF - with priorities on login SQLi, unauthenticated endpoints and account takeover. The payload spec is an uploader shell, explicitly not a command-executing webshell, and the environment is a Kali container. It documents, in the operator's own format, how the $5,000-token campaigns are actually tasked.
