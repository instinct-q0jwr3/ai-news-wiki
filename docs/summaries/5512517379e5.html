Show HN: Silent dictation for Claude Code via on-device lip reading

type: news-summary · created: 2026-11-26 · updated: 2026-11-26 · confidence: high

Summary

The lip-dictation prototype for Claude Code uses an on-device visual speech-recognition model to turn silent mouth movements into draft text. Its README describes a camera helper on Apple Silicon, local inference, optional personal adaptation and a history of transcriptions and alternative readings.

The author explicitly calls accuracy modest: a published speech-video word-error figure does not predict silent-mouthing accuracy for an individual user. Local recognition does not mean no data is retained, since history stores text and training keeps mouth crops; setup also downloads external dependencies. Destructive-action caution is a prompt behavior, not a hard permission guarantee. No camera, plugin, model download, training or command was used.

Highlights

  • Prototype uses video rather than microphone input
  • Silent mouthing differs from its training conditions
  • Personal adaptation uses held-out phrase checks
  • History retains transcription text
  • Training crops are an exception to transient frames
  • Setup requires external downloads
  • No camera or local-data operation was performed
