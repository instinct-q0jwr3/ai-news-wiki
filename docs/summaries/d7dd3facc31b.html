Vercel, Cloudflare and others quickly add Jev for agent tool selection

type: news-summary · created: 2026-09-20 · updated: 2026-09-24 · confidence: high

techmeme openai typesafe agentic-systems

Summary

Vercel, Cloudflare and others are moving quickly to add Jev, a model that makes AI tool selection much faster and cheaper, Forbes reports. TypeSafe says Jev matches GPT-5.6 and Sonnet 5 on workflow evaluations, targeting the reality that most of what an AI agent asks a frontier model to do is choosing - which tool to call next, whether to retry, whether a command is safe - rather than writing.
