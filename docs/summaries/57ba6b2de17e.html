Hello Deep Learning: Linear combinations

type: news-summary · created: 2026-09-26 · updated: 2026-10-01 · confidence: high

Summary

The opening chapter of Bert Hubert's Hello Deep Learning series builds a first neural network from scratch: a classifier that tells handwritten 3s from 7s, using the extended EMNIST dataset rather than the classic MNIST. The chapter splits deliberately into a code-free theory half and an implementation half, so readers can take the ideas without the plumbing.

Hubert's framing is that this trivial exercise should both underwhelm ('is this all?') and impress - linear combinations over pixels already separate most 3s from 7s, which is the seed from which everything else in deep learning grows.

Highlights

  • First chapter of the Hello Deep Learning from-scratch series.
  • Build a 3-vs-7 handwritten digit classifier.
  • Uses the improved EMNIST dataset (280k images).
  • Theory half needs no code; implementation half optional.
  • Message: even linear combinations do surprising work.
