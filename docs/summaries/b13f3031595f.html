Tell HN: Codex Is Down [fixed]

type: news-summary · created: 2026-09-26 · updated: 2026-09-26 · confidence: high

hacker-news openai ai-coding-agents

Summary

OpenAI's Codex coding service went down on Friday, with users hit by an 'Incorrect API key' 401 error even though nothing initially appeared on the status page; an incident entry was added later. Reports on X suggested the outage was widespread, and one user said requests were being flagged as security violations half an hour before the full outage. The service was later marked fixed.

The thread turned into a debate about depending on SaaS models for a whole workday. Some argued for local fallback models - one user said their luna agent automatically fell back to a locally hosted bonsai 2 model and the work still got done, just slower - while others pointed out that swapping Codex for Claude Code or another provider is far easier than when a moat-heavy service like GitHub goes down. A quieter faction suggested treating an AI outage like a power outage: do the neglected small tasks, or go outside and wait.
