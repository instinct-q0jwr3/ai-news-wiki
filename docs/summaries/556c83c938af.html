Show HN: BBRouter – Ben Eater's 8-bit computer, simulated on 3D breadboards

type: news-summary · created: 2026-11-01 · updated: 2026-11-14 · confidence: high

Summary

BBRouter is a browser simulator of Ben Eater's 8-bit breadboard computer, built because its author kept wiring the real thing wrong. The feature list is generous for a hobby tool: realistic 3D breadboards, side-by-side diff, an oscilloscope, schematics that auto-sync with the layout, an auto-router (the name stands for breadboard router), and upload from the real Arduino IDE. The twist that got it onto Hacker News: an MCP server, so Claude or another AI app can open, change and run your projects with you - sign in once and it works as you, on your projects only. The fetchable page was mostly UI strings, so finer details are unverified.
