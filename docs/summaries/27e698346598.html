Introducing the New Auto and Auto Code Routers

type: news-summary · created: 2026-11-09 · updated: 2026-11-10 · confidence: high

Summary

OpenRouter has rebuilt its Auto Router and added an Auto Code router for coding tools. It says the new router beats the old one by up to 4x on benchmarks and picks a model 3x faster at p90 (0.65s against 1.96s). Instead of the earlier coarse signals like task type, it weighs eleven factors per request together with live pricing, provider health and cache status, within whatever governance limits the user sets, such as zero data retention or allowed models.

Auto Code is tuned for coding with a higher tier of coding models. The company claims it scores in line with Claude Opus 5.5 across five benchmarks at 74% lower cost per task. It also says it moved back from favoring the cheapest models, which had made the old router drift downward. These are vendor claims.

Highlights

  • New Auto Router: up to 4x better, routing step 3x faster
  • Chooses by eleven factors plus live price, health, cache
  • Auto Code: near Opus 5.5 scores, 74% cheaper per task (vendor claim)
  • Works under guardrails, ZDR, allowed-model lists, BYOK
  • Sees 2.5T tokens a month from 100k+ users
