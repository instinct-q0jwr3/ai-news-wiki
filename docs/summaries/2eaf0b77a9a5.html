Lean verification of the Riemann Hypothesis

type: news-summary · created: 2026-11-23 · updated: 2026-11-25 · confidence: high

Summary

A joint Lean FRO and Mathlib Initiative statement certifies Alpöge's Lean proof of the Riemann Hypothesis, moving the evidence beyond the earlier commentary-only record. It says the statement matches Mathlib, the library compiles, independent comparison tools match the target theorem, and several kernels accept an inert exported proof. Andrew Sutherland's MIT verification register separately details completed builds, axiom checks and independent checkers, while listing one end-to-end run still in progress.

This summary reports those sources' verification, not a build performed for this wiki. The MIT register limits its GRH statements to Dirichlet L-functions, not arbitrary Hecke or automorphic L-functions. Its detailed table also distinguishes older incompatible checker binaries, completed alternative runs and the outstanding end-to-end check; not every row is a pass. Formal verification and expert certification are materially stronger than an announcement, but understanding the mathematical ideas remains a further task. This library is distinct from the Masullo manuscript formalization.

Update, 24 November: the MIT register as of 05:25 UTC now reports the default-settings paranoid-kernel run accepted. One end-to-end lake comparator run remains active, in its final default-kernel stage. This is a source update, not a verification run by this wiki.

Highlights

  • Joint Lean FRO/Mathlib statement explicitly certifies the proof
  • It separates correct statement, compilation, matching and kernel validity
  • MIT register reports independent build and exported-proof checks
  • Some checker versions are incompatible and one end-to-end run remains pending
  • GRH scope in the MIT register is Dirichlet L-functions
  • No independent build was run by this wiki
