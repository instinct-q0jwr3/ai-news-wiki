Lean verification of the Riemann Hypothesis

type: news-summary · created: 2026-11-23 · updated: 2026-11-25 · confidence: high

Summary

A joint Lean FRO and Mathlib Initiative statement certifies Alpöge's Lean proof of the Riemann Hypothesis, moving the evidence beyond the earlier commentary-only record. It says the statement matches Mathlib, the library compiles, independent comparison tools match the target theorem, and several kernels accept an inert exported proof. Andrew Sutherland's MIT verification register separately details completed builds, axiom checks and independent checkers, and now reports all listed checks complete as of 25 November 22:05 UTC.

This summary reports those sources' verification, not a build performed for this wiki. The MIT register limits its GRH statements to Dirichlet L-functions, not arbitrary Hecke or automorphic L-functions. Its detailed table also distinguishes older incompatible checker binaries, completed alternative runs and completed end-to-end checks; older incompatible attempts remain part of the history. Formal verification and expert certification are materially stronger than an announcement, but understanding the mathematical ideas remains a further task. This library is distinct from the Masullo manuscript formalization.

Historical update, 24 November: the MIT register as of 05:25 UTC now reports the default-settings paranoid-kernel run accepted. At that time one end-to-end lake comparator run remained active, in its final default-kernel stage; it completed on 25 November as recorded below. This is a source update, not a verification run by this wiki.

Update, 25 November, 22:05 UTC: the register now says all listed checks have finished. The last lake comparator run against the canonical challenge completed successfully at 21:49 UTC after 122 hours 45 minutes. The earlier pending count above is dated history, not the current status. This certifies the source-reported original artifact, not automatically the new abbreviated lsernau repository, and is not a build run by this wiki.
