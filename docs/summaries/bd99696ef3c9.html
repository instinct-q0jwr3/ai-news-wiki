Show HN: Log every LLM call with tokens, cost, latency, and time to first token

type: news-summary · created: 2026-11-13 · updated: 2026-11-13 · confidence: high

Summary

llmtee is a self-hosted proxy that records LLM requests with token usage, cost and latency while forwarding responses. Its documentation describes provider-key forwarding or proxy-specific keys, per-key spending limits, and support for OpenAI, Anthropic and compatible APIs.

The operational tradeoffs are explicit: the request that exceeds a budget can still finish, a failed proxy can interrupt calls, and slow storage can cause logs to be dropped. Request bodies are logged by default with 30-day retention, so privacy and redaction settings matter as much as the cost dashboard.

Highlights

  • Proxy records usage and latency
  • Budgets are checked before forwarding
  • A crossing request can overshoot its limit
  • Body logging is enabled by default
  • Proxy availability affects application calls
