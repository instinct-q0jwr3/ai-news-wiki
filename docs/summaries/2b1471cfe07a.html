Munich-based SE3, which is developing "spatial intelligence" software to combine feeds into a queryable 3D battlefield map, raised a $30M Series A led by Accel

type: news-summary · created: 2026-11-12 · updated: 2026-11-13 · confidence: high

Summary

Fortune reports that SE3 raised a $30 million Series A led by Accel for software that combines sensor and video streams from unmanned systems into a shared three-dimensional map. An additional semantic layer is intended to let operators query objects and spatial relationships in ordinary language.

The startup describes this as spatial intelligence for military systems. The financing and product description do not independently validate reliability in contested conditions or establish that the software can safely make operational decisions without human judgment.

Highlights

  • Reported $30 million Series A
  • Accel leads with other existing investors
  • Software fuses multiple sensor streams
  • Semantic map supports natural-language queries
  • Battlefield performance claims need separate validation
