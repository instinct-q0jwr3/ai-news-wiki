Show HN: Aq – an attention queue TUI for Claude Code

type: news-summary · created: 2026-11-11 · updated: 2026-11-14 · confidence: high

Summary

Aq is a Rust terminal app that queues every Claude Code session waiting on you: diffs to review, edits to allow, permission prompts and questions, one card at a time. A card arriving while you answer another waits its turn; if you answer in the session's own window, the card stays marked 'answered elsewhere'. Built for people running several tmux sessions; MIT licensed, Linux.

Highlights

  • One queue for all Claude Code sessions needing input
  • Cards never steal the screen
  • 'Answered elsewhere' state when handled in the session
  • Rust, tmux, MIT
