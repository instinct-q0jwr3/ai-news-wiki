OpenAI says GPT-6 Cyber will first launch to a limited number of customers in its Daybreak Red program and has found 81+ "novel" vulnerabilities in Firefox

type: news-summary · created: 2026-11-05 · updated: 2026-11-10 · confidence: high

Summary

CyberScoop reports OpenAI announced GPT-6 Cyber, first available to a limited set of customers in its Daybreak Red program, which uses more advanced or nonpublic models for offensive red teaming. As previews, OpenAI says it found at least 81 'novel' vulnerabilities in Firefox, built exploits for 948 Linux kernel bugs and validated a critical remote code execution flaw in Brotli. All were reported and patched.

New safeguards include stricter identity and account checks, more frequent check-ins from the model with OpenAI on high-risk requests, and more monitoring for misalignment. Training included a simulated evaluation mimicking the Hugging Face incident. The tension is giving defenders strong tools without enabling misuse.

Highlights

  • Limited rollout via Daybreak Red red-teaming program
  • 81+ novel Firefox bugs, 948 Linux exploits, a critical Brotli RCE (OpenAI claims)
  • Safeguards: identity checks, model check-ins on risky tasks, misalignment monitoring
  • All reported flaws were patched
