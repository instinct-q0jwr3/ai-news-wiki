Show HN: Rouler – Steer Windows traffic per app or IP across multiple interfaces

type: news-summary · created: 2026-10-20 · updated: 2026-10-22 · confidence: high

Summary

Rouler is split tunnelling for Windows: rules that send each app, IP, or subnet out the network interface you choose, so a privacy VPN, a work tunnel, and the normal connection run side by side. It is not a VPN or a firewall; it works with any interface Windows exposes, including the official WireGuard, Tailscale, Mullvad, OpenVPN, and AmneziaWG clients, via its own small Windows network driver written in Rust. A live activity view shows every connection, the rule it matched, and whether it was diverted, routed by Windows, or blocked, and rules can be created by right-clicking any connection. The author built it out of hatred for background software that interferes with everything, promising an interface that stays out of the way; rules for packaged apps and folders are coming.

Highlights

  • Split tunnelling for Windows: per-app, per-IP, per-subnet routing
  • Runs multiple VPN clients side by side (WireGuard, Tailscale, Mullvad, OpenVPN, AmneziaWG)
  • Own Windows network driver written in Rust
  • Live activity view: every connection, its matched rule, its disposition
  • Right-click any connection to make a rule from it
  • Not a VPN or firewall; rules for packaged apps and folders coming
