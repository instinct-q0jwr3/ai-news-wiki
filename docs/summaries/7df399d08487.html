Show HN: Uncracked City, detective game where you question LLM suspects that lie

type: news-summary · created: 2026-11-04 · updated: 2026-11-07 · confidence: high

Summary

Uncracked City is a Show HN detective game from a solo founder in which a model plays the detective and you question LLM suspects, one of whom lies. Each case is set in a real city with real public places, while the crime and characters are invented. The sample case is a Halloween 2025 mystery in Salem with four suspects.
