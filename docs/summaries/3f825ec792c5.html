Claude Ship

type: news-summary · created: 2026-11-24 · updated: 2026-11-27 · confidence: high

Summary

Anthropic's primary announcement describes Claude Ship as Code Review plus beta PR Steward and Claude Approvals. PR Steward fixes failing checks, conflicts and feedback but is designed not to approve or merge. Approvals evaluates a policy stored by the team, and the company recommends observe-only use before making its result a required check.

The primary source clarifies costs: policy classifiers and triggered reviews can be billed even in observe mode. Team and Enterprise GitHub repositories are the stated audience, but organizations using ZDR, HIPAA configuration or customer-managed encryption keys are excluded. Internal productivity changes are company observations, not a controlled causal evaluation. No repo policy, integration or spending setting was activated.

Highlights

  • Primary source separates review, repair and approval
  • PR Steward is not the approver or merger
  • Policies and branch rules constrain approval
  • Observe-only can still incur token costs
  • ZDR and certain other configurations are excluded
  • Internal productivity comparisons are not causal proof
