DeepSeek: DeepSeek v4.1 Flash 1017

type: news-summary · created: 2026-10-17 · updated: 2026-10-23 · confidence: high

Summary

DeepSeek has released V4.1 Flash 1017, the October 17 snapshot of its V4.1 Flash model, served under the deepseek-flash API name. It is the first model built on the company's Causal Encoder-Decoder (CED) architecture: a sparse mixture-of-experts with a 552B-parameter backbone that activates only 8B parameters on input and 16B on output, keeping per-token compute low relative to total size.

Image understanding is native this time, with visual and text embeddings trained jointly from the start of pre-training rather than bolted on afterward. DeepSeek targets coding, terminal and computer-use agents plus long-horizon tasks, and says compressed KV caching cuts cache memory to roughly a quarter of the previous Flash generation, a direct cost lever on agentic workloads. The company positions Flash as the cost-efficient V4.1 tier while claiming it beats V4 Pro on performance, speed and task completion time.
