Show HN: Daily GPU Rental Prices Across AWS, Azure, RunPod and Vast.ai

type: news-summary · created: 2026-11-11 · updated: 2026-11-14 · confidence: high

Summary

A daily tracker lists what one GPU-hour costs to rent across AWS, Azure, RunPod and Vast.ai, by GPU model and provider, since November 2, 2026. It warns that Vast.ai hosts set their own per-GB data charges, sometimes US$30 or more per TB each way, which can outweigh a lower hourly price when moving datasets or weights.

Highlights

  • Daily GPU-hour prices by model and provider
  • Vast.ai egress fees can exceed US$30/TB
  • Storage and transfer not in the hourly price
