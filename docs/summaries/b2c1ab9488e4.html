Show HN: Pay-per-Crawl – make AI crawlers pay per page in USDC, for 10 stacks

type: news-summary · created: 2026-10-18 · updated: 2026-10-28 · confidence: high

Summary

Pay-per-Crawl went from a WordPress plugin to ten stacks in a day: the same gate now runs on WordPress, Drupal, Laravel, Next.js, Node, Cloudflare, nginx, Caddy, Traefik and Python, published on npm, PyPI, Packagist and drupal.org. Behavior is identical everywhere: humans and reverse-DNS-verified search engines read free, while AI crawlers and scripts get an HTTP 402 with an x402 v2 header and must pay USDC on Base before the page is served.

The owner keeps 100% of payments, direct to their wallet - no custody, no ForgeMesh account, no API key. Every edition ships the same 85-agent crawler catalog and serves discovery files (/.well-known/x402.json, llms.txt, agents.txt), and each was validated with real $0.01 settlements on Base mainnet before release.
