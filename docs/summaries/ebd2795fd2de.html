Show HN: PhreshOS – OS for Web Apps

type: news-summary · created: 2026-10-02 · updated: 2026-10-04 · confidence: high

Summary

PhreshOS is an operating system for software built with web technologies. It runs on the machine you install it on, keeps your programs running and gives you a browser desktop. Programs get one sign-in, storage, permissions and communication from the system, and everything on the desktop including the file manager is itself a program.

Highlights

  • OS for web-tech programs with a browser desktop.
  • System provides sign-in, storage, permissions and messaging.
  • Even the file manager is a program.
  • Show HN project.
