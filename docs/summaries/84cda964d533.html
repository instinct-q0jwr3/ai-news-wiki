Talorys – A self-hosted personal AI agent on Cloudflare's free tier

type: news-summary · created: 2026-10-10 · updated: 2026-10-10 · confidence: high

Summary

Talorys is a free, open-source personal AI assistant that runs entirely inside your own Cloudflare account: it chats with streaming responses, keeps a durable memory of personal facts you can view, edit and delete, manages tasks, notes and projects, and runs reminders and routines on a schedule, all without any server, database or account operated by its developers.

The pitch is one person, one Cloudflare account, one command (an npx installer). Automations run on Durable Object alarms so nothing has to stay online, the tool is single-user by design with the owner password set at install, and tasks, notes, memories and reminders keep working even if Workers AI is unavailable.

Highlights

  • Personal AI agent living in your own Cloudflare account
  • Memory you can view, edit and delete
  • Tasks, notes and projects, from UI or chat
  • Reminders and routines run on Durable Object alarms
  • Single-user by design; one npx command to install
  • Degrades gracefully without Workers AI
