Here Be Monsters: What Do You Still Need to Know When Agents Do the Work?

type: news-summary · created: 2026-10-27 · updated: 2026-10-27 · confidence: high

Summary

A developer recounts CI failing on App.tsx: SonarQube flagged cyclomatic complexity in a file where Codex had packed entire components onto single lines. On inspection the code was correct and the complexity was warranted by the business requirements; Codex refactored it into ten files and CI passed.

The lesson he draws: as agents write more of the code, owning a software system depends less on having written it by hand and more on knowing enough to recognize when something is wrong, plus the willingness and ability to dive as deep as needed when it matters. The same incident could have gone much worse in code he had never seen.

Highlights

  • Agent-written code passed as correct but tripped a complexity linter
  • Human review confirmed the complexity was warranted; agent refactored on request
  • Owning systems shifts from writing code to knowing when something is wrong
