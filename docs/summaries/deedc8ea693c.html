Show HN: Fusor – Like Vue, but the logic is Rust

type: news-summary · created: 2026-09-28 · updated: 2026-10-01 · confidence: high

Summary

A Show HN for Fusor, pitched as 'like Vue, but the logic is Rust.' The captured fragment describes the template model: plain .html files with the elements, classes, labels and forms you'd write anyway, styled with CSS - with Rust living in double-brace bindings and attributes such as on:click.

On that basis: Fusor compiles a Vue-like single-file-component workflow to Rust logic instead of JavaScript - keeping the declarative template ergonomics while the reactive brain is systems-language code (presumably via WebAssembly, though the capture doesn't say). Rendering model, state handling and bundle story are unknown from the capture.

Highlights

  • Templates stay plain .html - elements, forms and CSS you already know
  • Rust goes in double-brace bindings and directives like on:click
  • Fragment capture; rendering model and toolchain details unknown
