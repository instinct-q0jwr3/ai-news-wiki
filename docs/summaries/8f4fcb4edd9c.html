Grok Bot to Get Local Computer Use

type: news-summary · created: 2026-11-24 · updated: 2026-11-26 · confidence: high

Summary

TestingCatalog reports development settings for local Computer Use and system-wide dictation in Grok Bot for macOS. The local option appears separately from the existing cloud computer, while an internal dictation entry describes hotkeys, a dictionary, snippets and its own settings window.

The article explicitly says both capabilities are still in development and unavailable, with no announced release timing. A visible setting does not prove working functionality, general rollout or access on a particular Mac. No desktop permissions, message integrations or account settings were changed, and the report is not a product test of a released local mode.

Highlights

  • Report is based on development settings
  • Local and cloud computer modes are shown separately
  • Dictation is marked internal
  • Both features are described as unavailable
  • No release date is announced
  • Settings visibility is not a successful product test
