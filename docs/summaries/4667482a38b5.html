Solo Developer Rebuilds Adobe Creative Suite in Rust Using Claude

type: news-summary · created: 2026-10-08 · updated: 2026-10-22 · confidence: high

Summary

A solo developer posting on Reddit as u/ai_art_is_art claims to have rebuilt the most-used Adobe Creative Suite products - PhotoCraft, LightCraft, ImageCraft, FilmCraft and more - as free, open-source Rust applications, generated with Claude and aiming for 100% parity with Adobe's layouts and workflows within a month. The tools are also 'agent-native', exposing menus and functions over a JSON control channel and an MCP server so AI can operate them directly.

Reactions are split. Supporters argue Adobe's business practices invite disruption, and the developer says the work is a clean-room reimplementation with no Adobe source code. Critics call it piracy in disguise, warn of lawsuits, and raise safety concerns about hundreds of thousands of lines of vibecoded software produced by one person with little verification. The original Reddit post was removed, though the GitHub links remain.

Highlights
