Vercel's eve 1.0

type: news-summary · created: 2026-11-18 · updated: 2026-11-18 · confidence: high

Summary

Vercel announces eve 1.0, an open-source agent framework that combines a configurable model-and-tool loop with workflow-backed persistence, approval controls and optional managed hosting. The article describes recovery from completed steps rather than restarting all work after a crash.

Customer testimonials and framework claims were not independently reproduced. Durable execution does not by itself make external side effects idempotent or generated code safe; permissions, replay behavior and sandbox boundaries still require application-specific design. This summary covers the examined release overview.

Highlights

  • Workflow persistence supports recovery

  • Managed hosting is optional
