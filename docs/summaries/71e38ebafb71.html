AI Security Issues Are Social Engineering Issues

type: news-summary · created: 2026-11-12 · updated: 2026-11-13 · confidence: high

Summary

This essay treats prompt injection as social engineering applied to software: untrusted input persuades a system to use authority it should not give the sender. The author argues that better detection alone is insufficient and favors capability-based security, where a program receives only the powers needed for a specific task.

The distinction is between recognizing deceptive language and limiting what a successful deception can do. Narrow authority does not make a model immune to manipulation, but it reduces the damage a confused deputy can cause. The piece connects longstanding computer-security design to the newer problem of instruction-following models.

Highlights

  • Prompt injection exploits misplaced trust in input
  • Social-engineering tactics are the analogy
  • Capability security narrows available authority
  • Detection and containment solve different problems
  • Limited privileges reduce the effect of a successful attack
