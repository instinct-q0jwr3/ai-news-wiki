Benchmarking retrieval for agents on messy real-world company knowledge

type: news-summary · created: 2026-10-02 · updated: 2026-10-08 · confidence: high

Summary

Kapa released Company Knowledge Bench, 1,000 eval cases annotated from real production data to measure retrieval for agents over docs, tickets, chat and code. It scored seven retrievers, all built by Kapa on its own ingestion pipeline, and flags that bias.

Main result: a frontier model with nothing but grep matches a tuned modern retrieval pipeline at 0.61 but takes five times as long, while Kapa's optimised agentic retriever, Kapa Deep, reaches 0.65 in about five seconds. It also notes Cursor dropped embeddings for grep and indexed search, and others are swapping rerankers for Jev-style models.

Highlights

  • 1,000 eval cases from real company-knowledge queries.
  • Grep with a frontier model scores 0.61, same as a tuned pipeline, at 5x the time.
  • Kapa Deep scores 0.65 in about five seconds.
  • All seven retrievers are Kapa's own, so results carry vendor bias.
  • Context: Cursor moved from embeddings to grep and indexed search.
