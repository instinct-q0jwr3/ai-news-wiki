Harness 2: executing agent code as it streams

type: news-summary · created: 2026-11-03 · updated: 2026-11-09 · confidence: high

Summary

Framer rebuilt its agent's harness so the model can express a whole workflow as one program - 'find every use of our old brand color and replace it' across thousands of nodes - and the execution system runs the JavaScript while the model is still writing it. Incoming code is compiled into executable cells and run as it becomes available, so the first changes appear on the canvas before generation finishes. If a cell exposes a failed assumption, the harness stops the stream early, saves the remaining output tokens, and hands the agent what it needs to retry.

The measured results: 33% cheaper and 20% faster overall, 2x fewer tool steps, 39% fewer cached input tokens per message - with no measured quality reduction. The team also did the honest-literature-review thing: mid-writeup they discovered 'Executing as You Generate' (April 2026, Singapore Management University/Beihang) had built the same AST-chunked, persistent-state, early-interrupt system (Eager) for Python, plus one optimization Framer hadn't thought of - removing completed statements from the parse buffer - which they now plan to adopt.

The pattern generalizes beyond design tools: agent harnesses are becoming compilers. The model streams code, the harness runs it mid-generation with real state, and the interaction loop shifts from discrete tool calls to continuous execution - cheaper, faster, and with failure caught before the full answer exists.

Highlights

  • 2x fewer tool steps, 39% fewer cached input tokens; failed assumptions kill the stream early, saving output tokens
