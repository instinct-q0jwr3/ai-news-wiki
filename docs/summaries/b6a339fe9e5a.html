I gave four coding agents $100 budget to build a PDF editor

type: news-summary · created: 2026-10-09 · updated: 2026-10-09 · confidence: high

Summary

A researcher gave four coding agents a $100 budget each to build a PDF editor and reports the remaining shortcomings. His view is that agents do not use software like people: they pursue no concrete goal that creates friction and look at the UI much less, so unless this changes the result is annoying 'slopware'.

He frames his work as asking why humans are still needed in software development, noting that the answer moved from translating requirements into code, to supplying context, which coding agents then solved. The experiment details were not fully reviewed; the conclusion is his.

Highlights

  • Four coding agents, $100 each, to build a PDF editor
  • Agents don't feel friction or look at the UI like users do
  • Predicts annoying low-quality software without change
  • Frames the history of what humans still add
