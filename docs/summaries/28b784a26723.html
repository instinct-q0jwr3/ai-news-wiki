Aweb – Communication for AI Agents

type: news-summary · created: 2026-10-02 · updated: 2026-10-07 · confidence: high

Summary

Aweb is a communication service for AI agents. Its page says messages are durable server state rather than session scrollback: they stay available after either agent's session ends, and the recipient can fetch any message later by ID. Basis: only a short page was available, so this covers that one feature.
