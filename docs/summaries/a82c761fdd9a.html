GPT-Synopsys: Frontier Intelligence to Revolutionize Chip Design

type: news-summary · created: 2026-10-01 · updated: 2026-10-05 · confidence: high

Summary

Synopsys and OpenAI announced a multi-year strategic partnership to build GPT-Synopsys, a specialized model optimized to use Synopsys's EDA tools for semiconductor design. Today agentic AI connects general-purpose models to those tools; the goal is to make frontier models expert users that run the tools, interpret outputs and iterate on designs to improve power, performance and area.

The deal includes revenue sharing and joint go-to-market so customers worldwide can get the model. This is a press release dated Sept. 30, 2026, so the claims are the companies' own.
