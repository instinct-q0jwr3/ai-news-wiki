Embedding EYG in Erlang programs

type: news-summary · created: 2026-10-22 · updated: 2026-10-27 · confidence: high

Summary

This guide shows how to embed the EYG scripting language inside an Erlang application, giving the host program a controlled scripting environment where access to capabilities is tightly governed. The walkthrough builds a minimal Erlang module, my_counters_script, that parses EYG source with eyg@parser:all_from_string and executes it with the interpreter, returning results to the Erlang shell.

From that starting point the guide layers on the affordances a real embedding needs: pretty-printing of parser errors and runtime values so failures are presentable to users, and composable EYG packages installed as the toolkit. The appeal for Erlang and BEAM hosts is that EYG scripts run under explicit control of what they can reach, making the pattern suitable for exposing safe user scripting on top of a long-running system. All code is available in a linked example repository.
