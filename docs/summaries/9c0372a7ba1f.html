DeepSeek V4.1 Flash 1017

type: news-summary · created: 2026-10-19 · updated: 2026-10-25 · confidence: high

Summary

Artificial Analysis profiles DeepSeek V4.1 Flash 1017 (Max), an open-weights model released in October 2026 that lands among the leaders on its Intelligence Index while staying reasonably priced for its size class. The model scores 45 on the index (median for comparable models: 19), supports text and image input with a 1M-token context window, and runs at a notably fast 230 tokens per second. The trade-offs: it is unusually verbose, burning 210M tokens across the evaluation suite versus a 140M median, which eats into its cost advantage. Pricing is moderate at $0.30 per million input and $1.20 per million output tokens, averaging $0.26 per evaluation task. The benchmark suite behind the score mixes agentic and knowledge tests including Terminal-Bench 4.0, SciCode and Humanity's Last Exam.
