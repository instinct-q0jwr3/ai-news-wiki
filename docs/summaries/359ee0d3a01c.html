Recursive releases Flint, an open-weight, 40B-parameter coding model developed with its Eureka Machine AI system, which automated most of the development

type: news-summary · created: 2026-10-21 · updated: 2026-10-26 · confidence: high

Summary

Wired's Will Knight tests Flint, an open-weight 40B-parameter coding model from Recursive, Richard Socher's new company, and calls it evidence that recursive self-improvement is getting closer. Socher says the Eureka Machine automated most of the model pipeline, devising a new way to train the base model, new architectures, and silicon-specific optimized code, letting a handful of researchers build a world-class model in months; shared benchmarks show Flint beating similar-sized models on coding tasks. Knight frames the stakes: AI already helps build AI, a full loop could theoretically improve indefinitely, and that prospect is exactly what worries the doomsayers about control.
