django-modern-rest@0.16.0 release

type: news-summary · created: 2026-10-01 · updated: 2026-10-01 · confidence: high

Summary

The release manager announces django-modern-rest 0.16.0, a fully typed, fast, async-ready framework for building REST APIs on Django. It supports Pydantic, msgspec, attrs and other model libraries. Listed features include built-in auth with sessions and JWT, request and response validation against the OpenAPI spec in debug mode, content negotiation, flexible error handling, SSE and JsonLines streaming, reusable typed abstractions, and OpenAPI coverage and property-based testing via schemathesis.

  • Works with Pydantic, msgspec, attrs

  • SSE and JsonLines streaming
