Show HN: Terse, a Claude Code plugin that halves reply length by cutting filler

type: news-summary · created: 2026-10-07 · updated: 2026-10-09 · confidence: high

Summary

Terse is a Claude Code plugin that tries to cut reply length in half and remove mannered prose such as slogans, metaphors, recaps and the 'it's not X, it's Y' construction. Its author found Claude's own concise mode shortened replies only somewhat.

The README reports measurements on 20 prompts against a real codebase: Fable 5.1 used 46% fewer words and 51% lower cost, and Opus 5.5 used 54% fewer words and 32% lower cost. A judge model counts style violations per thousand words. The rules apply to replies, documents, commits and subagents, and a context meter is included for the status line. The numbers are the author's own tests.
