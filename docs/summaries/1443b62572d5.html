MeshXFS: A clustered filesystem built on XFS, written by AI

type: news-summary · created: 2026-10-16 · updated: 2026-10-19 · confidence: high

Summary

MeshXFS is a shared-LUN clustered filesystem on XFS whose clustering, locking, fencing and on-disk code were written by AI. Claude Opus ran as an autonomous coding agent and consulted other models on the hardest problems.

Highlights

  • Clustered XFS filesystem written entirely by AI.
  • Claude Opus agent did much of the work.
