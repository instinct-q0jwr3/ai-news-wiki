battledrones v14: Compass Rose, a four player map

type: news-summary · created: 2026-10-24 · updated: 2026-10-29 · confidence: high

Summary

Simon Willison shipped battledrones v14, adding a four-player map called Compass Rose to his LLM-built browser game. Previous maps supported only two players; the new one has four-way rotational symmetry and works with the WebSocket multiplayer mode, so up to four humans can join via share links or QR codes, with AI filling spare slots. Claude Opus 4.5 built the map and modified the multiplayer network code from a single initial prompt. The new teams use purple and green robot designs alongside the existing blue and red, and Willison links a replay of a four-way AI battle with the Goliath Armada mutator.
