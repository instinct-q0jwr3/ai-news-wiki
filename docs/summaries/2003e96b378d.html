Open-weight AI models can exploit the patch gap

type: news-summary · created: 2026-10-30 · updated: 2026-10-30 · confidence: high

Summary

A new disclosure shows Z.ai's open-weight GLM 5.3 can identify and exploit Firefox vulnerabilities using security fixes that have been published but not yet shipped to users - the patch gap. In the researchers' experiments, the model built a webpage that, when visited, read a file from the visitor's computer and exfiltrated it with no further interaction; every Firefox version released between September 17 and October 26 was compromisable using only information available at release time. In every successful compromise, GLM 5.3 also found and used an unpublished vulnerability alongside the patch-gap ones.

The significance is the democratization curve: exploiting the patch gap used to require significant time, expertise or access to frontier models with advanced cyber capabilities, so few attackers bothered before fixes shipped. A widely available open-weight model now does much or all of the work, in a setup deliberately built to emulate an unsophisticated actor, at a cost of about $1,000 per Firefox version attacked. The team disclosed its findings to Mozilla and discussed mitigations.

Highlights

  • GLM 5.3 (open-weight) exploits Firefox via fixes published but not yet shipped
  • Drive-by demo: malicious page reads a local file and exfiltrates it, no interaction
  • Every Firefox release Sept 17 - Oct 26 compromisable with release-day information
  • The model also found unpublished vulnerabilities on its own in every compromise
  • ~$1,000 per version attacked, in a deliberately low-sophistication setup
  • Patch-gap exploitation moves from elite capability to commodity
  • Findings disclosed to Mozilla
