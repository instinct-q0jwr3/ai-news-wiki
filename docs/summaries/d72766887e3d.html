Microsoft opens preorders for the $5,999 Surface RTX Spark Dev Box, with 128GB of unified memory to run local models with 120B+ parameters, shipping in November

type: news-summary · created: 2026-10-07 · updated: 2026-10-10 · confidence: high

Summary

Microsoft opened preorders for the Surface RTX Spark Dev Box at $5,999. It is an Nvidia-powered AI mini PC with 128GB of unified memory for running local models with 120 billion parameters or more, and ships in November, The Verge reports.

It targets developers who want to run large models locally rather than in the cloud. Other specs are not in the excerpt.
