Show HN: A language model that lives in a boot sector

type: news-summary · created: 2026-10-31 · updated: 2026-11-14 · confidence: high

Summary

A neural network that boots your PC. bootgpt packs a language model into the master boot record: 512 bytes of hand-written assembly load an 11.5 KB int8 model from the next 23 disk sectors and run it in 16-bit real mode on a 386, with no OS and no C runtime. The machine wakes and dreams a Linux boot log - timestamps, PCI bars and ACPI events for hardware that never existed, generated by a single-hidden-layer character model with 8 characters of context. The output is gloriously almost-right: kernel version strings that parse, device names like ryndrde and usbbore that do not.

The engineering is as charming as the joke. corpus_gen.py fabricates 3 MB of fake dmesg - one kernel version and one disk per session, because repetition is what makes a tiny model look sane - and train.py quantizes everything to int8 with power-of-two scales so the boot sector can do the whole forward pass with imul and a single idiv. The trainer simulates the exact integer math the assembly will run, LCG sampler included, and the Python and boot-sector outputs match char for char. Code lives in the 510 boot bytes; strings, weights and vocab in the data sectors. Any keypress reboots. It joins the boot-sector genre next to Oscar Toledo's chess and BASIC, and sectorllm's real llama2 transformer.
