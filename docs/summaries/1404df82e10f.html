The Hackathon Where We Mostly Just Talked

type: news-summary · created: 2026-09-25 · updated: 2026-09-26 · confidence: high

works-on-my-machine agentic-systems ai-safety-incidents

Summary

Scott Werner and Justin went to a Google hackathon built around a striking fact: Chrome now ships with a language model inside. 'Built-in AI' gives developers local inference APIs - no server calls, no API keys, no rate limits, image understanding and text generation on-device.

Their project asked: what if you could navigate the latent space of image generation without writing prompts? Instead of elaborating 'a cat' into 'a tabby cat sitting...' forever, they explored steering generation directly. The post is mostly the story of the hackathon conversations - hence the title.

Highlights

  • Chrome ships a built-in small language model ('Built-in AI') with local inference APIs
  • No server calls, API keys or rate limits; multimodal on-device
  • Their hack: navigating image-generation latent space without prompts
  • The post is a hackathon narrative - the idea mattered more than the demo
