The Git Forge for Agent-Human Collaboration

type: news-summary · created: 2026-10-27 · updated: 2026-10-30 · confidence: high

Summary

Entire, co-founded by former GitHub CEO Thomas Dohmke, launched what it calls the first Git forge built for agent-human collaboration. Its argument: pull requests have become agent audit logs - coding agents and review agents spam the timeline while humans can no longer tell whether to merge with confidence.

Its central primitive, the Trail, groups work across repositories and computes eval scores on every push. Independent review agents run in cloud sandboxes and submit scores with rationales - examples include Security, Slop, and Human Review Required evals - with the last five runs plus the current run shown per eval, so developers can see whether the loop has converged before merging. Buildkite and Depot are launch CI partners.

Highlights

  • Entire: a Git forge designed for agent-human collaboration, from ex-GitHub CEO Dohmke
  • PRs described as degraded into agent-only audit logs
  • Trail primitive scores every push with independent review agents
  • Shows eval history (last 5 runs) so humans can judge convergence before merging
