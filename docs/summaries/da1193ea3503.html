Releasing AI-generated software

type: news-summary · created: 2026-10-13 · updated: 2026-10-19 · confidence: high

Summary

A piece on software engineering, epistemology and liability when code is written by LLMs, prompted by Robert C. Martin's tweet that he no longer reads his agents' code and instead surrounds them with extreme constraints: unit and Gherkin tests, QA procedures, quality metrics, mutation testing and coverage. The question is whether passing that gauntlet is enough confidence to release code nobody read, and who is responsible when it fails. Basis: the opening of the essay.

Highlights

  • Martin's strategy: don't read agent code, constrain it with tests and metrics.
  • Raises the question of what justifies confidence in unread code.
  • Also asks who is liable for generated software.
