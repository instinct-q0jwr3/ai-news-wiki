Show HN: Edi Life OS – self-hosted life dashboard with an MCP server for AI

type: news-summary · created: 2026-10-09 · updated: 2026-10-10 · confidence: high

Summary

Edi Life OS is a self-hosted dashboard that combines focus, habits, goals, money and projects in one app, with an MCP server so assistants like Claude can read the dashboard, plan goals, log habits and track expenses. It runs on PHP 8.1 and MySQL 8, even on cheap shared hosting, under an MIT license.

The pitch is that habits drive goal progress, Kanban cards appear in the calendar and an overview produces a daily score. It has ten workspaces sharing one sign-in and database. It is a one-person open-source project.

Highlights

  • Self-hosted life dashboard with ten workspaces
  • Built-in MCP server for assistants
  • PHP and MySQL, MIT license
  • Habits feed goals, cards show in the calendar
  • Solo open-source project
