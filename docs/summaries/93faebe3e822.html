Introducing Comfy Router: One API for Frontier Media Models

type: news-summary · created: 2026-09-24 · updated: 2026-09-25 · confidence: high

tldr-ai

Summary

Comfy Router is live on the Comfy Developer Platform: one API for frontier image, video, 3D and audio models, with the freedom to choose the provider for each job for better availability and better prices. Day-one access includes Seedance 2.5, MiniMax H3, Nano Banana Pro, GPT Image 2, Kling and Black Forest Labs, with more coming - the same models 3M+ ComfyUI users already use, now behind one API.

API keys and run history live in one account covering both the models called and the workflows deployed. Coming soon: deploying and scaling custom ComfyUI workflows with the Comfy API.
