AX is an open orchestrator for agent workloads, pitching itself against treating agents as microservices or batch jobs: agents accumulate state, need strict isolation, call model APIs and tool servers, and can burn money in a loop unwatched. It exposes four declarative primitives: sandboxed tasks with CPU/memory limits, workspaces that wire up git repos, MCP servers and skills before the task starts, network policies locked to an explicit allowlist of hosts and ports with credential injection, and centralized model and secret configuration that rotates with one apply. ## The case against careless AI coding

Concepts: [AI coding agents and the software pipeline](../concepts/ai-coding-agents.md)

CI reworked for agent throughput, a quality-management rebuttal, another 'don't write with AI' essay, and a Kool-Aid deconversion.

The author uses Claude, Codex/ChatGPT and Gemini all day for coding, research and data work, but refuses to let them write, because writing forces you to think deeply about the problem and what you want to communicate. Lossless-memory is a personal AI memory system built on a refusal to summarize: most long-term memory systems either compress conversations into notes or embed and retrieve similar chunks, and both lose what actually matters to someone who talks to the same AI every day, what was actually said, and when. This project appends every conversation turn as a fixed seven-field record (timestamp, actor, role, type, verbatim text, model, session) to a per-day JSONL file; the raw logs are the source of truth and every index can be deleted and rebuilt from them. ([read more](../summaries/ff78d6ac0015.md)).

Foremerge is an open-source coordination protocol for coding agents, built above Git. The problem: two agents working the same project in isolated worktrees can both finish, both look correct, and have undone each other's work, because Git compares text, not intent. If one agent moves every caller to a new StripePaymentService while another adds PayPal support to the old PaymentService, nothing overlaps textually, Git merges both, and the PayPal work is stranded on a class nothing calls. ([read more](../summaries/76c1ddbc8498.md)).

The Register's account of Amazon blocking Meta's Muse: the ecommerce giant cut off Meta's personal AI agent from shopping on its site after unsuccessfully asking Meta to keep it out, citing credential capture and transparency concerns while guarding a lucrative customer journey. Users attempting it are told access by an 'unauthorized AI agent' violates Amazon's Conditions of Use. ([read more](../summaries/b8c660d0347d.md)).

This Noema essay reads the AI moment through James Burnham's 1941 'The Managerial Revolution', which declared capitalism finished and wrongly predicted managerial superstates, and asks what class structure AI actually threatens. Its subject is the 'homoploutic' class: households that hold both capital and high-value labor, resolving the capital-labor conflict inside the same person. The class's ideological machinery is meritocracy, per Daniel Markovits's 'The Meritocracy Trap' (2019): an elite convinced its position is earned, even as parental investment per elite child approaches a $10 million inheritance by the end of graduate school, an M-E-M' circuit where E is the education of one's children. ([read more](../summaries/f6258524fd9c.md)).

Matthew Butterick - author, designer, programmer and lawyer - argues that the public debate about AI catastrophe is stuck in what he calls the 'Skynet fallacy': sci-fi scenarios of rogue AI that generate fear but no realistic policy paths. His own 2024 prediction was that a catastrophe from alignment failure is far more likely than one from malignant machine agency, and he sees that prediction 'ripening.' ([read more](../summaries/fdffa22cafa5.md)).

Ian Bogost argues in The Atlantic that AI did not break American college so much as expose that it was already breaking. Students can now do essentially all schoolwork automatically, problem sets, code, essays, leaving professors unsure whether they are teaching or LARPing for students pretending to learn, while some faculty offload recommendation letters, grant proposals and even papers to AI. Meanwhile universities invest in AI initiatives, infrastructure and degree programs, racing toward and away from the technology at the same time. ([read more](../summaries/a9e2d774140a.md)).

## Weekend hardware and oddities

Concepts: [Small and specialist models](../concepts/small-specialist-models.md)

An M5 Ultra Mac Studio review, frontier AI on your own hardware, escaping macOS 27's model downloads and Siri, and continual learning on 8GB of VRAM.

Mini-AGI is an experiment in continual learning: a byte-level language model that assembles its own architecture, trains from scratch on a single 8 GB VRAM GPU, and keeps learning from everything it reads. Weights are stored as ordinary files on disk and paged onto the card as needed, so the parameter count is bounded by free disk space rather than VRAM; the model grows new capacity while training when it runs short and prunes what nothing asks for. Reading and serving use exactly the same code path, so training never has to stop. ([read more](../summaries/458d8111da3b.md)).
