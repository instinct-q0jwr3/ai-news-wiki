## The bubble question

Whether the spending is a bubble or a one-off build-out.

A blogger argues the AI bubble may not exist. He grants that AI companies have committed to at least $3 trillion and spent an estimated $1.9 trillion, around $5 trillion in total, and that opaque financing vehicles make true costs hard to see, which he calls the strongest point for the bubble view. His claim is that the 'any day now' pop is taken for granted online, while there is a realistic chance that growth is justified with more room left. ## The workbench

Hands-on benchmarks.

Simon Willison, curious on a dog walk, asked Claude (Opus 5.5) to compare writing a SQLite parse_number() function, which strips commas, $, £ and % and handles a leading minus, as a C extension versus Rust. The binaries differ a lot: the Rust extension was 321 KB with rusqlite and 298 KB with sqlite-loadable-rs, against 14 KB for C. Yet the Rust version ran faster. He then asked for a C version that matches or beats Rust. Net cost per row over 2 million rows on mixed data was 67 ns for the first C, 19 ns for the new C, 46 ns for rusqlite and 41 ns for sqlite-loadable. On integers only: 25, 16, 36 and 32 ns. On decimals only: 106, 18, 55 and 47 ns. He had the model write the work up as a research report in the style of his simonw/research repository. ([read more](../summaries/5f9c9c54ca7d.md)).

Simon Willison says most changes to his projects now arrive as pull requests opened by Claude Code or Codex, and agents write PR descriptions that are accurate but so thorough they read like slop. His reaction is to skip them, even when he is the one driving the agent. He wants a short human-approved introduction that says what the PR is for and whether it deserves attention. His low-effort fix is the HTML details and summary elements, which GitHub Markdown supports. The human writes a short visible summary and the agent's long description sits collapsed underneath, so readers choose how deep to go. ([read more](../summaries/2f5838627a2c.md)).

Simon Willison says a Hacker News comment pushed him to try Three.js-free 3D. He had Claude Opus 5.5 build a nudibranch-themed Faberge egg in Three.js (77 KB), then port it to vanilla JS and WebGL (98 KB). The two differ and Claude explained why in a shared transcript. He finds Three.js code easier to read but rarely reads the code. ([read more](../summaries/8878da69c17a.md)).

OpenRouter has rebuilt its Auto Router and added an Auto Code router for coding tools. It says the new router beats the old one by up to 4x on benchmarks and picks a model 3x faster at p90 (0.65s against 1.96s). Instead of the earlier coarse signals like task type, it weighs eleven factors per request together with live pricing, provider health and cache status, within whatever governance limits the user sets, such as zero data retention or allowed models. Auto Code is tuned for coding with a higher tier of coding models. The company claims it scores in line with Claude Opus 5.5 across five benchmarks at 74% lower cost per task. It also says it moved back from favoring the cheapest models, which had made the old router drift downward. These are vendor claims. ([read more](../summaries/27e698346598.md)).

Flide is a GitHub project that serves 'Jev-style' decision models through an API and claims up to 9.5 times faster inference than vLLM and SGLang by forking model state exactly, with answers matching those the model gives a question alone. The README shows installing it with pip and serving a small model. ([read more](../summaries/15b43f2ededd.md)).

Samir Sarwar's repository teaches LLM inference from first principles by building a small engine in C++ and CUDA. The series follows what happens between a prompt and a generated token: loading weights, then running each transformer part on the GPU. Parts cover prefill, decode and the KV cache, then static and continuous batching with a paged cache and online-softmax decode attention, using a Llama 3.2 1B path. The author says the 80+ pages of handwritten notes and diagrams were written without AI. The engine keeps a fixed 2,048-token context and a KV pool of 128 MiB by default. Admission reserves room for each request's maximum length so generation cannot deadlock, which avoids preemption but can limit concurrency when output budgets are large. ([read more](../summaries/7b93e0d31c62.md)).

Uniform is a preview-stage UI library that replaces native text, layout and rendering with its own core written in C, compiled to WASM for the web and to native code elsewhere. A full web app using it is under 280 KB compressed. It renders through Metal on iOS and macOS and through GPU APIs in the browser, aiming for pixel-exact layout and consistent behavior across platforms. It offers a JavaScript API with no build step for fast iteration and a C API for more speed, and compiles from source, shaders included, in under a second. The README says it was written by hand with no AI involvement. The API may still change and not every feature is done. ([read more](../summaries/685570544cf8.md)).

## Code, licenses and security

Open source and security adapt to AI.

On The Verge's Decoder podcast, Nilay Patel talks with Alex Stamos, chief security officer at Cognition, about how AI is changing cybersecurity. Stamos argues the multibillion-dollar security industry as it existed is overdue for disruption. The page shown was the episode introduction, so the detail comes from the host's summary. ([read more](../summaries/b8770ac6b953.md)).

Terence Eden cut bot traffic to his hobby site OpenBenches by over 80% with a simple trap. The site had sent 2.5 TB in a month, mostly AI crawlers pulling data and images. He adds a honeypot directory forbidden in robots.txt; any visitor that requests it is a bot ignoring the rules, and a small PHP page writes its IP into a blocked list in .htaccess, which then returns a 402 'Payment Required' message. The post gives the code and warns it may block innocent visitors. ([read more](../summaries/bd049c9a3ec5.md)).

Asahi Linux, the project that made Linux run on Apple Silicon Macs, is moving all its repositories from the permissive MIT license to GPL version 2 or later. It says people have lifted unreleased feature code from developers' personal forks, or had AI rewrite it to hide where it came from, in order to replace the project and profit from it. MIT explicitly allows reuse and has no protection against bad-faith actors, so the team chose strong copyleft only. It Foss, which reports the change, explains 'code laundering': passing someone's code through a rewrite so it can be used without credit or license obligations. LLMs make that cheaper than the old manual renaming. Critics on social media object that relicensing may happen without every earlier contributor agreeing, and Asahi did not say how past contributions will be handled or name anyone it accuses. ([read more](../summaries/6ee4744c6df9.md)).
