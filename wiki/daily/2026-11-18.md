Simon Willison introduces an external-sandbox pattern in which a coding agent remains outside the environment that executes its generated code. Three demonstration implementations expose a common local API, with optional network allow-listing and credential replacement. The separation offers a way to compare isolation approaches, not proof that any agent workflow is safe. Its value depends on which operations are routed through the sandbox and what the proxy permits. The article describes an experiment and its design; no implementation was installed or security audit performed for this summary. ([read more](../summaries/4dd2685da65f.md)).

Cerebras describes a production inference design that moves prompt processing to AMD GPUs while Cerebras CS-3 systems generate the response. It reports five times the token throughput per megawatt against a CS-3-only baseline on a specified GPT-OSS-120B endpoint, without reducing generation speed in that deployment. This is a company-reported configuration comparison, not a universal efficiency ratio against GPU systems or across models.
