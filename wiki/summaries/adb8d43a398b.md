# Claude Mythos slashed software work to onboard AMD GPUs to around three days

_type: news-summary · created: 2026-11-17 · updated: 2026-11-21 · confidence: high_

`hacker-news` `anthropic` `nvidia` `compute-buildout`

## Summary

Tom’s Hardware reports Anthropic told IPO investors that Claude Mythos Preview handled most kernel work needed for prompt processing of one model on AMD MI355X GPUs in roughly three days. The comparison is with the company’s account of earlier accelerator bring-up projects taking six to twelve months.

That is a company claim about a defined workload reaching useful performance, not independent proof that a complete hardware migration takes three days or that every kernel beats hand tuning. It suggests one possible reduction in porting costs without establishing that Nvidia’s broader software advantage has disappeared.

## Highlights

- Claim comes from an investor presentation
- Scope is prompt processing for one model
- Historical staffing comparisons are not a controlled benchmark
- Useful performance is not universal optimality
- Broader switching costs remain separate
