# Show HN: phpClaw – AI agent runtime for PHP with tools, memory and guards

_type: news-summary · created: 2026-10-29 · updated: 2026-10-29 · confidence: high_

`hacker-news` `agentic-systems`

## Summary

phpClaw is an AI agent runtime for PHP with the pieces every 'AI in PHP' tutorial makes you hand-roll: tools, memory, security guards and a ReAct loop (reason, act, observe, repeat) with zero framework dependencies in core. Setup is one environment variable and a builder call - the builder probes ANTHROPIC_API_KEY, then OpenAI, Groq, Gemini, Mistral, DeepSeek and Ollama in order and uses whatever it finds, with no YAML and no vendor lock-in.

The tool kit is production-flavored: a shell tool restricted to an allowlist of commands, HTTP and file-read tools, a read-only database query tool and a code search tool. The agent decides which tools to call and in what order until it has an answer or hits the iteration cap, and the same loop works whether the tools touch the shell, a database, HTTP APIs or the codebase. MCP support is included.

## Highlights
