# The October inflection point for vibe game development

_type: news-summary · created: 2026-10-28 · updated: 2026-10-28 · confidence: high_

`simon-willison` `openai` `anthropic` `agentic-systems` `ai-coding-agents` `compute-buildout`

## Summary

Simon Willison declares October 2026 the inflection point for vibe coding computer games, a year after November 2025 did the same for coding agents generally. His evidence: a run of Claude Opus 5.5 sessions that went from single prompts ('build a three.js game called Tree Appreciator') through iterative direction to full games.

One sequence grew a top-down RPG village demo - NPCs, furniture, transparent walls indoors, basements and tunnels, a cave with a sleeping troll - then quadrupled the playable area and added plot, twists and a magic system on request. Another produced a mobile-friendly game with the instruction 'make it a LOT more fun'.
