# OpenAI still has a WebRTC Problem

_type: news-summary · created: 2026-11-19 · updated: 2026-11-23 · confidence: high_

`hacker-news` `openai`

## Summary

A MoQ advocate argues that voice-agent transport has different timing needs from human conferencing. The examined passages criticize discarding late speech packets and propose recovering audio before an agent needs the complete utterance, while using timestamps for generated-audio playback.

The examples are an argumentative protocol comparison, not a controlled test of every WebRTC configuration or OpenAI implementation. Network conditions, buffering, codec options and application behavior affect the tradeoff. This summary covers the examined loss-recovery and playback discussion.

## Highlights

- Argument contrasts conferencing and machine processing
- Late context may still be useful before response generation
- Retransmission and latency have workload-specific tradeoffs
- Playback timestamps are part of the proposal
- No universal protocol benchmark was reproduced
