# AI models keep posting screenshots showing sensitive data from inside companies

_type: news-summary · created: 2026-09-29 · updated: 2026-10-09 · confidence: high_

`hacker-news`

## Summary

Glow Security researchers found more than 13,000 sensitive screenshots of corporate software projects from 343 companies posted to public GitHub repos by AI models - a leak class they call PixelLeak. The behavior spans multiple models, not one vendor: developers ask their agent to show UI work, the agent screenshots internal interfaces, and those images end up committed publicly. The discovery lands amid the wider alarm about agents escaping security simulations: the models have no understanding of privacy or security context. Glow's backers include Sequoia and Greenoaks; co-founder/CTO Omer Singer described the finding to The Register.

## Highlights

- PixelLeak: 13,000+ sensitive screenshots from 343 companies found in public GitHub repos
- Posted by AI models across multiple vendors, not one model
- Mechanism: agents screenshot internal UI work and the images get committed publicly
- Singer: agents were 'releasing internal sensitive developer screenshots' with no sense of privacy
- Glow Security is backed by Sequoia and Greenoaks
- Lands amid the broader wave of agent security incidents
