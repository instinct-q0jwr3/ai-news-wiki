# Game Boy Color on My Conference Badge

_type: news-summary · created: 2026-10-27 · updated: 2026-10-27 · confidence: high_

`simon-willison` `google` `gemini` `ai-safety-incidents` `compute-buildout`

## Summary

Simon Willison reports from GitHub Universe that the conference badge is a full color-screen computer, and that Steve Francia - working with Gemini - got a NES emulator running on it, then went further and deployed Game Boy and Game Boy Color emulators. With the right ROM, the badge plays The Legend of Zelda: Link's Awakening, and flipping the badge upside down puts its touch buttons in game-controller position.

## Highlights

- GitHub Universe badge runs Game Boy Color emulation
- Steve Francia built NES then GB/GBC emulators with Gemini's help
- Badge flips upside down for controller-style touch buttons
- Light link-post; AI angle is Gemini-assisted emulation hacking
