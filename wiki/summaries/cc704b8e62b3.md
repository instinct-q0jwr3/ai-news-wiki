# Show HN: KiviDB, a faster Redis-compatible memory database and vector cache

## Summary

KiviDB is a multi-threaded, Rust-written alternative to Redis and Valkey that speaks the Redis protocol (RESP2 and RESP3), so existing clients, redis-cli and libraries work unchanged - with full-text and vector search built in. It runs every core on a sharded in-memory design and persists via snapshots plus an optional append-only file. The headline benchmark: on the same 32 cores, KiviDB serves 21 million pipelined GETs per second, about 9x Redis 8 and 2.3x Dragonfly, at under half of Dragonfly's p99 latency. It listens on port 6380 by default so it can run side by side with an existing Redis.
