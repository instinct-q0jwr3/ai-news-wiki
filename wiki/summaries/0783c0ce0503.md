# Claude Mods: Flipping the Harness Inside Out

_type: news-summary · created: 2026-10-21 · updated: 2026-10-22 · confidence: high_

`latent.space` `anthropic` `agentic-systems`

## Summary

Latent Space's Dan McAteer introduces Claude Mods, plugins for Claude Code made of TypeScript or JavaScript functions that run inside the application and respond to events like prompts, tool calls, and renders, observing them, modifying their display, or replacing default behavior outright. His framing: as models absorb more of the agent harness into their weights, what remains of the harness faces the human, becoming an Attention Interface that decides when the agent interrupts, what it shows, and which decisions need you. Claude Mods are middleware for that interface, letting the human and the agent co-design how Claude works with you. His bet: the harness becomes a platform other companies build on, the way the browser became a platform for web apps.

## Highlights

- Claude Mods: TypeScript/JS plugins that run inside Claude Code
- Respond to events: prompts, tool calls, renders; can replace default behavior
- Framed as an early 'Attention Interface': the harness now faces the human
- Human and agent co-design how the agent interrupts and asks
- Bet: the harness becomes a platform, as the browser did for web apps
- Author has used Mods for weeks to mold Claude Code to his workflow
