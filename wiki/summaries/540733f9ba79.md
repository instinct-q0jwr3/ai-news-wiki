## Summary

HaCI is a GitHub project for edge detection in RGB images using a compact, fully distributed algorithm. It compares each pixel with its eight neighbors, pools responses by orientation, and uses contour facilitation and suppression in several stages. It is linked to a Zenodo paper.

## Highlights

- Distributed edge detection with four stages
- Inspired by biological vision gain control
- Paper on Zenodo
