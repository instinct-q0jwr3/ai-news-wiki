## Summary

Penguin Mail is an open-source Rust email client for Linux with an AI assistant: press Ctrl+J and ask, for example, which sent mail is still waiting on a reply. The assistant reads mailboxes with the app's own tools and shows each one it ran. Basis: only a short fragment was available.
