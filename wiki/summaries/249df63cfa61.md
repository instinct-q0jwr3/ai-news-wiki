# Windows 11 Is Collecting Data on Which Coding Agents and Developer Tools You Use

_type: news-summary · created: 2026-11-17 · updated: 2026-11-25 · confidence: high_

`hacker-news` `agentic-systems` `ai-coding-agents`

## Summary

A reverse-engineering report traces Windows coding-agent and developer-tool usage categories from executable-name matching through saved state into a diagnostic upload queue. The author describes reproductions in a Windows 11 ARM64 VM and a clean US-region installation, including detection of an ordinary executable renamed as a coding agent.

The reported output is a bitmap of observed categories, not prompts, source code or time spent in each agent. Upload queuing depended on optional diagnostics, and the author found the feature disabled in another baseline image. The investigation supports a specific privacy concern without showing the behavior is enabled on every Windows installation or independently confirming delivery to Microsoft.

## Highlights

- Name matching can misidentify renamed executables
- Report contains category bitmaps rather than prompts
- Optional diagnostics govern the observed upload queue
- Tests cover specified builds and a US setup
- Queued transmission is not proof of server receipt
