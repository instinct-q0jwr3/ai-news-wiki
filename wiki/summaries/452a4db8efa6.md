# datasette-llm 0.1a9

_type: news-summary · created: 2026-11-01 · updated: 2026-11-14 · confidence: high_

`simon-willison` `openai` `agentic-systems`

## Summary

A one-beat tooling note from Simon Willison: datasette-llm 0.1a9 now picks up the default model configured in LLM, so Datasette Agent works out of the box - uvx --with datasette-agent datasette content.db --internal internal.db - without explicitly setting a model. Bigger Datasette Agent upgrades are promised soon.

## Highlights

- datasette-llm 0.1a9 inherits LLM's default model - no more explicit -s plugins.datasette-agent.default_model
- Datasette Agent now runs with a single uvx command
- Larger Datasette Agent upgrades are in the pipeline
