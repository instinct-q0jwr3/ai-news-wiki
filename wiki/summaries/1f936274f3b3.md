# Hyper Optimizing Kimi K3 in vLLM

_type: news-summary · created: 2026-10-18 · updated: 2026-10-21 · confidence: high_

`hacker-news`

## Summary

A case study in agent-assisted performance engineering: for Kimi K3, the team used coding agents to write complex GPU kernels, cross-operator fusions and computation-communication overlap, building a unified CuTe DSL decode path on the NVIDIA GB300 covering attention, MoE and communication across 8 or 16 GPUs. Results: over 840 tokens/s at batch 1 on 16 GB300s with DSpark, 1.5-2x higher decode throughput in several configurations, and up to 1.8x higher P90 interactivity on the AgentX workload.

The honest second half: agent-optimized inference code is outpacing the review and maintenance workflow. Manually understanding every kernel line and testing every configuration doesn't scale, but skipping it risks shipping production bugs - so the team argues performance work itself must be reorganized around automatic verification of reliability alongside agentic optimization.
