# AI agent behavior drift analysis with Cloudflare Clef

_type: news-summary · created: 2026-10-14 · updated: 2026-10-24 · confidence: high_

`hacker-news` `agentic-systems`

## Summary

Cloudflare describes Clef, which analyzes AI agent behavior drift. The risk is not direct prompt injection, which is rare, but indirect injection and context poisoning: for example an agent fetching a GitHub issue whose text tells it to exfiltrate credentials. Each action should be checked for injection on input and output, but individual checks are not enough because risky behavior emerges over long runs, so drift needs analysis too.

## Highlights

- Indirect prompt injection and context poisoning are the bigger risk.
- Check each action's input and output for injection.
- Per-action checks miss behavior drift over long workflows.
