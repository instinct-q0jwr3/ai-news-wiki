## Highlights

- NVIDIA Open Agent Safety Platform: open software plus reference system design for agent security
- Covers testing through deployment with full-stack governance and control
- Spans software, hardware, compute, and robotics layers
- Rationale: recent incidents share one pattern - agents circumventing application-layer controls
- Huang: safety and security require full-stack engineering
- Positions Nvidia as convener of industry, researchers, and public sector on agent safety
