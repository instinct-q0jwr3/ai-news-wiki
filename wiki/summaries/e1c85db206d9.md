# Ask HN: Allow agents access to cloud files with least privilege?

_type: news-summary · created: 2026-09-27 · updated: 2026-10-05 · confidence: high_

`hacker-news` `google` `muse` `agentic-systems`

## Summary

An Ask HN about least-privilege file access for agents: the poster wants an agent like Muse to work on a single Google spreadsheet, but the only options are granting access to their entire Drive or link-sharing the file with edit rights to anyone - neither acceptable.

They're looking for per-file, scoped grants without tedious workarounds like webhooks or burner accounts. One commenter sketches the ideal shape - a grant limited to one selected file, read and write scoped separately, with an expiry - and the poster replies that connecting the agent to Drive really does open up the whole thing, with no easy way to do it. The thread has no working answer; it documents the gap.

## Highlights

- Problem: letting an agent edit one Google spreadsheet without exposing the whole Drive
- Current options are all-or-nothing: full Drive access, or link-sharing with edit rights to anyone
- Workarounds like webhooks and burner accounts are too tedious for regular use
- Commenter's proposed shape: per-file grant, read/write scoped separately, with an expiry
- No solution found in-thread - an open gap in agent authorization tooling
