# Embedding boolean circuits in a neural network

_type: news-summary · created: 2026-11-03 · updated: 2026-11-14 · confidence: high_

`hacker-news`

## Summary

This post asks how to attach a boolean-circuit 'sidecar' to a trained neural network, and is openly thinking out loud. Representing logic is easy: with 0/1 inputs and a threshold activation, AND(A,B) = A+B-1.5 > 0, OR(A,B) = A+B-0.5 > 0 and NOT(A) = 0.5-A > 0, which compose exactly like symbolic operators.

The hard part is wiring the circuit to a network whose signals are not clean 0 or 1. It needs an ingress mapping from network neurons into the circuit and an egress mapping back. The author defines a Probe, a threshold on a specific neuron's output (for example 'L3 N234 > 1'), turning real values into booleans. The mental image is Neuralink for LLMs.

The interest is in editing behavior with exact logic: guaranteed rules grafted into learned systems. Only the setup and the probe idea were read; how the egress side and any results work is beyond the captured text.

## Highlights

- Boolean gates are single neurons: AND, OR and NOT as thresholded weighted sums
- The problem is ingress and egress mapping between messy real-valued activations and clean boolean signals
- 'Probe' = threshold on a chosen neuron, e.g. L3 N234 > 1
- Exploratory thinking-out-loud post; later sections not read
