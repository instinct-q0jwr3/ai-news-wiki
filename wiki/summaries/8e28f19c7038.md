# Huawei releases MACaQ, its internal quantizer for local inference

_type: news-summary · created: 2026-11-11 · updated: 2026-11-14 · confidence: high_

`hacker-news`

## Summary

MACaQ provides calibrated quantization for local inference across text and other model types. The project documents paths for GGUF with llama.cpp, compact checkpoints with vLLM and PyTorch, and diffusion workflows through Diffusers. It aims to reduce weight and activation precision without tying the method to one model family.

The repository claims a 122-billion-parameter model can be quantized in 64 minutes using 32.5 GB of device memory, and reports favorable accuracy-time comparisons. These are project measurements that depend on configuration. Backend support also has limits: the Ascend kernels require further runtime integration for full-model execution.

## Highlights

- Quantizes weights and activations
- Text, diffusion and speech workflows documented
- Multiple inference backends supported
- Project claims fast low-memory calibration
- Accuracy comparisons are project-reported
- Ascend kernels are not a complete serving integration
