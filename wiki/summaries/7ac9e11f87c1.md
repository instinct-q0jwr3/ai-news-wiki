# AI physics startup PSI says a system running a non-public Anthropic model proved the Aaronson-Ambainis conjecture, a quantum computing question open since 2008

_type: news-summary · created: 2026-11-06 · updated: 2026-11-14 · confidence: high_

`techmeme` `anthropic`

## Summary

AI physics startup PSI (Physical Superintelligence) says a research system running a non-public Anthropic model proved the Aaronson-Ambainis conjecture, open since 2008, which concerns when quantum computers can be exponentially faster than ordinary ones. The page quotes an outside expert calling it a huge result that draws on analysis of boolean functions and probabilistic combinatorics. PSI frames it against Shor's 1994 factoring algorithm as context. This is the company's own announcement; independent verification of the proof is not shown in the text read.
