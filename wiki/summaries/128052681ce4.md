# Introducing Clairic, a new System One class of extraction models

_type: news-summary · created: 2026-10-20 · updated: 2026-10-27 · confidence: high_

`tldr-ai` `small-specialist-models`

## Summary

Cloudflare announces a preview of Clairic, billed as the first System One extraction model, hosted on Workers AI as @cf/cloudflare/clairic with open weights promised soon. Where the decision models that defined the System One category (TypeSafe's Jev, Cloudflare's Clef) return probabilities over a listed set of options, Clairic extracts, computes, estimates, and forecasts typed values directly: numbers with an 80% range, plus names, dates, and lists. Because it answers in a single pass without generating tokens, it cannot mistype an answer or hallucinate in the LLM sense, returns null when the input contains no answer, and attaches confidence scores; Cloudflare claims higher accuracy, faster latency, and lower cost than routing the same structured-extraction calls through frontier LLMs.

## Highlights

- New model class: System One extraction models, complementing decision models
- Single-pass, token-free answers, typically under a second
- Returns typed values: numbers with 80% ranges, dates, names, lists, or null
- Confidence scores ship with outputs for trust gating
- Available now on Workers AI; open-weights release planned
- Pitched at repetitive structured calls like invoice totals, delivery dates, cost estimates
- Framing traces to TypeSafe's Jev and Kahneman's System One concept
