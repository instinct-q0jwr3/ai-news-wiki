# How are you dealing with all the negative side effects of AI on the web?

_type: news-summary · created: 2026-11-07 · updated: 2026-11-07 · confidence: high_

`lobsters` `google`

## Summary

A Lobsters thread asks how people cope with AI's side effects on the web. The opening post says high-quality human interaction has never been harder to find, and blames AI hype for the slop that now tops search results, aggressive rate limiting on Google and DuckDuckGo, GitHub pages that require login, and Anubis bot checks that sometimes block real users.

The author reports lost productivity, and notes the irony that LLM summaries become tolerable mostly because they surface good links buried under slop. Replies suggest relying less on the web, using books, communities like Lobsters and RSS. The author answers that a five-year-old book will not explain a bug in a new chipset, but an existing bug report on the web probably will.

## Highlights

- Search results are crowded with slop, which makes LLM summaries look acceptable.
- Rate limiting and error screens on major search engines interrupt ordinary use.
- GitHub browsing without login and Anubis checks add friction.
- Suggested fixes: books, communities, RSS.
- Counterpoint: for fresh technical problems, web bug reports remain the best source.
