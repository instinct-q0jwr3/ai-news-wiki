# Document Review with Unsiloed and TypeSafe Jev

_type: news-summary · created: 2026-10-13 · updated: 2026-10-28 · confidence: high_

`hacker-news` `typesafe`

## Summary

A tutorial on catching bad data in document extraction: a pipeline can read a value correctly and still pass on a wrong one, such as a clearly printed extra zero. The authors combine Unsiloed, which extracts structured fields and locates them on the page, with TypeSafe's Jev, which judges extracted information against focused questions.

A Jev request separates state (the extracted records plus context) from questions, each returning a typed answer: a probability that a statement is true, a choice among named options, or a score on a rubric. The results together decide which fields need human review. Basis: the first part of the article.

## Highlights

- OCR can be right and the data still wrong.
- Unsiloed extracts fields with page locations; Jev checks them against questions.
- Answer types: probability, named choice or rubric score.
- Combined output flags fields for review.
