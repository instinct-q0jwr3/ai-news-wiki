# ChatGPT Desktop forwards your SSH agent to remote machines

_type: news-summary · created: 2026-11-09 · updated: 2026-11-14 · confidence: high_

`hacker-news` `openai` `agentic-systems` `ai-coding-agents`

## Summary

A Hacker News submission says ChatGPT Desktop can forward a local SSH agent to remote machines, allowing remote work to authenticate using local credentials. It links a code-review discussion as support, but that underlying implementation was not independently inspected here.

Agent forwarding is an authentication capability, not evidence that private keys are copied or that every remote task is authorized. The precise defaults, access limits and affected versions remain unresolved from this short thread.

## Highlights

- User describes SSH-agent forwarding
- Linked code review is not examined here
- Authentication differs from copying a private key
- Remote access expands the trust boundary
- Defaults and version scope remain unknown
