# Gemini Agent

_type: news-summary · created: 2026-10-09 · updated: 2026-10-09 · confidence: high_

`tldr-ai` `google` `gemini` `agentic-systems`

## Summary

Google Cloud used its Gemini at Work 2026 event to present Gemini as one universal agent for work. The same agent answers questions, does knowledge work, creates images and media, and writes and runs code, behind a single API.

Inside Workspace it works in Gmail, Drive, Docs, Slides, Sheets, Chat and Calendar, carrying the same memory, skills and controls everywhere. Google says the model underneath is a separate choice from the agent, and cites nearly 80% of Cloud customers and nearly 90% of the Fortune 100 using its AI products. New data and analytics skills let business users ask questions in plain language.

## Highlights

- Gemini agent: one universal work agent
- Works inside Gmail, Docs, Sheets, Calendar and more
