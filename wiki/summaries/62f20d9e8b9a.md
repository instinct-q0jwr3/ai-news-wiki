# MemCurrent: Designing Persistent Memory for Production Agents

_type: news-summary · created: 2026-10-21 · updated: 2026-10-26 · confidence: high_

`tldr-ai` `agentic-systems`

## Summary

Databricks introduces MemCurrent, a persistent memory architecture for production agents that now powers Agent Bricks Memory and Genie. The design problem: memory can raise quality and efficiency at once by carrying user preferences, prior corrections, and successful workflows across tasks, but dumping every past interaction is costly and imports stale or conflicting context, so the core challenge is deciding what to retain, how to maintain it, and how to measure usefulness. Agents read and write memory as they work, while an offline 'dreaming' pipeline consolidates memory to keep it consistent and fresh. On an internal benchmark of realistic enterprise tasks, MemCurrent triples the no-memory pass rate while using 31% fewer tokens and running 26% faster, landing on the Pareto frontier ahead of Mem0, PropMem, and OpenClaw memory.
