# Local and Distributed Large LLM Inference with MLX and RDMA on Mac Studio

_type: news-summary · created: 2026-10-16 · updated: 2026-10-21 · confidence: high_

`hacker-news`

## Summary

A guide to running large LLMs locally and across several Mac Studios with MLX, Apple's open-source array framework, using RDMA to link the machines. It builds on unified memory on Apple silicon for private local experimentation with inference and fine-tuning.

## Highlights

- MLX plus RDMA to distribute large model inference across Macs.
- Private local inference on Apple silicon.
