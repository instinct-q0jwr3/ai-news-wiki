- First, let’s look at what such a system can do: Tensor x ( 2.0f ); Tensor z ( 0.0f ); Tensor y = Tensor( 3.0f ) * x * x * x + Tensor( 4.0f ) * x + Tensor( 1.0f ) + x * z; This configures y to be \( 3x^3 + 4x + 1 +xz\).
