# Google Harness² for Recursive Self Improvement

_type: news-summary · created: 2026-10-15 · updated: 2026-10-26 · confidence: high_

`tldr-ai` `google`

## Summary

Harness-squared is a framework for recursive agent harnessing: the harness is the prompts, tools, memory and orchestration around a model, and it is optimized in two linked levels of recursion with model weights fixed, aimed at tasks unseen during design.

## Highlights

- Optimizes the agent harness recursively, weights fixed.
- Targets unseen tasks.
