# Mxc: Microsoft Execution Containers version 1.0.0

_type: news-summary · created: 2026-10-10 · updated: 2026-10-22 · confidence: high_

`hacker-news` `microsoft`

## Summary

Microsoft announces that Microsoft Execution Containers (MXC) is now generally available, presenting it as the containment layer for AI agents on Windows. The problem it targets: agents work across files, networks and applications, and customers are left choosing between unrestricted access with fingers crossed or blocking agents and losing the productivity.

With MXC, developers and IT administrators define the resources an agent may use, such as files and network destinations, and MXC enforces those policies at runtime using the appropriate container. Microsoft says Windows will also soon use Microsoft Entra to distinguish agent activity from user activity, part of a broader push to run and manage agents securely on the platform.

## Highlights

- MXC now generally available on Windows
- Containment layer for AI agents
- Admins define allowed files and network destinations
- Policies enforced at runtime by the container
- Entra to distinguish agent from user activity
