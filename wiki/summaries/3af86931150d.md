# Agents fail like engineers, so I review them like engineers

_type: news-summary · created: 2026-10-23 · updated: 2026-10-30 · confidence: high_

`hacker-news` `agentic-systems`

## Summary

An incident-review veteran building Greenflagged, a security-focused package registry, notices something uncanny about the mistakes AI agents make on his codebase: they are exactly the mistakes human engineers make. His long-standing rule from production incidents is that the most common cause of failure is 'we didn't (or couldn't) follow our process' - and agents fail the same way: skipping steps, poking at problems instead of understanding them, taking the plausible path over the verified one.

The conclusion is operational: if agents fail like engineers, review them like engineers. That means the same code review discipline, the same process gates, the same post-incident curiosity applied to agent work as to a junior hire - not blind trust because the author is a machine, and not dismissal either, since the failure modes are familiar and manageable.

## Highlights

- Agents make recognizably human mistakes: skipped steps, poking instead of understanding, plausible over verified
- Author's incident-review background: most failures come from not following process
- Greenflagged (a security-focused package registry) supplies the case material
- Conclusion: review agent work with the same discipline as a human engineer's
- Familiar failure modes mean manageable ones - neither blind trust nor dismissal
