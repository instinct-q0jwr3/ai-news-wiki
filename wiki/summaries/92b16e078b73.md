## Summary

LayerFS pitches itself as the filesystem for AI coding agents, built on ephemeral computing: compute exists only while a command runs, each file tool call is one atomic store operation, and each Bash call mounts an ephemeral workspace that is committed afterwards, reflecting that agents spend roughly 80% of their time thinking and 10% in Bash.
