## Summary

CallSitter is a bot that answers the author's phone calls and wastes scammers' time. Calls divert to a Telnyx number where an OpenAI gpt-live-1 agent picks up; a classifier ('Jev') labels the growing transcript as spam, scam or genuine, and a deterministic call-flow config steers the agent - scammers get their time wasted, sales calls get a polite no, real callers get a message taken.

A second model ('Luna') writes for the owner, not the caller: rolling summaries, open questions, suggested replies, and the end-of-call summary with cost. The owner can steer live from Telegram - plain text lands as commentary, '!' cuts the agent off with an instruction - and there's a public playground at callsitter.org/play to try scamming the bot from a browser.
