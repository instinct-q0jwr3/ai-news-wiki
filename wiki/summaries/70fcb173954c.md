- But is using it making your eval lie to you?
- Want to know whether it used a particular API?

- Check whether the expected string is in the file.
- Suppose your eval says that the generated solution must use Azure, and your grader checks whether the generated files contain the string Azure .
- For a string contains "Azure" grader, the answers are narrow.
