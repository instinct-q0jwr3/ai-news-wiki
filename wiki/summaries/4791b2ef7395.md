## Summary

Durable Actors is an open-source alternative to Cloudflare Durable Objects, promising no vendor lock-in, no memory limits, and observability built in. It provides stateful serverless functions - a building block for chat systems, collaboration tools and agent swarms - that abstracts persistence, coordination and infrastructure in distributed systems.

The developer experience is a quick init/dev loop on Node 22.19+ and Bun: define actor classes in TypeScript (Python docs also available), mark fields @Persisted for automatic state, and use @Interleave to let other calls run during an await - for example, accepting new chat connections while a reply streams. The example shows a chat-history actor broadcasting streamed LLM replies to all connected sockets.

## Highlights

- Open-source alternative to Cloudflare Durable Objects with no vendor lock-in or memory limits.
- Stateful serverless functions for chat, collaboration and agent swarms.
- Fields marked @Persisted persist automatically; @Interleave allows concurrent calls during awaits.
- TypeScript and Python support; quickstart via npx durable-actors init/dev.
- Demo actor: chat history with streamed LLM replies broadcast to connected sockets.
