# Anthropic Upgrades Claude Code Projects to Run Parallel AI Workers Hands-Free

## Summary

AlphaSignal reports updates to Claude Code Projects that surface coordinator status, blocked work and pending decisions in the main project conversation. Parallel work continues in separate cloud sessions with separate repository copies and branches, so coordinating progress does not remove Git merge conflicts.

The report also describes limited read-only thread sharing, reminders and improved navigation. Worker sessions draw on the same subscriber allowance, and simultaneous high-effort work can consume it quickly; the product remains a waitlisted Pro and Max beta rather than a Team or Enterprise rollout.

## Highlights

- Status updates reduce manual thread checking
- Workers retain separate branches
- Read-only links do not expose the whole project
- Threads accessing local machines cannot be shared
- Parallel work still shares usage limits
