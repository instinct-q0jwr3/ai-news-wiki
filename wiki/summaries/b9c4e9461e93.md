## Highlights

- Differently from other vibe coding tools, this is local first - meaning the workflows are orchestrated by the LLM based on the file schema but then the execution happens in the browser - the cool thing is that you can see the canvas,…
- Everything can be exported in an excel data pack with M code in case someone would want to reproduce - think Audit ready.
- And, I also connected to quickbooks on line so someone can directly pull in and manipulate their financials live - I also connected to Fred which carries literally 800k series in terms of macro economic data - i.e. oil prices,…
- I am hoping people find holes in the architecture or any ideas to make this flow a little bit better.
