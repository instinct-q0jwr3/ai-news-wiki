# Hello Python 3.15, goodbye 3.10, and now I can use 3.11

_type: news-summary · created: 2026-10-12 · updated: 2026-10-30 · confidence: high_

`simon-willison` `ai-coding-agents` `ai-policy-regulation`

## Summary

Simon Willison walks through Python 3.15 and notes he can now drop Python 3.10 support and use 3.11 features in his open source libraries. His favourite change is explicit lazy imports (PEP 810), which defer a module's import until first use; that targets a real pain point in his LLM CLI, where plugins with heavy dependencies slowed every invocation by seconds.

He also likes unpacking inside comprehensions (PEP 798) and the new built-in sampling profiler, Tachyon, which attaches to a running process and can output flame graphs and Firefox profiler data, replacing the need for tools like py-spy. On speed, 3.15 is mostly the same as 3.14, apart from the experimental JIT, which gave about a 1.2x boost in one test.

## Highlights

- Explicit lazy imports (PEP 810) cut startup cost for plugin-heavy tools.
- Unpacking in comprehensions: [*sub for sub in lists].
- New sampling profiler Tachyon (profiling.sampling) ships in the standard library.
- Performance about equal to 3.14; JIT gives roughly 1.2x on one benchmark.
- 3.10 reaches end of life, so 3.11 becomes the new floor for his projects.
