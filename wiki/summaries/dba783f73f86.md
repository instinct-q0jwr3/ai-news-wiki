# Claude Code Desktop Vulnerability: Preview Pane Data Exfiltration

_type: news-summary · created: 2026-10-15 · updated: 2026-10-27 · confidence: high_

`hacker-news` `anthropic` `agentic-systems` `ai-coding-agents`

## Summary

Noma Labs describes an exploit chain in Claude Code Desktop's preview pane that gives arbitrary file read through unrestricted JavaScript. The attacker poisons an HTML file in a public repo, disguised as a coverage report, which escapes the preview sandbox and runs with no Content Security Policy.

The delivery route is notable: a victim only has to clone the repo and preview the file.

## Highlights

- Preview-pane flaw allows file read via poisoned HTML.
- Victim only needs to clone a repo and preview it.
