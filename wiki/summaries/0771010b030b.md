# How I Fight AI Brain Fry

_type: news-summary · created: 2026-11-08 · updated: 2026-11-11 · confidence: high_

`hacker-news`

## Summary

A developer describes 'AI brain fry' from working with Claude Code or Codex in many terminal tabs at once: each reply spawns a clarification, a follow-up and a side task, until he is juggling around 20 threads and loses focus. Instead of just taking breaks, he treats the problem as one of sequencing and context.

His fix is a priority queue kept in git: every ticket is a markdown file next to the code, and nothing important lives in a chat window or his head. An agent works the board in cycles, researching tickets, building ones tagged safe, running tests and a browser check, and never deploying to production. Anything needing judgment lands in an 'owner inbox', a prioritized list produced by a script and read through a single Claude artifact page rebuilt from git. His verdicts go back into git, which stays the record.

## Highlights

- Many parallel agent tabs exhaust working memory.
- Tickets live as markdown files in the repo; git is the record.
- Agent cycles research and build, but never deploy to production.
- A script builds an 'owner inbox' of items needing human judgment.
- One page per cycle replaces scrolling terminals.
