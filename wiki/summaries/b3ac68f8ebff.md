## Highlights

- New portal: submit Claude plugins, track review, and view usage analytics after launch
- Plugins package MCP connectors, Agent Skills, or both - Claude's main extension mechanism
- Open to developers on paid Claude plans
- Analytics cover installs by surface/version and discovery (views, search terms)
- Claude supports MCP 2.0 plus MCP Apps (in-chat UI) and Enterprise Managed Auth (zero-touch OAuth)
- One discovery experience across Claude and Claude Code rolls out in coming weeks; existing listings need no changes
