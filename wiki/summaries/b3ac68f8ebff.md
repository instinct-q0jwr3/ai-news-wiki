# Build plugins for Claude with the directory submission portal

_type: news-summary · created: 2026-09-28 · updated: 2026-10-09 · confidence: high_

`tldr-ai` `anthropic`

## Summary

Anthropic opens a directory submission portal for Claude plugins, giving developers a path to publish, track review, and see usage analytics once live. Plugins - which package MCP connectors, Agent Skills, or both - are the main third-party extension mechanism for Claude, and the portal is open to developers on paid plans. Once published, analytics show installs by product surface and version plus discovery data (listing views, search terms). Anthropic also notes Claude supports MCP 2.0's stateless core plus two extensions: MCP Apps for interactive UI inside chat, and Enterprise Managed Auth for zero-touch OAuth. A unified discovery experience across Claude and Claude Code rolls out over coming weeks; existing skills, connectors, and plugins need no changes.
