# Firecracker VM Escape: PwnEscape Part 2

_type: news-summary · created: 2026-11-06 · updated: 2026-11-08 · confidence: high_

`hacker-news`

## Summary

A write-up from pwn.ai shows an escape from Firecracker, the microVM meant to isolate untrusted code, achieving root code execution on the host. Building on a host-memory primitive from Part 1, the authors find Firecracker in memory and take over a live vCPU thread: while the thread sits in the KVM_RUN ioctl, its saved registers (pt_regs) control where it resumes, so altering them makes it run a chosen call on return. Firecracker keeps running and the VM stays reachable over SSH. It is tied to a CVE identifier in the post.

## Highlights

- Escape from a Firecracker microVM to root on the host
- Hijacks a vCPU thread by editing saved registers during KVM_RUN
- Firecracker and the VM keep running
- Continuation of PwnEscape Part 1
