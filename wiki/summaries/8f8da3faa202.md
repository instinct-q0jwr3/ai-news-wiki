# Show HN: Jevcrawl – A web crawler for AI agents with no LLM in the crawl loop

_type: news-summary · created: 2026-10-14 · updated: 2026-10-30 · confidence: high_

`hacker-news` `typesafe` `agentic-systems`

## Summary

Jevcrawl is an open-source web crawler for AI agents in which a small decision model, not the agent's LLM, picks every link and passage, so the agent reads only what answers its question at a few cents per crawl. It avoids both reading everything a crawler fetches and letting the LLM choose each link, and installs as an MCP server with a Jev API key.

## Highlights

- Small decision model chooses links and passages; no LLM in the crawl loop.
- Aims to cut tokens and cost to a few cents per crawl.
- Installs as an MCP server for Claude Code, Desktop and Cursor.
