## Summary

AI-DLC is an open workflow harness that turns AI coding assistants into structured, verifiable software-delivery processes. One tool-neutral core runs natively in Claude Code, Kiro, Codex CLI, Cursor, opencode and GitHub Copilot, installed through a quick-start script.
