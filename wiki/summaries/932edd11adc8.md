# JetBrains Air: A System of Products for Agentic Software Development

_type: news-summary · created: 2026-09-22 · updated: 2026-09-22 · confidence: high_

`hacker-news` `agentic-systems`

## Summary

Agentic development is changing how software gets made, but it hasn’t changed what it costs to be wrong.

Around the same time, we introduced JetBrains Central as an open control and execution system for agent-driven development.

Today, we are bringing this work together as JetBrains Air: an open, coherent system of products for developers, teams, and organizations, inside and beyond JetBrains IDEs.

## Highlights

- Six months ago, we began publicly experimenting with agentic development environments.
- We subsequently began rolling out JetBrains Central CLI , shared context, cloud agents, automations, governance, and AI cost controls for teams and organizations.
- Each product solves a distinct problem, but the products work better together.
- JetBrains Air marks a significant expansion in what JetBrains is building for.
- JetBrains Air connects the wider system developing around it.
- JetBrains Air includes products that are available today alongside others that will be introduced as the system develops: Junie is JetBrains’ coding agent for professional software development.
- Air in JetBrains IDEs gives developers the environment to direct agents and verify their output using JetBrains’ code intelligence.
- But an open system cannot stop at JetBrains’ own products.
