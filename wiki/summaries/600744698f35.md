# The full Claude Platform, available on Google Cloud

_type: news-summary · created: 2026-10-23 · updated: 2026-10-24 · confidence: high_

`tldr-ai` `anthropic` `google`

## Summary

The full Claude Platform is now available on Google Cloud through Anthropic's managed offering: customers get the native Claude API with Google Cloud as the access layer, keeping existing IAM setups and counting usage toward Google Cloud commitments. Customer quotes emphasize day-one access to new Claude features and keeping capabilities like prompt caching while moving billing and access onto Google Cloud.

Strategically, this completes Claude's availability across the major clouds' managed layers, letting enterprises standardize procurement, identity, and billing on Google Cloud without giving up the native Anthropic API surface - a distribution play that meets enterprise buyers inside their existing cloud commitments.
