# Blunt Banhammer Blocks Basic Bots Ballistically

_type: news-summary · created: 2026-11-09 · updated: 2026-11-10 · confidence: high_

`terence-eden`

## Summary

Terence Eden cut bot traffic to his hobby site OpenBenches by over 80% with a simple trap. The site had sent 2.5 TB in a month, mostly AI crawlers pulling data and images. He adds a honeypot directory forbidden in robots.txt; any visitor that requests it is a bot ignoring the rules, and a small PHP page writes its IP into a blocked list in .htaccess, which then returns a 402 'Payment Required' message. The post gives the code and warns it may block innocent visitors.

## Highlights

- Honeypot directory disallowed in robots.txt
- Visiting it adds the IP to .htaccess blocklist
- Blocked requests get HTTP 402
- Over 80% less bot traffic, 2.5 TB in a month before
- Risk: false positives
