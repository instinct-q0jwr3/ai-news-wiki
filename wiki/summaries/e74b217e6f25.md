# Beating benchmarks by weight-space optimizing decision models with DSPy

_type: news-summary · created: 2026-11-13 · updated: 2026-11-13 · confidence: high_

`hacker-news` `external-evaluation`

## Summary

Compound introduces dspy-wsp, an experimental DSPy optimizer in which a writer model inspects and edits another model’s weights. The published experiment gives the writer a fixed forward-pass budget, then evaluates edited decision models on held-out Typed Decisions cases.

The authors report improvements across five models, with larger gains when weight editing is combined with threshold refitting. These are results on one reported benchmark and a small set of model families; the post warns that text-generating model runs can be costly and unproductive.

## Highlights

- Writer model directly edits model weights
- Forward-pass budget limits each search
- Five decision models were tested
- Evaluation uses 400 held-out cases
- The release remains experimental
