# Forever Junior: The Skills AI Can't Develop for You

_type: news-summary · created: 2026-10-07 · updated: 2026-10-08 · confidence: high_

`hacker-news`

## Summary

A junior engineer at Criteo argues that the risk of AI coding is becoming permanently dependent on agents instead of developing senior judgment. Writing instructions that make an agent behave like a mentor is only a start; the engineer must still learn to explain designs, defend tradeoffs, review code and recognize when automation is going wrong.

The essay proposes curiosity, learning from senior reviewers' recurring comments, occasional unaided implementation, and real human mentorship. It connects those habits to architectural understanding, confidence and knowing when delegation actually saves time or tokens. The point is to use AI without outsourcing the experience that makes independent judgment possible.

## Highlights

- Agent productivity does not automatically produce senior expertise.
- Questioning design choices rehearses ownership of the code.
- Review comments reveal team-specific engineering standards.
- Occasional manual changes test real understanding.
- Human mentorship remains part of learning.
