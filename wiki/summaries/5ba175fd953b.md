# Perplexity rolls out Teammates, an always-on AI agent system that integrates with Computer to handle multiple roles and execute large-scale tasks simultaneously

_type: news-summary · created: 2026-11-06 · updated: 2026-11-14 · confidence: high_

`techmeme` `openai` `anthropic` `agentic-systems` `compute-buildout`

## Summary

The Verge reports Perplexity launched Teammates, always-on agents that take multiple roles in a workspace, reuse projects, skills and memory from existing Perplexity tools and build on Perplexity Computer for ongoing large-scale work. Like OpenAI's Dots and Claude Duet, each Teammate can run jobs simultaneously, tracked in app threads and Slack. It needs the $200/month Max plan. CEO Aravind Srinivas envisions hundreds of teammates per person over time.

## Highlights

- Always-on multi-role agents built on Perplexity Computer
- Progress via threads and Slack
- Requires the $200/month Max plan
