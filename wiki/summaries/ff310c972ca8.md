# Show HN: RSI-Anything – JEPA world models for self-improving agents

_type: news-summary · created: 2026-10-14 · updated: 2026-10-16 · confidence: high_

`hacker-news` `agentic-systems`

## Summary

RSI-Anything is an open-source framework that uses JEPA world models for recursive self-improvement: candidates are generated, the world model predicts consequences to guide selection, an external evaluator scores the chosen action, and the system learns from the result. The paper applies the same cycle to code repair, GUI interaction, lab planning, reaction optimization and immune science.

## Highlights

- Domain-general loop: propose, predict, evaluate, learn.
- Built on JEPA-Anything world models.
- Applied to code repair, GUI use, lab planning, reaction optimization and immune science.
