# Stripe evals: Measuring real-world coding agent performance

_type: news-summary · created: 2026-11-20 · updated: 2026-11-20 · confidence: high_

`tldr-ai` `agentic-systems` `ai-coding-agents`

## Summary

Stripe evaluates coding agents on integration scenarios and distinguishes average criterion scores from strict success on all required criteria. It reports that its plugin improves scores, while the strict pass rate remains far lower than the headline average, exposing nearly-correct integrations that miss important requirements.

The study uses a simulated developer, model judges, paired runs and a limited scenario set. Timeouts are excluded from score calculation, which matters when interpreting completion reliability. This is a vendor-authored evaluation of its own integration guidance, not a guarantee that a generated payment flow is production-ready.

## Highlights

- Sixty-nine scenarios cover several business models
- Criterion average differs from strict required success
- Plugin improves scores in the reported tests
- Roleplayer and model judges shape the evaluation
- Timeout exclusion limits completion interpretation
- Production safety needs additional validation
