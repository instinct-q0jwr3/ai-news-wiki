# Anthropic says Claude for Government is now generally available to federal and state agencies, with Claude Code CLI and Claude for Microsoft 365 in early access

_type: news-summary · created: 2026-10-01 · updated: 2026-10-08 · confidence: high_

`techmeme` `anthropic` `microsoft` `agentic-systems` `ai-coding-agents`

## Summary

Anthropic says Claude for Government is now generally available to federal and state agencies, after a public beta that began in July. It runs in a FedRAMP High authorized environment and gives agencies capabilities comparable to Anthropic's commercial customers, arriving on the commercial release cadence. Staff can use Claude on desktop files for memos, RFP reviews and casework, and teams can use Claude Code to build and modernize public-service software.

Governance is the selling point: administrators set configuration defaults and control spending across departments, security teams get audit logs and documentation for the ATO process, and procurement officers can contract directly with Anthropic. Pricing has no seat fees; agencies pay for usage in fixed increments with a hard not-to-exceed cap. The Claude Code CLI and Claude for Microsoft 365 are rolling out in early access in the same environment.
