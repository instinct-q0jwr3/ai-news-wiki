## Summary

Apogee is a privacy-first browser extension that summarizes articles, videos, PDFs, DOCX files and pasted text entirely on your device - a rebuild of Mozilla's discontinued Orbit without its central servers. Inference runs on WebGPU in Chromium browsers or WebAssembly everywhere else (the default on Firefox), and power users can point it at a local Ollama or llama.cpp server instead.

The design rules out data collection by construction: no account, no API key, no backend, no telemetry, and page content never leaves the machine. Models download on first use and run offline afterward. The project compares itself against cloud-based AI extensions and Orbit, positioning local-first summarization as both a privacy fix and an architecture fix.

## Highlights

- Local-first AI summarizer extension for pages, videos, PDFs, DOCX and pasted text.
- Rebuilds Mozilla's discontinued Orbit without its central API servers.
- Runs on WebGPU (Chromium) or WebAssembly (default on Firefox, fallback elsewhere).
- Optional backends: local Ollama or llama.cpp over 127.0.0.1.
- No account, API key, backend, telemetry or cloud upload.
- Models download once and work offline afterward.
- Available on the Chrome Web Store and Firefox Add-ons.
