## Summary

Latent.Space interviews Clay's Jeff Barg about rebuilding its go-to-market agent around a coding harness, shared data access and a CLI rather than a narrow set of predefined actions. The editorial overview describes saturated lead-qualification evals, bursty row-level workloads, provider throttling and a desire for outside coding agents to use the same infrastructure as Clay's own interface.

The much-discussed $1,500 estimate is a back-of-the-envelope classifier inference bill for forty million company records, not an executed production rollout or the all-in price of data acquisition, research and outreach. The overview says that classifier was not yet in production and model routing was forthcoming. Reported adoption, fundraising and debugging failures are interview claims, not audited metrics; the full automated transcript was not exhaustively checked. No customer data, prospecting or outbound messages were accessed.

## Highlights
