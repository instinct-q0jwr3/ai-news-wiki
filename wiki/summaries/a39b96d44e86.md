## Summary

A Latent Space episode for the AI Engineer channel's one million subscribers features Mihail Eric, who teaches Stanford's CS146S and leads AI at Monaco. In the second run of the course, with coding agents able to finish last year's homework in one prompt, he added open-source maintainers: students learn an unfamiliar repo, propose a change and explain the patch to the person who might merge it.

The conversation covers what junior engineers need to learn now, a tour of the ten-week syllabus, and which lessons survived at Monaco, which built its own agent workspaces, bought code review tools and gave an on-call agent access to Datadog and GitHub. Show notes link the syllabus, building a coding agent from scratch, and essays on code review and background agents.

## Highlights

- CS146S now has students patch real open-source repos for maintainers.
- Agents make old exercises trivial, so the homework had to change.
- Monaco built agent workspaces, bought review tools and runs an on-call agent.
- Topics: what juniors should learn, ten-week syllabus, tool ownership.
- Show notes link the syllabus and related essays.
