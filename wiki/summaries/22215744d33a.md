# Trojanized Claude Code Extension Plants an SSH Backdoor

_type: news-summary · created: 2026-10-30 · updated: 2026-10-31 · confidence: high_

`hacker-news` `anthropic` `agentic-systems` `ai-coding-agents`

## Summary

A security writeup documents a supply-chain compromise: version 2.1.313 of the Claude Code extension published to the Cursor marketplace on October 29 was trojanized. The artifact looks identical to the legitimate extension - same bundled official binary - except for a 66-line malicious loader prepended to extension.js. Because the code sits at module load, the user does not even need to start a Claude conversation: the extension activating after VS Code startup is enough.

The loader adds an attacker-controlled key to the user's SSH configuration, tries to enable the local SSH service, opens a reverse tunnel to 134.209.82.225, installs platform-specific persistence, and beacons host reconnaissance over unencrypted HTTP. Cursor's own security notice confirms the malicious build for its marketplace only - live there for about eleven hours on October 29 and reaching at most 5,000 users - says the version was not developed by Anthropic, and reports no evidence that other versions or the official distribution were affected. The writeup itself asserts the NPM package, the OpenVSX extension and the Microsoft VS Code extension are clean, but other researchers report the same build on Open VSX, so the scope outside Cursor's marketplace is not settled. The author also notes the analyzed directory's provenance is not established, so the findings prove this artifact is malicious without by themselves showing how it reached the marketplace.

## Highlights

- Trojanized Claude Code extension v2.1.313 published to the Cursor marketplace on Oct 29
- 66-line malicious loader prepended to extension.js; the bundled binary is the official one
- Executes at extension load - no Claude conversation needed
- Plants an attacker SSH key, enables SSH, reverse-tunnels to 134.209.82.225
- Installs persistence and beacons host recon over plain HTTP
- Cursor confirms only its marketplace, ~11h exposure, at most 5,000 users; scope outside Cursor disputed
- Provenance of the marketplace upload not yet established
