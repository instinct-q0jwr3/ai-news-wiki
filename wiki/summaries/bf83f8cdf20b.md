# Nvidia Kubernetes Engine

_type: news-summary · created: 2026-11-06 · updated: 2026-11-07 · confidence: high_

`hacker-news` `nvidia`

## Summary

NVKE (Nvidia Kubernetes Engine) is a preview, open-source managed Kubernetes service for your own NVIDIA GPU infrastructure. Platform teams install the management plane and create clusters for customers, each with its own control plane, etcd and node pools. NVIDIA Infra Controller (NICo) is the only supported infrastructure provider at preview. The local quickstart needs a Linux host or VM with 6 CPUs, 12 GiB RAM, 100 GiB disk, Docker and virtual TPM; macOS runs through Colima. Not recommended for production.

## Highlights

- Managed Kubernetes for your own NVIDIA GPU fleet
- Each cluster gets its own control plane and etcd
- Only NICo supported at preview
- Preview; not for production
