# Show HN: Mason – A lightweight Postgres read-replica, built on columnar storage

_type: news-summary · created: 2026-11-24 · updated: 2026-11-26 · confidence: high_

`hacker-news` `meta` `compute-buildout` `labor-displacement`

## Summary

Mason describes a Postgres-compatible analytical read replica backed by DuckDB, with selected tables and columns synchronized through polling, on-demand updates or logical replication. Its product page emphasizes columnar scans, role-based and row-level access, query logs and an MCP interface.

Publisher benchmarks favor aggregates over many rows and explicitly show primary-key lookups running slower than Postgres. The advertised speedups depend on dataset, concurrency and cold-cache protocol, not all SQL workloads. Compatibility, isolation and synchronization correctness were not independently tested, and no package or database connection was installed.

## Highlights

- DuckDB is the analytical storage engine
- Users choose synchronized tables and columns
- Aggregations are the intended fast path
- Point lookups can be slower than Postgres
- Benchmarks use a stated cold-start median-of-three protocol
- Access controls and compatibility remain product claims
- No private database was connected
