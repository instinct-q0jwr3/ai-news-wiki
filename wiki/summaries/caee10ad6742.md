# Anthropic Donates Agent Skills to Linux Foundation

_type: news-summary · created: 2026-10-23 · updated: 2026-10-30 · confidence: high_

`tldr-ai` `anthropic` `agentic-systems`

## Summary

Anthropic's own announcement that it is donating Agent Skills - the open standard giving AI agents specialized knowledge and workflows - to the Agentic AI Foundation under the Linux Foundation. More than 70 agent platforms, including ChatGPT, Cursor, GitHub Copilot, and VS Code, have integrated the standard since its December 2025 publication.

The post explains what a skill is: a folder containing a SKILL.md file that teaches an agent a specific task or domain, plus any scripts or reference material it needs. Anthropic developed skills while building Claude Code, which handled general knowledge work well but often lacked the procedural knowledge real business tasks demand; within weeks of the October 2025 launch, developers published thousands of skills. The AAIF donation - following MCP - formalizes skills as neutral infrastructure no single vendor controls.
