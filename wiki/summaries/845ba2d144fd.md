# OpenAI announces new features for Codex, including reusable cloud development environments, a refreshed Codex CLI, a new code review experience, and more

_type: news-summary · created: 2026-09-29 · updated: 2026-10-04 · confidence: high_

`techmeme` `openai` `agentic-systems` `ai-coding-agents`

## Summary

OpenAI announced a Codex upgrade at DevDay centered on reusable cloud development environments: instead of each cloud task being an isolated sandbox, environments are now persistent and configurable, accessible from any device - laptop, phone, or cloud. The update also brings a refreshed Codex CLI, a new code review experience, infrastructure-hardening tools, and API enhancements. The direction is clear: Codex as a software-engineering agent that runs wherever the developer happens to be, with continuity between sessions.

## Highlights

- Codex gets reusable cloud development environments, persistent across sessions
- Accessible from any device - computer, phone, or cloud
- Also announced: refreshed Codex CLI, new code review experience, infra-hardening tools, API updates
- Moves Codex from isolated remote sandboxes to persistent, configurable environments
