# Show HN: I Put an AI Agent on a Nokia 110

_type: news-summary · created: 2026-10-08 · updated: 2026-10-09 · confidence: high_

`hacker-news` `agentic-systems`

## Summary

A Show HN project runs an AI agent on a Nokia 110 feature phone with only 48MB of RAM. The author wanted to cut screen time, tried Android, failed, then reverse-engineered the firmware for days and got custom code running in RAM through the Calculator app.

The agent sends messages to the DeepSeek chat API and uses tool calls to answer over SIM data, check battery, toggle the torch, place a call and set an alarm. He used Codex to help. It is a prototype that must be reloaded from a computer after a restart.

## Highlights

- AI agent on a Nokia 110 with 48MB RAM
- Custom code runs in RAM via the Calculator entry point
- Chat goes to the DeepSeek API with tool calls
- Can check battery, torch, calls and alarms
- Must be reloaded after power-off
- Working prototype
