# Q&A with Nvidia's Vera team on agentic AI driving CPU demands and forcing CPU design priority back to single-threaded performance over core counts, and more

_type: news-summary · created: 2026-10-19 · updated: 2026-10-22 · confidence: high_

`techmeme` `nvidia` `agentic-systems`

## Summary

A Wccftech Q&A with Nvidia's Vera CPU team argues that agentic AI is reversing a decade of CPU design priorities. The chiplet era - filling packages with as many cores as possible - sacrificed single-threaded performance and IPC, because chiplets leave no space to design for per-core performance and force cores to cross IO boundaries. Agent workloads invert the requirements: an agent runs sequential control logic on the CPU between reasoning steps, and the goal is to finish that sequential work fast and get back to the GPU, keeping the expensive accelerators highly utilized. Nvidia's answer in Vera is a single monolithic compute die where all cores talk to each other without crossing IO boundaries or incurring that latency - a deliberate move back to per-core performance over core counts.
