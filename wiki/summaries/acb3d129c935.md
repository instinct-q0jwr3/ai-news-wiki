# Show HN: PaperMono, e-ink fridge magnet shopping list with mobile web page

_type: news-summary · created: 2026-09-28 · updated: 2026-10-05 · confidence: high_

## Summary

PaperMono turns the M5Stack PaperMono - an ESP32-S3 with a 3.97-inch 480x800 e-paper touchscreen - into a household shopping list that lives on the fridge and syncs with a phone web app. The firmware is deliberately small enough to read (about 2,400 lines of C++) and works as a starting point for other PaperMono projects. The list is grouped by aisle in the order you walk the shop; you set the aisle order once from the phone. Everything - the list, suggestions, ticking, adding - works offline, including in a shop with no signal.

A small FastAPI + SQLite server sits between device and phones, remembering a catalog of every item ever added (which drives suggestions on both screens) and optionally auto-sorting brand-new items into the right aisle via the Claude Code CLI - with manual corrections sticking. The docs warn to back up the device's flash before the first flash, since it holds factory calibration data.

## Highlights

- E-ink fridge shopping list on the M5Stack PaperMono (ESP32-S3, 3.97" touchscreen)
