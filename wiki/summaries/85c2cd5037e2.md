# We let our cloud agents query prod (with OIDC, not secrets)

_type: news-summary · created: 2026-10-27 · updated: 2026-10-28 · confidence: high_

`hacker-news` `agentic-systems`

## Summary

Formal explains why it lets cloud coding agents like Cursor and Devin query production infrastructure using OIDC instead of secrets. Because those agents are themselves OIDC issuers, Formal can give them auditable, policy-controlled, read-only access to production data and cloud infrastructure on the strength of their own infrastructure identity.

Each OIDC integration maps to a machine user, and can optionally resolve a token claim to a human identity for logs and policy input - a claim Formal cryptographically authenticates for the machine but accepts on trust for the human, because the customer explicitly configures that trust. The goal: zero long-lived secrets in the path between agents and production.

## Highlights

- Cloud agents get prod access via OIDC, no stored secrets
- Cursor and Devin are OIDC issuers, enabling auditable read-only access
- Machine identity is cryptographic; human identity is a trusted asserted claim
- Formal's stated goal: zero long-lived secrets
