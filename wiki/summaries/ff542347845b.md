## Summary

Apron proposes a small protocol for self-hosted chat using JSON over transports such as WebSocket. Its design keeps a minimal core and adds optional capabilities with fallbacks, aiming to support rooms, threads, bots and reactions without requiring every implementation to build everything.

The project provides specifications, schemas, fixtures and reference implementations. These make implementation and testing more concrete, but the public demonstration does not establish security, federation properties or operational reliability at every deployment scale.

## Highlights

- Minimal JSON chat protocol
- Transport can include WebSocket
- Optional capabilities allow smaller implementations
- Schemas and fixtures support compatibility testing
- Demo is not a production reliability audit
