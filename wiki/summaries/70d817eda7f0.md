# Elon Musk says Grok Bot will use the "best back end model for any given task, including Claude Opus 5.5, MidJourney, Suno"

## Summary

The Information reports Elon Musk said on Tuesday night that SpaceX's AI unit will now use models from competitors for Grok Bot, choosing the best back end model for each task, including Claude Opus 5.5, Midjourney and Suno.

The report presents this as a shift away from relying only on its own models. The article is behind a paywall, so the summary rests on the Techmeme excerpt.
