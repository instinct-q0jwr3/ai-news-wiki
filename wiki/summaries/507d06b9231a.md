# SetShot 1.0 (and a Personal Tale of Defaults System Spelunking)

_type: news-summary · created: 2026-11-17 · updated: 2026-11-23 · confidence: high_

`daring-fireball` `anthropic` `apple` `agentic-systems` `small-specialist-models` `ai-coding-agents`

## Summary

SetShot’s author describes a macOS utility that snapshots system settings, compares changes and maintains a chronological journal. Version 1.0 expands the recognized settings and distinguishes them from background values that routinely change.

The app is described as observing rather than writing settings. Its comparisons can help investigate a change, but a difference alone does not identify which process caused it. Recognition lists and clean-install baselines are incomplete, and author-reported counts are not an independent audit.

## Highlights

- Snapshots enable before-and-after comparison
- Journal retains recognized changes
- Unknown values remain separately visible
- App is described as read-only
- A change record does not prove its cause
