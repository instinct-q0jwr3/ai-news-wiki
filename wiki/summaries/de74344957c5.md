# Agents in the Cloud

## Summary

AgentsInTheCloud is a one-page guide for moving coding agents off a laptop: get a server, perhaps on Hetzner or DigitalOcean, install Tailscale on your dev machine, and run one installer script on both. The site tells readers to read the installer first and lists feedback via the author's account.

Beyond the steps, it gives no technical detail in the excerpt. It echoes the argument that agent harnesses should run in the cloud.

## Highlights

- Three steps to run coding agents on a server
- Tailscale links the server and dev machine
- One curl-pipe-bash installer, read it first
- Tiny page with few details
