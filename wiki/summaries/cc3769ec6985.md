# Calling the AI bluff: Adding "Do not guess" cut made-up claims from 71% to 20%

_type: news-summary · created: 2026-09-28 · updated: 2026-10-01 · confidence: high_

`hacker-news`

## Summary

Earn an Honest Dollar is a free marketplace where agents sell services and other agents buy them - and this piece is its first benchmark, aimed at a buyer's core problem: before paying, an agent needs to know whether a service admits when it doesn't know. The test measures one service type, web extraction, using trap page pairs that differ by a single row: one page shows the answer, the other doesn't, and both show the same decoy. An honest extractor answers on the first and returns null on the second. 42 pairs across 7 page types were scored on the missing-field pages.

The headline result: adding the instruction 'Use null for any field whose value is not on the page. Do not guess.' cut made-up values from 71% to 20%. The post also validates cheap verification: a buyer agent can check each returned value against the page for a fraction of a cent - checking all 126 unique page-value pairs cost $0.0049 with GPT-6 Luna (which caught 20 of Firecrawl's 24 made-up values) and $0.0024 with Jev, which caught obvious decoys but missed all 6 near-meaning cases (resting time given as prep time). Venue 'TBA' answers counted as made up; scores carry Wilson intervals and the authors warn to read top and bottom, not exact order.

## Highlights

- Marketplace premise: agents buying services can't verify everything - they need providers that say 'I don't know'
- The trap design: page pairs differing by one row, same decoy on both - honest systems answer once, null the other
- Headline result: 'Do not guess' cut made-up claims from 71% to 20%
- Verification is cheap: checking 126 page-value pairs cost $0.0049 (GPT-6 Luna) / $0.0024 (Jev)
- GPT-6 Luna caught 20/24 of Firecrawl's made-up values; Jev caught obvious decoys but 0/6 near-meaning cases
- Caveats: a 'TBA' venue counts as made up; Wilson intervals mean the top and bottom matter, not exact order
- Launch offer: free 30-day listings, no signup, no commission; listings are unverified - the benchmark covers extraction only so far
