# Show HN: Agents infer Lego mechanisms from sources, then animate them

_type: news-summary · created: 2026-11-06 · updated: 2026-11-07 · confidence: high_

`hacker-news` `agentic-systems`

## Summary

A follow-up Show HN to LDraw Nova: ldraw-mecha lets an agent take an LDraw LEGO model and return a Blender-animated version, inferring mechanisms from the sources. Setup installs tools locally in the repo (uv, bun, Blender 5.2.3, LeoCAD, the LDraw parts library and several project packages) and needs Python 3.12+ and a few env vars. Setup scripts exist for macOS, Linux and Windows WSL.

## Highlights

- Agent animates LEGO models in Blender from LDraw files
- Local installs: Blender 5.2.3, LeoCAD, parts library
- Python 3.12+; setup scripts for macOS, Linux, WSL
