# OpenAI open-sources MCP Extensions for ChatGPT-native plugins

_type: news-summary · created: 2026-11-12 · updated: 2026-11-12 · confidence: high_

`tldr-ai` `openai`

## Summary

OpenAI MCP Extensions adds interface features intended to make plugins behave like native ChatGPT components. The project lists sidebar entry points, custom file viewers, resource search from the composer and thumbnail selections. It is an Apache-licensed extension layer for richer interactions, not a guarantee that every MCP host supports the same features.

## Highlights

- Adds ChatGPT-specific interface capabilities
- Sidebar and file-viewer hooks are included
- Composer can reference plugin resources
- Selection controls can show thumbnails
- Apache 2.0 license covers the project
