# Show HN: An MCP server that finds text your agent reads and you can't see

_type: news-summary · created: 2026-10-07 · updated: 2026-10-18 · confidence: high_

`hacker-news` `agentic-systems`

## Summary

HiddenContent is an MCP server and API that checks documents for hidden text - content an AI agent would read but a human never sees - before the agent ingests it. The same capability ships as a browser extension for assistant-side checks and as an API for embedding in your own code, with one key covering both.

The onboarding is deliberately frictionless: sign up with GitHub (email only, no repo access), get a production key immediately with 20 free pages, then pay a cent per page with a $10 minimum via Stripe. Keys are stored as hashes and shown once; a device flow recovers lost keys. The pitch targets a real agent-security gap: invisible prompt-injection payloads riding inside otherwise normal pages and files.
