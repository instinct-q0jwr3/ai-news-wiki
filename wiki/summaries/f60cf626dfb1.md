# AI Engineer Code Summit: OpenAI on New Ways of Working With Codex

_type: news-summary · created: 2026-11-11 · updated: 2026-11-11 · confidence: high_

`latent.space` `openai` `ai-coding-agents`

## Summary

At the AI Engineer Code Summit, OpenAI developer experience engineers Dominik Kundel and Charlie Guo ran a workshop on new ways of working with Codex. They admitted the shift to cloud was confusing for a long time; Codex Cloud v2, announced at DevDay in late September, lets you publish an environment once and run many tasks in isolated instances, shared within a company. Kundel demoed handing a local task off to the cloud and reopening a cloud task with its saved Appshot.

The session also covered personal agents that assist between sessions (OpenAI's dots, Anthropic's Claude Duet) and voice steering of coding tasks.

## Highlights

- Codex Cloud v2: publish an environment, run isolated tasks
- Handoff between local and cloud is a known pain point
- Personal agents assist between sessions
- Voice mode as a steering channel
