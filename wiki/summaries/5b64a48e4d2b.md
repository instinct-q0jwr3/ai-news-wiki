## Summary

I'm having a really hard time working with claude.

In the past when I wrote all the code manually, it was always carefully reviewed and architected, with all possible flows carefully mapped out.

Now, my code is mostly AI written which has led to things going out of control.

## Highlights

- Since it's easy to add new features and support many user flows, we went ahead and implemented flows that support a lot of cases our users run into.
- But now, I feel like things are getting too complex with no central notion of behaviour definitions, which causes every bug-fixing session to feel like a game of whack-a-mole, and results in missing edge cases and UI bugs that are…
- Every time I build anything new, it adds more complexity and the agent only seems to focus on the surrounding code within that session without keeping track of how it fits into the rest of the code base/product.
