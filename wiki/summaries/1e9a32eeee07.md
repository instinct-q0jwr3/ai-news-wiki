# Computer use on the phone itself: a 2B model that operates Android apps

_type: news-summary · created: 2026-10-22 · updated: 2026-10-26 · confidence: high_

`tldr-ai` `agentic-systems` `compute-buildout`

## Summary

Erik is an Android app that brings computer-use agents onto the phone itself: it reads the screen through the accessibility service and can tap and type in any other app. Claude, ChatGPT, or Codex can drive it from a computer, but when none is connected, a 2-billion-parameter model - GUI-Owl 1.5 2B in 4-bit quantization on llama.cpp - runs the same loop entirely on-device with no server involved.

The engineering notes are striking: on a Mac M2 CPU with 4 threads, one agent step takes 7.3 seconds (down from 10.6), half of it the vision encoder; on a Galaxy S25's NPU that encoder runs in 236 ms versus 3.9 s on the M2. GUI-Owl 1.5, from Alibaba's Mobile-Agent team, is a Qwen3-VL fine-tune that maps a screenshot to a single action. It runs in the app via llama.cpp at 4 bits - 1.05 GB for the language model and 445 MB for the vision encoder, both kept resident between steps - with accuracy holding on a 36-screen test set.
