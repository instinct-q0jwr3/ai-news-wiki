# How to Build an AI-Native Software Factory

`tldr-ai`

## Summary

A field guide to building an AI-native software factory, mixing quotes and hard numbers. On economics: if LLMs add $1,000/month per engineer for 10% more productivity, that's too cheap - spend more. On review queues: PostHog merges ~200 PRs a day, and an analysis of one day's merges found the median wait for a first human review is 6.1 hours with a 90th percentile of 160.8 hours - and 40% of PRs merged with no human review at all (bot reviewers like CodeRabbit see nearly every PR within 4 minutes).

Practical advice threads through: use 'claude -p' in CI to triage failed builds, summarize flaky tests and draft changelogs; don't try to recreate Copilot, Cursor or Replit in-house; expect failed first attempts, like one company's unsuccessful multi-file test migration. The emotional undercurrent is captured in one engineer's line: after 25 years of programming, feeling competent in that skill set is ending.

## Highlights
