# macOS 27.3 beta warns if an app would get full device control, nudging users to "Choose Apps" for the app to control instead, brought on by AI apps' popularity

_type: news-summary · created: 2026-11-17 · updated: 2026-11-21 · confidence: high_

`techmeme` `apple`

## Summary

MacRumors reports macOS 27.3 beta changes intended to steer new app permission requests toward narrower folder or app access. Developers are told to handle limited access and some backup or assistive use cases may request entitlements for broader behavior.

The report says existing permissions remain in effect and further entitlement details are pending. A beta announcement is not a guarantee of final shipping behavior, nor does it mean every existing app immediately loses access. The underlying API changes were not independently tested here.

## Highlights

- Changes concern new permission requests
- Narrower access requires app handling
- Existing grants are reported as preserved
- Specialized use cases may use entitlements
- Beta details can change
