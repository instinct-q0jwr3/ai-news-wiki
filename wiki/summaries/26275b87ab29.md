# AI is now capable of developing its own inference hardware

_type: news-summary · created: 2026-10-06 · updated: 2026-10-29 · confidence: high_

`hacker-news`

## Summary

openTPU is an open-source AI accelerator designed by AI agents, extending the auto-arch-tournament approach to hardware: the repo asks how far agents can go at chip design and whether they can build the chip that runs their own inference. The entire accelerator lives in one readable monorepo - SystemVerilog hardware, an instruction set, a bit-exact simulator, a kernel language and compiler, and host software for a real PCIe FPGA card.

It runs ten modern models with real weights on a Xilinx Kintex-7 card, producing bit-for-bit the same tokens as the simulator. Successive agent-built images improved decode speed: build B beats its predecessor by 8-10% while hitting 91-94% of DRAM peak. Larger MoE models run with experts streamed from host storage, and 4-bit weights (4.25 bits per weight with two-level block scales) cut bytes per token by a third and raise decode speed 40-45% at a measurable perplexity cost.

## Highlights

- Open-source AI accelerator designed by AI agents, from RTL to compiler.
- Whole stack in one monorepo: SystemVerilog, ISA, bit-exact simulator, kernel language, host drivers.
- Runs ten real models on a Xilinx Kintex-7 FPGA card, bit-identical to the simulator.
- Latest agent-built image decodes 8-10% faster at 91-94% of DRAM peak.
- MoE models larger than the card's 4GiB run with experts streamed from host storage.
- 4-bit quantization (4.25 bits/weight) raises decode speed 40-45% with a known perplexity cost.
- Doubles as a learning project for understanding accelerators end to end.
