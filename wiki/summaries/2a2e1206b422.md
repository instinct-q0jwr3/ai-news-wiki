## Summary

Declare an agentic task with workspaces and gateway specifications.

AX sandboxes it, wires up its workspace, fences its network, and helps running it at scale.

AX is a high-throughput, declarative orchestrator to run billions of autonomous agent workloads in a cluster.

## Highlights

- Warning We are still actively refining our core concepts, protocols, and specifications.
- We will likely to introduce major breaking changes prior to a stable release.
- It runs on top of Agent Substrate for sandboxed execution and is built to run billions of tasks per cluster.
- They are neither stateless microservices nor run-to-completion batch jobs.
- They accumulate state, need strict isolation, call out to model APIs and tool servers, and can burn money in a loop if nobody is watching.
- AX gives you four small primitives that handle all of that declaratively: Everything is expressed as ax.io/v1alpha1 manifests and applied with a single command. go install github.com/google/ax/cmd/ax@latest This puts the ax binary in…

- It applies a custom workspace, waits for readiness, runs commands over ax ssh , and suspends the task. ax talks to the control plane over gRPC.
