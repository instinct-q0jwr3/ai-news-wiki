# You click a PostHog survey. An attacker gets your whole account

_type: news-summary · created: 2026-10-07 · updated: 2026-10-07 · confidence: high_

`hacker-news`

## Summary

Security startup Strix reports that one of its AI agents, reading PostHog's source code, found a flaw that let an attacker take over a PostHog account with a single survey link. PostHog had added an optional intro screen to surveys; its description was stored through the API and rendered as raw HTML by the browser SDK on the public hosted survey page.

Because only a report-only content security policy protected the page, an attacker could run JavaScript in a signed-in victim's session. In the test, opening the link was enough to mint a personal API key with maximum scope, and the survey still looked normal. PostHog fixed it quickly and audited all surveys, confirming no exploitation beyond Strix's own tests.
