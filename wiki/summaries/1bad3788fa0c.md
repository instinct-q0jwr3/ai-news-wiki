# Show HN: I built a game where you are an LLM's subagent

_type: news-summary · created: 2026-11-22 · updated: 2026-11-24 · confidence: high_

`hacker-news` `agentic-systems`

## Summary

Worker 755 turns the usual coding-assistant relationship into a game: a human player carries out timed assignments for an LLM manager that treats the player as a software worker. The project's README describes an in-memory filesystem and simulated database, a manager that sees reports and command transcripts, and hidden mission checks that can catch it approving broken work. The tension is between producing a convincing report and actually preserving the fictional user's files and completing the task.

The repository also describes a scripted offline mode and hosted play using server credit or a player's own API key. These are the developer's descriptions, not a tested review of the game, its billing or its handling of credentials. A clever role reversal and mission-level checks do not establish a general measure of model reliability. No installation, sign-in or credential submission was performed for this editorial pass.
