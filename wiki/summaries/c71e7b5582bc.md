# AI coding agents generate more code, but not more software

_type: news-summary · created: 2026-10-12 · updated: 2026-10-29 · confidence: high_

`hacker-news` `agentic-systems` `ai-coding-agents`

## Summary

A Harvard study of real engineering data finds AI coding agents generate more code but not more software. Fiona Chen and James Stratton analyzed Jellyfish analytics covering 300 million work events across 700,000+ employees at 700+ software firms from 2021 to March 2026, and found 'little evidence that firms increase software output or reduce employment' from AI coding tools.

The mechanism is a downstream bottleneck: whatever efficiency the coding phase gains gets absorbed later - code review takes significantly longer, pull requests need more revisions, and reviewers leave more comments. Anyone who uses these tools knows the pattern: huge volumes of functional-looking code that nobody trusts without review.

## Highlights

- Harvard study: AI coding agents produce more code, not more software.
- Data: 300M work events, 700K+ employees, 700+ firms, 2021 to March 2026 (Jellyfish).
- Little evidence of increased software output or reduced employment.
- Gains are absorbed downstream: longer reviews, more revisions, more comments.
- Human code review is the bottleneck for AI coding efficiency.
