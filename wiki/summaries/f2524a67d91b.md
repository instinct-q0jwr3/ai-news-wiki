# Show HN: Use your OpenAI subscription to create audiobooks

_type: news-summary · created: 2026-10-13 · updated: 2026-10-14 · confidence: high_

`hacker-news` `openai`

## Summary

A Show HN project, PDF TO MP3, turns PDFs into audiobooks through an MCP server you connect to your AI client such as Codex. Document processing uses your existing OpenAI subscription, while speech generation is billed separately by Google or OpenAI through an API key. Basis: the landing page text only.

## Highlights

- MCP server that converts PDFs to audiobooks from inside your AI chat.
- Uses your subscription for document processing.
- Speech generation billed by Google or OpenAI via your own API key.
