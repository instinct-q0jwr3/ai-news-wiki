# Rabbit launches OS3, a cloud AI agent that connects to local apps and files on Windows, Mac, and Linux and works via web, Telegram, iMessage, or its R1 device

_type: news-summary · created: 2026-09-23 · updated: 2026-09-26 · confidence: high_

`techmeme` `agentic-systems`

## Summary

Rabbit announced OS3, a standalone 'agentic operating system' designed to run across multiple screens - delivered as a software update for the R1 but usable without one, through a desktop browser, Telegram or iMessage. It is a striking pivot for a company that once championed handheld hardware, arriving as agent software has become Silicon Valley's obsession; CEO Jesse Lyu notes Meta's new Muse agent was just banned from crawling Amazon with a virtual machine, something Rabbit was criticized for doing a year and a half ago.

Lyu insists the R1 was no flop financially despite scathing reviews (WIRED gave it 3/10): he claims more than 100,000 units delivered worldwide, return rates under 5%, and roughly 45-50% hardware margins with no subscription. The bet is that the environment has finally ripened for the agent model the R1 tried early.

## Highlights

- OS3 is a standalone agentic OS running across screens, no R1 required.
- Accessible via desktop browser, Telegram and iMessage; also ships as an R1 update.
- Lyu claims 100,000+ R1 units delivered, under 5% returns, 45-50% hardware margin.
- The R1's panned virtual-machine agent approach prefigured today's agent wave.
- Meta's Muse was just banned from crawling Amazon with a VM - the tactic Rabbit was criticized for.
