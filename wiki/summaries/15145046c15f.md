# TIRx Harness: An Open Compiler Harness for Agentic GPU Programming

_type: news-summary · created: 2026-09-30 · updated: 2026-10-05 · confidence: high_

`hacker-news` `agentic-systems` `compute-buildout`

## Summary

The MLC community introduces TIRx Harness, an open compiler harness designed to let coding agents develop correct, fast GPU kernels: it combines a minimal stable compiler foundation, a knowledge base, tools and a benchmark server. The motivation is that agents working on kernels like Kimi Delta Attention spend much of their budget on peripheral uncertainty - predicting lowering behaviour, diagnosing flaky timing, finding relevant strategies - rather than on optimization itself.

On evaluated workloads, KDA kernels developed with the harness reach geometric-mean speedups of 2.94x over FlashKDA (forward) and 6.84x over Flash Linear Attention (backward).
