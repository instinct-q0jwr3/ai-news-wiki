# Turning GLM-5.3-Flash into a Jev-like decision model

_type: news-summary · created: 2026-09-27 · updated: 2026-10-04 · confidence: high_

`hacker-news` `typesafe` `external-evaluation`

## Summary

Privatemode shows how an off-the-shelf LLM can produce typed decisions - each option with a probability - in a single forward pass, effectively turning it into a Jev-like decision model. Instead of making the model write a whole JSON object (or think for hundreds of tokens first), their approach reads the decision directly from the forward pass, which also yields a confidence signal for free.

Evaluating GLM-5.3-Flash running on Privatemode against a benchmark built from public datasets, they report decision accuracy and speed on par with TypeSafe's Jev. A bonus: the LLM setup extends typed decisions to images, which Jev cannot do.

## Highlights

- Typed decisions with per-option probabilities in a single forward pass
- Turns an off-the-shelf LLM into a Jev-like decision model
- GLM-5.3-Flash matches Jev on decision accuracy and speed in their benchmark
- Bonus: typed decisions on images, not possible with Jev
- Avoids JSON-generation overhead and yields confidence for free
