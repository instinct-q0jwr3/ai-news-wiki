# Hedra is a 3D open world game I wrote from scratch while in highschool

_type: news-summary · created: 2026-10-22 · updated: 2026-10-24 · confidence: high_

`hacker-news`

## Summary

Project Hedra is an open-world, low-poly RPG whose author started it in high school at around 15 to learn OpenGL - and scope creep turned it into a full 3D game plus its own engine, roughly 100k lines of code with first-class Linux and Windows support. Players choose a class, explore endless procedurally generated worlds, unlock skills, and complete procedurally generated quests.

The technical write-ups are the draw: the world renders in as few as three draw calls (water, terrain, instanced) using glMultiDrawElements; the block system has a dedicated procedural-meshing blog post; a custom native-array primitive backs performance; and mods are written in Python via IronPython against the C# API, with a Fishing.py example shown. It is a hobbyist engine project that grew into a genuinely engineered game.

## Highlights

- Hedra: open-world low-poly RPG started by a 15-year-old to learn OpenGL, now ~100k LOC with its own engine
- Procedurally generated worlds and quests, class and skill systems

- Mods written in Python through IronPython against the C# API
- First-class Linux and Windows support
