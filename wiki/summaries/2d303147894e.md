# Droid 1.0: Building a Frontier Harness

_type: news-summary · created: 2026-10-30 · updated: 2026-10-30 · confidence: high_

`tldr-ai`

## Summary

Factory introduces Droid 1.0, its agent harness - everything around the model: the prompts, the tools, how results come back, and the loop that runs it all. The pitch is that as agents work for hours or days across hundreds of turns, the harness matters as much as the model: on the same tasks, Droid outperforms the native harnesses built for their models by up to 20% more efficiently, and a new programmatic tool-calling engine lets a model run hundreds of tool calls in a single request when it can plan a whole workflow as code.

Factory is deliberately model-independent: the harness is tuned across many models rather than adapted to one model's quirks, which the company argues makes improvements generalize, and an auto model router (Factory Router) can pick the most efficient model mix per task. The release follows a year of working with enterprise development teams, where the requirements were quality on complex tasks, resource efficiency and strong safety controls.

## Highlights

- Factory launches Droid 1.0, its enterprise agent harness
- Up to 20% more efficient than models' native harnesses on the same tasks
- Programmatic tool-calling engine: hundreds of tool calls in a single model request
- Model-independent by design; Factory Router picks the most efficient model mix
- Tuning across many models is claimed to make improvements generalize
