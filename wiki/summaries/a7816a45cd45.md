# ExecuTorch WebGPU: PyTorch Models on the GPU, in the Browser

_type: news-summary · created: 2026-11-11 · updated: 2026-11-12 · confidence: high_

`tldr-ai` `compute-buildout`

## Summary

Meta's ExecuTorch WebGPU backend runs PyTorch models on the GPU inside WebGPU browsers, without converting to GGUF, ONNX or TFLite. Browser inference keeps prompts and outputs on-device, cuts latency, works offline and lowers server cost; WebGPU's compute shaders and shared memory make it viable. Works across desktop, laptop and mobile browsers.

## Highlights

- PyTorch models run in-browser on WebGPU, no format conversion
- On-device: privacy, offline, lower server cost
- Chrome, Firefox and Safari, desktop and mobile
