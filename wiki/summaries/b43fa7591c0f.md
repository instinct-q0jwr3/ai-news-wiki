## Summary

Bert Hubert's 'Hello Deep Learning' is a from-scratch, GPU-free introduction to modern machine learning that aims to actually explain what's happening, ground up - and to end with a demo that is genuinely useful on real-life data you supply yourself.

He rejects both common on-ramps: learning deep learning through PyTorch is like learning aerodynamics by flying an Airbus A380, and the pure-maths approach ('it's just a Jacobian matrix') suits only seasoned mathematicians. The tutorial builds modern neural networks entirely from scratch while still reaching impressive results. Code is published, and the blog posts' markdown lives on GitHub so readers can turn typos into pull requests.

## Highlights

- A from-scratch, GPU-free deep-learning tutorial aiming at real understanding
- Ends with a demo that works on the reader's own real-life data
