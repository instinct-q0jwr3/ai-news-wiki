# CowAgent – Open-Source Super AI Assistant

_type: news-summary · created: 2026-10-24 · updated: 2026-10-27 · confidence: high_

`hacker-news` `agentic-systems`

## Summary

CowAgent is an open-source 'super AI assistant' and agent harness that plans tasks, runs tools and skills, and maintains persistent memory and knowledge. It decomposes complex tasks into steps and loops over tools until the goal is reached, with a three-tier memory architecture (context, daily, core) that uses automatic 'Deep Dream' distillation and hybrid keyword-plus-vector retrieval.

The project auto-curates structured knowledge into a Markdown wiki with cross-references, installs skills from a Skill Hub, GitHub or ClawHub (or creates them from natural language), and ships with file I/O, terminal, browser, scheduler, web search and native MCP integration. It is multi-model (Claude, GPT, Gemini, DeepSeek, Qwen, GLM, Kimi, MiniMax, Doubao and more), multi-channel (Web, WeChat, Feishu, DingTalk, WeCom, QQ, Official Accounts) and multi-agent, letting users compose teams of role-specific agents with group-chat collaboration and delegation. Installation is a one-line script or docker compose, aimed at always-on deployment on a laptop or server.
