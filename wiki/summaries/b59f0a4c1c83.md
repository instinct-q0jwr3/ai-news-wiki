## Summary

ENZO is an open-source, self-hosted AI platform that pitches itself against subscription AI workspaces: chat with 300+ models, build agents, research and run code, all on your own provider keys and infrastructure, with no account, no usage meter and no middleman taking a cut. Installation is three commands: clone, docker compose up, open localhost:5001 and paste a provider key.

The security model is spelled out in a written threat model: keys live encrypted in a passphrase-protected browser vault, and on a fresh instance the first live-validated key pasted 'claims' the instance for server-side features like scheduled agents (a pre-seeded compose key avoids that claim window). Projects, learned skills and agent memory persist in named Docker volumes, and a hosted demo plus a Colab notebook offer zero-install trials.

## Highlights

- Open-source AI workspace: chat with 300+ models, agents, research and code execution, self-hosted via Docker.
- No ENZO account, no subscription, no usage metering: users pay providers directly at normal prices.
- Install is git clone + docker compose up -d; the app runs on localhost:5001.
- Provider keys are stored encrypted in a browser vault (passphrase-protected, with downloadable recovery file).
- First validated key on a fresh instance claims it and unlocks server-side agents, skills and memory; the trade-off is documented in docs/SECURITY.md.
- Data lives in named Docker volumes, surviving upgrades and restarts.
- A hosted demo (enzo-hub.duckdns.org) and a Colab notebook with keep-alive/watchdog hacks offer quick trials.
- Requires Docker Desktop with at least 4 GB RAM on Mac or Windows (WSL 2).
