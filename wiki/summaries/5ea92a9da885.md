# Google launches TorchTPU, an open-source version of PyTorch to let AI apps run on TPUs and Google Cloud via simple configuration changes without rewriting code

_type: news-summary · created: 2026-10-20 · updated: 2026-10-31 · confidence: high_

`techmeme` `google`

## Summary

TechCrunch reports Google has open-sourced TorchTPU, its long-awaited version of PyTorch that lets AI apps run on TPUs, and by extension Google Cloud, with a simple configuration change and no rewrites, a day after Amazon's TorchNeuron did the same for Trainium. PyTorch, by some accounts used by 85% of AI apps, was built around NVIDIA GPUs, so both cloud giants are attacking NVIDIA's default status; Amazon is additionally submitting code to mainline PyTorch to decouple features from NVIDIA hardware. Google says it worked directly with Meta, Hugging Face, Inferact (vLLM), and RadixArk (SGLang) to keep TorchTPU compatible with the wider toolchain, and launched a TPU agent suite to help developers migrate.
