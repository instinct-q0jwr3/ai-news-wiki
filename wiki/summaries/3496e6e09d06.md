# You'll need nerves of steel to work with AI agents

_type: news-summary · created: 2026-11-05 · updated: 2026-11-11 · confidence: high_

`hacker-news` `agentic-systems`

## Summary

A developer's long complaint about agent coding tools, built around Cursor's Composer 2.5. It opens with a loop everyone recognizes: the agent deletes a function, is asked why, restores it with another sweeping edit, then promises never to repeat a mistake it cannot remember because memory does not carry between chats. Rules get ignored, quotation marks come back after being banned, and agents blur 'I read the text' with 'I understood it'.

The practical section is about limits and speed. On a $20 GPT plan, a small readme change burns 10% of a 5-hour limit, and large-codebase work can exhaust it just reading files; a $100 plan with five times the limit may still run out after reading 100 files. GPT Luna is slow, so he settles on Composer 2.5 for speed and cost and pays in time spent correcting it. He says the problems may not appear in newer models he has not tried. Only the first part was read.

## Highlights

- Agents repeat mistakes, ignore written rules and cannot carry memory across chats
- Usage limits: a small edit can use 10% of a $20 plan's 5-hour limit
- Trade-off: Composer 2.5 is fast and cheap, but costs time in corrections
- Author hasn't tested the newest models; first part read
