# How the Claude Code team does code review

_type: news-summary · created: 2026-10-16 · updated: 2026-10-28 · confidence: high_

## Summary

The Claude Code team explains how it reviews code at agent volume. With Claude writing about 90% of its own code, it optimizes for the least human review time that does not raise reverts or incidents, after building high test coverage and deep automated reviews.

## Highlights

- Claude writes ~90% of Claude Code's own code.
- Goal: minimum human review that keeps reverts low.
