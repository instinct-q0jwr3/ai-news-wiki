# LLM Classification Is Feature Engineering

_type: news-summary · created: 2026-09-20 · updated: 2026-09-23 · confidence: high_

`tldr-ai`

## Summary

This essay argues that using an LLM directly as a classifier, a prompt that returns a label, is the wrong abstraction, and that the practical fix is to treat the LLM's verdict as a feature inside an ordinary statistical model. Wrapping the LLM output in a simple logistic regression recovers the properties practitioners actually need, such as calibration to the class distribution of the population being scored, without any prompt gymnastics.

Worked through on the SemEval 2018 irony-detection dataset (4,618 tweets), the one-shot LLM classifier shows decent ranking ability but a poor Brier score for lack of calibration; the logistic wrapper fixes calibration without changing the ordering. The broader point: when performance disappoints, prompt tweaking is arcane folklore, while the classic ML toolkit (better features, more data, model tuning) becomes available again once the LLM is demoted to feature extractor.

## Highlights

- Core claim: an LLM's verdict should be a feature, not the classifier; wrap it in logistic regression, p(y=1|x) = sigma(alpha + beta*LLM(x)).
- LLM classifiers lack calibration: the model cannot know whether the positive class is rare or prevalent in the tested population.
- Demo dataset: SemEval 2018 Task 3, 4,618 tweets (3,834 train / 784 test) labeled for irony by expert annotators.
- One-shot prompting (gemini-3.1-flash-lite, temperature 0, structured JSON output) ranks well but calibrates poorly; random guessing scores Brier 0.25.
- The logistic wrapper achieves calibration while leaving F1 unchanged, since it does not alter the ordering.
- Enrichment trick: have the LLM answer auxiliary questions (humor? plausibility? needs context? genuine complaint? tone mismatch) and feed those as extra features.
- When accuracy disappoints, prompt engineering offers folklore; the ML framing reopens feature engineering, data and model selection as levers.
