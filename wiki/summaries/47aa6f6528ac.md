# GPT-6.2 Astra is the first model to beat Googlers' code golf records

_type: news-summary · created: 2026-11-25 · updated: 2026-11-26 · confidence: high_

`hacker-news` `openai` `google` `external-evaluation`

## Summary

An independently maintained code-golf benchmark revives thirty-two problems from a 2015 internal Google contest and runs models for thirty minutes per problem in eight languages. It measures short accepted programs rather than basic task completion: every complete model run solves all 256 cells, while byte-count scores vary substantially.

The human comparison principally uses JavaScript, Python and C++, excluding weaker historical Haskell participation and languages without human records. Oracle runs have more information and resources and set moving reference sizes; they are not the same as blind timed model runs. The headline's record claim is therefore benchmark-specific, not proof of universal coding superiority or AGI. No programs or leaderboard experiments were run here.

## Highlights

- Thirty-two problems across eight languages
- Each timed cell gets thirty minutes
- All complete runs pass all cells
- Scores reward brevity rather than only correctness
- Strong human comparison is JS/Python/C++
- Oracle has additional access and sets reference sizes
- Historical runtimes and contest quirks matter
- No universal software-engineering ranking follows
