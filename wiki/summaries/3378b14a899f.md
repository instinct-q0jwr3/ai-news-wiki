# Using AI to reverse engineer hardware

_type: news-summary · created: 2026-10-15 · updated: 2026-10-20 · confidence: high_

`hacker-news`

## Summary

A writer wanted to scan his late mother's film negatives with a Plustek 8200i, only to find the scanner's newer chipset no longer worked on Linux. He had partial success with configuration changes first.

The post describes using AI to help reverse engineer the hardware and get Linux support back.

## Highlights

- Newer chipset broke Linux support for a film scanner.
- AI assisted reverse engineering of the hardware.
