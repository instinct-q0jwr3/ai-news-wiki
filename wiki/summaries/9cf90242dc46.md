# AI agents in a stand-up call

_type: news-summary · created: 2026-10-11 · updated: 2026-10-15 · confidence: high_

`hacker-news` `agentic-systems`

## Summary

Agent Standup turns a Claude Code session into a live team meeting: the lead agent gives orders, sub-agents join, share their screen and report back, so you can see who is waiting on whom and who is blocked, at zero token cost. Its makers call it a bit silly and weirdly useful.

It works by reading the session files Claude Code already writes, so nothing is sent anywhere and there is nothing to configure; it runs wherever Claude Code runs, from VS Code and Cursor to a plain terminal, and starts with a single npx command.

## Highlights

- Turns a Claude Code session into a live stand-up
- See who is blocked and who waits on whom
- Zero token cost; reads local session files
- Works in VS Code, Cursor, terminal, desktop app
- Starts with one npx command
