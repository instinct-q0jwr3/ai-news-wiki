# Asahi Linux Drops MIT, Goes Full GPL After AI Used to Steal Unreleased Code

_type: news-summary · created: 2026-11-09 · updated: 2026-11-14 · confidence: high_

`hacker-news`

## Summary

Asahi Linux, the project that made Linux run on Apple Silicon Macs, is moving all its repositories from the permissive MIT license to GPL version 2 or later. It says people have lifted unreleased feature code from developers' personal forks, or had AI rewrite it to hide where it came from, in order to replace the project and profit from it. MIT explicitly allows reuse and has no protection against bad-faith actors, so the team chose strong copyleft only.

It Foss, which reports the change, explains 'code laundering': passing someone's code through a rewrite so it can be used without credit or license obligations. LLMs make that cheaper than the old manual renaming. Critics on social media object that relicensing may happen without every earlier contributor agreeing, and Asahi did not say how past contributions will be handled or name anyone it accuses.

## Highlights

- Asahi moves all code to GPLv2-or-later, copyleft only
- Trigger: unreleased code taken from personal forks and AI-rewritten to hide origin
- MIT has no carveout against bad-faith reuse
- Open question: consent of past contributors, not addressed
- Pitched as a precedent like WINE's license history
