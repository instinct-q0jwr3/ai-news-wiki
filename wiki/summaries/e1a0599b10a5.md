## Summary

Simon Willison runs an experiment in Claude Code for web's 'Ultracode' mode, where dynamic workflows generate JavaScript coordinating networks of subagents. A single phone-typed prompt with an accidental typo, 'hit the delete rows directly' instead of 'hit the rows directly', asked for a SQLite extension in Rust implanting SPARQL, and Claude Code churned for over 12 hours producing a full SPARQL 1.1 implementation in Rust inside SQLite. A follow-up prompt added READMEs per crate, a tutorial teaching SPARQL with the extension, and a script populating realistic example data. His verdict: next-level vibe coding, the code is not remotely feasible to review, and he is unsure what a full SPARQL-in-SQLite implementation is worth if nobody can vouch for it.
