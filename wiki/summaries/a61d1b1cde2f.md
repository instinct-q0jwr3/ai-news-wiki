# Reverse Engineer Anything

`lobsters`

## Summary

Reverse Engineer Anything (REA) connects a coding agent to tools for inspecting apps without their source code: native binaries, JavaScript and Electron apps, .NET assemblies and websites. The agent investigates how a feature works, shows evidence and limits for each conclusion, and can build a version for your project.

Setup is one command, npx rea-agents setup, which registers an MCP server and workflow instructions after you approve the changes. Analysis runs locally and can use an existing Hopper or Ghidra install.

## Highlights

- Agent tooling to reverse engineer apps
- Covers native, Electron, .NET and web targets
- Results cite evidence and limitations
- Local analysis, optional Hopper or Ghidra
- One-command npx setup
