# How Agent Anomaly Detection scores on benchmarks we didn't write

_type: news-summary · created: 2026-11-13 · updated: 2026-11-14 · confidence: high_

`tldr-ai` `agentic-systems` `external-evaluation`

## Summary

Google reports results for Agent Anomaly Detection on five public benchmarks it did not author. The asynchronous monitor reviews traces after execution: it flagged 87% of harmful actions that the tested agent actually carried out, with benign-session false alarms ranging from 2% to 16%.

That is a post-execution detection result, not an attack-prevention rate. The report identifies poisoned memory as a gap, catching only four of eighteen successful cases in that category. Independent benchmark authorship improves test diversity but does not make the vendor's evaluation an independent audit.

## Highlights

- Monitor reviews agent traces asynchronously
- 87% figure concerns executed harmful behavior
- False-alarm rates vary by benchmark
- Poisoned-memory cases expose a weakness
- Detection is not prevention
