# Nvidia unveils its Rubin HPC GPU with "more than 50,000" CUDA cores, up from 28,672 in the current Rubin GPU, for agentic workflows and scientific simulations

_type: news-summary · created: 2026-11-17 · updated: 2026-11-28 · confidence: high_

`techmeme` `nvidia` `agentic-systems` `compute-buildout`

## Summary

Tom’s Hardware reports Nvidia announced Rubin HPC for scientific simulation and agent-assisted workloads, with more than 50,000 CUDA cores and a stated 2028 arrival. The report says physical packaging, memory capacity and bandwidth, and native FP64 details were not disclosed.

Core counts and vendor positioning do not establish delivered application performance. The article’s suggestion of a multi-die configuration is inference, not a confirmed layout, and the expected arrival date is a roadmap statement rather than current availability.

## Highlights

- Announcement targets HPC and agent-assisted research
- Core count is vendor-reported
- Memory and FP64 details remain unknown
- Packaging inference is not confirmed design
- Roadmap timing is not present availability
