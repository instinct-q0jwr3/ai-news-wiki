# Lessons from building Copilot Cowork

_type: news-summary · created: 2026-11-03 · updated: 2026-11-13 · confidence: high_

`tldr-ai` `microsoft`

## Summary

Microsoft's Copilot Cowork team tells the whole arc out loud: empty repo in January, worldwide GA in about four and a half months, then - the actually-hard part - migrating the runtime from Python to Rust while the service was live. On October 21, nine engineers merged 1,211 pull requests in a day. Agents wrote most of the code; engineers stayed responsible for defining the work and judging results.

The six practices that emerged are the reusable payload. Specs got clearer because agents punish ambiguity; architecture and security boundaries are set by humans and enforced mechanically; review effort concentrates on high-risk changes and disagreements between automated checks and agent reviewers, which examine everything. Agents could propose changes but never decide what ships. And the meta-lesson: every few weeks the agents improved, some existing part of the process broke, and the team adapted - the workflow was never designed, it was repeatedly re-fit to capability.

The Python-to-Rust-while-live case study is the proof of the method: the kind of migration that organizations postpone for years, done by the same spec-review-check loop on a running global service. For engineering leaders the number that should sting is the staffing: nine engineers, 1,211 PRs a day. The constraint on shipping is no longer writing code - it's specification quality, review discipline, and how fast your process can re-adapt.

## Highlights

- Copilot Cowork: empty repo to worldwide GA in ~4.5 months, then Python→Rust runtime migration while live
- Nine engineers merged 1,211 PRs in one day; agents wrote most code, humans defined work and judged results
- Six practices: precise specs, human-set boundaries, risk-focused human review, automated+agent review of everything, agents propose but never decide
- Meta-lesson: every capability jump broke part of the process; the workflow was repeatedly re-fit, never designed once
