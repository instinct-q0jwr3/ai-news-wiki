# Introducing OpenDocRouter: every document model under one API

_type: news-summary · created: 2026-10-08 · updated: 2026-10-10 · confidence: high_

`tldr-ai`

## Summary

LlamaIndex launches OpenDocRouter, a platform and API that parses documents into markdown using many open-source and frontier models. Each model runs a versioned recipe of prompts, processing and settings, so users do not have to manage prompts, rate limits, deployments and benchmarks for each new OCR model.

The API accepts PDFs and images or URLs, in synchronous or asynchronous modes. The post compares it with LlamaParse, LlamaIndex's own product, and covers pricing and how new models get added. It is a vendor launch post.

## Highlights

- API to parse documents into markdown with many models
- Versioned recipes per model
- Accepts PDFs, PNG, JPEG or URLs
- Sync and async modes
- Compared with LlamaIndex's own LlamaParse
- Vendor announcement
