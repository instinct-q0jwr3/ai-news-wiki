## Summary

Vector Sets are still a beta feature but I can tell you something, I can guarantee you can learn the API in 3 minutes.

I decided that a fundamental requirement for implementing vector similarity was to also reimplement from scratch HNSWs (you can see my implementation in hnsw.c), because that was going to be my core data structure, and I didn’t want to…

In Vector Sets you can add new elements with VADD, and you can remove elements with VREM.

## Highlights

- However, as I started reading the papers, I started to understand that a few pieces were missing.
- They are slow, a lot slower than other data structures modeled by Redis.
- So Vector Sets ship with both 8 bit quantization and binary quantization.
- But for me the most interesting part of Vector Sets is the data model and the API supporting it.
- Many databases propose vector similarity as a kind of index, but that’s Redis, and things in Redis are data structures: no exception this time.
- So you can have many small vector sets if you want, one per key.
- For now I really (really!) hope you’ll enjoy Vector Sets.
