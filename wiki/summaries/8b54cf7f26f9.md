# Building an AI-native engineering org

_type: news-summary · created: 2026-10-30 · updated: 2026-10-30 · confidence: high_

`hacker-news`

## Summary

A FurtherAI engineer's widely-bookmarked thread describes what nine months of deliberately building an AI-native engineering org looks like. The headline numbers: code changes merged per engineer per day are up about 5x since January, while the revert rate has stayed under half a percent. The method was not handing out coding agents but re-engineering the whole shipping pipeline - every time one step sped up, work piled up at the next, so they optimized step by step.

The org now runs in-house agents (Poirot and Sherlock) that investigate and resolve production and staging issues with read access to logs, metrics, traces and databases, and the agents cooperate: Claude Code triages a request, Devin does the work, Poirot pulls internal data. A side effect: non-engineers ship code too - the designer has merged ~50 changes since August, including the design system, and customer-facing staff tweak the UI from Slack. None of it was free: much of the summer's engineering effort went into tests and tooling.
