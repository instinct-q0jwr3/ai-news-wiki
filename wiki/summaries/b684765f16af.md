# Harness Engineering 101: The LLM is the brain, the harness is the body

_type: news-summary · created: 2026-10-19 · updated: 2026-10-27 · confidence: high_

`hacker-news`

## Summary

Harness Engineering 101 is a free 16-chapter online book that builds AI agents from first principles, growing a roughly 300-line toy agent in plain Python. Its organizing claim: an LLM API is stateless - every turn you resend the whole conversation as a JSON array and get text back - so the 'harness', the program that builds, maintains and protects that array, is where agency actually lives. Everything the field calls agents is a set of patches to that one loop, and each patch exists because something concrete broke. Every chapter follows the same shape: the failure, the minimal patch, what the patch costs. The patterns are developed in full in One Code, an open-source coding agent, and the book is meant to be read in order or as standalone chapters when needed.
