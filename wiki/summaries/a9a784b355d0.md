# Compare Commits to Your Code, Resolve Conflicts in Bulk, Keep Coding

_type: news-summary · created: 2026-10-28 · updated: 2026-10-28 · confidence: high_

`tldr-ai`

## Summary

The October Visual Studio 2026 Stable Channel update lets developers compare any earlier commit directly against the working tree - including uncommitted edits - to review refactors or investigate changes since a known-good version, and resolve merge conflicts in bulk with Keep All Current or Take All Incoming across selected files, folders or the whole repository.

The update also brings a new GitHub Copilot Chat experience built on the Copilot SDK foundation introduced with Agent (Preview), plus Hot Exit for unfinished work, tab-organization shortcuts and a refreshed Fonts and Colors page.

## Highlights

- Compare any commit against the working tree, uncommitted edits included
- Bulk conflict resolution across files, folders or the repo
- New Copilot Chat on the Copilot SDK / Agent foundation
- Ships in the Visual Studio 2026 Stable Channel October update
