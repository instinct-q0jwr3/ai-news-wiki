# Show HN: Mini-AGI – Dynamic continual learning model trained on 8GB VRAM

_type: news-summary · created: 2026-09-21 · updated: 2026-09-26 · confidence: high_

`hacker-news` `anthropic`

## Summary

Mini-AGI is an experiment in continual learning: a byte-level language model that assembles its own architecture, trains from scratch on a single 8 GB VRAM GPU, and keeps learning from everything it reads. Weights are stored as ordinary files on disk and paged onto the card as needed, so the parameter count is bounded by free disk space rather than VRAM; the model grows new capacity while training when it runs short and prunes what nothing asks for. Reading and serving use exactly the same code path, so training never has to stop.

The author is explicit that this is a toy-level model, not a frontier contender: the point is to show that continual learning from a single stream of data without catastrophic forgetting is possible on modest hardware, meaning almost anyone could train their own version or continue training this one. The pitch is ownership: every language model you can actually own today is a model somebody else trained and froze, fine-tunable at the edges but stopped the day it shipped. The current run is still on its first pass over the corpus; weights will be published once that pass completes, a couple of weeks away at the current rate.

## Highlights

- Author's caveat: a small toy-level model; the claim is that continual learning without catastrophic forgetting works on modest hardware.

- Target hardware: any PC or laptop with at least an 8 GB VRAM GPU.
