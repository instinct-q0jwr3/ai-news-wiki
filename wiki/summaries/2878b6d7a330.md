# Hands-on with the "Install as app" feature for Claude artifacts: they are HTML apps wrapped inside an Electron shim, which is managed via the main Claude app

_type: news-summary · created: 2026-11-26 · updated: 2026-11-27 · confidence: high_

`techmeme` `anthropic` `ai-coding-agents`

## Summary

Federico Viticci's MacStories hands-on describes installed Claude artifacts as HTML interfaces launched through Electron shims and the main signed-in Claude app, rather than standalone native Swift apps. Personal experiments include disk analysis, shortcut launching and document routing, with macOS permissions and helper processes doing much of the underlying work.

The account distinguishes a working interface from native conventions, independent identity and durable access: shared artifacts can be revoked and depend on Claude and its account. Some technical explanations come from Claude's own analysis and are not an independent security audit. Viticci's speculation about Apple and future mobile distribution is opinion, not an announced roadmap. No artifact, permission, helper or computer command was executed for this wiki.

## Highlights
