## Summary

Armin Ronacher explains Codemode, which came to the Pi 1.0 harness as MCP support. A year ago he urged people to use scripts instead of loading custom tools or MCP servers into context. Models call tools through definitions shaped by reinforcement learning, and he prefers CLI and bash because calls compose and models learn how the filesystem behaves. Bash can only compose programs that run, though, which is the limit Codemode addresses. Basis: the first part of a long post was read.
