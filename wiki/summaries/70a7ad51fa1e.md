# Show HN: Pots – Open-source Grok Bot alternative, used by 6 startups for a month

_type: news-summary · created: 2026-11-11 · updated: 2026-11-13 · confidence: high_

`hacker-news` `openai` `anthropic` `xai` `agentic-systems` `ai-coding-agents`

## Summary

Pots is an open-source alternative to Grok Bot and similar AI teammates: it reads the channels, email and events you give it, decides what matters, does work on your own computer and speaks up when it should. It runs on your machine with the model you choose, inside the chat tools your team already uses; MIT licensed. The README says six startups have used it for a month, and it ships a docs page written for the agent that will install it.

## Highlights

- Open-source AI coworker for Slack, email and events
- Runs locally with your choice of model
- Claims six startups using it for a month
- Includes setup docs written for AI agents
