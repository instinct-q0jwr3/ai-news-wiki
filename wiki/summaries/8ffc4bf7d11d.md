# Show HN: I wrote a custom assembler for CHIP-8 in C++

_type: news-summary · created: 2026-09-19 · updated: 2026-09-26 · confidence: high_

`hacker-news` `small-specialist-models`

## Summary

In a Show HN post, a developer shares a custom CHIP-8 assembler written in C++, which has just gained support for the DB/.byte directive so sprites can be embedded directly in the ROM. The author says it should support all original CHIP-8 instructions, with rough edges still being ironed out, and notes it is a first-ever C++ project, written without AI assistance and much of it on livestream.

## Highlights

- Custom CHIP-8 assembler in C++, now with DB/.byte sprite support.
- Should cover all original CHIP-8 instructions; rough edges remain.
- Author's first C++ project, written by hand without AI.
