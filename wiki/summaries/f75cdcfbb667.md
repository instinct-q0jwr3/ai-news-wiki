# Artificial Analysis shows GPT-6.2 Astra trailing only Claude Fable 5.2 in its main index, flat vs. GPT-6 Astra in coding; Epoch AI has Astra tied with Fable 5.2

## Summary

The Decoder compares OpenAI’s GPT-6.2 launch claims with external evaluation results. It describes improvements on several work and science tests while noting that measured coding results do not uniformly advance over the prior model.

Vendor scores, independent indexes and user-workflow outcomes are different evidence. Costs depend on token use, reasoning effort and task success, not simply the advertised token price. The article’s launch coverage does not establish one model is best for every task.

## Highlights

- Report distinguishes vendor and outside evaluations
- Gains differ across task categories
- Coding improvement is not uniform
- Task costs include more than unit prices
- No universal winner follows from one index
