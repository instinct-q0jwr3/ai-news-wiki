# ChatGPT is about to start making GIFs

_type: news-summary · created: 2026-11-04 · updated: 2026-11-06 · confidence: high_

`tldr-ai` `openai`

## Summary

Token Gremlin reports that ChatGPT is about to make animated GIFs: OpenAI merged animated GIF output into image generation, already visible in Codex code behind a flag called image_generation_animation. Users would choose frame count and per-frame duration, and spritesheets could be turned into GIFs. The animation comes from OpenAI's Images API rather than Codex, so it should reach ChatGPT too. This is a leak-based report; OpenAI has not announced it.

## Highlights

- Animated GIF output spotted in Codex code behind image_generation_animation
- Controls: frame count, per-frame duration, spritesheet to GIF
- Generated by the Images API, implying a ChatGPT launch
- Unannounced; based on code inspection
