# Debian Inference Portal

_type: news-summary · created: 2026-10-03 · updated: 2026-10-03 · confidence: high_

`hacker-news`

## Summary

Debian launched an Inference Portal, a self-service portal where Debian Developers and Maintainers get LLM inference, manage API keys and track budget. It was announced on September 23 and added scaleway/qwen3.8-27b on September 25, with DebGPT configuration docs.

## Highlights

- Self-service LLM inference for Debian contributors.
- Limited to Developers and Maintainers; login via Salsa.
- Added qwen3.8-27b on September 25.
- Announced September 23.
