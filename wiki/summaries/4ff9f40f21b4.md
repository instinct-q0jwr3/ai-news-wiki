# I ran 120B MoE models on my 32GB M1 Max using under 16 GB

_type: news-summary · created: 2026-11-09 · updated: 2026-11-10 · confidence: high_

`hacker-news`

## Summary

A developer ran gpt-oss-120b and Qwen3.5-122B-A10B on a 32 GB M1 Max with a hard 16 GiB process-memory budget. The prototype keeps most mixture-of-experts weights on the SSD and brings in only what is needed. Memory is limited in practice and checked against macOS counters, not just set in config.

On gpt-oss-120b it averaged 7.84 tokens/s over eight prompts against 5.78 for another engine, about 36% faster, with the gap growing when other processes used memory. Weights were checked byte for byte. The engine code is not released, so results are unreproduced.

## Highlights

- 120B-class MoE models run within a 16 GiB budget
- Experts stream from SSD; limit enforced and measured
- 7.84 vs 5.78 tokens/s, about 36% faster
- Gap widens under memory pressure
- Code unreleased; single-author results
