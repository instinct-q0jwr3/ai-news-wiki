# Nano Banana can be prompt engineered for extremely nuanced AI image generation

_type: news-summary · created: 2026-09-25 · updated: 2026-09-30 · confidence: high_

`max-woolf`

## Summary

Max Woolf tests Google's Nano Banana - the text-to-image model released as Gemini 2.5 Flash Image after appearing mysteriously on LMArena in August 2025 - and finds its prompt adherence far stronger than Google advertises. Unlike diffusion models, it is autoregressive, generating 1,290 tokens per image, and its popularity pushed the Gemini app to the top of the mobile app stores. Woolf's benchmark is not leaderboards but whether the model follows comically specific instructions, like a three-dimensional pancake in the shape of a skull garnished with blueberries and maple syrup that must drip logically.

Practical notes: images are free through the Gemini app or AI Studio (the latter allows aspect-ratio control, both add a visible watermark), while the Gemini API costs roughly $0.04 per megapixel image - on par with diffusion models and far cheaper than gpt-image-1's $0.17. Woolf prefers the API despite the cost because web UIs carry system prompts that interfere with inputs, API output has no visible watermark, and some prompts are 'inconvenient' for a public UI. He open-sourced gemimg, a small Python wrapper that hides the API's encoding boilerplate.

## Highlights

- Nano Banana = Gemini 2.5 Flash Image, Google's autoregressive image model (1,290 tokens per image), ex-LMArena mystery model
