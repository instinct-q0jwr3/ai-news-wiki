# Google's Open Agentic Orchestrator

_type: news-summary · created: 2026-09-20 · updated: 2026-09-22 · confidence: high_

`hacker-news` `google` `agentic-systems`

## Summary

AX is an open orchestrator for agent workloads, pitching itself against treating agents as microservices or batch jobs: agents accumulate state, need strict isolation, call model APIs and tool servers, and can burn money in a loop unwatched. It exposes four declarative primitives: sandboxed tasks with CPU/memory limits, workspaces that wire up git repos, MCP servers and skills before the task starts, network policies locked to an explicit allowlist of hosts and ports with credential injection, and centralized model and secret configuration that rotates with one apply.

Underneath, AX runs on 'Agent Substrate', a compute runtime built for massive density and fast stateful actor lifecycles: every task is a lightweight actor, idle agents waiting on model or human responses are checkpointed and resumed in under a second with zero cold start, and dozens of tasks share worker resources so you pay only when agents are actively thinking. A generative layer can prepare an environment from a plain-English goal on first boot, and the CLI flow (ax apply, watch, ssh, suspend, resume, delete) targets use cases from interactive coding agents to massive RL trajectory collection.

## Highlights

- Four primitives: sandboxed tasks, declarative workspaces, allowlist network policies, central model/secret config.
- Workspaces wire git repos, MCP servers and skills into every sandbox before the task starts.
- Network policies lock traffic to explicit host/port allowlists and inject credentials into incoming requests.
- Built on Agent Substrate: lightweight actors, billions of concurrent agent sessions per cluster claimed.
- Idle agents are checkpointed, suspended and resumed in under a second with zero cold-start delay.
- Worker sharing turns idle waiting time into spare capacity: pay only when agents are actively thinking.
- Generative workspaces: describe the environment in plain English, an agent prepares it on first boot.
- CLI lifecycle: ax apply, watch, ssh into the task, suspend, resume, delete.
