## Summary

Short note from the Show HN listing: inspired by Karpathy's HackerTube, HackerBooks does the same for books - roughly 16,500 titles mentioned by at least two different HN commenters from 2007 to now, each linking back to the comments that mentioned it, built with Claude Opus 5.5. The site itself is a keyboard-driven browser (j/k to move, Enter to open). The page fetch came back thin, so only the listing-level description is verified.
