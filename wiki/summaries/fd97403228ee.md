# Show HN: Spotatui, a Spotify TUI/GUI without web API rate limits

_type: news-summary · created: 2026-10-13 · updated: 2026-10-16 · confidence: high_

## Summary

Spotatui, a revived Spotify terminal and desktop client, now works without Spotify's web API rate limits and supports other sources: YouTube, Subsonic/Navidrome, internet radio, local files, Qobuz and Apple Music on macOS, with Spotify Premium needed only for the Spotify source. Prebuilt binaries include the extra sources.

## Highlights

- Revived spotify-tui, now Spotatui.
- Works with YouTube, Subsonic, radio, local files, Qobuz, Apple Music.
- Spotify Premium only needed for the Spotify source.
