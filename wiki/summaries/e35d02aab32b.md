# DeepSeek Elastic Compute (DSec): Sandbox Infrastructure for Effective Agentic Training at Scale

_type: news-summary · created: 2026-09-23 · updated: 2026-09-26 · confidence: high_

`lobsters` `deepseek` `agentic-systems` `compute-buildout`

## Summary

DeepSeek presents DeepSeek Elastic Compute (DSec), a production sandbox platform built for large-scale agentic training and evaluation with LLMs. The paper argues these workloads - models inspecting repositories, invoking tools and executing commands in isolated, stateful environments, created in large bursts with heterogeneous isolation requirements - need an elastic execution platform rather than a single sandbox runtime. DSec exposes FnCall, container, microVM and full-VM sandbox backends through one unified SDK, coordinates placement and lifecycle across the cluster, composes environments from independently versioned layers, and loads image data on demand from 3FS, a cluster-wide distributed filesystem.

DSec is co-designed with the reinforcement learning framework: it decouples stateful rollout execution from preemptible GPU training, preserves rollout state while reclaiming idle resources, and mitigates agent misbehavior such as reward hacking. A single production-scale unit spans around 160 nodes serving about 3 million sandboxes per day; in production it supports over 380,000 concurrent sandboxes and sustains over 5,000 sandbox creations per second. DeepSeek reports the design cuts environment setup and image-distribution overhead, improves memory efficiency, and preserves latency-sensitive performance under high-density overcommit.

## Highlights

- DSec is DeepSeek's production sandbox platform for agentic RL training and evaluation.
- Unified SDK over four sandbox backends: FnCall, container, microVM and full VM.
- Co-designed with the RL framework: stateful rollouts decoupled from preemptible GPU training.
- Explicitly mitigates agent misbehavior such as reward hacking.
- Scale: ~160 nodes per unit, ~3M sandboxes/day, 380K+ concurrent, 5K+ creations/second.
- Images load on demand from 3FS, DeepSeek's cluster-wide distributed filesystem.
