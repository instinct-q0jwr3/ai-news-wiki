# Declare is a UI language for you and your AI

_type: news-summary · created: 2026-11-24 · updated: 2026-11-25 · confidence: high_

`hacker-news`

## Summary

David Temkin presents Declare, a domain-specific UI language combining structure, state, layout and motion with compiler checks and explicit dependencies. The project demonstrates calendars, a desktop and an issue tracker, and argues that a small language plus useful diagnostics can make AI-generated interfaces easier to inspect and repair.

Its ticket-app comparison is explicitly a single paired run, not an established benchmark: the publisher reports fewer lines and more hidden checks passed than its React example. Compiler checks and a proposed verification ladder establish only the properties they cover, not complete usability, accessibility or security. No language package or agent skill was installed and none of the interactive examples was operated or independently tested.
