# Aikido Altar: open-weight AI for sovereign security

_type: news-summary · created: 2026-09-22 · updated: 2026-09-26 · confidence: high_

`tldr-ai` `ai-safety-incidents`

## Summary

Aikido introduced Altar, its first open-weight security model, built to bring frontier-grade defensive security into infrastructure customers control. It powers the Aikido Machine autonomous pentesting appliance, which runs entirely inside a customer's own infrastructure - including fully air-gapped environments - so source code and internal documentation never leave for a third-party inference service.

To bridge the deployment gap, Aikido started from GLM-5.3, the strongest model in its security evaluations: the full model occupies 1.51 TB, quantization brings it to 488 GB, and an expert-pruning process reduces it further to 328 GB while preserving most of the parent's reasoning quality.

## Highlights

- Altar: open-weight security model for defensive security in your own infrastructure

- Pruning preserves most of the parent model's reasoning quality
