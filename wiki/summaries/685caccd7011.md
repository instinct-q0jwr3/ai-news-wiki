# Kev

## Summary

Small Jev-like decision models you can train and run yourself.

Kev is a family of small decision models built on Qwen3.5 and based on the architecture described in Jev's Architecture Unmasked .

The repo's .python-version makes uv sync use 3.13; torch has no wheels for 3.14 yet. git clone https://github.com/jaredpalmer/kev.git && cd kev uv sync --extra serve uv run --extra serve python -m kev.serve --run jaredpalmer/kev-4b…

## Highlights

- You can use the pretrained weights or train your own.
- The API matches TypeSafe's System One , so you can point their Python SDK at your local server.
- The first run downloads the adapter and base model. --run also accepts a local checkpoint directory or a Hub revision, such as jaredpalmer/kev-4b@qwen3 for the previous generation.
- You can play against Kev or let it play itself.
- "Trained sources" means held-out examples from the datasets used to train Kev.
- "New sources" means datasets and policy rule types Kev wasn't trained on.
- Kev can't subtract dates reliably but it can use a stated day count: on the deadline policy questions Kev-9B goes from 0.80 to 0.90 (Jev 0.93).
- The first Kev family used Qwen3 bases with the same data and settings.
