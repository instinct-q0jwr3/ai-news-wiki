# Once Claude can measure something, it can make it faster

_type: news-summary · created: 2026-09-24 · updated: 2026-09-26 · confidence: high_

`hacker-news` `anthropic`

## Summary

Anthropic's engineering team describes handing website and desktop performance work to an @Claude channel briefed to monitor deploys for regressions, assess telemetry, maintain observability dashboards, implement fixes for low-hanging fruit and propose performance projects - with an explicit goal of becoming as autonomous as possible. The team says it ended up funding nearly every project on Claude's original list, and pushed it to prove that hill-climbing against each candidate produced measurable wall-clock wins before keeping the benchmarks.

The motto: once Claude can measure something, it can make it faster - so the team kept finding more things to measure. Reported results include a rebuilt streaming renderer that only touches what is still changing: long answers on web and desktop stream about 4x smoother, a long reply stalls 9x less on a slower laptop, its worst freeze is 4.5x shorter, and on a 120Hz MacBook it holds 120fps start to finish.
