# Show HN: AgentTrust – Zero-trust security and human approvals for AI agents

## Summary

AgentTrust is an open-source security gateway that sits between an autonomous agent runtime - LangChain, CrewAI, AutoGen, OpenAI Assistants or custom tool-calling loops - and the outside world, enforcing zero-trust capability boundaries on every proposed action. Tool calls are intercepted before execution and passed through a pipeline: an egress proxy with SSRF shielding, a prompt and data-leak scanner, semantic goal-drift checks, a blast-radius scoring engine, and micro-budget velocity caps.

Actions that score as high-blast-radius require cryptographic human approval: a one-click mobile callback issues a single-use execution nonce, and authorized actions run in an isolated sandbox with a three-second hard watchdog and prototype-pollution guards. Every decision is recorded in an immutable audit ledger with SHA-256 backward hash chaining, Merkle inclusion proofs, ECDSA P-256 checkpoints and NIST PQC ML-DSA attestation, so the approval trail itself is verifiable evidence rather than a log line.

## Highlights

- AgentTrust is an interoperable zero-trust gateway for LangChain, CrewAI, AutoGen, OpenAI Assistants and custom agent runtimes
- Every tool call is intercepted pre-execution and scored for blast radius before being allowed, denied, or escalated
- High-blast actions require human approval via one-click mobile callback with a cryptographic single-use execution nonce
- The pipeline includes SSRF shielding, prompt and data-leak scanning, semantic goal-drift checks, and velocity caps
- Authorized actions run in an isolated sandbox with a 3000ms hard watchdog and prototype-pollution protection
- The audit ledger is hash-chained and Merkle-proven, with ECDSA P-256 checkpoints and NIST PQC ML-DSA attestation
