# We just shipped support for the ugliest part of HTTP: Vary

_type: news-summary · created: 2026-09-28 · updated: 2026-10-03 · confidence: high_

`simon-willison` `agentic-systems` `ai-safety-incidents`

## Summary

A Simon Willison beat on Cloudflare finally shipping support for the Vary header - 'the ugliest part of HTTP' - something he says he'd wanted for years. The classic problem: serving HTML to user agents that send 'accept: text/html' and JSON to those that don't was undeployable behind Cloudflare's cache, which ignored Vary for anything but images. You risked the cache storing the JSON variant and serving it to a browser expecting HTML.

He adds the coda that independent of the Cloudflare feature, he'd already sworn off content negotiation: he prefers URLs that predictably return one format, adding a .json suffix for the JSON version of a page. Vary support removes a footgun; explicit URLs remove the whole category.

## Highlights

- Cloudflare now honors the HTTP Vary header - a years-long Willison wishlist item
- The bug it fixes: cached JSON getting served to HTML-expecting browsers under content negotiation
- Willison's own practice: skip negotiation entirely - .json suffix URLs that return one predictable format
- Vary support removes a footgun; explicit URLs remove the category
