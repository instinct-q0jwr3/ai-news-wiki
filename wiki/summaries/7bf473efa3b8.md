# Whistle: Speech to Text in 16.9 MB

_type: news-summary · created: 2026-10-05 · updated: 2026-10-05 · confidence: high_

`tldr-ai`

## Summary

Whistle is a speech recognition model released as one 16.9 MB file that runs on the CPU with no dependencies, aimed at phones, wearables, robots, smart home, cars and microcontrollers. It uses the same C++ engine, container and quantisation as the earlier Needle model, and everything runs on the device. Only the opening was read.

## Highlights

- 16.9 MB on-device speech-to-text.
- CPU only, no dependencies.
- Shares an engine with Needle.
- Basis: opening of the post.
