# Gemini Notebook API

_type: news-summary · created: 2026-11-04 · updated: 2026-11-13 · confidence: high_

`tldr-ai` `google` `gemini`

## Summary

Google published a Gemini Notebook API: a REST interface to create and manage notebooks and sources in Gemini Notebook. Developers can ingest web pages, YouTube videos, plain text and Markdown into persistent notebooks. The docs show creating a notebook with a display name and adding a source such as a web URL, with Bearer auth and a project header, and suggest copying a setup prompt into your coding agent.

## Highlights

- REST API for creating and managing Gemini Notebook notebooks and sources
- Sources: web pages, YouTube, text and Markdown
- Docs include a quickstart prompt for coding agents
