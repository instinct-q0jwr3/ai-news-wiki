# NVIDIA Introduces Hardware-Aware LLM Compression

_type: news-summary · created: 2026-11-10 · updated: 2026-11-11 · confidence: high_

`tldr-ai` `nvidia`

## Summary

NVIDIA's AutoCompress is a hardware-guided LLM compression framework. Instead of targeting parameter counts, it folds latency, throughput and memory limits into differentiable architecture search, using serving-engine cost models validated against end-to-end measurements to produce heterogeneous pruned models.

## Highlights

- Compression driven by hardware limits, not parameter count
- Differentiable architecture search
- Cost models validated against real serving
