# Particle-1

_type: news-summary · created: 2026-10-28 · updated: 2026-10-30 · confidence: high_

`hacker-news`

## Summary

Particle launched Particle-1, a model post-trained on DeepSeek V4.1 Flash for token efficiency: around 45% fewer tokens on average across tasks, meaning lower cost and faster completion. Training used internal RL environments with a reward for solving tasks successfully with fewer reasoning and tool-call tokens; this first release focuses on software engineering.

Across four benchmarks, Particle-1 uses 28.4-52.2% fewer output tokens and costs 34.4-51.6% less per task than the base model, with pass@1 rates within the base model's confidence intervals. On out-of-domain benchmarks it stays close to base: GPQA Diamond 90.40% vs 90.91%, Tau Airlines 86.00% vs 88.00%.

## Highlights

- Particle-1: ~45% fewer tokens than DeepSeek V4.1 Flash
- 28-52% fewer output tokens, 34-52% lower cost per task
- Pass rates statistically unchanged; accuracy holds out-of-domain
- First release targets software engineering
