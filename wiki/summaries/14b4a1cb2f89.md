# Show HN: Gdocs-me-up: a high-fidelity Google Docs exporter

## Summary

gdocs-me-up is a Node.js script that exports Google Docs to HTML and CSS with unusually high fidelity, aimed at creating offline or self-hosted versions of documents that closely match the original. Where simpler exports lose alignment, line spacing or right-to-left details, this one pulls detailed styling directly from the Google Docs API, heading levels, inline font sizes, document-based image sizes, bullet indentation, and merges it into HTML with CSS that replicates the Docs look while neutralizing browser default quirks.

Usage is one command: node gdocs-me-up.js <DOC_ID> <OUTPUT_DIR>, producing an index.html plus an images/ subfolder. Options inject external stylesheets and scripts, insert raw HTML fragments before </head> (with {{title}} substitution), and rename the output file or images directory. Prerequisites are Node and Google API authentication.
