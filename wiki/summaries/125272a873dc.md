# Show HN: Deslop – Oxlint rules for AI-generated TypeScript

## Summary

Deslop is a set of opinionated Oxlint rules that reject low-signal, AI-generated TypeScript patterns: unsafe types, duplicate code and low-value tests. It vendors rules from dmmulroy/anti-slop under an MIT license and installs as an npm dev dependency working with Bun, Deno or Node.

## Highlights

- Oxlint rules aimed at AI-slop TypeScript.
- Catches unsafe types, duplicate code and low-value tests.
- Vendors MIT-licensed anti-slop rules; install via npm.
