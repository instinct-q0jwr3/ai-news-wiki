# Artificial Analysis says Inkling 2 Mini, with 5.4B active parameters, matches Qwen3.8 27B (xhigh) on its Intelligence Index with ~5x fewer active parameters

_type: news-summary · created: 2026-11-21 · updated: 2026-11-28 · confidence: high_

`techmeme` `alibaba` `qwen`

## Summary

Artificial Analysis reports Inkling 2 Mini’s task cost, completion time and Intelligence Index position while distinguishing stored parameters from repeated active computation. Its account says the model uses more output tokens than a comparator despite a lower active-parameter-times-token compute proxy.

That proxy is not measured energy consumption, and a tied index score does not imply identical performance on every task. Reported task prices use the stated provider rates and evaluation settings, rather than establishing the cheapest model for all users. The page’s unique-weight figure also differs from the vendor’s earlier active-parameter wording and should not be silently equated with it.

## Highlights

- Index score aggregates particular evaluations
- Repeated layers affect active-compute accounting
- Output-token count and task price differ
- Compute proxy is not a power-meter reading
- Provider rates and effort affect comparisons
- Parameter terminology differs across sources
