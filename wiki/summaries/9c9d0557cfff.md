# Decisions API is in public beta

_type: news-summary · created: 2026-10-07 · updated: 2026-10-07 · confidence: high_

`hacker-news`

## Summary

OpenAI put its Decisions API into public beta, with general availability expected in weeks. It evaluates text, images or both and returns typed answers, a probability that a condition is true, a choice from a fixed set, or a score against a rubric, about 10x faster than the Responses API, through a dedicated POST /v1/decisions endpoint. It is aimed at classifying content, routing requests and prioritising work. Only gpt-6-luna is available now.

## Highlights

- Public beta; GA expected in coming weeks.
- Returns probabilities, choices or scores, about 10x faster than Responses.
- Dedicated /v1/decisions endpoint.
- Only gpt-6-luna available.
