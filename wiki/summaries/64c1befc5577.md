# Compress any LLM 3x in one click, near-lossless, in under 50 MB RAM

_type: news-summary · created: 2026-11-11 · updated: 2026-11-13 · confidence: high_

`hacker-news`

## Summary

SPECTRA is a neural compression engine and runtime claiming to compress LLMs about 3x near-losslessly with under 50 MB of RAM, aimed at 4-8 GB consumer GPUs. It targets the memory wall: single-token generation reads the whole weight matrix per token, so bandwidth, not arithmetic, bounds edge inference. Supported examples include DeepSeek-R1-Distill, IBM Granite-3B, Llama-3.2, Nemotron-3-Nano and LFM-3. Claims are the project's own.

## Highlights

- Claims about 3x compression, near-lossless, under 50 MB RAM
- Runs 3B-class models on 4-8 GB GPUs
