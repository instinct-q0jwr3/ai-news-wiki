# MCP vs CLI vs Skills: What Each Costs in Context

_type: news-summary · created: 2026-11-12 · updated: 2026-11-14 · confidence: high_

`tldr-ai`

## Summary

OpenRouter compares three ways to expose a GitHub task to several models: a full MCP tool set, a command-line interface and a task skill. On its Sonnet run, all answered correctly but the reported input usage ranged from 1,421 tokens for the CLI to 59,417 for the default MCP configuration.

The article attributes cost to both tool definitions and bulky results, and discusses loading only relevant tools. It is a narrow task comparison, not proof that one interface is always cheaper or more reliable. The amount exposed, result filtering and model behavior can change the outcome.

## Highlights

- One GitHub task underpins the comparison
- Tool definitions and returned data both consume context
- Default MCP loading was expensive in the example
- CLI and skill used less input in that run
- Results do not generalize to every tool configuration
