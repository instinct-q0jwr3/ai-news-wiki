# Anthropic upgrades Claude Code Projects to run parallel AI workers

_type: news-summary · created: 2026-11-14 · updated: 2026-11-14 · confidence: high_

`hacker-news` `anthropic` `agentic-systems` `ai-coding-agents` `labor-displacement`

## Summary

Anthropic describes redesigned Claude Code Projects as a persistent place to coordinate work across cloud sessions. A coordinator divides a goal into threads, while each thread works on its own repository copy and branch; shared project memory and a file library carry context across that work.

The announcement starts with a selective Pro and Max beta and says wider product and organizational access will follow. Parallelism still consumes the subscriber’s existing allowance and overlapping edits still produce ordinary merge conflicts. This is the vendor’s description of the workflow, not proof that coordination removes review or integration work.

## Highlights

- Threads use separate repository branches
- Shared memory carries project context
- A library collects inputs and outputs
- Initial beta access is selective
- Parallel sessions share usage limits
