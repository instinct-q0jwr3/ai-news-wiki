# The Components of Agent Memory

_type: news-summary · created: 2026-11-07 · updated: 2026-11-12 · confidence: high_

`hacker-news` `anthropic` `agentic-systems`

## Summary

Anthropic's research post on agent memory borrows from neuroscience. The hippocampus captures experience quickly, and consolidation into long-term knowledge happens largely offline, during sleep. Agents can split work the same way: they log or transcribe their work, then use idle time to reflect on those logs to fix mistakes or write new notes. The idea builds on sleep-time compute proposed by Letta and UC Berkeley, and Anthropic calls the process dreaming. It says dreaming has helped it give Claude better memory.
