## Summary

Recalc is an open-source spreadsheet where each cell can be a Claude Code or Codex terminal. Agents fill cells in real time, and you can open any cell as a terminal and steer it by prompting or editing the cells. It runs locally on macOS, with Linux experimental.

## Highlights

- Each cell can run an agent terminal
- Watch and steer agents via cells
- Local, free, open source
