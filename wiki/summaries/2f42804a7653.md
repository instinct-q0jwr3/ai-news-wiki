## Summary

Simon Willison adds tag-based browsing to his collection of 244 small tools. He describes using Fable 5.2 and tree-sitter to identify JavaScript APIs, libraries and web-service hosts, then turning those extracted categories into tag clouds. It is a concrete example of using code analysis to make a growing collection easier to discover.

## Highlights

- Collection contains 244 tools
- Tree-sitter extracts code-level categories
- Tags cover APIs, libraries and service hosts
- AI-assisted indexing improves browsing
