_type: news-summary · created: 2026-09-26 · updated: 2026-09-26 · confidence: high_

## Summary

John Gruber notes that Xcode 27.2 supports a new JSON project file format - a notable step away from the famously merge-conflict-prone pbxproj plist that has defined Xcode projects for decades. (Summary based on the Daring Fireball post and Apple's Xcode 27.2 release notes.)

## Highlights

- Xcode 27.2 introduces a JSON project file format
- A break from the ancient, merge-hostile pbxproj plist format
- Summary from Daring Fireball and Apple's release notes
