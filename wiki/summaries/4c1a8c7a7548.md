# Show HN: db-branch – database branches in seconds for AI agents and CI, via ZFS

_type: news-summary · created: 2026-11-15 · updated: 2026-11-17 · confidence: high_

`hacker-news` `agentic-systems`

## Summary

db-branch is a self-hosted beta for giving tests, pull requests and coding agents disposable MySQL or PostgreSQL databases. It uses ZFS snapshots and copy-on-write clones so a branch can be created without first copying the entire underlying database; each branch runs a separate server on its own port.

The project documents reset, checkpoint and restore operations alongside runtime and storage requirements. Its core is Apache-2.0, while authentication, audit, history and other modules are separately licensed. Fast branch creation is a project claim, not a measured guarantee of query performance, production isolation or protection for sensitive data copied into a base.

## Highlights

- Linux and ZFS underpin the design
- Branches avoid an initial full data copy
- Separate database processes serve branches
- Project is beta and interfaces may change
- Paid modules sit outside the open-source core
