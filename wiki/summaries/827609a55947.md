# webframe: evaluated as a scraper and a sandbox

_type: news-summary · created: 2026-10-27 · updated: 2026-10-27 · confidence: high_

`simon-willison` `anthropic` `external-evaluation`

## Summary

Simon Willison evaluates webframe, a small Go project by Jeff Lindsay that 'runs a web page like a program': point it at a URL or file and it executes the page in a hidden headless web view, streaming console.log to stdout and exceptions to stderr. Built on the glaze library, it uses the system browser - WKWebView on macOS, WebKitGTK on Linux, WebView2 on Windows - so it ships without a bundled engine and without Playwright.

Willison put Claude Opus 5.5 to work running it through its paces and writing a research report, assessing two uses: as a sandboxing tool, and as a scraper following the patterns of his own shot-scraper javascript command. The verdict space he maps - lightweight, system-browser automation in a single binary - makes webframe a neat alternative to heavier browser-automation stacks for agents that need to drive pages.
