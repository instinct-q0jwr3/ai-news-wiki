# Stolen AI API keys generated nearly $1M in charges for a single company

_type: news-summary · created: 2026-11-03 · updated: 2026-11-13 · confidence: high_

`hacker-news`

## Summary

Mandiant and Google Threat Intelligence Group put a name and a number on the newest cloud-billing nightmare: 'LLMJacking,' the hijacking of enterprise LLM access through stolen API keys and cloud identity tokens. Across incidents they responded to in 2026 - in North America, South America and Asia Pacific, spanning finance, retail, tech and transportation - fraudulent charges topped $100,000 in a single day, and cumulative charges at some organizations reached $1 million before access was revoked. Unlike cryptojacking's slow resource drip, LLMJacking produces massive billing spikes within hours.

The report maps a maturing criminal supply chain. Initial access comes mostly from exposed or stolen credentials - IAM keys, service accounts, GitHub tokens - or publicly exposed LLM endpoints (the report shows attackers probing open Ollama instances and registering their own models via /api/create). Downstream, specialist operators run 'LLM Mixers': illicit routing gateways that proxy, aggregate and resell unauthorized LLM access to underground subscribers. GTIG watched two distinct clusters cooperate - one compromising environments, one monetizing - a division of labor that mirrors the ransomware economy.

The defensive guidance is concrete: watch for sudden spikes in API call volume and billing, lock down identity tokens (the dominant vector), don't expose model endpoints publicly, and scope keys so a leaked one can't run up uncapped usage. The deeper point for the industry: as inference becomes a metered commodity, stolen model access has become a resellable good with its own wholesale market - every leaked key is now inventory.

## Highlights

- Mandiant/GTIG document LLMJacking across 2026 incidents: >$100K fraudulent charges in a single day, up to $1M cumulative at some organizations before access was revoked
- Dominant vector is exposed/stolen cloud identity tokens and API keys, plus publicly exposed LLM endpoints (Ollama instances probed and re-registered)
- 'LLM Mixers' proxy and resell stolen access to underground subscribers - a wholesale market for illicit inference, with specialized access and monetization clusters cooperating
- Mitigations: billing/usage spike detection, token hygiene, no public endpoints, scoped keys with usage caps
