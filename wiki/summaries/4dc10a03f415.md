# OpenAI Finds 948 Local Privilege Escalation Bugs in the Linux Kernel

_type: news-summary · created: 2026-11-05 · updated: 2026-11-05 · confidence: high_

`hacker-news` `openai`

## Summary

Phoronix summarizes OpenAI's blog post on autonomous vulnerability discovery in the Linux kernel. The prototype found 2,308 candidate vulnerabilities, dynamically reproduced 1,724, and ended with 948 valid local privilege escalation exploits that let an unprivileged user gain root. It also generated candidate patches for maintainers. The run cost $1.2 million in API credits.

OpenAI says that within a few years frontier models will likely find any vulnerabilities in a given project, so the focus should shift to secure-by-default code, smaller attack surface and formal verification. One odd detail: its GPT-5.5 Cyber model found over 5x more novel LPEs than GPT-5.6 Sol, even after three months of kernel hardening between scans.
