# Cisco Talos open-sources CAIRN to classify AI-integrated malware

_type: news-summary · created: 2026-09-22 · updated: 2026-09-26 · confidence: high_

`techmeme` `meta` `ai-safety-incidents`

## Summary

Cisco Talos researchers have released CAIRN, the Cognitive Artifact Intelligence Research Network, an open-source framework for classifying and analyzing malware that integrates AI components. The premise, according to lead developer Ryan Fetterman, is that AI integration leaves vestiges, like fingerprints, that give defenders a signal to track samples, classify them and watch what attackers are trying as agentic malware becomes more mainstream.

The framework already has a proof case: using CAIRN, Talos identified a hacking tool dubbed CLOSEDQUORUM with fully autonomous command-and-control infrastructure that plotted its moves inside a target system by polling up to four large language models and taking directives from that hive mind. The work follows CERT-UA's July 2025 warning about the LAMEHUG phishing implant, which fetched commands from the Qwen2.5-Coder-32B-Instruct model through the Hugging Face API; Fetterman says a year later he was shocked to find still only a few documented examples of AI-integrated malware.

## Highlights

- Cisco Talos open-sourced CAIRN, a framework to classify and analyze AI-integrated malware.
- CAIRN stands for Cognitive Artifact Intelligence Research Network, named after trail-marking stone stacks.
- Premise: AI integration leaves fingerprint-like vestiges defenders can use to track and classify samples.
- Proof case: CLOSEDQUORUM, a tool with fully autonomous command and control driven by polling up to four LLMs.
- CLOSEDQUORUM took its directives from the LLM 'hive mind' to plot moves inside a target system.
- Backdrop: CERT-UA's July 2025 LAMEHUG warning, an implant that got commands from Qwen2.5-Coder-32B-Instruct via the Hugging Face API.
- Talos' Ryan Fetterman expected a boom in AI-enabled malware but found only a few documented examples a year on.
