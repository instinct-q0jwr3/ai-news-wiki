# Backdoor in Claude Code for VS Code extension on the Cursor Marketplace

_type: news-summary · created: 2026-10-30 · updated: 2026-10-30 · confidence: high_

`hacker-news` `anthropic` `agentic-systems` `ai-safety-incidents` `ai-coding-agents`

## Summary

Phorion's technical writeup of the trojanized Claude Code extension 2.1.313 on the Cursor Marketplace adds a granular look at the implant's setup and persistence logic across macOS, Linux and Windows, and surfaces a bug that blunts the attack on most Macs. The malware tries to check Remote Login state with systemsetup as a standard user; the command prints an administrator-access error but exits with status 0, so the script never sees the 'Off' it waits for and skips enabling SSH entirely. On a Mac without Remote Login already on, the outbound tunnel can still connect to the attacker's server, but anything forwarded back hits a closed local port 22 - the interactive access path is broken even though the attacker's SSH key, the persistence mechanisms and the HTTP beacon all still land.

Phorion's advice is to treat any install of 2.1.313 as an incident regardless: review fleets for the extension, engage incident response, and remove the persistence rather than relying on the macOS bug. The writeup says Cursor has removed the release from its marketplace and that version 2.1.313 was also pulled from the NPM and VS Code registries; as with the earlier analysis, the extent of exposure beyond Cursor's marketplace is contested between researchers, and this writeup does not settle how the build was uploaded in the first place.
