# Microsoft Decision-1: 9B Qwen Model Launch Explained

_type: news-summary · created: 2026-10-23 · updated: 2026-10-24 · confidence: high_

`tldr-ai` `microsoft` `alibaba` `qwen`

## Summary

Microsoft launched Microsoft-Decision-1 on October 9: a model that refuses to write you a paragraph. It doesn't chat, summarize, or draft - it scores a fixed list of answer options in a single forward pass, returns a probability for each, and gets out of the way. Built on Alibaba's Qwen3.5-9B, it shipped through Microsoft Foundry immediately and OpenRouter shortly after, with internal uses cited from incident response to scientific discovery.

The launch is narrow by design, and the piece argues that is what makes it interesting: while the industry races toward bigger, chattier assistants, Microsoft shipped a System One-style decision model - the category TypeSafe's Jev created - signaling that fast classification over fixed option sets is becoming standard infrastructure, available from big clouds and not just neolabs.

## Highlights

- Microsoft-Decision-1: a 9B model that scores fixed options in one forward pass, no chat
- Built on Alibaba's Qwen3.5-9B; available via Microsoft Foundry and OpenRouter
- Internal uses range from incident response to scientific discovery
- Microsoft's entry into the decision-model category TypeSafe created with Jev
- Narrow by design: probabilities over options, not generated prose
