# Google Cloud unveils the Gemini agent to handle multi-day enterprise workflows across Workspace, Microsoft 365, and Slack, with support for multiple AI models

## Summary

VentureBeat reports Google Cloud unveiled a Gemini agent for multi-day enterprise workflows across Workspace, Microsoft 365 and Slack, with support for multiple AI models. It can research, create documents and write code, and gets its own Gmail, Calendar and Drive.

Only the excerpt and headline were reviewed, so pricing and availability are unknown.
