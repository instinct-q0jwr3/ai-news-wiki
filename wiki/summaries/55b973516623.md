# Unofficial Command-Line Tool Removes Apple Intelligence From MacOS 27

_type: news-summary · created: 2026-10-06 · updated: 2026-10-19 · confidence: high_

`daring-fireball` `openai` `apple`

## Summary

macOS 27 'Golden Gate' removed the toggle to turn off Apple Intelligence, leaving its models - 12GB by the developer's count, over 30GB by The Verge's - sitting on disks of users who never asked for them. RemoveMacAI, an open-source command-line tool by developer Om Lahore, restores the off switch: it disables Siri, Writing Tools, Genmoji, Image Playground, the ChatGPT extension and the summaries, deletes the models, and stops macOS from downloading them again, while dictation keeps working.

The implementation is deliberately conservative: a user-approved configuration profile plus Apple's own asset service, so System Integrity Protection stays on and /System is untouched. 'removemacai revert' restores everything, and features can be removed selectively. The tool has 1,700 GitHub stars, and Daring Fireball reads its popularity as evidence of real user aversion to Apple's AI push.

## Highlights

- macOS 27 has no toggle to disable Apple Intelligence; the models consume 12-30+ GB.
- RemoveMacAI is a free open-source CLI that turns off Apple Intelligence and deletes the models.
- Works via an approved configuration profile and Apple's asset service - SIP stays on, /System untouched.
- Fully reversible; features can be removed selectively; dictation still works.
- 1,700 GitHub stars; seen as a signal of user resistance to forced AI features.
