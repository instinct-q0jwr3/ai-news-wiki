# Imp is a full port of DSPy to the BEAM

_type: news-summary · created: 2026-09-28 · updated: 2026-10-03 · confidence: high_

`hacker-news`

## Summary

Imp brings DSPy's model of declarative, self-improving language-model programs to Elixir and the BEAM. You declare what each LLM step takes and returns as a typed signature ('issue -> kind: enum[bug,feature,question], summary'), choose how it thinks (predict, chain_of_thought, react with tools), and never write a prompt or parser - Imp builds the prompt from the signature, validates the reply, and hands back typed fields or an error. On the BEAM, an agent is a supervised process: Imp.start_run/3 runs a program under OTP with an authorize callback that can approve or deny each tool call (the example allows only raw.githubusercontent.com URLs).

Optimization is the other half: give Imp labeled train/val/test sets and a metric, and optimizers improve the program itself - GEPA reads failures and rewrites the instructions with a stronger model, while LabeledFewShot, BootstrapFewShot, MIPROv2, SIMBA and GRPO offer other strategies, and the result is a readable, diffable JSON artifact. Optimizers work on whole agent runs too, and 'Optimize Anything' rewrites any scorable text, including tool descriptions. Ships as {:imp, "~> 0.5"}, requires Elixir 1.19+, reaches models through ReqLLM.

## Highlights

- Imp = DSPy ported to the BEAM: declarative, typed, self-improving LM programs in Elixir
- Signatures replace prompts and parsers: declared inputs/outputs with types and enums, validated replies
- Agents as OTP processes: supervised runs with per-tool-call authorize callbacks
- GEPA optimizer: reads where the program failed and rewrites its instructions with a stronger model
- Other optimizers: LabeledFewShot, BootstrapFewShot, MIPROv2, SIMBA, GRPO - plus weight-training routes
- Optimized programs are readable JSON diffs you can review and save
- Requires Elixir 1.19+; {:imp, "~> 0.5"}; works on single typed calls up to long-running agent swarms
