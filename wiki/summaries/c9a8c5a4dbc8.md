# Getting the most out of Opus 5.5 in Claude and Claude Code

_type: news-summary · created: 2026-10-04 · updated: 2026-10-04 · confidence: high_

`hacker-news` `anthropic` `agentic-systems` `ai-coding-agents`

## Summary

Anthropic's guide to working with Opus 5.5 in Claude apps and Claude Code says the model behaves differently from earlier Opus versions: it works longer on its own, reports plainly what it did, and thinks before every reply.

Practical advice is to give the whole task in one message with a clear finish line such as passing tests, and then let it run. It also recommends deleting lines like 'think carefully' from prompts and saved instructions, since the model decides how much to think and removing them made replies start sooner with no clear quality drop in Anthropic's tests. Only the opening sections of the guide were read.

## Highlights

- Give the full task and a finish line in one message.
- Drop 'think hard' style instructions.
- Long multi-step runs, such as repository migrations, are the main gain over Opus 5.
- Basis: first part of the guide only.
