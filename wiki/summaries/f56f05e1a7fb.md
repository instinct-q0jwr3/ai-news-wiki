## Summary

We were wondering how many computer use tasks actually need a full general purpose LLM (e.g. gpt-6-astra, claude-opus-5 etc.) to think through all their decisions and steps. Some tasks require thinking about a plan, exploring different paths, recovering from failure.

Our inspiration was Typesafe's Jev and its System One Model framing.

## Highlights

- Other tasks are a question of making local decisions, like this value should go in this box, or should I check this box, or this element should be ignored.
- We wondered how far we could go with a small model trained to only make these kinds of decisions.
- This is a nod to the dichotomy between thinking quickly, automatically, and intuitively (system 1) vs. thinking slowly, analytically (system 2), as described by Daniel Kahneman.
- The interesting question for us was: what happens if you give a model an interface of current context, and a set of possible choices, and you ask it to return a probability for each choice?
- This kind of model does not generate output token by token like most LLMs do, but rather scores the options you give it, which you can check, trust, and use to drive your app's behavior.
- CUA-S1 is our answer for narrow, specialized decision models for computer use.
- We built this from ideas and code in jevlike, and then trained a second model just to handle form interactions.
- Try Cua Fleets now at run.cua.ai Bring your own agent and model, or explore CUA-S1 for specialized decisions.
