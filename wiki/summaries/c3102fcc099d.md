# Amazon launches TorchNeuron, an open-source framework that lets developers run PyTorch code on Amazon's Trainium chips with no rewriting needed, in public beta

_type: news-summary · created: 2026-10-19 · updated: 2026-10-20 · confidence: high_

`techmeme` `amazon` `nvidia`

## Summary

GeekWire reports Amazon's public beta of TorchNeuron, software that runs PyTorch code on Amazon's Trainium chips with no modification - previously, developers had to rework code to call Annapurna-specific interfaces, said Colin Brace, Amazon's VP of technology software. In private beta since late last year, TorchNeuron is Amazon's most direct attack yet on CUDA's lock-in: the pitch is that switching from Nvidia to Trainium becomes as simple as changing a setting. If it works at production scale, it removes the main practical objection to Amazon's price-performance play in AI chips.
