# Introducing LFM3: Every Modality for Specialized Intelligence

_type: news-summary · created: 2026-10-27 · updated: 2026-10-31 · confidence: high_

`hacker-news`

## Summary

Liquid AI introduced LFM3, a new generation of Liquid Foundation Models built for specialized, on-device intelligence: a natively multimodal family combining text, vision and audio in one architecture with open weights for fine-tuning. AMD and Qualcomm endorsements emphasize efficient deployment on Ryzen AI and Snapdragon hardware.

The headline claim: in 65 everyday agent tasks in real macOS environments, the 1.7B LFM3 beat Qwen3.5-2B with 64% task success versus 48%, using 58% fewer tokens per task and getting stuck in under 1% of attempts versus 15%. Liquid calls it the first sub-2B model ready for real agent work on a Mac.

## Highlights

- LFM3: multimodal (text, vision, audio) open-weights family for edge deployment
- 1.7B model beats Qwen3.5-2B 64% to 48% on 65 real macOS agent tasks
- 58% fewer tokens per task; stuck in under 1% of attempts
- AMD and Qualcomm backing for Ryzen AI and Snapdragon deployment
