# MAI Code 2 and Code 2 Flash

_type: news-summary · created: 2026-11-17 · updated: 2026-11-21 · confidence: high_

`hacker-news`

## Summary

Microsoft announces MAI Code 2 and Code 2 Flash for enterprise coding work, distinguishing deeper repository work from high-volume edits and explanations. It reports favorable average benchmark performance relative to selected competitors at lower estimated cost.

The company explicitly limits those comparisons by workload, effort and pricing assumptions, and says the models are not yet tuned for fundamental science or very long tasks. Current Copilot access and limited Foundry preview differ from planned distribution on other platforms.

## Highlights

- Release targets everyday coding workloads
- Flash emphasizes routine high-volume work
- Cost comparisons depend on settings
- Research and long-task limits are explicit
- Current access differs from planned integrations
