# Claude Code reads AGENTS.md only when telemetry is on

_type: news-summary · created: 2026-09-23 · updated: 2026-09-24 · confidence: high_

`hacker-news` `anthropic` `agentic-systems` `external-evaluation` `ai-coding-agents`

## Summary

A developer investigation shows Claude Code's new AGENTS.md support silently depends on a server-side feature flag: the loader ships as a built-in plugin whose availability asks a remote flag (tengu_agents_md_mod) with fallback false. With telemetry or non-essential traffic disabled (DISABLE_TELEMETRY=1 or CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1), the flag never arrives and AGENTS.md is never read, even though reading a local markdown file needs no network. The post documents canary-word experiments across configurations and notes the first session in a new configuration only fetches the flag while the second uses it.

## Highlights

- Claude Code 2.1.277's AGENTS.md loading is gated on a remote feature flag, not just file presence.
- Telemetry-off setups (DISABLE_TELEMETRY=1, CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1) silently block AGENTS.md.
- Verified with canary-word tests; tracked in issue #95690 with the author's own measurements.
- First session in a new config only fetches the flag; the second session uses it.
