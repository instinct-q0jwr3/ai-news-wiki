# Show HN: Aura – a self-hosted, multi-user AI agent with per-person graph memory

_type: news-summary · created: 2026-10-09 · updated: 2026-10-10 · confidence: high_

`hacker-news` `agentic-systems`

## Summary

Aura is an open-source, local-first personal AI agent platform written in Go. One binary on your own machine hosts the agent runtime, shell and file tools, web, documents, scheduling, skills, and access through CLI, Telegram and a web interface, with graph-backed memory in Postgres and ArcadeDB.

It uses a swappable model, DeepSeek-V4 through OpenRouter by default. The project says it is built as a product and could ship as a DGX Spark bundle for small businesses wanting a private assistant. The commit history shows one main author plus 130 commits credited to Claude.

## Highlights

- Local-first AI agent in one Go binary
- Terminal, web, documents and scheduling tools
- Memory in Postgres and ArcadeDB
- Default model DeepSeek-V4 via OpenRouter
- Access by CLI, Telegram and web
- Mostly one author with Claude commits
