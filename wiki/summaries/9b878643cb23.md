# Apple Creator Studio Updated With a Slew of AI Features, Along With a New Open JSON File Format for Keynote

_type: news-summary · created: 2026-10-28 · updated: 2026-10-28 · confidence: high_

`daring-fireball` `apple` `agentic-systems`

## Summary

Apple's 'Pro and Tell' week continues with a sweeping Creator Studio update: Final Cut Pro gains built-in MotionVFX effects, templates and transitions plus a video-stocked Content Hub; Logic Pro gets an intelligent assistant in beta, a Stem Splitter that now separates drums, and a redesigned sound Browser with music understanding and a Splice library; Pixelmator Pro adds Generate Fill for natural-language image edits.

Keynote, Pages and Numbers pick up beta AI assistants that understand document context plus Model Context Protocol support for workflow automation, alongside stock video and premium themes. Apple also introduced a new open JSON file format for Keynote. The updates land on the App Store in November, free for existing subscribers.

## Highlights

- Final Cut Pro: built-in MotionVFX library plus Content Hub video assets
- Logic Pro: beta AI assistant, drum-splitting Stem Splitter, Splice integration
- Pixelmator Pro Generate Fill edits image regions by description
- iWork apps get context-aware assistants, MCP support and an open JSON Keynote format
