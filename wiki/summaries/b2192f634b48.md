# Relate – the agent-native graph database

_type: news-summary · created: 2026-11-12 · updated: 2026-11-12 · confidence: high_

`hacker-news` `agentic-systems`

## Summary

Relate presents an embedded graph database for agents and applications. It uses Cypher to query connected facts, can store data in memory or local files and offers several interfaces without requiring a separate database server. The site's examples illustrate relationships among people, tasks and documents.

The product page describes local operation and open-source code, but its previews are scripted examples rather than evidence of production performance. A database can make relationships explicit without making the facts stored in it trustworthy. This summary describes the product only; no installation or data import was performed.

## Highlights

- Embedded graph storage rather than separate server
- Cypher expresses connected-data queries
- Local and in-memory storage options
- Multiple application and agent interfaces
- Scripted examples do not validate production performance
