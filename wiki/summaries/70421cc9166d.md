# MuscleMemory: Open-source procedural memory for AI agents

_type: news-summary · created: 2026-10-16 · updated: 2026-10-18 · confidence: high_

`hacker-news` `agentic-systems`

## Summary

MuscleMemory is an Apache-2.0 open-source tool that gives coding agents procedural memory. Agents relearn the same things each session: which files to open, how tests run, what broke before. It watches the agent work, and when a task truly succeeds (tests pass after the last change) it records how the task was done.

It is local by default and also learns from failures.

## Highlights

- Learns from successful and failed agent runs.
- Local by default, Apache-2.0.
