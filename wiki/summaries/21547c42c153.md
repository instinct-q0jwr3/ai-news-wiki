# AWS Launches Strands Harness, an Agent That Brings Its Own Everything but the Model

_type: news-summary · created: 2026-09-22 · updated: 2026-09-24 · confidence: high_

`tldr-ai` `amazon` `agentic-systems`

## Summary

AWS released the Strands harness, a ready-to-run agent that can search the web, run commands, edit files, remember prior work, and hand off tasks to helper agents - everything except the intelligence, which developers supply from Amazon Bedrock, Anthropic, OpenAI, Google, or a local Ollama model. It extends the open-source Strands Agents SDK launched in May 2025.

AWS claims the harness costs 26% less using the same model across seven benchmarks, is more token-efficient, and performs better than Claude Code and Codex; in one evaluation with Fable 5 it reportedly cost 77% less.

## Highlights

- Strands harness: ready-to-run agent shell, BYO model
- Searches web, runs commands, edits files, remembers, delegates to helper agents
- Supports Bedrock, Anthropic, OpenAI, Google and local Ollama models
- Extends open-source Strands Agents SDK (May 2025)
- AWS claims 26% lower cost than same-model baselines across 7 benchmarks
- 77% cheaper than rivals in one Fable 5 evaluation, per AWS
