# Show HN: jevals – replacing LLM judges with typed Jev decisions

_type: news-summary · created: 2026-09-21 · updated: 2026-09-22 · confidence: high_

`hacker-news`

## Summary

jevals replaces the LLM judge in agent evaluation with Jev-style typed decision models. All the evals for a trace, tool choice, groundedness, scope, relevancy, completeness, indirect-injection and PHI checks, go out as a single HTTP request that costs a few thousandths of a cent and returns in a few hundred milliseconds, cheap and fast enough to run on every trace and even inside the agent loop. The quickstart numbers: eight evals in one request, 1,388 tokens, $0.00006, 0.33 seconds.

The cost argument is the point. With a frontier LLM as judge, Ragas-style metrics explode into many calls: faithfulness is two LLM calls, answer relevancy three plus embeddings, context precision one call per retrieved chunk, each carrying few-shot examples and generating JSON token by token with retries. Four metrics on one sample means six to eleven round trips and several seconds, so teams sample 1% nightly and never touch the request path. jevals runs through Jev via the TypeSafe or Vercel AI Gateway APIs, locally on a Mac with Kev or Laya, or against a regular chat LLM as a slower fallback.
