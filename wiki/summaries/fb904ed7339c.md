`hacker-news` `anthropic` `external-evaluation`

## Summary

In a Show HN for Vellum, a diagram editor, the author tells a debugging war story: every save of a diagram containing a new image was blocked because the app's CSP connect-src lacked the S3 origin that hosts the bytes - a third origin beyond the SPA and the API. img-src already allowed the S3 domain for displaying images, but connect-src never got the matching entry for transferring them.

The bug hid behind a genuine CORS misconfiguration on the uploads bucket, because a CSP-blocked fetch fails with the same wording as a CORS-blocked one ('NetworkError when attempting to fetch resource.' in Firefox, 'Failed to fetch' in Chrome) - so fixing the real CORS issue did not reveal it.
