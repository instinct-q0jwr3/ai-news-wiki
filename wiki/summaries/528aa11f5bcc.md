## Summary

Whiteboard (YC W26) is an open-source desktop IDE where humans and agents architect software together in a common workspace. It plugs into the tools developers already use, such as Claude Code and Codex, and gives the agent an SDK to draw on an in-app canvas to describe its work - for example proposing API examples and motivations for a stack of commits, or explaining the telemetry changes in a PostHog PR and how to build dashboards from them.

The makers say Whiteboard works best with frontier models such as GPT-6 Sol and Claude. It is available as a macOS download, with the code on GitHub and a one-minute demo video.
