# Baseten partners with OpenAI to let OpenAI enterprise customers use existing commitments for open models served by Baseten within Codex or via the Responses API

_type: news-summary · created: 2026-09-30 · updated: 2026-10-10 · confidence: high_

`techmeme` `openai` `ai-coding-agents`

## Summary

Baseten announces a partnership with OpenAI as one of the first open-model inference providers in the OpenAI B2B Marketplace, including a native integration inside Codex. OpenAI enterprise customers can now apply their existing OpenAI spending commitments to open models served by Baseten within Codex or via the Responses API, which Baseten pitches as more intelligence per dollar and validation of the multi-model future in which routers pick the best model per task.

## Highlights

- Baseten joins OpenAI B2B Marketplace as an early open-model inference provider
- OpenAI enterprise commitments now usable for Baseten-served open models
- Native integration inside Codex and via the Responses API
- Pitches multi-model routing across open and closed models as the emerging pattern
- Frames agentic coding as the most widely adopted AI use case
