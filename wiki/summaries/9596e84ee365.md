## Summary

Drew Breunig has baked a working Nintendo Entertainment System 6502 CPU emulator into the weights of Qwen3.5-4B, Simon Willison links. Inspired by Divyansh Agrawal's qwenputer, the project lets you play NES ROMs like Super Mario Bros - very slowly - running inside the model itself.

In a Hacker News comment, Breunig reveals the Opus 5.5 prompts that built it: read the qwenputer article and source, explore whether the NES chip and RAM could be emulated with the same technique, estimate the model size, then 'I think we should build it! Just for fun. It's okay if it's not fast. We want to be able to have the weights, and a cli to run them that we can point at a ROM.' Opus found and used a collection of NES CPU conformance tests released 15 years ago to validate the emulation.
