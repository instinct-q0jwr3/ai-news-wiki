## Highlights

- Ultrafast references appeared in OpenAI's cloud-agent API docs ahead of DevDay (Sept 29)
- A hidden Standard/Fast/Ultrafast selector was spotted in the Responses API Playground
- Ultrafast with GPT-5.6 Sol: up to 750 output tokens/sec, up to 14x faster than Standard
- The mode is powered by Cerebras and still limited to selected customers
- OpenAI's 750 MW Cerebras partnership is being deployed in stages through 2028
- Support for GPT-6 Sol and GPT-6 Astra at launch is a key open question
