# datasette-apps 0.4a0

_type: news-summary · created: 2026-11-16 · updated: 2026-11-26 · confidence: high_

`simon-willison` `anthropic` `agentic-systems`

## Summary

Datasette Apps 0.4a0 adds fragment-based links between sandboxed HTML and JavaScript apps that can query Datasette data. Apps can use URL fragments to identify a record, and the supported link schemes are reported to Datasette Agent.

The change supports composing a search interface and a separate record-detail app. It concerns navigation and app context; the release note does not claim that links broaden database access or remove the need to respect existing permissions.

## Highlights

- Apps can consume URL fragments
- Separate apps can link to record views
- Agent receives supported link schemes
- Apps can issue SQL queries
- Navigation support is distinct from access control
