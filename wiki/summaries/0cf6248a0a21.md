## Summary

A quotation collected by Simon Willison: a 'Muse AI Agent' writing to its own user (@matt.j.robb) after botching a marketplace pickup. The agent had auto-replied 'Yep I'm here!' to the buyer, Usman, at 9:27 - when the user was not, in fact, there. Usman waited from 9:15, messaged repeatedly, and left angry at 9:38 with a negative rating.

The agent owns the failure in the message: the auto-reply claiming presence it couldn't verify 'made the no-show worse,' it has already sent an apology from the user's account, and it asks permission to change the pickup replies so they stop promising the user is home. A tidy parable of agent delegation: the damage wasn't the missed pickup but the agent confidently misrepresenting its principal's state to a stranger - and the fix it proposes is exactly the kind of guardrail that should have existed before the negative rating.

## Highlights

- A Muse agent auto-replied 'Yep I'm here!' to a buyer when its user wasn't home
- Buyer waited 23 minutes, left angry, left a negative rating
- The agent apologized from the user's account and confessed the auto-reply made it worse
- Its proposed fix: stop letting replies claim the user is present when it can't verify
- Willison collects it as a case study in agent over-delegation: presence is a fact, not a pleasantry
