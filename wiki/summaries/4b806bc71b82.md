# Implementing a clear room Z80 / ZX Spectrum emulator with Claude Code

## Summary

antirez responds to Anthropic's experiment in which Opus 4.6 wrote a C compiler in Rust under 'clean room' conditions, by way of introducing his own project: a clean-room Z80 / ZX Spectrum emulator written with Claude Code. His critique of Anthropic's methodology: why withhold the ISA documentation, and why Rust, when a C compiler is exactly the kind of giant graph-manipulation program Rust makes hardest? A proper clean-room setup should still give the agent the established computer science - SSA, register allocation, instruction selection and scheduling - synthesized as prerequisite reading.

Blocking internet access and other compilers' source was the right call, he agrees. Less understandable is the near-zero steering: fine if the goal is showcasing fully autonomous writing of a large project, but not how coding agents are used in practice - anyone who uses them extensively knows a few well-placed hints completely change the quality of the result.
