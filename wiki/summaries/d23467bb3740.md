# ROCmFix and InferBench – AMD Local-LLM Setup and Vulkan vs. Hip Benchmarking

## Summary

ROCmFix is a single-file, zero-install utility that fixes the most common pain of running local LLMs on AMD GPUs: cryptic ROCm errors like HSA_STATUS_ERROR_INVALID_ISA or silent fallbacks to CPU. It detects the exact AMD GPU, checks a live community database, applies the right HSA_OVERRIDE_GFX_VERSION environment override, and runs health diagnostics.

Beyond the fix itself, it ships a doctor command for driver/HIP/Vulkan health checks, an InferBench benchmark comparing Vulkan vs HIP/ROCm in LM Studio or Ollama, a HIP SDK installer for Windows, and an opt-in telemetry system that shares GPU model, driver and benchmark results (never usernames, IPs or prompts) to grow the community database. It supports RDNA4, RDNA3, RDNA2 and integrated graphics, and is MIT licensed.

## Highlights

- One Python file, no installs: detects the AMD GPU and auto-applies the correct HSA_OVERRIDE_GFX_VERSION override.
- Targets llama.cpp, Ollama, LM Studio and PyTorch failures like HSA_STATUS_ERROR_INVALID_ISA and silent CPU fallback.
- 'rocmfix doctor' runs full health checks of drivers, HIP and Vulkan; 'rocmfix bench' compares Vulkan vs HIP/ROCm performance.
- Supports RDNA4 (RX 9070/9060), RDNA3 (RX 7000), RDNA2 (RX 6000) and integrated graphics, synced from a live database.
- Opt-in telemetry shares only GPU model, driver, OS and benchmarks; PRIVACY.md states no usernames, IPs, paths or prompts.
- Extras: HIP SDK installer for Windows, Markdown system reports for troubleshooting, safe undo of overrides.
- MIT licensed; new GPUs can be contributed via a pre-filled GitHub issue generated by the tool.
