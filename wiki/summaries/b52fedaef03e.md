# Show HN: NanoMuse – An open-source AI agent for your phone and computer

## Summary

NanoMuse presents an open-source personal-agent system spanning Android, desktop and a web console. Rather than one centrally running agent, the README describes a local agent on each device connected through a relay, allowing devices to ask each other for help while sharing an account and conversation view.

The repository includes the apps and relay under GPL-3.0-or-later. Its developer offers a limited community-relay model allowance, with user-supplied model keys and self-hosting as alternatives. It says conversation text crosses the relay while files and screenshots remain on their originating devices, and promises confirmation before irreversible actions. These are project descriptions, not independently tested privacy or safety guarantees.

## Highlights

- Phone, desktop, web console and relay live in one repository.
- Each device runs its own agent.
- A relay connects accounts and device requests.
- Community model usage has an allowance, not unlimited access.
- Self-hosting and user-provided keys are supported options.
- Privacy and confirmation behavior have not been independently tested here.
