# Show HN: Black Ops II statically recompiled to native ARM64 macOS

_type: news-summary · created: 2026-11-11 · updated: 2026-11-11 · confidence: high_

## Summary

A fan project statically recompiles Call of Duty: Black Ops II from 32-bit x86 Windows to native ARM64 macOS: campaign, Zombies and bot multiplayer. Remill lifts about 150,000 functions to LLVM IR, custom passes rewrite it, and the result links against a hand-written Win32 runtime whose Direct3D 11 draws through Metal. There is no Wine and no JIT.

The copy protection is executed, not bypassed: the sequences it hides run in a small Unicorn-based x86 interpreter. On an M1 the campaign runs at 51-60 fps, Zombies 57-60, multiplayer 53-60. The repo contains no game code; each player builds the app from their own Steam copy, and the result may not be shared.
