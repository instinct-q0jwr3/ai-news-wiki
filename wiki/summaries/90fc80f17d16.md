# API credits benefit for eligible ChatGPT subscriptions

_type: news-summary · created: 2026-10-30 · updated: 2026-10-31 · confidence: high_

`simon-willison` `openai` `anthropic` `ai-price-war`

## Summary

Simon Willison notes that OpenAI has matched Anthropic's subscription benefit from earlier this month: ChatGPT subscribers on $100, $200 or $500 monthly plans now get the same amount in credits to apply to one of their API organizations - the same expiring-credits deal Anthropic introduced for Max and Team subscribers.

Willison, who holds subscriptions with both companies, calls it great news and muses about shipping public-facing demos now that the API spend is covered by subscriptions he already pays for. The matching move underlines how subscription bundles have become the labs' retention battleground.

## Highlights

- OpenAI mirrors Anthropic: $100/$200/$500 plans get equal API credits
- Credits apply to an API organization, matching Anthropic's Max/Team benefit
- Willison holds both subscriptions and plans public demos on the covered spend
- Subscription bundles as the new retention battleground between labs
