# GPT-6.2 Astra appears in Codex usage ahead of possible launch

_type: news-summary · created: 2026-11-03 · updated: 2026-11-03 · confidence: high_

`tldr-ai` `openai` `ai-coding-agents`

## Summary

OpenAI's next frontier model may already be serving traffic. Over the weekend, Codex users noticed a new line item in their usage analytics - gpt-6.2-astra, listed next to the GPT-6 Astra model that launched in September. In every breakdown shared so far it appears only on the October 31 bar, but its share varies wildly by account: 1.6% of one user's week, 19.8% of another's, 37.7% of a single day for a third. The model picker still says GPT-6 Astra, which suggests requests are being quietly routed - an A/B test or the start of a staged rollout.

The evidence hardened when an X user shared a raw API response event with the model field reading 'gpt-6.2-astra' - strong proof the ID is live on OpenAI's servers, though not an announcement. OpenAI has said nothing; its docs still list GPT-6 Astra, GPT-6.1 Sol and GPT-6 Luna. Meanwhile self-identified testers are posting outputs: a 360-degree 3D pelican-on-a-bicycle scene, a one-shot 3D semi-open-world RPG.

The pattern is now familiar across labs: ship to a slice of production traffic before the announcement, let usage analytics leak the launch. If the screenshots are authentic, GPT-6.2 Astra looks like a refined Astra rather than a new family - and the 'single greatest week of releases' chatter suggests the formal reveal is imminent.
