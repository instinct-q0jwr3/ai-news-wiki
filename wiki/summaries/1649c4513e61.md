# Show HN: Plimsoll, a self-hosted sandbox for code your AI agent writes

_type: news-summary · created: 2026-10-12 · updated: 2026-10-28 · confidence: high_

`hacker-news` `agentic-systems`

## Summary

Plimsoll is a self-hosted sandbox for running untrusted code - like code an AI agent wrote - where every result states how strong the isolation actually was. Named after the Plimsoll load line painted on a ship's hull, it reports an isolation tier on every run (process, container, kernel, vm, weakest first); a request can set a floor, and if the available sandbox is weaker, nothing runs. The official Go client re-checks the tier when results come back.

The same machinery runs exams, not just containment: a trial runner inside the simulation image tests the agent's program against scenarios the program cannot read (each arrives in a file deleted before the program starts). Every run returns SHA-256 hashes of request and result for clients to recompute, and plimsoll-attest signs checked results, refusing chains with a missing link. The exam content stays yours; plimsoll supplies the boundary and the evidence.

## Highlights

- Self-hosted sandbox for untrusted (agent-written) code with stated isolation strength.
- Four tiers: process, container, kernel, vm; requests can demand a minimum.
- Named for the ship's Plimsoll line - the load limit anyone can check.
- Trial runner tests agent code against scenarios it cannot read.
- SHA-256 hashes on request and result; plimsoll-attest signs verified runs.
- Demo: an AI-written controller for a 10ms-tick simulated system.
