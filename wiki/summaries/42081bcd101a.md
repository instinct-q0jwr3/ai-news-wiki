# Show HN: Sphinx – A hook that quizzes you on your AI's code before shipping

## Summary

Sphinx is a Git hook for agent-assisted development with a simple demand: before your agent's code ships, prove you understand it. On protected branches the push pauses and you get a question generated from your diff about what the change actually does when things go wrong - answer wrong and you learn why, then face a new scenario; answer right and the push continues.

The example quiz walks through a Stripe webhook handler that saves an event ID before calling charge(): what happens on a retry after a timeout, and what happens if charge() fails after the ID was saved. Sphinx runs from your existing coding agent, OpenRouter or any OpenAI-compatible endpoint, works with Codex, Claude Code, Cursor, OpenCode and Pi or plain Git, is designed for minimal tokens, and promises your answers never reach the coding agent and .env files are never opened. Free and open source.
