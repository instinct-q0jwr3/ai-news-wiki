## From circuits to serving constraints

A physical synthesizer build and inference engineering notes make the role of testing and workload choices visible.

A hardware developer describes using Claude Code to design an analog synthesizer through specifications, SPICE simulations, PCB generation and firmware. After assembled boards arrived, software-controlled instruments and an audio loopback supported calibration and comparison with simulation. The account includes substantial human direction: choosing the concept, reviewing the design, reorganizing PCB blocks, switching to four layers and fixing a hand-soldered bridge. Small touch keys remained awkward. The working board is evidence from one reported build, not proof that arbitrary mixed-signal circuits can be designed without expert oversight. ## Datasette connects exports, prompts and applications

Four maintainer release notes describe specific changes across the data platform and its plugins.

Simon Willison’s Datasette 1.0a43 release note introduces streaming output renderers, including CSV and TSV exports, alongside smaller interface changes and security fixes. One reported flaw exposed the title and SQL of private stored queries without allowing those queries to execute. The release also adds cross-document view transitions while retaining a multi-page application. Browser support and future Firefox timing are the author’s report, not a promise that every client receives the same effect. ([read more](../summaries/58bd47a08a82.md)).

Datasette Agent 0.6a0 puts an agent prompt on the Datasette homepage and supports hash-mentions of tables and queries. Simon Willison presents it as a collection of small fixes to the data-questioning plugin. The short release note does not establish new model capabilities, permission changes or accuracy guarantees. ([read more](../summaries/8b1995c75e00.md)).

Datasette Apps 0.4a0 adds fragment-based links between sandboxed HTML and JavaScript apps that can query Datasette data. Apps can use URL fragments to identify a record, and the supported link schemes are reported to Datasette Agent. The change supports composing a search interface and a separate record-detail app. It concerns navigation and app context; the release note does not claim that links broaden database access or remove the need to respect existing permissions. ([read more](../summaries/23b31c283446.md)).

Simon Willison introduces a Datasette mapping plugin combining MapLibre GL with OpenFreeMap. It renders latitude-longitude points and GeoJSON shapes, using SVG previews before loading WebGL previews when they enter view. The author says most of the initial implementation came from one Claude prompt guided by existing plugins and a local demo, and supplies a Datasette Lite demonstration. This is a maintainer account of assisted development, not an independent test of the plugin’s correctness or mapping-service availability. ([read more](../summaries/db9d958881e7.md)).
